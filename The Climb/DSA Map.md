## Practice loop

1. Read the actual specification and constraints. Don't open the reference first.
2. State brute force and the improved invariant/state.
3. Attempt independently within a declared time cap.
4. Test empty/boundary/duplicate/large cases relevant to the problem.
5. Record complexity, help used and the precise mistake.
6. Choose a cold retry date after the attempt; starter records have no invented last-practice or review dates.

Suggested retries after a weak attempt: next available study day, then several days later if retrieval improves. This is an adjustable policy, not automatic scheduling.

## Promotion rule

Use existing source notes for discovery. Create an assigned record in the question bank only when a problem enters your actual queue. Do not generate hundreds of empty notes or overwrite imported solutions. Daily counts come from real attempts, not how many records exist.
