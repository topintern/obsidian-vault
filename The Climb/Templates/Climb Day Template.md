# Climb Day Template

Assistant reference, not an automatically configured daily-note template. Copy the structure into a new `The Climb/Days/YYYY-MM-DD.md`, replace dates and select real actions; never assign every possible lane by default.

## Properties for a dated record

Use `kind: climb-day`, `date: YYYY-MM-DD`, `day_state: open`, `plan_mode: full / constrained / interview / evening`, and `tags: [climb/day]`.

Keep unreported numeric properties empty: `spirit_minutes`, `japa_count`, `companies_checked`, `applications_submitted`, `outreach_sent`, `prep_minutes`, `dsa_attempted`, `dsa_independent`, `creative_minutes`, `movement_minutes`.

## Next actions

Assign feasible, linked actions from [[Current Sprint]] and the department milestones. Use checkboxes only for actual assigned actions, with estimated minutes and a finish condition.
