# Tailoring Desk

[[Resume Bank]] · [[Resume Working Context]] · [[Resume Catalogue.base]] · [[The Climb/HUNT|Hunt]]

Keep the job page in Web Browser beside a relevant resume record and this chat. Read [[Resume Working Context]] in full before any resume work. The imported bank is historical source material; Neel's explicit confirmations take precedence over conflicting variants.

## What to bring

- Paste the JD or recruiter message, with company, role, requisition ID and URL when available.
- Include any changes to the standing context or identify an active resume for follow-up edits. A particular open `.tex` instruction takes precedence; preserve that editor and the latest manual changes.

There is no need to choose a source, format or destination each time. Select the strongest supported foundation from [[Resume Working Context]], inspecting its latest contents. Ask only one concise, grouped question if an essential claim cannot safely be resolved; otherwise proceed with supported material and briefly flag any material gap.

## A focused tailoring request

> Tailor my resume for this JD using Resume Working Context. Produce the finished editable LaTeX and matching, newly compiled, visually checked one-page PDF. Preserve truthful history and my latest manual edits; select relevant supported work rather than inventing claims. Do not send messages or submit an application.

## Default output and verification

Create a clearly named company/role folder within `D:\HDD F\downloads\CV\Resumes`. Preserve existing source resumes. For follow-up edits, read the latest active targeted `.tex` and update it in place rather than generating a competing version or restoring deleted content.

Follow the current environment's relevant document/PDF skills and compilation instructions. Compile the actual edited source, confirm one page, check extracted text and hyperlink targets, render the final PDF and visually inspect clipping, overlap, wraps and bolding. Never present an old PDF as reflecting new source edits. If compilation or verification is blocked, report it honestly; do not label an unchecked file verified.

## Version and submission boundaries

An optional tracking note under **The Climb/Resume Bank/Tailored** can record the source, role URL, changes and exact external `.tex`/PDF paths. It is not a substitute for the finished deliverables. No empty resume or invented application record is needed.

Markdown is the readable editing layer. Editing it does **not** automatically rebuild or modify the preserved PDF, Word or external LaTeX source. Final-document generation is a separate, explicitly checked step.

After a final document is approved, use its exact file path in the application's upload chooser. Record a submission only after a success page, confirmation or other reliable evidence. No application or message is sent by this workflow note.

## Current sources

Use the catalogue's **Favorites** checkbox for quick access after reviewing a version. Keep **resume_review** as `unreviewed`, `needs-correction`, `reviewed` or `approved-for-specific-role` as appropriate. A review status never hides a row from **My Resumes**.
