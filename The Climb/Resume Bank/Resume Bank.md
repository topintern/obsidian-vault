## Use it while applying

1. Open the role in Web Browser and select a relevant source record.
2. Review the readable content, dates, titles, ownership and metrics. Use [[Claims to Reconcile]] where evidence is unresolved.
3. Open the original PDF or Word link for the formatted version. A file-chooser path is included in Neel-labelled resume records when a local document exists.
4. For a tailoring request, use [[Tailoring Desk]] and [[Resume Working Context]]. Create a targeted external version; keep imported sources intact. Follow-up edits update the active targeted resume in place after reading its latest contents.
5. Confirm the exact final file before uploading or sending. A prepared resume is not a submitted application.

A browser upload may still invoke a native file chooser; the included path can be pasted there. This import does not automate uploads, applications, messages or submissions.

## Source boundaries

Some documents bear different names or are examples. They remain separated from the default Neel resume view. Folder labels such as 3, 4, 6 or 8 YOE are preserved source labels, not verified career history. No current master was selected.

Cover letters, references, job descriptions and prep material have their own catalogue view. Archived domain and formatting preferences are available as [[The Climb/Resume Bank/Versions/Source tailoring conventions - resume conventions - dca903b85f8c316a.md|source conventions]], not new vault instructions.
