## Summary





- Senior Backend Engineer with 5+ years of experience building and operating large-scale Java microservices on cloud platforms.

- Deep expertise in Spring Boot, distributed system design, platform development, Kafka-based messaging, and NoSQL data stores.

- Proven leader of small engineering teams, comfortable owning delivery end-to-end—from discovery and design through production support, RCA, and stakeholder communication.




## Skills


**Languages**: Java (Core Java, J2EE), SQL

**Frameworks**: Spring, Spring Boot, REST APIs

**Architecture**: Microservices, event-driven systems, scalable platform design

**Messaging**: Kafka (producers, consumers, async workflows)

**Datastores**: NoSQL (Cosmos-like, Cassandra-style), relational databases

**Cloud**: Azure, GCP

**Engineering Practices**: Code reviews, design reviews, CI/CD, unit testing

**Leadership**: Team mentoring, cross-functional collaboration, delivery ownership




## Professional Experience



**CIFC Asset Management**  |  *Jun 2025 - Present*

**Senior Backend Engineer (Platform & Services)**




- Designed and implemented Spring Boot microservices to power internal platforms, focusing on scalability, fault tolerance, and clear service boundaries.


- Built RESTful APIs that exposed core business capabilities while enforcing validation, authentication, and backward compatibility.


- Implemented Kafka-based asynchronous workflows to decouple services and improve system resilience under load.


- Designed NoSQL data models optimized for high-throughput reads and writes, supporting low-latency service responses.


- Led delivery for medium-scale initiatives by translating business requirements into technical designs and executable plans.


- Owned production support and incident response, performing root-cause analysis and implementing long-term fixes to prevent recurrence..

 



**Samay Systems LLC**  |  *Feb 2025 - Jun 2025*

**Senior Backend Engineer (Microservices & Integrations)**




- Built Java Spring Boot services to integrate multiple internal and external systems into a cohesive platform.


- Designed event-driven pipelines using Kafka to handle asynchronous processing and system-to-system communication.


- Implemented service-level monitoring, logging, and alerting to meet uptime and reliability expectations.


- Collaborated closely with product and business teams during the discovery phase, shaping high-level designs and delivery plans.


- Provided technical leadership by reviewing proposed solutions, offering architectural guidance, and mentoring junior engineers.



**Arvam Tech**  |  *Jul 2023 - Jan 2025*

**Enterprise Automation Engineer**




- Developed and maintained Spring-based microservices supporting enterprise workflows.

- Designed APIs and backend services with clear separation of concerns, enabling independent service evolution.


- Integrated NoSQL databases to support scalable data access patterns across distributed services.


- Partnered with QA and product teams to ensure features were delivered on time with appropriate test coverage.






**RHYM Tech**  |  *Aug 2022 - May 2023*

**Associate solutions Engineer**




- Built backend services in Java and Spring to support platform features.


- Implemented message-based communication patterns to support asynchronous processing.


- Participated in code reviews and design discussions, improving system reliability and maintainability.



**ZeMoSo Technologies**  |  *Jul 2021 - Aug 2022*

**Associate Developer**





- Developed backend components using Core Java and Spring.


- Assisted in building service integrations and database interactions.


- Gained hands-on experience with enterprise development practices, testing, and deployment workflows.




## Projects



**Enterprise Microservices Platform – CIFC**

**Problem**: Monolithic systems limited scalability and slowed feature delivery.

**Solution**: Designed Spring Boot microservices with Kafka-based communication and NoSQL persistence for scalable, resilient operations.

**Event-Driven Backend Services – Samay Systems**

**Problem**: Tight coupling between systems caused cascading failures.

**Solution**: Introduced Kafka-driven async processing and service isolation to improve reliability and throughput.
