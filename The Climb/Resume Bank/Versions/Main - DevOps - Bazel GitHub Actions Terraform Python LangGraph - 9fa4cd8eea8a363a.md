## Professional Experience


**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Security Platform*




- Optimized **Bazel** remote execution (RBE) and remote caching on **GCP GKE** cloud runners, cutting average CI build times by 45% and achieving 90%+ cache hit rates across the multi-language monorepo autoscaled with **Terraform**.

- Built **LangGraph**-powered agentic CI failure analysis tool integrating **OpenAI GPT-4o**, automatically classifying flaky tests vs. real regressions and surfacing root-cause context, reducing developer debug time by 40%.

- Instrumented CI/CD pipelines (**GitHub Actions**, **Jenkins**, cloud runners) with **OpenTelemetry** telemetry, publishing cross-platform build speed, reliability, and cost dashboards for  CI health across 12+ pipelines.

- Built a **Python**-based GitHub bot powered by **LangGraph** for automated PR triage, inline **code review suggestions**, and stale-build detection, cutting manual CI re-trigger overhead and average PR review TAT by 40%.

- Enabled **GitHub Copilot** and **Cursor** AI coding assistant adoption across the engineering org, publishing onboarding guides, measuring productivity impact via usage dashboards, and iterating on workflow integrations.

- Simplified local dev environment onboarding with **Docker** container-based dev environments and automated setup scripts, reducing new engineer time-to-first-build from days to under 2 hours.



**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance Platform*




- Migrated a multi-language (**Java** + **Python**) codebase to a **Bazel** monorepo, authoring custom **Starlark** rules and macros for Spring Boot service packaging, Python wheel builds, and Docker image targets.

- Improved **Bazel** build hermeticity and configured **Azure Blob Storage** as the remote cache backend, enforcing sandbox constraints and strict visibility rules, eliminating build failures across 6+ services.

- Designed and maintained **GitHub Actions** CI/CD pipelines with matrix parallelization, remote caching, and incremental test selection, reducing full-suite CI wall-clock time from 45 minutes to under 12 minutes.

- Built automated flaky test detection in **Python** tracking per-test failure rates across CI runs, quarantined flaky tests, posted **PR annotations** via GitHub webhooks, automated JIRA tickets, recovering 15% of lost CI cycles monthly.

- Developed internal **CLI** tooling and **VS Code**/**IntelliJ** plugins in **Go** for developer workflows service scaffolding, Bazel target discovery, and build graph visualization adopted by all 10 engineers within one sprint.

- Provisioned and maintained **Kubernetes**-based self-hosted **GitHub Actions** runners on **AWS EC2** with **Terraform**, autoscaling runner pools based on queue depth and reducing peak CI queue wait times by 60%.



**Associate Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps Platform*




- Maintained and improved **Maven**-based **Java** multi-module monorepo build, optimizing dependency management and build lifecycle configuration to reduce full build times by 25% across 10+ modules.

- Configured **Jenkins** CI pipelines with staged build, test, and deploy phases publishing artifacts to **AWS S3** and enforced test gate policies cutting environment-related deployment failures by 35%.

- Built **Python** and **Bash** automation scripts for developer workflow tasks schema migration runners, environment seed scripts, and test data generators reducing per-engineer setup overhead by 40%.

- Authored 100+ **JUnit** and **pytest** automated test cases across backend services and data pipelines, establishing testing standards that improved code coverage from 45% to 75% across the LabOps platform.

- Built **React.js**/**Java** Spring Boot full-stack features for a lab platform used by 500+ scientists, gaining deep product engineering context that now informs developer tooling design decisions.
