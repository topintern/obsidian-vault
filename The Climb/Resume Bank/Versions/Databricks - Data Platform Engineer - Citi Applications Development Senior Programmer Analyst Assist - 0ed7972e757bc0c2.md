## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Data Platform Optimization*

- Architected and implemented **Lakehouse architecture** using **Databricks**, **Delta Lake**, and **Apache Iceberg** for unified data access, improving data consistency by 35% across analytical systems.

- Developed advanced **PySpark** and **Spark SQL** ETL pipelines on **Databricks** for processing 50TB daily financial transactions, accelerating data availability by 40% for reporting.

- Designed and deployed data federation solutions with **Starburst/Trino** across **AWS S3** and **Snowflake** data sources, reducing query latency for federated datasets by 25%.

- Led initiatives for data governance, implementing **RBAC**, **metadata management**, and **data quality** checks within **Azure Data Lake**, ensuring 99.8% data integrity.

- Optimized **Spark** workloads on **GCP Dataflow** through partitioning strategies and cost-efficient processing, cutting computational costs by 20% while maintaining performance.

- Collaborated with ML teams to enable robust data pipelines for **AI/ML** and **RAG**-based use cases using **Databricks MLflow**, accelerating model deployment by 15%.

- Participated in **Agile** sprints, facilitating requirements gathering and backlog refinement with stakeholders to ensure data solutions aligned with business needs by 10%.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | Financial Data Warehousing & Analytics*

- Developed and maintained scalable **PySpark** ETL pipelines on **AWS Glue** and **S3** for ingesting diverse financial datasets, improving data freshness by 30% for analytics.

- Implemented data warehousing solutions using **Snowflake** for analytical reporting and business intelligence, supporting 150+ concurrent users with sub-second query response times.

- Performed extensive **performance optimization** for **Spark SQL** queries on **Databricks** clusters, reducing query execution times by an average of 25% for critical reports.

- Contributed to data governance initiatives, establishing robust **data quality** frameworks and lineage tracking for critical financial data, enhancing compliance by 20%.

- Assisted in designing and implementing **data models** for various analytics and reporting needs using Kimball methodology, improving report generation efficiency by 18%.

- Automated data ingestion processes using **Apache Airflow** and **Python** scripts, reducing manual effort by 70% and ensuring timely data availability for downstream systems.

- Managed cloud data platform resources on **Azure Data Factory** and **Synapse Analytics**, ensuring high availability and cost efficiency, reducing operational costs by 15%.

- Supported **AI/ML** data pipelines by preparing structured datasets from raw sources, accelerating data scientist's feature engineering time by 20% for model development.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Web & API Development*

- Developed and maintained **Java** microservices using **Spring Boot** and **REST APIs** for a customer relationship management platform, handling 10,000 requests per minute.

- Designed and optimized relational database schemas in **PostgreSQL** for high-traffic applications, improving query performance by 30% for core business operations.

- Implemented data processing modules using **Python** and **Pandas** for batch processing customer activity logs, reducing processing time by 20% for daily reports.

- Integrated third-party APIs for payment gateways and communication services using **Node.js**, enhancing platform functionality and customer engagement by 15%.

- Contributed to **CI/CD** pipeline development using **Jenkins** and **Docker** for automated deployments, decreasing deployment time by 40% and increasing release frequency.

- Authored comprehensive technical documentation for APIs and system architecture, improving developer onboarding efficiency by 25% and reducing future maintenance overhead.
