## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Nagarro | Real-time Mobility Platform*

- Designed and implemented scalable **Python** microservices for the core rider experience, integrating with external mapping **APIs**, reducing response latency by 15% for 10M daily requests.

- Led the development of a new real-time driver matching algorithm using **Go** and **Kafka**, enhancing match accuracy by 10% and decreasing wait times for 500K users.

- Optimized critical data pathways on **AWS RDS** and **Redis** for ride state management, improving system reliability by 20% and handling peak loads effectively.

- Implemented robust **CI/CD** pipelines using **GitLab CI** for multiple **Go** microservices, accelerating deployment frequency by 25% and ensuring code quality.

- Performed extensive system design and code reviews for new features, ensuring adherence to object-oriented programming principles and maintainability across 15+ services.

- Managed on-call rotations, triaging and resolving critical production issues across distributed **Python** and **Go** applications, achieving 99.9% uptime availability.

- Collaborated cross-functionally with product and data science teams to define requirements for user-facing features, improving user engagement by 8% through iterative development.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Globant | Enterprise FinTech Data Platform*

- Developed and maintained backend **Python** microservices for a FinTech data platform, processing 100GB of daily financial transactions on **AWS Lambda** and **S3**.

- Implemented high-performance **Java Spring Boot** **REST APIs** for data ingestion and retrieval, supporting over 20 concurrent enterprise clients with 99.9% uptime.

- Designed and optimized complex **SQL** queries for **PostgreSQL** databases, enhancing report generation speed by 30% for critical business intelligence dashboards.

- Integrated new data sources using **Apache Kafka** for real-time streaming, reducing data lag from hours to minutes for analytics teams, impacting 500K daily events.

- Wrote comprehensive unit and integration tests using **Pytest** and **JUnit** for critical system components, increasing code coverage by 20% and reducing bug density.

- Participated in code reviews, providing constructive feedback on architectural patterns and object-oriented programming best practices, improving team's overall code quality by 15%.

- Assisted in migrating monolithic applications to a microservices architecture on **AWS ECS**, reducing infrastructure costs by 10% and improving deployment flexibility.

- Responded to and resolved production incidents during on-call rotations, debugging complex issues across distributed systems, reducing average resolution time by 25%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Persistent Systems | B2B Integration Solutions*

- Developed and maintained **Java Spring Boot** applications for B2B integration, creating robust **REST APIs** that handled 50,000 requests per hour efficiently.

- Designed and implemented database schemas using **MySQL**, optimizing queries to reduce report generation time by 25% for internal analytics tools.

- Contributed to **CI/CD** pipeline setup using **Jenkins** for automated builds and deployments, decreasing release cycle time by 15% across several projects.

- Applied object-oriented programming principles and data structures to optimize core business logic, improving application performance by 10% for concurrent users.

- Collaborated with senior engineers on system enhancements and bug fixes, reducing critical defect count by 20% through rigorous testing and code reviews.
