## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | AI-Enhanced Cloud Security Platform*

- Architected and implemented advanced **IAM** policies for **AWS** cloud resources using **Terraform**, ensuring Zero Trust principles for over 100 microservices.

- Developed custom **Python** security automation scripts integrated with **AWS Security Hub** to detect and remediate misconfigurations, reducing critical findings by 45%.

- Designed and enforced container security best practices for **Kubernetes** (**EKS**) workloads, improving runtime threat detection coverage by 60% across clusters.

- Led the integration of **OpenAI API** with internal tools for **AI-assisted Development**, enhancing code review efficiency by 30% while maintaining data privacy.

- Implemented **Agentic AI** systems using **LangChain** to proactively identify and mitigate security risks in newly deployed infrastructure, decreasing incident response time by 25%.

- Orchestrated a secure secrets management solution using **AWS KMS** and **Secrets Manager**, achieving 99.9% compliance with data protection standards for sensitive credentials.

- Managed comprehensive vulnerability management programs, leveraging **Splunk** for log analysis to prioritize and resolve 200+ high-severity issues quarterly, improving system resilience.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise FinTech Data Platform*

- Developed and maintained critical security controls for **AWS** infrastructure using **Terraform** and **Python**, securing data for 500K+ daily transactions.

- Implemented robust network security configurations in **AWS VPC** and security groups, restricting unauthorized access by 90% across production environments.

- Automated the deployment of secure **Kubernetes** clusters (**EKS**) via **Helm** charts and **GitHub Actions**, reducing setup time from hours to 15 minutes.

- Contributed to a secure software development lifecycle by integrating static analysis tools into **CI/CD** pipelines, catching 70% of vulnerabilities pre-deployment.

- Designed and implemented secure data storage solutions on **AWS S3** and **DynamoDB** with encryption policies, ensuring compliance with industry regulations by 100%.

- Developed **Python** scripts to monitor and alert on suspicious activities using **CloudWatch** and **Prometheus**, reducing detection latency for critical threats by 50%.

- Managed security incident response, investigating root causes with **Splunk** and **Grafana** to implement preventative measures, decreasing recurring incidents by 35%.

- Reviewed and hardened **API Security** for microservices using **OpenAPI** specifications, preventing 80% of potential injection and authentication bypass attempts.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | E-commerce Platform Backend Services*

- Developed and maintained scalable backend services for an e-commerce platform using **Java** and **Spring Boot**, handling 100K+ concurrent user requests efficiently.

- Implemented **API Security** measures including authentication and authorization (**RBAC**) for internal microservices, reducing unauthorized access attempts by 95%.

- Designed and optimized **PostgreSQL** database schemas and queries, improving data retrieval performance by 40% for customer and product information.

- Created automated testing suites with **JUnit** and **Mockito** for backend services, increasing code coverage to 85% and reducing production bugs by 20%.

- Configured and managed **CI/CD** pipelines using **GitLab CI** for automated builds and deployments, decreasing release cycle time from weekly to daily.

- Deployed containerized applications using **Docker** and orchestrated with **Kubernetes** for high availability, achieving 99.9% uptime for core services.
