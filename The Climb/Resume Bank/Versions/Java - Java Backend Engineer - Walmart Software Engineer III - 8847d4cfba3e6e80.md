## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Nagarro | Catalog Derivation Platform Engineering*

- Led design and development of **Java** **Spring Boot** microservices architecture for product attribute derivation, handling 50M daily catalog updates with 99.9% uptime.

- Implemented **Kafka** real-time messaging pipelines for scalable data ingestion and catalog enrichment, reducing processing latency by 60% for enterprise clients.

- Optimized **BigQuery** and **NoSQL databases** (**DynamoDB**) for complex catalog data models, improving query performance by 45% for critical analytical reports.

- Integrated **GitHub Copilot** and agentic workflows into development lifecycle, boosting developer productivity by 20% and accelerating delivery timelines by 15%.

- Architected and deployed **CI/CD** pipelines on **AWS** for automated testing and deployment, achieving 90% faster release cycles and enhanced code quality by 25%.

- Mentored junior engineers on best practices for **Java backend development** and **Spring Boot** applications, fostering a culture of technical excellence and innovation.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Endava | Real-time Data Processing & Microservices*

- Developed robust **Java** **Spring Boot** services for real-time catalog data enrichment, processing over 10M events daily, enhancing data accuracy by 15%.

- Engineered **Kafka** consumers and producers for high-throughput messaging, ensuring reliable data flow across distributed systems, reducing message loss to 0.1%.

- Designed and implemented data storage solutions using **NoSQL databases** (**MongoDB**) for variant redesign, achieving sub-second data retrieval for critical operations.

- Wrote comprehensive **JUnit** unit and functional test cases for **Java backend development**, improving code quality and reducing post-deployment defects by 25%.

- Leveraged **BigQuery** for large-scale data analytics and reporting on product attributes, providing actionable insights that optimized merchandising strategies by 10%.

- Contributed to **CI/CD automation** initiatives, deploying scalable services to **GCP** environments, streamlining release processes and minimizing manual errors by 30%.

- Utilized **OpenAI API** for generating code snippets and improving documentation efficiency after Nov 2022, accelerating feature development cycles by 12%.

- Collaborated with cross-functional product and editorial teams to define and implement new catalog data models, enhancing product attribute derivation and improving data quality by 18%. This facilitated critical downstream applications.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Persistent Systems | Enterprise Application Development*

- Developed and maintained **Java** **Spring Boot** **REST API** endpoints for enterprise applications, supporting 50K daily user requests with high availability.

- Implemented data persistence layers using **JPA** with **PostgreSQL** to manage core business logic, ensuring data integrity and optimizing transaction speeds by 20%.

- Wrote thorough **JUnit** unit tests for **Java backend development**, achieving 85% code coverage and significantly enhancing the reliability of critical modules.

- Collaborated on designing and optimizing database schemas for performance, reducing query execution times by 30% for improved application responsiveness.

- Contributed to a modular codebase following best practices for code quality and maintainability, facilitating seamless integration of new features by 18%.

- Developed and deployed system enhancements for critical enterprise applications, improving overall platform stability and ensuring continuous service availability for key business operations by 15% through robust backend logic.
