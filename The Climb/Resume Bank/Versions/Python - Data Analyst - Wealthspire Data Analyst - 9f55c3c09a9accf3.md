## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Financial Data Analytics & Integration Platform*

- Architected and implemented scalable **Python** data pipelines on **Azure Data Lake** and **Azure Functions** for financial record ingestion, improving processing efficiency by 40% across 50M records daily.

- Developed advanced **Power BI** dashboards and interactive reports for executive stakeholders, utilizing **DAX** and **SQL Server** to visualize complex financial trends, increasing data-driven decisions by 30%.

- Led initiatives for **data quality** and **data classification** across critical financial datasets using **Azure Purview**, ensuring compliance with industry regulations and reducing data errors by 25%.

- Collaborated with **AI teams** to preprocess and assemble large-scale **datasets** for machine learning models, utilizing **Databricks** and **Spark** to accelerate model training by 20%.

- Designed and maintained robust **data integration** solutions for various **downstream systems** and **internal data repositories**, ensuring seamless data flow and reducing manual reconciliation effort by 35%.

- Implemented **automation tools** using **Azure DevOps** and **PowerShell** scripts to streamline data validation and deployment processes, reducing deployment time by 50% for critical updates.

- Mentored junior engineers on best practices for data modeling, **SQL** optimization, and efficient report generation within the **Microsoft Power Platform**, elevating team productivity by 15%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise Financial Reporting System*

- Built and optimized **C#** microservices to process financial transactions, integrating with **SQL Server** databases and improving data retrieval speeds by 20% for reporting modules.

- Developed custom **Power BI** reports and interactive dashboards to monitor key financial performance indicators, providing real-time insights to management and reducing manual data compilation by 40%.

- Implemented data validation rules and cleansing routines using **Python** scripts to enhance **data quality** within the enterprise system, reducing reporting discrepancies by 18% monthly.

- Contributed to the development of an **ETL** framework for ingesting data from external financial APIs, significantly improving data freshness and availability for analysis by 30%.

- Managed and maintained various **Azure** cloud resources, including **Azure SQL Database** and **Azure Blob Storage**, ensuring high availability and cost-efficiency for data operations by 15%.

- Collaborated with business analysts to gather **data requirements** and translate them into technical specifications for new reporting features, streamlining development cycles by 25% for critical projects.

- Automated operational tasks and data synchronization processes across multiple systems using **PowerShell** and **Azure Functions**, reducing manual effort by 20 hours per month.

- Assisted in preparing structured **datasets** for experimental **AI** initiatives using **Pandas** and **NumPy**, supporting early-stage model development and evaluation efforts.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Customer Relationship Management (CRM) Platform*

- Developed and maintained core backend services using **Java** and **Spring Boot** for a customer data platform, improving system responsiveness by 15% for 10,000 active users.

- Designed and implemented **REST APIs** for seamless **data integration** with third-party marketing and sales platforms, enabling bidirectional data flow for 5 external systems.

- Managed and optimized **PostgreSQL** databases, including schema design and query tuning, which resulted in a 20% reduction in data retrieval times for key customer data.

- Wrote comprehensive unit and integration tests using **JUnit** and **Mockito** to ensure code reliability and **data output** accuracy, reducing critical production bugs by 30%.

- Assisted in creating technical documentation for **data definitions**, system architecture, and API endpoints, improving developer onboarding time by 15% for new team members.
