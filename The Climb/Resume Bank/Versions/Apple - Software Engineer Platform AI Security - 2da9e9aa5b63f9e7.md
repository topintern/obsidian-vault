## Professional Experience

**Software Engineer AI**  |  *Jun 2025 - Present*

*Epik Solutions | Enterprise Security Platform*

- Built **Go/Python security telemetry microservices**, processing **5M+ daily events** through Kafka, Redis, and PostgreSQL with **99.9% uptime**.

- Developed **Java Spring Boot/FastAPI services** for investigation, policy, and evidence workflows using clean API contracts and regression tests.

- Instrumented distributed services with **OpenTelemetry, Prometheus, and Grafana**, reducing **mean incident detection time by 40%** across production systems.

- Built **React/TypeScript operational dashboards** for service health, security workflows, and data quality metrics, giving partners self-service visibility.

- Integrated **LLM/RAG workflows** using AWS Bedrock, OpenAI API, and Pinecone, adding prompt regression tests, latency tracking, and fallback paths for production AI features.

- Implemented secure platform controls including **OAuth2/JWT, RBAC**, secret handling, and vulnerability triage, aligned with **secure SDLC** practices.

**Software Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance AI Platform*

- Designed **multi-tenant backend systems** using Java Spring Boot, Go, Python, AWS Lambda, ECS, SQS, and PostgreSQL, serving **15+ enterprise clients** with strict tenant isolation.

- Built **Kafka/Airflow data pipelines** to ingest cloud, audit, and application metadata for reporting, ML evaluation, and downstream analytics.

- Productionized **AI-assisted compliance workflows** using PyTorch/TensorFlow prototypes, LangChain, and model-version tracking, reducing manual evidence review by **70%**.

- Created **React/TypeScript and GraphQL applications** for evidence management, document review, policy authoring, admin configuration, and operator workflows.

- Built **platform APIs and deployment tooling** for feature flags, schema migrations, and environment promotion, reducing release coordination by **25%**.

- Improved reliability with **idempotent consumers, retry queues, dead-letter handling**, cache tuning, and Grafana/CloudWatch alerts, cutting production support issues by **35%**.

**ML / Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Autonomous Vehicle Perception*

- Built **Python preprocessing pipelines** for image, sensor, and telemetry datasets used in perception model training, converting raw field data into validated artifacts.

- Evaluated **computer vision models** with **PyTorch, TensorFlow, and OpenCV**, analyzing quality regressions and operational edge cases for autonomous systems.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies | LabOps / Scientific Workflow Platform*

- Built **full-stack scientific workflow tools** using React, Java/Python REST APIs, and PostgreSQL for experiment tracking, sample metadata, and analysis workflows for **500+ scientists**.

- Developed **async upload, validation, and background-processing services** for large experiment files, decoupling long-running processing from user-facing screens.

- Implemented **Java Spring Boot APIs** for inventory, sample lineage, and experiment status workflows, standardizing service contracts across **10+ LabOps modules**.

- Built **React/TypeScript dashboards** for validation errors, pipeline status, and experiment review queues, giving research and QA teams faster visibility into blocked workflows.

- Added **data quality checks, audit logs**, and retry-safe processors for scientific metadata changes, improving traceability across regulated datasets.

- Designed **event-driven job telemetry and operational alerts** for LabOps pipelines, improving failure triage across upload, validation, analysis, and reporting services.

- Optimized **schemas, indexes, and query paths** for experiment reports and metadata search, reducing slow report generation by **30%**.

- Authored **automated tests, CI quality gates, and release checks** for scientific data workflows, reducing production regressions.
