**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Real-time Financial Data Platform*

- Developed and maintained core components of a real-time financial data platform using **Python** and **Django**, supporting 10,000 concurrent users with zero downtime.

- Built interactive dashboards and reporting features with **Vue.js** for visualizing complex financial metrics, improving client data analysis efficiency by 20%.

- Managed **Postgres** databases, optimizing queries and schemas to handle increased data volumes by 50% for critical market analysis systems.

- Implemented **Docker** containerization for scalable deployment of microservices on **AWS ECS**, reducing resource consumption by 15% across environments.

- Contributed to defining architectural standards for new features, integrating secure **API frameworks** for external system interoperability, achieving 99.99% data integrity.

- Designed and developed robust data ingestion pipelines from various financial sources using **Python**, processing over 1TB of data daily with 99.5% accuracy.

- Enhanced existing web applications by refactoring legacy code and introducing new features, improving overall system responsiveness by 10% for users.

- Utilized **Git** for version control and collaborative development within an agile **SDLC**, accelerating feature delivery by 25% for clients.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Enterprise SaaS Web Solutions*

- Developed responsive user interfaces for enterprise **web applications** using **Vue.js** and JavaScript, enhancing user engagement metrics by 15%.

- Implemented backend services with **Python** and Flask, integrating with various third-party APIs for seamless data exchange, processing 100,000 transactions hourly.

- Managed relational databases, primarily **Postgres**, for storing critical business data, ensuring data consistency and query performance for all applications.

- Collaborated on defining and implementing frontend architectural standards, ensuring maintainable and scalable codebases across multiple projects, reducing technical debt by 10%.

- Utilized **Git** for version control and participated in code reviews, adhering to best practices within a collaborative development environment, improving code quality by 10%.

- Deployed applications to production environments, gaining foundational experience with cloud platforms like **AWS**, contributing to a 99% service uptime.
