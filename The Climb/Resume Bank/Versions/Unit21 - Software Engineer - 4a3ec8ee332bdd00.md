## Professional Experience

**Software Engineer AI**  |  *Jun 2025 - Present*

*CIFC Asset Management | Enterprise Security AI*

- Owned **Python ingestion services and REST APIs** that validated and routed heterogeneous security alerts, logs, and tickets through PostgreSQL, Redis, queues, and AWS for downstream analysis.

- Engineered **event normalization, entity correlation, and alert deduplication** to prepare heterogeneous security signals for reliable downstream detection and incident triage.

- Improved **Redis-backed queued processing and failure instrumentation** to reuse incident context across jobs and **reduce repeat triage cycles by 35%** while making queue failures diagnosable.

- Designed and owned reusable **AI infrastructure for RAG, prompt versioning, and LLM evaluations**, with regression tests, guardrails, and failure telemetry for severity and remediation workflows.

- Designed **approval-state transitions, RBAC, and traceable audit controls** across review, escalation, and remediation workflows, enforcing least-privilege access and human approvals.

- Built the **React, TypeScript, and Material UI operator workflow** around backend-owned incident state, integrating evidence, confidence scores, approvals, escalations, and audit history through REST APIs.

**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance AI Platform*

- Owned **Python and GraphQL services on AWS Lambda, ECS, and SQS** for a multi-tenant compliance platform using PostgreSQL and Neo4j across **15+ enterprise clients**.

- Designed **compliance-graph data modeling and traceable-source retrieval** across policies, evidence, cloud controls, tickets, and documents to produce audit-ready answers.

- Implemented asynchronous **agentic evidence-review workflows** with AWS Bedrock, Azure OpenAI, LangChain, tool-calling agents, vector search, and eval datasets, cutting manual review effort by **70%**.

- Instrumented asynchronous jobs with **queue latency, failure, evidence-coverage, and automation-gap telemetry**, giving engineering teams release-readiness signals before customer rollouts.

- Enforced **tenant isolation across APIs, data access, and background jobs** with RBAC and audit logging, then added CI/CD gates and environment-promotion controls for releases.

- Demonstrated **end-to-end feature ownership** from customer discovery and API/data modeling through implementation and production debugging, using post-launch behavior to prioritize releases.

**ML / Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Autonomous Systems & Workflow Automation*

- Engineered **Python telemetry pipelines and validated ML artifacts** from image, sensor, and field-operations data for labeling, analysis, and downstream model workflows.

- Automated **cross-system identity and data-quality checks** across UKG, JumpCloud, and Azure AD-style services, **reducing provisioning and validation time by 80%**.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies | LabOps / Regulated Workflow SaaS*

- Built **Rails and Java backend services, REST APIs, and PostgreSQL data flows** for inventory, sample lineage, scheduling, uploads, and experiment tracking used by **500+ scientists**.

- Improved **SQL query/index performance and background-job execution** by removing redundant reads and reworking high-volume sample-event processing, reducing timeouts and debugging cycles.

- Designed **validation, controlled retries, and explicit failure states** across regulated data paths, with role-based workflows and audit logs preserving recoverability.

- Developed **React, TypeScript, and Material UI operational dashboards** for sample queues, upload failures, inventory exceptions, and experiment blockers, reducing support handoffs.

- Converted release checks into **repeatable smoke tests and release validation**, giving QA and infrastructure teams consistent coverage of deployment-critical workflow behavior.
