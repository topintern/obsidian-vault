**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise SaaS Platform Development*

- Developed and maintained robust **Python** backend services using **Django** and **REST APIs** for a CRM platform, optimizing performance and supporting 20,000 active users daily.

- Implemented data processing workflows on **AWS S3** and **Lambda** using **SQL** for ETL operations, ensuring data integrity and reducing data latency by 30% for analytics dashboards.

- Integrated third-party APIs like **Stripe** and **Twilio** into the platform using **Node.js**, enhancing core functionalities for payment and communication features, increasing customer engagement by 15%.

- Optimized complex database queries in **PostgreSQL** by 40% through index creation and query refactoring, improving report generation time from 5 minutes to 30 seconds.

- Contributed to **CI/CD** pipeline improvements using **Jenkins** and **Git** for automated testing and deployment, ensuring reliable releases and reducing release cycles from bi-weekly to daily.

- Developed a recommendation engine using **Python** and **Scikit-learn** on **AWS EC2** to personalize user experience, contributing to business transformation and boosting feature adoption by 20%.

- Implemented monitoring and logging solutions using **Prometheus** and **Grafana** for system health, proactively addressing issues and reducing incident detection time by 75% for critical services.

- Refactored legacy codebase into modular **microservices** with **Spring Boot** and **Java** reducing technical debt, enhancing maintainability for future development by 30%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Custom Software Development*

- Developed robust backend services using **Java** and **Spring Boot** for a client-facing web application, processing 5,000 transactions per hour reliably, ensuring high system uptime.

- Designed and implemented efficient database schemas in **MySQL** for various project modules, ensuring data integrity and optimizing query performance by 20%.

- Built interactive user interfaces using **React** and **JavaScript** for a B2B portal, enhancing functionality and improving user experience scores by 15%.

- Implemented **RESTful APIs** for secure data exchange between frontend and backend systems, ensuring reliable integration and handling 10,000 daily requests with 99.9% uptime.

- Utilized **Git** for version control and collaborated effectively in an **Agile** environment, ensuring code quality and delivering features on schedule with 90% adherence.

- Performed comprehensive unit and integration testing using **JUnit** and **Mockito** for backend components, significantly reducing post-deployment bugs by 40%.
