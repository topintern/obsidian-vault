## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*EPAM Systems | Financial Risk & Compliance Platform*

- Designed and implemented a high-throughput **financial risk** assessment engine using **Go** and **Kafka** for 50M daily transactions, reducing fraud detection latency by 35% across the financial platform.

- Led the migration of legacy services to a **Kubernetes** microservices architecture with **Spring Boot** and **AWS**, improving system **scalability** by 40% and deployment efficiency by 25%.

- Developed and maintained **RESTful APIs** using **Python** and **Django** for secure data exchange, integrating 15+ external partners, enhancing service uptime to 99.99% for critical operations.

- Implemented real-time **data analysis** and **monitoring** solutions using **PromQL** and **Grafana** for critical production issues, improving incident response time by 20% across **distributed systems**.

- Architected and deployed an automated rules system on **AWS Lambda** leveraging **Python** to mitigate **financial risk**, processing 10M records hourly and decreasing manual review by 60%.

- Improved engineering standards and **CI/CD** pipelines using **Jenkins** and **GitLab** for **Go** and **Java** projects, accelerating feature delivery cycles by 30% for all development teams.

- Designed and built secure, multi-tenant data ingestion pipelines with **Kafka** and **PostgreSQL** on **AWS** to process diverse signals, ensuring data integrity and improving partner onboarding by 45%.

**Software Engineer**  |  *Jan 2024 - Jun 2025*

*Globant | Enterprise FinTech Data Platform*

- Developed **scalable distributed systems** using **Java** and **Spring Boot**, deployed with **Docker**, supporting 2M daily user transactions with 99.9% availability.

- Built and maintained **RPC** and **RESTful APIs** using **Python** and **Ruby** to support internal service communication, enabling seamless integration for 10+ partner applications.

- Implemented **data analysis** and **monitoring** dashboards with **Elasticsearch** and **Kibana** to debug production issues, reducing incident resolution time by 25% for critical services.

- Designed and optimized **SQL** queries for a **PostgreSQL** database, processing complex financial reports 3x faster, significantly improving data accessibility for business intelligence.

- Engineered robust **ETL** pipelines in **Python** on **AWS S3** and **Lambda** to ingest and process signals from various sources, handling 100GB daily with 99% accuracy.

- Contributed to designing adaptable rules systems for automated actions using **Java** and **Drools**, improving **financial risk mitigation** by 15% for enterprise clients.

- Debugged and resolved critical production issues across multiple services and levels of the stack using **Java** and **Go**, enhancing system stability and performance by 18%.

- Translated complex business needs into detailed **software requirements** and design specifications for new features, improving development team efficiency by 20% and project alignment.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*Nagarro | Core Banking & Transaction Services*

- Developed and deployed core banking features using **Java** and **Spring Boot** for high-volume transaction processing, improving system responsiveness by 20% for 500K users.

- Implemented **RESTful APIs** with **Python** and **Django** to facilitate secure communication between internal microservices, reducing data retrieval latency by 15% on average.

- Optimized **SQL** database performance for **MySQL** by refactoring complex queries, improving reporting speeds by 30% and overall system efficiency for financial operations.

- Participated in the full software development workflow, translating business needs into **software requirements** and technical designs, contributing to 10+ successful feature releases within project timelines.

- Debugged production issues and performed root cause analysis across various services, enhancing system reliability by 10% and minimizing user impact from reported defects.

- Integrated third-party payment gateways using **Java** for online transactions, expanding service offerings by 25% and increasing payment success rates to 98%.
