## Professional Experience

**Automation Engineer (Full Stack / Distributed Systems)**  |  *Jun 2025 - Present*

*Epik Solutions*

- Designed scalable microservices (Go, Python) to integrate enterprise security platforms, automating 40% of SOC workflows and reducing MTTR by 15 mins for teams.

- Built React-based analytics dashboards (Front-end experience) for 15+ systems, eliminating 20+ hours/week manual reporting and improving decision latency for stakeholders.

- Developed object-oriented language pipelines (Python) processing 1,000+ daily security events, significantly reducing analyst workload by 30% through automated triage.

- Automated enterprise workflows using PowerShell scripting and CI/CD tools, serving 500+ users, cutting operational cycle times by 40%.

- Enhanced application performance and reliability by debugging distributed Go runbooks, improving end-to-end pipeline success rates by 25% across production environments.

**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected multi-tenant full-stack software SaaS platform (AWS, Go) serving 15+ clients, scaling to 10,000+ users while ensuring high availability.

- Designed distributed backend systems (Golang, AWS, PostgreSQL) with strict tenant isolation across relational, graph, and object database technologies.

- Developed Python-based compliance automation (LangChain) to orchestrate evidence collection and control scoring, reducing manual auditor effort by 70%.

- Built continuous integration data ingestion pipelines (Step Functions, Lambda) from enterprise systems into graph-based access models, boosting data accuracy.

- Developed full-stack React + GraphQL applications, enabling controls, identity graph visualization, and exceptional user experiences for enterprise clients.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built automated identity lifecycle system (Python, AWS/Azure Serverless), syncing 500+ employees, reducing provisioning time by 80% through CI/CD.

- Developed full-stack features (React, Golang) for MLOps data labeling infrastructure, improving annotation throughput by 20% for ML training build systems.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered full-stack features for cloud-based lab automation platform (React, Ruby on Rails, PostgreSQL) used by 500+ scientists in microservices architecture.

- Implemented features across 10+ core product modules (inventory, compounds), enabling accurate tracking of complex experimental data using database technologies.

- Authored 100+ test cases and resolved critical production issues, ensuring data integrity and system reliability, directly impacting application performance.
