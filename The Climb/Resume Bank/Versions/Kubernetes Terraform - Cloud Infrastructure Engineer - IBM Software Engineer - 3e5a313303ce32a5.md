## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*EPAM Systems | Cloud DBaaS Operations Platform*

- Designed and deployed **Kubernetes** operators for the full lifecycle management of **DBaaS** instances on **AWS**, reducing manual intervention by 40%.

- Implemented advanced auto-scaling algorithms for distributed **microservices** using **Prometheus** and **Grafana**, optimizing cloud resource consumption by 25%.

- Developed robust **Go** applications to manage multi-cloud infrastructure across **GCP** and **Azure**, enhancing system performance by 30%.

- Executed comprehensive synthetic load tests using **JMeter** on **Kubernetes** clusters, validating performance under production conditions for 1M concurrent users.

- Collaborated with cross-functional teams to define system performance requirements, integrating new hardware components that improved data throughput by 15%.

- Monitored production runtime data with **PromQL** queries, identifying and resolving bottlenecks that increased platform stability by 20%.

- Authored technical documentation for **DBaaS** deployment and maintenance procedures, streamlining onboarding for new engineers by 35%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Globant | Multi-Cloud Infrastructure Solutions*

- Developed and maintained **Python** microservices for a multi-cloud platform, ensuring high availability and data integrity across **AWS** and **GCP** environments.

- Utilized **Kubernetes** for container orchestration and application deployment, managing scaling and networking efficiently across 100+ production services.

- Designed system requirements for new software solutions, optimizing performance and scalability in cloud environments, reducing latency by 18%.

- Implemented refined auto-scaling heuristics for distributed components using **Prometheus**, improving workload management and resource utilization by 22%.

- Performed extensive debugging and deployment of software features, collaborating with teams to deliver enhancements that boosted user satisfaction by 10%.

- Contributed to the full software development lifecycle, designing robust solutions for critical systems that processed over 500GB of daily data.

- Monitored production infrastructure using **Grafana** dashboards, identifying bottlenecks and implementing optimizations that reduced cloud costs by 15%.

- Prepared detailed technical documentation for software installations and maintenance, reducing support ticket resolution time by 20% for internal users.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Thoughtworks | Enterprise Application Development*

- Designed and developed robust **Java** applications for an enterprise platform, enhancing system performance and user experience for 5,000 daily users.

- Participated in the full software development lifecycle, implementing new features and maintaining existing systems using **Git** for version control.

- Analyzed user requirements to design scalable software solutions, optimizing data processing workflows that reduced report generation time by 30%.

- Implemented **CI/CD** pipelines using **Jenkins** and **Docker** for automated testing and deployment, improving release frequency by 50%.

- Maintained databases and related systems within the application area, ensuring high availability and data integrity for over 1TB of sensitive data.

- Collaborated with cross-functional teams to identify and recommend system improvements, leading to a 15% increase in operational efficiency.
