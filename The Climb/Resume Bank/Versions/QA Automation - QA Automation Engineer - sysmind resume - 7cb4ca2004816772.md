## Experience

- Led testing efforts for enterprise asset management (EAM) solutions, ensuring system reliability and performance.


- Developed and executed test strategies, including **automated and manual testing**, for frontend and backend services.


- Designed **Selenium-based automation scripts** to streamline functional and regression testing.


- Collaborated with developers and business analysts to define test cases and ensure full test coverage.


- Utilized **Azure DevOps** to manage test plans, execute test cases, and track defects.



**Software Engineer,** RHYM Tech - Remote, Stillwater, OK  |  Aug 2022 - May 2023






- Conducted **software testing, including unit, integration, and performance testing**, to improve cybersecurity tools.


- Built automated test scripts using **Cypress** for frontend testing and **JUnit** for backend validation.


- Developed CI/CD pipelines with Jenkins to automate testing and deployment workflows.


- Integrated **Power BI dashboards** to monitor application performance and security metrics.


- Delivered custom web applications and solutions tailored to the unique needs of cybersecurity systems, enhancing the performance and scalability of key tools

- Built secure, **responsive web applications** using **React** and **Node.js**, leveraging **JWT for secure authentication** and OAuth for third-party integration

- Contributed to designing and implementing **real-time data analytics** systems with **Kafka and Splunk** for monitoring network traffic and detecting anomalies

- Enhanced system security by developing **web-based dashboards** for **intrusion detection and security event management**, providing users with visual insights into potential vulnerabilities

- Collaborated with a cross-functional team to integrate **threat detection algorithms** and APIs into existing systems, supporting **penetration testing and vulnerability assessments**




**Full stack developer,** ZeMoSo Technologies - Hyderabad, India  |  Jul 2021 - Aug 2022





- Implemented robust test strategies for a biotech AI robotic lab platform, enhancing security and user experience.


- Designed **test automation frameworks** for RESTful APIs using **Postman and JUnit**.


- Led defect triage sessions and provided root cause analysis for identified issues.


- Optimized database performance using PostgreSQL queries and indexing strategies.



**Software developer,** RHYM Tech - Hyderabad, India  |  Jun 2020 - May 2021





- Developed and tested cybersecurity solutions, ensuring compliance with security best practices.


- Performed **penetration testing** and vulnerability assessments to detect and address security flaws.


- Automated functional and regression testing using **Selenium WebDriver and Python scripts**.






## Projects

 


**Test Automation Framework for EAM Solutions | Arvam Tech**




- **Problem**: The enterprise asset management system required a robust and scalable test automation framework to improve efficiency and reduce manual testing efforts

**Solution**:  Developed a comprehensive test automation suite using **Selenium and Cypress**, reducing test execution time by 40%. Enhanced defect tracking and reporting through **Azure DevOps dashboards**



**Cybersecurity Intrusion Detection System | RHYM Tech**




- **Problem**: The existing intrusion detection system lacked automated testing, making it difficult to validate security responses effectively

**Solution**: Implemented test plans to validate system performance against security threats. Automated test cases to simulate cyberattacks and measure detection efficiency, improving system reliability



**Strateos Platform API Testing | ZeMoSo Technologies**




- **Problem**: The platform required comprehensive API testing to ensure seamless interaction between microservices and maintain system integrity

**Solution**:  Designed automated API test scripts using **Postman and JUnit**, validating complex API integrations. Conducted end-to-end testing for microservices, ensuring seamless data flow across distributed systems
