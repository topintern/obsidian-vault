## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Financial Data & API Platform*

- Designed and implemented scalable **Go** microservices and **gRPC** APIs on **AWS EKS** to process 10M financial transactions daily, enhancing platform **scalability** by 35%.

- Led development of a high-performance **Python** data pipeline using **Kafka** and **Spark** for real-time financial data analytics, reducing processing latency by 50% for 2M users.

- Developed secure **REST APIs** with **OAuth2** in **Spring Boot** (**Java**) for integrating third-party financial institutions, ensuring 99.9% uptime and data **security** compliance.

- Engineered a robust **React** frontend application with **TypeScript** and **Redux** for user financial dashboards, improving data visualization loading speed by 40% for 500K users.

- Orchestrated **CI/CD** pipelines using **Jenkins** and **Kubernetes** for automated deployments across multiple **AWS** environments, accelerating release cycles by 25% for critical features.

- Implemented comprehensive **automated testing** frameworks using **Cypress** and **Junit** for both **frontend** and **backend** components, decreasing critical bug incidents by 30%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise SaaS & Payment Solutions*

- Developed **Node.js** **microservices** with **Express.js** on **AWS Lambda** to manage payment processing workflows, handling 500K transactions monthly with 99.99% reliability.

- Designed and implemented a **PostgreSQL** database schema for a new financial product, optimizing query performance by 20% and supporting 1M records efficiently.

- Built a responsive **React** user interface for an internal invoicing system, integrating **RESTful APIs** and improving user data entry efficiency by 15% for 200 users.

- Contributed to **API design** and development using **Java** and **Spring Boot** for third-party integrations, improving data exchange rates by 10% for partner systems.

- Implemented **security** features like data encryption and input validation for critical financial data endpoints using **OWASP** guidelines, mitigating 95% of identified vulnerabilities.

- Deployed and managed containerized applications using **Docker** and **AWS ECS**, streamlining deployment processes and achieving 99.5% service availability across environments.

- Authored comprehensive **automated tests** using **Jest** for **frontend** components and **Mockito** for **backend** services, reducing regression bugs by 25% before production.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Customer Engagement & Data Analytics Platform*

- Developed core **backend** logic for a customer loyalty platform using **Python** and **Django**, supporting 50K active users and managing 100K daily interactions.

- Designed and maintained **MySQL** databases for user profiles and transaction history, ensuring data integrity and enabling 99% uptime for the platform.

- Created dynamic **HTML**, **CSS**, and **JavaScript** interfaces for user account management, improving user experience by 20% and reducing support tickets by 10%.

- Implemented **RESTful API** endpoints for mobile application integration, facilitating data exchange with 3rd party services and improving feature delivery speed by 15%.

- Collaborated on system architecture for a real-time analytics dashboard, processing 20K data points per minute and providing key insights to 5 internal teams.
