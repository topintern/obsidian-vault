## Professional Experience


**Senior QA Automation Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Platform Testing*




- Architected end-to-end test automation framework using **Selenium WebDriver** with **Java**, **TestNG**, and **Page Object Model** design pattern for enterprise SaaS platform, achieving 85% automation coverage across 500+ tests.

- Developed **BDD** test suites using **Cucumber** and **Gherkin** syntax, collaborating with product owners and business analysts to translate user stories into executable test scenarios, improving requirement traceability by 70%.

- Built **API test automation** framework using **Rest Assured** and **Postman** collections integrated with **Newman** for **CI/CD** pipelines, validating 100+ REST endpoints for microservices architecture with 99.9% reliability.

- Integrated test automation into **Jenkins** CI/CD pipelines with parallel execution on **Selenium Grid** and **Docker** containers, reducing regression test execution time from 8 hours to 45 minutes across multiple browsers.

- Implemented comprehensive test data management strategy using **SQL** queries against **PostgreSQL** and **MySQL** databases, creating reusable data sets for functional, integration, and performance testing scenarios.

- Designed and executed **System Integration Testing (SIT)** and **User Acceptance Testing (UAT)** plans, coordinating with stakeholders across 5 teams to validate end-to-end workflows before production releases.

- Established defect tracking and reporting processes using **Jira** and **Xray**, implementing custom dashboards for test execution metrics, defect trends, and release readiness indicators for executive reporting.



**QA Automation Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | B2B SaaS Testing*




- Developed robust **Selenium WebDriver** automation suite with **Python** and **pytest** framework for B2B compliance platform, automating 300+ test cases covering functional, regression, and smoke testing scenarios.

- Created **Cypress** end-to-end test automation for React-based frontend applications with custom commands and fixtures, achieving 90% code coverage for critical user workflows and reducing manual testing effort by 60%.

- Built **API automation** framework using **Python requests library** and **Postman**, validating RESTful services with JSON schema validation, authentication flows, and error handling for 50+ microservices endpoints.

- Implemented **data-driven testing** approach using **TestNG** DataProviders and Excel/CSV files, enabling execution of 1000+ test permutations with parameterized inputs for comprehensive functional validation.

- Configured **Selenium Grid** with **Docker Compose** for cross-browser testing across Chrome, Firefox, Safari, and Edge, executing parallel tests on 10+ nodes to optimize test execution time and resource utilization.

- Developed **mobile test automation** using **Appium** for iOS and Android applications, creating framework with reusable components for native and hybrid mobile apps supporting 15+ device configurations.



**Software QA Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | SaaS Product Testing*




- Designed and executed manual test cases for web applications covering functional, regression, smoke, sanity, and exploratory testing, identifying and documenting 200+ defects with detailed reproduction steps.

- Built **Selenium WebDriver** automation scripts with **Java** and **JUnit** for regression testing of scientific data management platform, reducing regression cycle time from 3 days to 4 hours for critical release paths.

- Performed **SQL** database testing with complex queries to validate data integrity, ETL processes, and backend business logic across **PostgreSQL** databases, ensuring accuracy of scientific experiment tracking workflows.

- Executed **API testing** using **Postman** and **SoapUI** for REST and SOAP services, validating request/response payloads, status codes, headers, and authentication mechanisms for backend integrations.

- Conducted **performance testing** using **JMeter** to identify bottlenecks and validate system behavior under load, simulating 1000+ concurrent users and generating detailed performance analysis reports.

- Collaborated with developers in **Agile/Scrum** sprints for continuous testing, participating in daily standups, sprint planning, and retrospectives, ensuring quality gates were met before each sprint release.

- Managed defect lifecycle in **Jira** from identification through closure, working with cross-functional teams to prioritize, reproduce, and verify fixes, maintaining 95% defect resolution rate within SLA.
