## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | AI-Native Underwriting Platform*

- Designed and implemented advanced **agentic workflows** for **underwriting decision-making** using **CrewAI** and **Python** with robust error handling, improving processing speed by 35% for high-value policies.

- Developed **ML/LLM systems** using **PyTorch** and **Hugging Face** models for submission triaging and intelligent routing, achieving 90% **accuracy** in identifying high-appetite business efficiently.

- Established robust **evaluation pipelines** on **AWS SageMaker** to validate **ML models** and **agentic workflows** with comprehensive testing, reducing deployment risks by 25% significantly.

- Engineered **monitoring systems** with **Datadog** and **Elasticsearch** for **production systems** using advanced dashboards, enabling real-time performance insights and reducing outage duration by 40%.

- Led **end-to-end ownership** of **ML models** from research to **production-ready** deployment on **Kubernetes** via **MLOps**, decreasing time-to-market for new features by 20%.

- Implemented **prompt engineering** techniques for **OpenAI API** integrations within customer-specific workflows, boosting solution adaptability and overall user satisfaction by 15%.

- Collaborated with **Data Science** teams to optimize **Feature Engineering** for **ML models** on **Apache Spark**, enhancing prediction **accuracy** by 12% across diverse and complex datasets.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | Enterprise Data Analytics & SaaS Platform*

- Developed **Python** **data pipelines** on **AWS Lambda** and **S3** for ingesting 10M daily compliance records reliably, reducing ingestion lag from 4 hours to 20 minutes.

- Designed and implemented **REST APIs** using **Java** and **Spring Boot** to serve **ML models** predictions, supporting 500+ concurrent requests with 99.9% uptime efficiently.

- Optimized **PostgreSQL** **SQL** queries for **ML models** feature stores, improving data retrieval latency by 60% for critical **production systems** and analytics.

- Utilized **Scikit-learn** and **Pandas** in **Jupyter** notebooks to develop classification **ML models**, achieving 85% **accuracy** in predicting customer churn for financial services.

- Deployed containerized applications with **Docker** and orchestrated using **AWS EC2** instances, ensuring **reliability** and scalability for 5+ **microservices** with zero downtime.

- Integrated **OpenAI API** (post-Nov 2022) for natural language processing features within client-facing **SaaS** applications, increasing user engagement by 20% across key modules.

- Implemented **CI/CD** pipelines using **GitLab CI** for automated testing and deployment to **Azure** cloud, reducing release cycles from bi-weekly to daily.

- Collaborated on **System Design** for a new data warehousing solution, handling 5TB of data monthly and improving report generation speed by 75% for analysts.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Digital Transformation & Cloud Solutions*

- Developed scalable **REST APIs** using **Java** and **Spring Boot** for critical backend services and integration, handling 1M daily transactions with 99.8% uptime.

- Managed **MongoDB** and **PostgreSQL** databases, designing schemas and optimizing **SQL** queries to support enterprise applications, reducing data retrieval time by 45%.

- Implemented **CI/CD** pipelines with **Jenkins** and **Git** for automated deployments to **AWS** cloud, improving release efficiency and reducing manual errors by 30%.

- Built and maintained **data pipelines** for integrating customer data from various sources into a centralized warehouse, enhancing data availability by 95% reliably.

- Contributed to **System Design** discussions for new product features, ensuring **scalability** and maintainability for future expansions supporting 10K users effectively.

- Utilized **Docker** to containerize applications, streamlining development and deployment workflows across multiple **cloud environments**, cutting setup time by 50%.
