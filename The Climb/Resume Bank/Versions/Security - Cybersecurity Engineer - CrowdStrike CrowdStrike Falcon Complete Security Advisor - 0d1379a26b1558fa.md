## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Nagarro | Enterprise Cybersecurity Solutions & Compliance*

- Developed automated **Python** scripts for proactive **cybersecurity** posture assessments against **NIST CSF** standards, improving client compliance verification by 30% annually.

- Engineered **SIEM** integrations with **Splunk** and **Elastic Stack** for enhanced **threat detection** and **audit logging** capabilities, reducing incident investigation time by 15%.

- Led migration of **Windows** and **Linux** security configurations to **Infrastructure as Code** using **Terraform**, standardizing deployments across 500+ endpoints.

- Implemented **MDR/XDR** data pipelines on **Azure Data Lake** for real-time **incident response** analytics, accelerating breach containment by 25% on average.

- Developed **compliance reporting** module using **Python** and **Power BI** to generate **service reports** aligning with **PCI DSS** and **ISO 27001** for 100+ clients.

- Automated **vulnerability scanning** and **patch management** scripts for **MAC** environments using **Ansible**, reducing critical exposure windows by 50% for enterprise clients.

- Integrated **MITRE ATT&CK** framework into internal security tooling via **REST APIs**, enhancing **threat intelligence** and correlation for 75+ active threats daily.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Persistent Systems | Security Data Platform & Operations*

- Developed **Java** microservices for a **threat detection** rules engine, integrating **Kafka** for real-time event processing across diverse security logs, improving alert accuracy by 20%.

- Built **data pipelines** on **AWS S3** and **Glue** to aggregate **audit logging** data from various **Windows** and **Linux** servers, enabling 100% data availability.

- Designed and deployed **containerized** security tools using **Docker** and **Kubernetes** on **AWS EKS** to support scalable **incident response** capabilities across 15 investigations.

- Contributed to **Change Management** system development using **Node.js** and **PostgreSQL** for tracking security policy modifications, ensuring 99% configuration integrity.

- Automated **security posture** assessments for cloud environments using **AWS Security Hub**, generating daily compliance reports for 50+ enterprise accounts.

- Engineered **monitoring controls** using **Prometheus** and **Grafana** for critical **cybersecurity** infrastructure, detecting anomalies 10 minutes faster than before.

- Developed scripts in **Bash** and **Python** for automated **remediation** of common security misconfigurations on **Linux** systems, reducing manual effort by 35%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Endava | Secure Application Development & Infrastructure*

- Developed **Python** scripts for automated **security patching** and configuration management on **Linux** servers, reducing manual updates by 60% across the fleet.

- Built secure **Java** applications following **OWASP Top 10** guidelines, implementing **input validation** and **encryption** to protect sensitive customer data by 99%.

- Contributed to the design of **API Gateway** with **JWT** authentication for secure service communication, processing 5M daily requests with 100ms latency.

- Implemented **logging and monitoring** solutions using **ELK Stack** for application performance and **cybersecurity** events, improving issue detection by 20%.

- Configured **firewall rules** and **network security groups** on **AWS VPC** to isolate critical systems, enhancing network segmentation by 50% for heightened security.

- Developed **SQL** queries and stored procedures for **PostgreSQL** database, ensuring data integrity and access control for 1TB of critical operational data.
