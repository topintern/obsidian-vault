## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Intelligent Finance Platform & Spend Management*

- Designed and developed scalable **microservices** for a global corporate card platform using **Spring Boot** and **Kafka**, processing 50M transactions monthly, ensuring 99.9% uptime.

- Led implementation of a robust **GraphQL API** for intuitive spend management features, integrating with **React.js** frontend, improving data fetching efficiency by 30%.

- Architected and deployed an **AWS Lambda**-based real-time expense processing system with **Python**, reducing manual accounting tasks and processing time by 40%.

- Implemented CI/CD pipelines using **Jenkins** and **Docker** for continuous delivery of customer-facing products, accelerating deployment cycles by 25%.

- Optimized **PostgreSQL** database performance and data models for bill pay and travel software, achieving 2x faster query response times for users.

- Developed robust fraud detection modules utilizing **machine learning** principles and **AWS Sagemaker** to protect financial transactions, reducing fraudulent activities by 15%.

- Engineered a multi-tenant architecture using **Kubernetes** and **Terraform** for new market expansion, enabling seamless onboarding of 1000+ enterprise clients, enhancing scalability.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise SaaS Platform & FinTech Solutions*

- Developed full-stack features for an enterprise SaaS platform using **Node.js Express** and **React.js**, enhancing user experience for 500k+ active users.

- Implemented **RESTful APIs** for core banking functionalities, integrating with third-party financial services, improving data exchange reliability by 20%.

- Optimized data retrieval from **MongoDB** for a real-time analytics dashboard, decreasing load times from 10 seconds to 2 seconds for critical insights.

- Contributed to design and implementation of event-driven architectures with **AWS SQS** and **SNS** for robust system communication, reducing message loss to 0.1%.

- Enhanced client-side code for a spend management application using **TypeScript**, improving application responsiveness and reducing bug reports by 18%.

- Deployed containerized applications using **Docker** and orchestrated them with **AWS ECS**, achieving 99.95% availability for critical services, supporting business impact.

- Developed data migration scripts in **Python** for a legacy system upgrade, ensuring data integrity and successful transfer of 10TB+ financial records.

- Monitored system performance and operability using **Prometheus** and **Grafana** dashboards, identifying and resolving bottlenecks, improving system efficiency by 10%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | B2B Software Development & Digital Transformation*

- Developed and maintained back-end services using **Java** and **Spring Framework** for B2B digital transformation projects, serving 100+ clients reliably.

- Implemented user authentication and authorization modules with **JWT** and **Spring Security**, enhancing application security by 25% for sensitive data.

- Designed relational database schemas in **MySQL** for various client applications, ensuring data consistency and optimizing query performance by 15%.

- Created front-end components using **AngularJS** and **HTML/CSS** for customer-facing interfaces, improving user engagement metrics by 10%.

- Contributed to CI/CD pipeline setup using **GitLab CI** for automated testing and deployment, reducing manual deployment efforts by 30%.
