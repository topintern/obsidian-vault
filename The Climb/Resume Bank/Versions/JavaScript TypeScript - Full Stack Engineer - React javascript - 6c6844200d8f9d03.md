## Projects

- **Problem**:The platform required a secure and flexible permissions management system to handle varying user roles with different levels of access to sensitive experimental data.

- **Problem**: The cybersecurity firm required a custom web application to enhance the performance and scalability of their monitoring tools, specifically in real-time threat detection and data visualization

**Solution**:  Developed secure and **responsive web applications** using **React and spring boot**, implementing **JWT** for secure authentication and OAuth for third-party integrations. The applications provided seamless user experiences for monitoring network traffic and detecting anomalies, supporting the firm’s cybersecurity initiatives
