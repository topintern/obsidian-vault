## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Healthcare Innovation Platform*

- Led the design and development of critical **Ruby on Rails** microservices using **PostgreSQL** for a new healthcare claims processing platform, improving data processing throughput by 30%.

- Architected and implemented scalable **Elixir** and **Phoenix** API endpoints for patient data exchange, ensuring high availability and processing over 100,000 requests per minute.

- Spearheaded front-end redesign efforts utilizing **React** and **Svelte** for an intuitive clinician dashboard, enhancing usability and reducing navigation time by 15%.

- Mentored junior engineers on best practices in full-stack development, **Agile** methodologies, and **CI/CD** pipelines, improving team code quality by 20%.

- Optimized database queries and schemas in **PostgreSQL** and **MSSQL** for a large-scale data analytics service, accelerating report generation by 40% annually.

- Implemented comprehensive automated testing strategies using **Cypress** and **RSpec** for web applications, reducing production bug occurrences by 25% significantly.

- Developed serverless functions on **AWS Lambda** using **Node.js** for secure patient data anonymization, reducing processing costs by 18% monthly.

**Software Engineer**  |  *Jul 2023 - Jun 2025*

*Samay Systems LLC | Digital Healthcare Solutions*

- Developed and maintained full-stack features for a patient portal using **Ruby on Rails** and **React**, improving appointment scheduling efficiency by 15%.

- Built secure **RESTful APIs** in **Ruby** to integrate third-party medical device data, supporting over 50,000 daily data synchronizations securely.

- Contributed to front-end development using **JavaScript** and **Svelte** for a prescription management system, enhancing user experience and reducing errors by 10%.

- Designed and optimized **PostgreSQL** database schemas for new application modules, improving query response times by an average of 20%.

- Implemented robust unit and integration tests with **RSpec** and **Jest** within a **CI/CD** pipeline, decreasing regression issues by 25%.

- Refactored legacy codebases to improve performance and maintainability, reducing technical debt in key modules by 30%.

- Deployed and managed containerized applications using **Docker** on **AWS EC2**, ensuring scalable and reliable service uptime 99.9%.

- Collaborated with product teams to gather requirements for new features, ensuring technical solutions aligned perfectly with business goals 90% of the time.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*Zemoso Technologies | B2B SaaS Platform*

- Developed core features for a business analytics platform using **Ruby on Rails** and **JavaScript**, contributing to a 5% increase in user adoption.

- Implemented responsive front-end components using vanilla **JavaScript** and **HTML/CSS** for improved user interface, boosting mobile engagement by 15%.

- Managed and optimized **PostgreSQL** database operations, including migrations and performance tuning, reducing query execution time by 10%.

- Wrote comprehensive unit tests with **RSpec** for backend services, ensuring code reliability and maintaining test coverage above 85%.

- Collaborated within a small team on various software development projects, adhering to project timelines and delivering features on schedule 90% of the time.

- Utilized **Git** for version control and actively participated in code reviews, ensuring code quality and collaborative development across 7 team members.
