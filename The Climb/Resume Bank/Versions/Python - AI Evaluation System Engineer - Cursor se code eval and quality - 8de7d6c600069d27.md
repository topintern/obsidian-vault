- Implemented robust data validation checks and monitoring pipelines for incoming **datasets** using **Python**, ensuring data integrity and consistency, which reduced downstream **model** errors by 18%.

- Designed and deployed **MLOps infrastructure** with **MLflow** and **Docker** for experiment tracking and model versioning, improving deployment frequency by 2x for data scientists.

- Engineered an **experimentation platform** leveraging **A/B testing** methodologies with **Python** and **PostgreSQL** for feature rollouts, driving a 10% increase in user engagement.

- Implemented **RESTful APIs** using **Python** **FastAPI** for real-time model inference and data retrieval, supporting 10K requests per second for critical business applications.

- Optimized **PostgreSQL** database performance and schema for large-scale data ingestion, improving query speeds by 40% while accommodating 20% annual data growth.

- Developed performance monitoring dashboards and alerting systems for **machine learning models** using **Grafana** and **Prometheus**, proactively identifying performance degradations and ensuring operational stability for critical services.

- Collaborated with **data scientists** to operationalize **concrete metrics** and reporting **dashboards** using **Looker** and **AWS S3**, enhancing decision-making accuracy by 25%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | SaaS Platform*

- Developed robust **microservices** using **Java Spring Boot** and **REST APIs** on **AWS EC2** to support new features, accommodating 20% user growth without downtime.

- Designed and implemented **ETL pipelines** with **Python** and **AWS S3** for data synchronization across enterprise systems, reducing manual data reconciliation efforts by 35%.

- Implemented **CI/CD pipelines** using **Jenkins** and **Docker** for automated testing and deployments, accelerating release cycles by 50% for various backend services.

- Contributed to a high-traffic payment processing module using **Java** and **Kafka**, handling 1M transactions daily with 99.99% reliability for financial operations.
