## Professional Experience

**Software Engineer**  |  *Jun 2025 - Present*

*Epik Solutions*

- Shipped full-stack React and TypeScript features for an enterprise AI search platform, owning end-to-end technical decisions from component architecture to Node.js API design for 10,000+ users.

- Designed and optimized Node.js backend services with PostgreSQL, applying query indexing and caching strategies that cut API response times by 40% under concurrent production load.

- Built high-quality TypeScript React interfaces translating product and design requirements into production-ready experiences, reducing front-end bug reports by 32% across enterprise-facing features.

- Hardened full-stack application security with input validation, auth middleware, and OWASP-aligned practices, reducing API-level vulnerabilities by 30% and maintaining compliance across all deployments.

- Drove rapid iteration in a fast-moving engineering environment, delivering 5+ production features per sprint while owning code review, performance profiling, and long-term maintainability decisions.

**Full Stack Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected and shipped full-stack React and TypeScript dashboards helping enterprises analyze AI-driven compliance data, collaborating with design and product to deliver production experiences.

- Built scalable Node.js REST and GraphQL APIs for a multi-tenant platform serving 15+ clients, designing database schemas with PostgreSQL and Redis that sustained 99.9% uptime at peak load.

- Optimized back-end performance across 10+ services using query plan analysis, Redis caching, and connection pooling, reducing average API response time by 45% under concurrent enterprise traffic.

- Owned key architectural decisions for a distributed microservices system including tenant isolation, API versioning, and error boundary design, directly reducing production incidents by 35% over six months.

- Provisioned AWS infrastructure with Terraform and configured CI/CD pipelines across all services, enabling reliable, repeatable deployments and cutting manual release errors by 40% for all clients.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built Python and Node.js data pipeline services on AWS Lambda, applying best practices for scalability and maintainability while managing all versioning via GitHub across 3 production systems.

- Developed TypeScript utility scripts for data validation and transformation, enforcing type safety and reducing cross-system data inconsistencies by 40% across 500+ employee workflows.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered 10+ full-stack features using React, TypeScript, and Node.js REST APIs with PostgreSQL, ensuring accurate data tracking for a regulated scientific cloud platform used by 500+ scientists.

- Designed scalable relational database schemas in PostgreSQL with indexed queries and execution plan analysis, improving application response times by 35% under concurrent production user load.

- Authored 100+ automated test cases, resolved critical production performance bottlenecks through systematic profiling, and enforced code review standards reducing regression incidents by 40%.
