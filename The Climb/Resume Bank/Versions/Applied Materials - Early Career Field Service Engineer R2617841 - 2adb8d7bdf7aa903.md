## Profile

Software engineer transitioning into field service, with experience investigating incidents, validating system behavior, and supporting operational software. Background spans enterprise support workflows, autonomous-system telemetry, and regulated LabOps. Seeking Applied Materials' early-career training pathway to develop semiconductor equipment service skills.

## Skills

**Technical Support**: Incident Triage, Log Analysis, Defect Reproduction, Escalation Workflows, Monitoring

**Testing & Documentation**: Regression Testing, Data Validation, Test Procedures, Release Checklists, Audits

**Tools**: Python, SQL, PostgreSQL, REST APIs, Git, CI/CD, AWS/Azure, PowerShell

**Collaboration**: Customer Requirements, Issue Resolution, QA Partnership, Technical Documentation

## Professional Experience

Software Engineer AI | Jun 2025 - Present | Epik Solutions | Enterprise Security / Incident Triage

- Built an **incident-triage workflow** that consolidated security alerts, logs, and tickets into prioritized summaries, giving operators evidence and recommended actions for investigation and escalation.

- Developed a **review, approval, and escalation interface** backed by Python APIs and PostgreSQL, preserving incident context and audit history across operator handoffs.

- Instrumented **queue depth, response latency, failures, and operator decisions** to expose recurring bottlenecks, contributing to a **35% reduction in repeat triage cycles**.

- Created **regression evaluations across incident categories** and paired automated testing with code review and rollback planning to validate software changes before production release.

Founding Engineer (Full Stack AI) | Jul 2024 - Jun 2025 | Samay Systems LLC | B2B Compliance SaaS

- Delivered and supported a **compliance software platform for 15+ enterprise clients**, translating customer requirements into workflows and resolving issues through production fixes and follow-ups.

- Linked policies, controls, tickets, and supporting documents into **traceable evidence records**, helping users investigate compliance questions with consistent source information.

- Added **job-latency, queue-failure, and evidence-coverage reporting** to identify operational gaps and assess readiness before customer rollouts.

- Implemented **access controls, audit logs, and controlled environment promotion**, protecting customer data while supporting repeatable software releases.

ML / Software Engineering Intern | Jun 2023 - Aug 2023 | Monarch Tractor | Autonomous Systems / Workflow Automation

- Built **Python telemetry pipelines for image, sensor, and field-operations data**, producing validated datasets for analysis and downstream autonomous-system model workflows.

- Automated **identity, device, and data-quality checks** across internal operational systems, reducing provisioning and validation time by **80%**.

Software Engineer | Jul 2020 - Aug 2022 | ZeMoSo Technologies | LabOps / Regulated Workflow Software

- Developed **LabOps software used by 500+ scientists** for sample tracking, inventory, scheduling, and experiment records, supporting reliable day-to-day laboratory workflows.

- Created **exception dashboards** for sample queues, failed uploads, inventory issues, and experiment blockers, reducing support handoffs by making failure context visible to users.

- Added **input validation, background retries, and failure reporting** for uploads and sample-lineage workflows, improving recovery when data processing failed.

- Authored **100+ automated tests** and worked with QA and product teams to reproduce defects, validate fixes, and document deployment behavior for regulated releases.
