## Professional Experience

**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Security Automation Platform*

- Architected and delivered **Python** core services for enterprise security platform, building **RESTful APIs** with **FastAPI** that process 50,000 authentication requests daily across multi-tenant infrastructure.

- Designed and implemented **ReBAC** authorization model using **Python**, evaluating resource ownership and delegation chains to enforce fine-grained contextual access decisions for 500+ enterprise users.

- Integrated **Microsoft Entra ID** (formerly Azure AD) with platform services, implementing **OAuth2** and **SCIM** provisioning to automate identity lifecycle management across 15+ integrated security systems.

- Built foundational data ingestion pipelines on **AWS Lambda** and **S3**, establishing reusable event schemas and telemetry patterns adopted as departmental standards for 10+ downstream services.

- Delivered end-to-end features independently within **agile** sprints, from requirements gathering to production deployment, reducing security incident response time by 15 minutes through **AI-driven** automated triage.

- Built **AI-assisted** security automation using **Azure OpenAI** and **LangChain**, processing 1,000+ daily security events to generate intelligent incident summaries and recommendations that reduced analyst workload by 30%.

- Maintained and optimized **PostgreSQL** database schemas for core security event storage, designing indexes and partitioning strategies that improved query performance by 40% for reporting dashboards.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance Platform*

- Owned and delivered core compliance data services using **Python**, **AWS CDK**, and **PostgreSQL**, defining foundational data models for identity graphs and access relationships used across entire platform.

- Implemented comprehensive **RBAC** and **ABAC** authorization frameworks in **Python**, enforcing tenant isolation and least-privilege access policies that reduced unauthorized access incidents by 30% for enterprise customers.

- Built **Microsoft Entra ID** and GitHub identity sync pipelines using **AWS Lambda** and **Step Functions**, processing 5M+ daily events to maintain real-time access graphs for compliance workflows.

- Designed multi-tenant data architecture with per-tenant **PostgreSQL** schemas and **Neo4j** graph databases, establishing isolation boundaries and data retention policies that met SOC 2 security requirements consistently.

- Built **LLM-powered** compliance automation using **AWS Bedrock** and **LangChain**, orchestrating evidence collection and control testing workflows that reduced manual auditor effort by 70% for SOC 2 assessments.

- Designed **RAG** pipelines for compliance document search using **Pinecone** vector database and **OpenAI** embeddings, enabling natural language queries across 5M+ regulatory documents with sub-second response times.

- Collaborated with cross-functional teams in **agile** environment, launching 8 major features including AI-powered compliance testing, evidence collection automation, and identity access review workflows for B2B customers.

**SDE Intern**  |  *Jul 2023 - Aug 2023*

*Monarch Tractor | Autonomous Agricultural Systems*

- Contributed to MLOps data infrastructure for autonomous tractor systems, processing location telemetry and sensor data to support computer vision model training and real-time navigation algorithms.

- Developed **React** and **Golang** features for internal ML data labeling platform, improving annotation throughput by 20% for training datasets used in production agricultural vehicle deployments.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Scientific Cloud Platform*

- Developed core platform modules using **Python**, **React**, and **Spring Boot**, delivering features for experimental tracking, inventory management, and sample lifecycle workflows serving 500+ laboratory scientists.

- Designed **PostgreSQL** schemas and optimized queries for scientific data management, reducing report generation time by 30% through strategic indexing and query optimization across 10+ product modules.

- Authored 100+ automated test cases using **pytest** and JUnit, established CI/CD pipelines with Jenkins, and resolved critical production issues through systematic debugging in agile development workflow.
