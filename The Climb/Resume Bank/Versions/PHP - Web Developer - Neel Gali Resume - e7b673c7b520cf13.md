## Professional Experience

**Software Engineer**  |  *Jun 2025 - Present*

*Epik Solutions*

- Developed and maintained PHP-based web application modules, writing targeted code patches to fix functionality deficiencies and improve CMS platform performance for 10,000+ enterprise users.

- Enforced secure coding standards across all web application deployments, performing periodic vulnerability testing and implementing WCAG accessibility-compliant UI features across production envs.

- Designed SQL queries and data transformation scripts to ensure compatibility between enterprise application data stores, improving cross-system data integrity and reducing integration errors by 40%.

- Provided technical analysis and support for vendor-hosted enterprise applications, coordinating with vendors to perform upgrades, patches, and database backup procedures ensuring  access and security.

- Administered Linux server environments and configured CI/CD pipelines with Docker and Kubernetes, reducing release cycle time from two weeks to three days across all production systems.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected and deployed Drupal-based web applications for 15+ enterprise clients, writing custom PHP modules and extensions that resolved critical workflow deficiencies and improved functionality by 20%.

- Maintained and updated CMS extensions in response to core application upgrades, applying SQL database queries to transform and migrate data across 10K+ application records monthly.

- Provided technical support and training for vendor-hosted compliance applications, creating documentation and training materials that improved user adoption rates by 70% across all client tenants.

- Built full-stack React web applications integrating PostgreSQL relational schemas and DynamoDB stores, applying formal relational data structure design principles to support 10,000+ concurrent users.

- Configured project management workflows in JIRA and Terraform IaC across 10+ microservices, coordinating with stakeholders to define system requirements and reducing deployment errors by 40%.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Developed Python data ingestion scripts on Linux servers, applying GitHub code versioning to manage version-controlled datasets and improve cross-system data consistency for 500+ employees org-wide.

- Implemented serverless data synchronization services applying SDLC checkpoints, secure coding standards, and input validation, eliminating unauthorized cross-system data exposure across 3 envs.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered 10+ web application feature modules using React and Spring Boot REST APIs, ensuring accurate data integrity for a regulated scientific platform used by 500+ scientists.

- Designed relational database schemas in PostgreSQL with optimized SQL queries and formal relational data structure design, improving application response times by 35% under concurrent scientific user load.

- Authored 100+ automated test cases, resolved critical web application bugs through systematic debugging, and created technical documentation adopted by all 10+ platform module teams organization-wide.
