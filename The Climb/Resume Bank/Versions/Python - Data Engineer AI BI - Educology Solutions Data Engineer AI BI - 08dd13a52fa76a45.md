## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise AI/BI & Data Governance Platform*

- Architected and scaled **Databricks AI/BI** solutions end-to-end, integrating **governed semantic models** with **SQL** and optimized query layers, boosting reporting speed by 35%.

- Developed and operationalized **Databricks Genie experiences** by curating datasets, metadata, and prompts for **natural language analytics**, increasing self-service data access by 40%.

- Designed and delivered complex **Databricks dashboards** and visual products, translating data into clear, actionable insights for stakeholders, improving decision-making accuracy by 25%.

- Implemented and optimized end-to-end **ELT pipelines** on **Databricks** using **Medallion Architecture** principles, reducing data processing latency by 50% for critical systems.

- Built robust and scalable **ETL pipelines** using **Apache Spark** and **Delta Lake**, transforming raw data into trusted curated layers for enhanced analytics, improving data quality by 30%.

- Operationalized **Databricks Workflows** for orchestrating complex dependencies and automating data pipelines, achieving a 99.9% uptime for daily data refreshes.

- Applied advanced **schema evolution** and **data versioning** techniques to support agile data development, ensuring backward compatibility across 10+ major data releases.

- Enforced stringent **data security** best practices including **row-level security** and **fine-grained access control** via **Unity Catalog**, achieving 100% compliance.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Cloud Data Integration & Analytics*

- Developed high-volume **ELT pipelines** using **Python** and **Apache Spark** on **Databricks**, processing 100TB+ monthly data into **Medallion Architecture** layers, reducing processing time 30%.

- Integrated data from enterprise systems like **PeopleSoft** and **Salesforce** using **APIs** and **JDBC** connectors, establishing robust ingestion for critical business data.

- Designed and implemented standardized data ingestion processes with automated error handling and retries, reducing data load failures by 75% across 20+ sources.

- Built **Delta Lake** based data marts and warehousing solutions on **Azure Data Lake Storage (ADLS)**, optimizing storage for performance and cost-efficiency by 20%.

- Developed comprehensive **data quality checks**, validation rules, and anomaly detection mechanisms, ensuring data integrity across all data layers, reducing reporting errors by 40%.

- Integrated **monitoring and observability tools** like **Grafana** to track **ETL** performance, latency, and failures, improving pipeline reliability to 99.95%.

- Implemented **Unity Catalog** for centralized metadata management, data lineage, and governance policy enforcement, enhancing data discoverability and trust by 50%.

- Supported **MLOps lifecycle workflows** using **MLflow** for experiment tracking and model registry, streamlining model deployment within **Databricks** by 30%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Backend Systems & Data Services*

- Developed robust **Python** backend services for data processing and RESTful **APIs**, handling 500K daily requests from various client applications with 99.9% uptime.

- Designed and maintained scalable data ingestion pipelines that processed diverse structured and semi-structured data formats, improving data availability for analytics by 20%.

- Optimized database queries and schemas for a critical transactional system, significantly improving data retrieval performance by 35% for high-traffic applications.

- Implemented automated data validation routines and error reporting mechanisms within ETL processes, reducing manual data discrepancy identification efforts by 60%.

- Contributed to a **CI/CD** pipeline development, automating testing and deployment processes for backend services, reducing release cycle time by 40%.
