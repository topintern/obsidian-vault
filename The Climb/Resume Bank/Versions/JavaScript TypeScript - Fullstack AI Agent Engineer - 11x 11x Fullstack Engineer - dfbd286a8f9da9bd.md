**Senior Software Engineer**  |  *Jul 2025 - Present*

- Led integration of **LangGraph** for complex **agent orchestration**, enabling sequential and parallel task execution within **autonomous digital workers**, boosting workflow efficiency by 25%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise SaaS Platform Development*

- Developed and maintained core backend services using **NodeJS** and **Express.js** for an enterprise **SaaS platform**, processing over 100,000 API requests daily efficiently, increasing system throughput by 15%.

- Implemented responsive UI features with **React** and **Typescript**, enhancing the user experience for complex data dashboards, resulting in a 20% increase in user engagement.

- Designed and optimized **PostgreSQL** schemas for critical application data, improving query performance by 30% and supporting over 5 million customer records reliably for enterprise clients.

- Integrated **AWS S3** for secure document storage and retrieval, managing petabytes of user-generated content, achieving 99.9% availability for key services globally.

- Built robust **CI/CD** pipelines using **GitLab CI** and **Docker** for automated deployments, reducing release cycles from bi-weekly to daily with 95% success rate.

- Refactored legacy modules into scalable **microservices** architecture using **NodeJS**, enhancing maintainability and reducing operational costs by 10% annually for the platform.

- Explored and prototyped integration of **OpenAI API** for internal content generation tools, demonstrating potential for 15% efficiency gain in marketing material creation, post Nov 2022.

- Participated in **Agile** ceremonies and peer code reviews, ensuring high-quality software delivery and fostering **cross-functional collaboration** across product and design teams by 10%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Custom Software Solutions*

- Developed and maintained robust backend services using **Java** and **Spring Boot**, handling critical business logic for enterprise clients, achieving 99.99% uptime reliably.

- Designed and implemented database schemas in **MySQL** for various client applications, optimizing data retrieval operations, reducing average query times by 25% for users.

- Built interactive front-end interfaces using **HTML**, **CSS**, and **JavaScript** with **jQuery**, enhancing user experience for internal dashboards by 15% for productivity.

- Contributed to a modular **RESTful API** architecture, enabling seamless integration with third-party systems and expanding platform functionality by 20% for partners.

- Managed code versions and collaborated effectively using **Git** workflows, ensuring clean merges and efficient team development practices across 5 concurrent projects.

- Deployed applications to **AWS EC2** instances, configuring security groups and load balancers to ensure high availability and reliability for 1000+ daily users.
