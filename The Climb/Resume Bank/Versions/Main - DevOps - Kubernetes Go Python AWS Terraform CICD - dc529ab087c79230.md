- Drove **build-vs-buy decisions** for observability stack, integrating **Prometheus** and **Grafana** into existing **AWS** infrastructure, achieving 25% cost savings.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Distributed Systems & Platform Engineering*

- Developed a scalable data ingestion service using **Kafka** and **Python** on **AWS EC2**, processing 100M events daily, reducing data lag by 60%.

- Implemented **RESTful APIs** for external partners using **Java Spring Boot** on **Azure App Service**, increasing integration capabilities by 40% for new clients.

- Migrated monolithic applications to **microservices architecture** using **Docker** and **Kubernetes** on **GCE**, improving scalability and resilience by 35%.

- Built automated deployment scripts using **Bash** and **Ansible** for **on-prem infrastructure**, reducing manual deployment errors by 80% and deployment time by 50%.

- Designed and optimized **PostgreSQL** databases for high-traffic applications, improving query performance by 25% and ensuring data integrity for 5M active users.

- Collaborated with SRE teams to implement enhanced monitoring with **Grafana** and custom **Python** scripts, identifying system bottlenecks 20% faster.

- Contributed to architectural decisions for a new authentication service, leveraging **OAuth2** and **JWT** for secure user access, decreasing security vulnerabilities by 15%.

- Developed an internal tool using **Go** to manage **AWS S3** buckets and permissions, ensuring compliance and reducing manual administrative tasks by 30%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Enterprise SaaS & Data Integration*

- Developed and maintained data integration pipelines using **Python** and **Airflow** to process large datasets from various sources, improving data availability by 40%.

- Implemented **RESTful APIs** using **Java Spring Boot** for a core enterprise SaaS product, enabling seamless communication between services, supporting 100k daily transactions.

- Optimized database queries and schema designs for **MongoDB**, enhancing data retrieval speed by 30% and supporting 50% more concurrent users.

- Collaborated on a team project to containerize existing applications using **Docker**, reducing environment setup time for new developers by 60%.

- Built automated test frameworks using **Selenium** and **Python** for a web application, increasing test coverage by 70% and reducing defect escape rate by 20%.

- Managed version control using **Git** and configured **Jenkins** for continuous integration, reducing integration issues by 25% and accelerating release cycles.
