## Professional Experience



**Software Engineer AI**  |  *Jun 2025 - Present*

*CIFC Asset Management | Enterprise Security AI*




- Converted noisy **security alerts, logs, and tickets** into a 0-to-1 AI incident triage workflow that produced prioritized summaries, cited evidence, confidence scores, and recommended actions.

- Built the product surface with **React, TypeScript, Python, REST APIs, PostgreSQL, Redis, and AWS**, giving operators a single workflow for review, approval, escalation, and audit history.

- Designed the **RAG, prompt-versioning, and evaluation layer** for duplicate detection, severity reasoning, remediation guidance, and regression testing across incident categories.

- Implemented **RBAC, least-privilege service access, source citations, human approval queues, and structured audit logs** to protect sensitive enterprise security data.

- Instrumented queue depth, LLM latency, failure modes, and operator decisions with CloudWatch, Prometheus, and Grafana, reducing repeat triage cycles by **35%**.

- Packaged reusable AI service patterns for retrieval, workflow state, guardrails, telemetry, and error handling so adjacent teams could ship AI features on the same foundation.

- Accelerated delivery with **Cursor, Claude, GitHub Copilot, and Codex** while enforcing code review, automated tests, eval checks, and production rollback plans.



**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance AI Platform*




- Engineered a **B2B Compliance AI SaaS product** using Python, TypeScript, GraphQL, Lambda, ECS, SQS, PostgreSQL, and Neo4j for **15+ enterprise clients**.

- Modeled policies, evidence, cloud controls, tickets, and documents into a structured compliance graph, enabling AI workflows to return audit-ready answers with traceable sources.

- Built **agentic evidence-review workflows** with AWS Bedrock, Azure OpenAI, LangChain, tool-calling agents, vector search, and eval datasets, cutting manual review effort by **70%**.

- Shipped customer-facing iterations from discovery through design tradeoffs, API/data modeling, implementation, demos, production fixes, and post-launch measurement.

- Added analytics for **AI job latency, queue failures, evidence coverage, and automation gaps**, giving teams a release-readiness view before customer rollouts.

- Implemented tenant isolation, RBAC, audit logging, CI/CD gates, and environment promotion so AI features could ship quickly without weakening customer trust.



**ML / Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Autonomous Systems & Workflow Automation*




- Built **Python telemetry pipelines** that transformed image, sensor, and field-operations data into validated ML artifacts for labeling, analysis, and downstream model workflows.

- Automated identity, device, data-quality, and field-operations checks across UKG, JumpCloud, and Azure AD-style systems, reducing provisioning and validation time by **80%**.



**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies | LabOps / Regulated Workflow SaaS*




- Delivered LabOps workflows in **React, TypeScript, Ruby on Rails, Java Spring Boot, and PostgreSQL** for inventory, sample lineage, scheduling, uploads, and experiment tracking used by **500+ scientists**.

- Built **REST APIs, role-based workflows, audit logs, and validation checks** that improved reliability across regulated scientific data capture and approval flows.

- Optimized backend jobs and SQL queries for high-volume sample events, reducing repeated timeout/debug cycles in daily lab operations.

- Developed **React/TypeScript operational dashboards** for sample queues, upload failures, inventory exceptions, and experiment blockers, reducing support handoffs for lab users.

- Implemented background job retries, validation rules, and failure-state reporting for file uploads and sample lineage workflows, improving recoverability in production paths.

- Added deployment checklists, feature validation notes, and release smoke tests for regulated workflows so QA and infrastructure teams could verify changes consistently.
