## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*EPAM Systems | Distributed Systems & Cloud Infrastructure*

- Architected and implemented a core **Python**-based distributed key-value store using **Redis** on **AWS**, supporting 50M daily transactions with 99.99% availability.

- Developed a schema-less data store utilizing **Apache Cassandra** and **Kafka** for event streaming, reducing data ingestion latency by 45% for critical analytics.

- Designed and deployed a robust **Go**-based authentication and authorization service using **OAuth2** with **Istio** for microservices, securing 20+ internal applications efficiently.

- Enhanced observability and reliability by building distributed logging and tracing with **Prometheus**, **Grafana**, and **Jaeger**, improving incident resolution time by 30%.

- Implemented advanced rate limiting and circuit breaking mechanisms using **Envoy Proxy** on **Kubernetes** to protect services, mitigating 90% of potential cascading failures.

- Led the integration of a distributed configuration management system with hot reloading capabilities via **Consul**, enabling dynamic updates for 15+ microservices instantly.

- Developed an **AWS Lambda**-based system for feature flags and A/B testing, allowing product teams to launch experiments faster, boosting conversion rates by 12%.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Globant | Enterprise Backend Development*

- Engineered scalable microservices using **Java** and **Spring Boot** on **AWS EKS**, processing 100K requests per minute, enhancing system performance by 25%.

- Implemented event streaming pipelines with **Apache Kafka** for real-time data processing, integrating diverse systems and improving data consistency across 5 distinct services.

- Developed robust **RESTful APIs** for a customer relationship platform, facilitating seamless data exchange and improving partner integration efficiency by 20%.

- Optimized **PostgreSQL** database queries and indexing strategies for high-traffic applications, reducing average API response times from 300ms to 80ms.

- Deployed and managed containerized applications using **Docker** and **Kubernetes** on **Azure**, streamlining development workflows and reducing deployment time by 40%.

- Contributed to observability by implementing comprehensive monitoring and alerting using **CloudWatch** and **Splunk**, reducing critical alert response time by 15 minutes.

- Designed and built secure authentication flows using **JWT** tokens for various client applications, enhancing user data protection and reducing unauthorized access incidents by 95%.

- Automated **CI/CD** pipelines with **Jenkins** and **GitLab CI** for continuous deployments, increasing release frequency by 50% while maintaining high quality.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*Nagarro | Web Application & API Development*

- Developed core backend functionalities for an e-commerce platform using **Java** and **Spring**, supporting 50K concurrent users effectively during peak seasons.

- Implemented and maintained **RESTful APIs** for mobile and web clients, ensuring data integrity and enabling a 30% faster feature delivery cycle for frontend teams.

- Designed and optimized relational database schemas in **MySQL** for application features, improving query performance by 35% and supporting growing data volumes.

- Collaborated on bug fixes and performance tuning for existing systems, utilizing profiling tools to decrease system latency by an average of 15% across key modules.

- Integrated third-party payment gateways and services, ensuring secure transactions and expanding payment options for users, resulting in a 10% increase in successful purchases.
