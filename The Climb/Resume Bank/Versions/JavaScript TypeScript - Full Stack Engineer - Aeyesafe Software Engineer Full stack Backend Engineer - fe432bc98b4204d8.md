**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | B2B Platform*

- Developed backend services with **Python** and **Django REST Framework**, handling high-volume data processing and integrating third-party APIs efficiently for 500 daily requests.

- Migrated on-premise data stores to **AWS S3** and **DynamoDB**, reducing operational costs by 30% and enhancing data availability for analytics platforms.

- Optimized database performance by writing efficient **SQL** queries for **MySQL**, decreasing query execution times by 30% for critical business intelligence reports.

- Collaborated on full-stack feature development, from **JavaScript** frontend to **Flask** backend, delivering new functionalities 15% faster in an an agile environment.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | SaaS Platform*

- Developed interactive web pages using **HTML5**, **CSS3**, and vanilla **JavaScript**, enhancing user engagement for client portals by 18% with new features.

- Designed and implemented **RESTful APIs** using **Java** and **Spring Boot**, facilitating data exchange between various microservices and improving system interoperability by 20%.

- Managed and optimized relational databases with **SQL Server**, performing data migrations and ensuring data consistency for applications supporting 10,000 transactions daily.

- Contributed to a high-traffic e-commerce platform by developing robust backend logic in **Python** using **Flask**, supporting 500 concurrent users effectively.

- Collaborated closely with QA teams to identify and resolve software defects using **Jira**, contributing to a 15% reduction in post-deployment issues and faster releases.
