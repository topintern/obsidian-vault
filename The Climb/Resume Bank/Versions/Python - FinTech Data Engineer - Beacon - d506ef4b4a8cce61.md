## Summary

## Professional Experience


**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise FinTech Platform*




- Built a **Python** market data ingestion framework processing real-time equity, options, and futures tick feeds with normalization, deduplication, and configurable alert thresholds across 15+ instruments.

- Developed a **Python** time series framework for storing and querying high-frequency OHLCV data, integrating **TimescaleDB** to achieve sub-10ms response on 3 years of historical data.

- Built trade ingestion microservices in **Python** handling 50K+ high-frequency trade events per second via **Kafka**, with idempotent processing, DLQ error handling, and audit trail persistence.

- Integrated three third-party market data vendor APIs into the platform ingestion layer, building **Python** adapters with retry logic, circuit breakers, and vendor-specific protocol normalization.

- Extended the platform application deployment framework with a **Python** plugin system, enabling engineers to register custom data processors and schedule jobs with zero configuration changes.



**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | B2B Data & Compliance Platform*




- Built **Python** ETL pipelines on **AWS Lambda** and **S3** processing 10M+ daily compliance records, reducing data ingestion lag from 4 hours to under 20 minutes.

- Architected **Kafka**-based event streaming for real-time compliance data synchronization across microservices, adding **Redis** caching layer that reduced downstream API latency by 65% under peak load.

- Designed **PostgreSQL** relational schemas and **MongoDB** document collections for a dual-store compliance system, optimizing each to its query patterns and reducing ORM overhead by 40%.

- Integrated seven third-party compliance data providers via REST and SFTP adapters in **Python**, building idempotent reconciliation logic that automatically detected and resolved cross-system data discrepancies.

- Tuned **Python** data pipeline throughput with connection pooling, batched writes, and async I/O, sustaining 3x data volume growth without additional infrastructure scaling or latency degradation.



**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps Platform*




- Developed **Python** REST APIs for a regulated LabOps platform, applying data structures and algorithms to streamline sample processing and reduce API response times by 35%.

- Authored optimized **PostgreSQL** queries and stored procedures for multi-step lab sample tracking, reducing report generation time by 30% through strategic index tuning and query denormalization.

- Built **Java Spring Boot** microservices alongside **Python** services, demonstrating cross-language fluency and maintaining 75%+ test coverage with JUnit and pytest suites across the full stack.
