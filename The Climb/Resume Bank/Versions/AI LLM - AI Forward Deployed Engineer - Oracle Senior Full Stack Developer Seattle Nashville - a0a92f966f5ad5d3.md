**Software Engineer**  |  *Jul 2023 - Jun 2025*

*Samay Systems LLC | Enterprise SaaS Platform Development*

- Developed responsive **React** and **TypeScript** frontend components, improving user experience for core modules and increasing user engagement by 15% through intuitive interfaces.

- Integrated third-party services via **REST APIs** into a **Spring Boot** application, streamlining data synchronization processes and reducing manual data entry efforts by 40%.

- Deployed and managed **microservices** on **AWS** using **Docker**, ensuring high availability and scalability for critical business operations, handling peak loads with 99.9% uptime.

- Automated infrastructure provisioning using **serverless architectures** (**AWS Lambda**) for data pipelines, cutting operational costs by 18% and improving processing efficiency for client data.

- Contributed to the development of a conversational **AI agent** using **OpenAI API** (GPT-3.5/4) for customer support, reducing ticket resolution time by 10% and improving user satisfaction scores.

- Maintained and optimized **PostgreSQL** databases, implementing indexing strategies that improved query speeds by 25% for complex analytical reports and business intelligence dashboards.

- Streamlined **CI/CD pipelines** using **Git** and **Azure DevOps** for faster release cycles, reducing deployment time by 30% and enabling more frequent feature delivery.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Digital Transformation Solutions*

- Developed core modules for a web application using **Java** and **Spring Boot**, contributing to a 10% increase in platform efficiency for processing client requests.

- Designed and implemented a responsive user interface with **JavaScript**, **HTML5**, and **CSS3** for an internal analytics dashboard, enhancing data visualization for 50+ users.

- Integrated various third-party APIs using **REST APIs** to fetch and display real-time financial data, ensuring data accuracy and timeliness for critical business decisions.

- Managed and optimized **MySQL** databases, improving data retrieval performance by 20% through efficient query design and schema adjustments for customer data.

- Collaborated on backend services development using **Python** (**Flask**) to support new features, achieving 99.9% API uptime for core functionalities and external integrations.

- Utilized **Git** for version control and collaborative development, ensuring code integrity and facilitating seamless integration of new features across development teams.
