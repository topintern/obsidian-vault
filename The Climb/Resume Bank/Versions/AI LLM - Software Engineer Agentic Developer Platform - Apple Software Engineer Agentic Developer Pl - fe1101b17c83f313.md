## Summary

Software Engineer with 4+ years building **agentic AI systems**, **developer productivity platforms**, and scalable **Java**/**Python** backend services across **LangGraph**, **LangChain**, **Kubernetes**, **Kafka**, and **CI/CD**; experienced translating engineer pain points into production tools for code review, testing, deployment orchestration, and workflow automation.

## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Security Platform*

- Built **LangGraph**-powered developer agents for an **enterprise security platform**, classifying flaky tests vs. real regressions and surfacing root-cause context, reducing developer debug time by **40%**.

- Developed **Python** and **Java** backend APIs for agent-assisted **code review**, test selection, and deployment readiness workflows used across **12+** security engineering pipelines.

- Implemented a **LangChain**/**OpenAI API** GitHub bot for PR triage, inline review suggestions, and stale-build detection, cutting manual CI re-trigger overhead and review turnaround by **35%**.

- Designed agent evaluation gates tracking **accuracy**, **latency**, groundedness, and false-positive review feedback, promoting only reliable AI workflows into production **CI/CD**.

- Built agent-driven **deployment orchestration** workflows that checked build status, service ownership, and rollout risk before releases, reducing failed production deploys by **25%**.

- Instrumented **GitHub Actions**, **Jenkins**, and **Kubernetes** runners with **OpenTelemetry**, publishing build health dashboards that improved incident diagnosis across **20+** services.

- Created secure **tool-calling** interfaces for autonomous agents to query builds, test history, and service metadata, improving self-serve developer insights for **100+** engineers.

- Partnered with PMs, SREs, and developers to convert workflow friction into maintainable platform features, reducing new engineer time-to-first-build from days to under **2 hours**.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B AI Compliance SaaS Platform*

- Built **Java Spring Boot** and **Python FastAPI** microservices for a **B2B AI compliance SaaS platform**, sustaining **99.9%** uptime across tenant workflows and internal tooling.

- Designed **LangChain** and **LangGraph** agent orchestration for evidence collection, document classification, and audit-trail summarization across **10K+** monthly compliance records.

- Engineered **Kafka** event-driven services with dead-letter queues, idempotent consumers, and retry logic, decoupling **6+** services and improving peak processing throughput by **50%**.

- Created internal developer tooling in **Python**, **Go**, and **TypeScript** for service scaffolding, API contract checks, and environment validation, reducing onboarding toil by **40%**.

- Integrated **LlamaIndex**-style retrieval tools with compliance APIs, enabling agents to fetch tenant evidence, validate citations, and return structured outputs for **15+** enterprise clients.

- Provisioned **Docker**/**Kubernetes** workloads with **Terraform** and **GitHub Actions**, adding automated rollback paths that reduced AI deployment errors by **40%**.

- Optimized **PostgreSQL** and **Redis** data models for agent context, audit events, and user permissions, cutting compliance report generation time by **70%**.

- Collaborated with product managers and compliance stakeholders to translate domain requirements into resilient APIs, agent tools, and user workflows shipped across **15+** enterprise clients.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps Platform*

- Built **Java Spring Boot** and **Python** **REST APIs** for a regulated **LabOps SaaS platform**, supporting experiment and sample tracking for **500+** scientists.

- Developed **React.js** and **TypeScript** workflows connected to async backend APIs, improving data-entry speed across **10+** LabOps product modules.

- Authored **JUnit**, **pytest**, and integration tests for backend services, raising coverage from **45%** to **75%** and reducing production regressions by **35%**.

- Configured **Jenkins** and **GitHub Actions** pipelines for build, test, artifact publishing, and staged deployment, reducing environment-related release failures by **30%**.

- Built **Python**/**Bash** utilities for schema migrations, seed data, and local service startup, cutting repeated developer setup tasks by **40%** across LabOps teams.

- Created reusable **OpenAPI** contracts and service templates for **Java**/**Python** APIs, reducing integration defects by **20%** across LabOps modules.

- Designed normalized **PostgreSQL** schemas and query paths for experiment metadata, improving high-read retrieval performance by **30%** for concurrent lab users.

- Participated in code reviews, architecture discussions, and production troubleshooting for **Linux**-hosted services, strengthening maintainability and reliability across regulated workflows.
