## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Application Operations & Support*

- Led development of robust **Oracle PL/SQL** packages for critical business logic, integrating with **ServiceNow** for incident management, improving data integrity and system reliability by 25%.

- Designed and implemented complex **Unix Shell Scripts** for automated data backups and system health checks, leveraging **Control-M** for scheduling, reducing operational overhead by 20% across environments.

- Provided expert **applications production support**, resolving high-priority issues using **AppDynamics** for performance monitoring, reducing incident resolution time by 30% and ensuring business continuity.

- Collaborated with cross-functional teams in an **Agile environment** to refine system requirements, delivering enhancements to the **annuity policy administration** platform, increasing processing efficiency by 18%.

- Performed extensive **performance tuning** of **Oracle** databases and **PL/SQL** code, optimizing query execution plans, resulting in a 40% reduction in reporting generation time for key stakeholders.

- Conducted **Client-interaction** sessions to gather feedback and provide technical solutions, managing expectations effectively and leading to a 95% client satisfaction score for project deliveries.

- Spearheaded **release management** processes, coordinating deployments across environments using **Serena Dimensions** and **JIRA**, ensuring zero rollback incidents over 15 major releases.

- Developed advanced **troubleshooting** guides and knowledge base articles for complex system issues, empowering junior engineers and decreasing average ticket escalation by 15%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Core Banking System Development & Support*

- Developed and maintained complex **Oracle PL/SQL** procedures for financial transaction processing, ensuring compliance with regulatory standards, resulting in zero audit findings over three years.

- Wrote and optimized efficient **Unix Shell Scripts** for nightly batch job automation and data transformation tasks, significantly reducing manual intervention by over 60%.

- Participated in **Agile** sprints, contributing to the design and implementation of new features for the banking platform, enhancing user experience and system reliability by 20%.

- Provided **applications production support** for critical banking systems, diagnosing and resolving issues promptly, maintaining a 99.9% uptime for core services.

- Implemented **change management** protocols for database schema updates and application deployments, ensuring seamless transitions with minimal downtime, achieving 98% successful deployments.

- Utilized **JIRA** for issue tracking and project management, collaborating with developers and QA to resolve defects, reducing bug re-open rates by 25% across 10+ projects.

- Assisted in **Client-interaction** to understand business requirements for system enhancements, translating needs into technical specifications, improving project clarity and reducing rework by 15%.

- Conducted thorough **data processing** and migration using **SQL** and **PL/SQL** scripts, ensuring data integrity during system upgrades, successfully transferring 100GB of historical data.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Enterprise Resource Planning Solutions*

- Developed core functionalities for an **ERP** module using **Oracle PL/SQL**, handling inventory management and order processing, improving data consistency across 5 departments.

- Authored and maintained **Unix Shell Scripts** for automated report generation and routine system maintenance tasks, decreasing manual processing time by 35% weekly.

- Performed database queries and scripting using **SQL** to extract, transform, and load data, supporting various business intelligence initiatives, processing over 50,000 records daily.

- Engaged in system monitoring and initial **troubleshooting** of application issues on **Linux** servers, escalating complex problems to senior engineers, maintaining 99% system availability.

- Collaborated with team members in an **Agile** framework to develop features and resolve bugs, contributing to on-time delivery for 8 major sprint cycles.

- Documented technical specifications and user manuals for implemented features, facilitating smoother onboarding for new team members and reducing support queries by 10%.
