## Summary




Automation Engineer with 1.5 years of experience designing cloud-native infrastructure, setting up DevOps pipelines, and building intelligent automation using Python, YAML, and AI workflows. Hands-on with CI/CD practices, IaC, and agentic AI systems using tools like GitLab, Terraform, Ansible, and n8n. Skilled at orchestrating scalable workflows across AWS and Azure, driving automation-first culture.

## Professional Experience



**Samay Systems LLC**  |  *Feb 2025 - Present*

**Automation Engineer (Cloud & Compliance Automation)**

*Project: Compliance Platform (SaaS) – Security & Compliance Automation*



- Developed PowerShell modules to automate evidence collection from AWS CloudTrail, Azure Logs, and GitHub Audit Logs.

- Built Power Automate and n8n workflows for multi-system compliance checks via REST APIs (Jira, GitHub, Azure AD).

- Designed Power BI reports using DAX and DirectQuery for real-time SOC 2 and HIPAA control tracking.

- Implemented AWS Lambda (Python), EventBridge, and Step Functions to schedule tasks and send alerts.

- Automated IAM provisioning via Microsoft Graph API with Slack webhook notifications.

- Partnered with compliance teams to reduce audit prep time by 40%.



**Arvam Tech**  |  *Jul 2023 - Present*

**Automation Engineer**

*Project: Enterprise Asset Management System*



- Built PowerShell scripts to automate CMDB updates and validate asset configs using JSON schema.

- Developed n8n workflows to sync asset inventory and process webhook-driven events.

- Integrated Power BI dashboards with gateway refresh for asset tracking and usage metrics.

- Used Power Automate to route asset approvals and escalate issues via Teams and SharePoint.

- Configured Jenkins jobs with Groovy and shell scripts to enforce tagging compliance.



**RHYM Tech**  |  *Aug 2022 - May 2023*

**Automation Engineer**

*Project: Cybersecurity Threat Intelligence Platform*



- Created PowerShell scripts for threat detection using Windows Event Logs and Linux syslogs.

- Built Python pipelines to ingest Splunk and Kafka data into MongoDB.

- Developed Power BI dashboards using custom connectors for threat trend visualization.

- Integrated n8n to auto-create Jira tickets, tag CVEs, and alert via Slack.

- Managed conditional access and credential rotation using Azure AD Graph API.



**ZeMoSo Technologies**  |  *Jul 2021 - Aug 2022*

**Automation Developer**

*Project: Biotech LabOps Automation*



- Automated lab workflows using PowerShell, REST APIs, and CSV processors.

- Integrated OAuth2-secured APIs for RBAC control in lab pipelines.

- Built Power Automate flows for experiment approvals and lab availability checks.

- Designed Power BI dashboards with Power Query to visualize experiment KPIs.

- Created reusable n8n workflows for task orchestration and CRM syncing.




## Projects



**Compliance Automation Platform – Samay Systems**

**Tech Stack**: PowerShell, Python, AWS, Power BI, n8n, PostgreSQL

Designed serverless, fully automated compliance platform. Used PowerShell for scheduled data scraping and orchestration.

**Enterprise Asset Management Automation – Arvam Tech**

**Problem**: Manual asset tracking was inefficient.

**Solution**: Automated data flows with PowerShell + Express.js, integrated Power BI, and used Power Automate for approval chains.

**Real-Time Threat Dashboard – RHYM Tech**

**Problem**: Poor visibility into threats and incidents.

**Solution**: Built Kafka/Splunk ingestion pipelines with Power BI dashboards and automated incident responses.
