## Professional Experience



**Software Engineer AI**  |  *Jun 2025 - Present*

*Epik Solutions | Enterprise Security & Operational Workflow Platform*




- Built **Go and Python microservices** integrating enterprise platform APIs, automating high-trust workflows for **500+ users** and reducing mean time to resolution by **15 minutes**.

- Designed **event-driven reconciliation pipelines** that compared internal state, downstream API responses, telemetry events, and manual overrides to surface mismatches before they became production incidents.

- Developed **React/TypeScript dashboards** for audit trails, operational reporting, data quality checks, and exception queues across **15+ backend systems**, eliminating **20+ hours/week** of manual reporting.

- Implemented **idempotent processing, retry-safe jobs, and deterministic recovery** for workflow automation, reducing duplicate processing and inconsistent state across distributed services.

- Deployed services with **Docker, Kubernetes, Terraform, and GitHub Actions**, improving pipeline success rates by **25%** while strengthening validation, logging, and rollback paths.

- Partnered with product, QA, DevOps, and operators to translate ambiguous workflow requirements into concrete API behavior, test coverage, documentation, and release-ready features.



**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance AI Platform*




- Architected a **multi-tenant SaaS platform** on AWS serving **15+ enterprise clients** and **10,000+ users/org**, owning backend architecture, tenant isolation, and release reliability in a fast-moving startup.

- Designed **ledger-style state models** and database validation for audit workflows, ensuring every evidence, identity, policy, and reporting change had traceable source-of-truth history.

- Built **regulatory reporting and audit-trail surfaces** with React, GraphQL, PostgreSQL, and Neo4j, giving enterprise reviewers clear visibility into compliance status and operational exceptions.

- Developed **distributed data pipelines** ingesting **5M+ daily identity events**, adding reconciliation logic across cloud systems, graph data, document stores, and customer-facing reports.

- Productionized AI-assisted workflows using **AWS Bedrock, Azure OpenAI, LangChain, and RAG**, reducing manual evidence review by **70%** while keeping citations, review queues, and human approval paths.

- Deployed **17 AWS CDK stacks** across Lambda, ECS Fargate, AppSync GraphQL, SQS, S3, RDS, and Secrets Manager, establishing reproducible environments and CI/CD release patterns.



**ML / Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Physical AI & Autonomous Systems*




- Built **Python telemetry pipelines** for sensor, image, and field-operation datasets used in autonomous perception workflows, converting raw physical-world data into validated artifacts.

- Delivered React and Go features for internal **MLOps data labeling tools**, improving annotation throughput by **20%** for computer-vision model iteration.



**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies | LabOps / Scientific Workflow Platform*




- Delivered **full-stack LabOps features** using React, Ruby on Rails, Java Spring Boot, and PostgreSQL for experiment tracking, inventory, batch processing, and sample metadata used by **500+ scientists**.

- Designed workflows across **10+ product modules** including compounds, LCMS uploads, container linkage, and review queues, improving correctness across dependent scientific records.

- Built REST APIs, audit logs, and database validation around regulated data changes, strengthening traceability, reconciliation, and operational reporting for scientific workflows.

- Optimized PostgreSQL and MySQL queries for complex reports, reducing generation time from **2 minutes to 15 seconds** while improving data integrity checks and support visibility.

- Authored **100+ automated tests**, resolved critical production issues, and integrated Jenkins CI/CD gates for high-trust releases in an Agile engineering team.
