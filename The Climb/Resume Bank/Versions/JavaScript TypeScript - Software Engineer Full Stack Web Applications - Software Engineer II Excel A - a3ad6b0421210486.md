## Summary





- Software Engineer with 3+ years of experience delivering user-facing web applications and cloud-backed services at scale.

- Experienced working end-to-end across frontend, backend, and cloud infrastructure, collaborating closely with product managers, UX designers, and partner engineering teams to ship high-quality features with speed and consistency.




## Skills


**Frontend**: HTML5, CSS3, JavaScript, TypeScript, React

**Backend**: Python, C#, Java, RESTful APIs

**Cloud Platforms**: Microsoft Azure (App Services, Functions, Storage), AWS (S3, Lambda, EC2, CloudWatch, Terraform)

**Web & Application Engineering**: Responsive UI, accessibility fundamentals, client–server architecture

**Engineering Practices**: Modular design, reusable components, code reviews, automated testing, CI/CD

**Reliability & Operations**: Monitoring, logging, incident response, live-site support

## Professional Experience



**Epic Solutions**  |  *Jul 2025 - Present*

**Software Engineer II**

*Cloud-Backed Web Applications*



- Delivered end-to-end user-facing features by designing React-based UI components backed by scalable cloud APIs, enabling customers to complete core workflows efficiently.


- Built reusable frontend and backend components to reduce duplication and improve consistency across features, accelerating delivery while maintaining quality.


- Designed and implemented RESTful services in Azure to support UI workflows, focusing on low latency, fault tolerance, and secure data access.


- Instrumented applications with telemetry and monitoring to understand user behavior, detect regressions, and guide iterative improvements based on real usage data.


- Partnered with product managers and UX designers to translate customer needs into well-scoped engineering tasks and intuitive, accessible user experiences.


- Operated services in production by participating in on-call rotations, diagnosing issues, and implementing post-incident improvements to enhance reliability.



**Samay Systems LLC**  |  *July 2024 - Jun 2025*

**Software Engineer I**

*Product Engineering & Automation Team*



- Developed modern web application features using HTML5, CSS, JavaScript/TypeScript, and React, ensuring responsive design and cross-browser compatibility.


- Implemented backend APIs and data access layers to support UI-driven workflows, balancing correctness, performance, and maintainability.


- Applied clean, modular design principles to break down complex requirements into composable components that were easy to test and evolve.


- Contributed to code reviews, automated testing, and CI/CD pipelines, improving code quality and reducing defects reaching production.


- Collaborated across engineering teams to integrate shared services and deliver cohesive user experiences across product boundaries.



**Monarch Tractor**  |  *Jun 2023 - Aug 2023*

**SDE Intern**

*Enterprise Cloud Services*



- Prototyped web and service components supporting customer-facing applications, gaining hands-on experience with full-stack development.


- Implemented UI enhancements and backend integrations to improve usability and reliability of internal tools.


- Supported production deployments by validating application behavior, monitoring early usage signals, and addressing issues discovered after release.




**ZeMoSo Technologies**  |  *Jul 2021 - Aug 2022*

**Associate Developer**

*Biotech LabOps*



- Designed and implemented backend APIs supporting high-volume application workflows, emphasizing correctness, performance, and security.

- Built data-backed features that required efficient querying, transformation, and response-time guarantees under concurrent access.

- Worked closely with frontend engineers to ensure backend systems supported accessible, responsive user experiences, including predictable latency and clear error semantics.

- Participated in on-call support and post-incident analysis, strengthening skills in debugging, root-cause analysis, and long-term fixes.

- Participated in system debugging and production support, strengthening operational reliability.




## Projects



**Customer Workflow Web Portal**




- Designed and implemented a web portal that abstracted complex backend processes into a simple, task-oriented UI, improving customer efficiency and reducing support requests.


- Built reusable React components and cloud APIs to support rapid feature iteration while maintaining consistency and reliability.


**Application Monitoring & Insights Dashboard**




- Developed dashboards to visualize application health, usage patterns, and error trends, enabling teams to identify issues early and prioritize improvements.

- Integrated telemetry from frontend and backend services to provide a holistic view of user experience and system performance.


**System Health & Monitoring Framework**




- Built a Python-based monitoring layer to track latency, error rates, and throughput.


- Enabled faster incident diagnosis and improved overall system stability.
