**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise SaaS & AI Integration*

- Developed **backend systems** in **Java** and **Spring Boot** for a **SaaS** platform, supporting **API** integrations with external partners, improving data exchange latency by 20%.

- Engineered **RESTful APIs** using **Spring WebFlux** to power **content consumption** for enterprise clients, achieving 99.9% **system reliability** for critical operations.

- Utilized **Python** and **OpenAI API** for **generative AI** text summarization within a data product, enhancing user productivity by 15% for report generation.

- Optimized **database performance** for large-scale **PostgreSQL** instances, leading to a 25% reduction in query times across complex **reporting** dashboards.

- Implemented **CI/CD pipelines** using **Jenkins** and **Docker** for **backend systems**, automating deployments and reducing release cycle time by 30%.

- Collaborated on designing **service-based architectures** for new modules, ensuring **scalability** and maintainability for future feature expansions, supporting 50K users.

- Wrote **clean, maintainable code** and comprehensive unit/integration tests for **Java** applications, contributing to a 10% reduction in production bugs.

- Monitored **production systems** using **Prometheus** and **Grafana**, proactively identifying and resolving **performance** bottlenecks, minimizing downtime by 15%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | B2B Digital Transformation Services*

- Developed **backend systems** using **Java** and **Spring Boot** for **B2B** digital solutions, processing high volumes of transactional data with 99.8% uptime.

- Designed and implemented **RESTful APIs** for client-facing applications, enabling seamless integration with third-party services, increasing data throughput by 20%.

- Optimized **SQL** queries and **PostgreSQL** schemas for improved **database performance**, reducing average response times for critical services by 30%.

- Participated in **code reviews** and advocated for **clean, maintainable code** standards, improving overall code quality and reducing technical debt by 15%.

- Deployed and managed **backend systems** on **AWS EC2** instances, ensuring **system reliability** and security compliance for sensitive customer data.
