## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Tax Technology Platform*

- Led architectural redesign of core **Python/Django** tax filing microservices on **AWS Lambda**, improving processing efficiency for 10M user tax computations by 30%.

- Optimized database queries and **Django ORM** operations for critical data pathways, leveraging **PostgreSQL** to enhance platform response times by 45%.

- Implemented robust **CI/CD** pipelines using **GitHub Actions** for automatic deployment to **AWS EC2** instances, reducing release cycles from bi-weekly to daily.

- Designed and developed a scalable **REST API** using **Django Rest Framework** for external partner integrations, facilitating secure data exchange with 50+ clients.

- Integrated **Prometheus** and **Grafana** for real-time **event analytics** and system monitoring across **AWS** cloud-based infrastructure, preempting 90% of potential outages.

- Mentored junior engineers on best practices in **Python** development, **Docker** containerization, and **Agile methodologies**, fostering team skill growth by 25%.

- Executed performance optimization initiatives across backend services using **Celery** and **Redis** caching, handling 200K concurrent users during peak tax season.

- Developed a secure user authentication system with **JWT** and **RBAC** for consumer finance data, ensuring compliance and protecting sensitive financial information for 5M users.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | FinTech Data Platform*

- Developed and maintained **Python/Django** web applications for consumer finance data analytics, enhancing platform stability and processing capabilities for 500K transactions daily.

- Designed and implemented scalable **ETL** pipelines on **AWS S3** and **Lambda** functions, processing terabytes of financial data, achieving 99.9% data integrity.

- Built dynamic front-end features using **JavaScript** and **jQuery** for interactive dashboards, significantly improving user engagement and data visualization by 20%.

- Configured and managed **PostgreSQL** databases on **AWS RDS**, optimizing schema and queries to support high-volume transactions and complex financial reporting.

- Automated server deployments and configuration management using **Fabric** scripts on **Linux** instances, reducing deployment time by 75% for critical updates.

- Implemented unit and integration tests for new features with **Pytest** and **Selenium**, ensuring code quality and reducing production bugs by 40% across modules.

- Contributed to migration of monolithic architecture to microservices on **AWS EC2** and **Docker**, improving system resilience and service isolation by 35%.

- Collaborated on system design for new data ingestion services, focusing on fault tolerance and scalability using **Kafka** for real-time event streaming across financial systems.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Web Application Development*

- Developed robust web applications using **Python** and **Django** for various client projects, handling complex business logic and data models for 10+ applications.

- Implemented user-facing features and interactive UI components using **JavaScript** and **jQuery**, enhancing front-end responsiveness and user experience by 25%.

- Designed and consumed **REST APIs** for seamless data communication between front-end and back-end systems, improving application integration capabilities for clients.

- Managed and optimized **MySQL** databases for application data storage, ensuring data consistency and query performance for high-traffic web solutions.

- Configured and deployed web applications to production environments on **Linux** servers using **Nginx** and **Gunicorn**, ensuring 99.9% uptime for client services.
