## Professional Experience

**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Security Platform*

- Architected and led development of core **Python** backend services for an **enterprise security platform**, powering **AI-driven security workflows** that process **50,000+ daily events** for enterprise clients.

- Owned end-to-end feature delivery from **ambiguous requirements** to production, working directly with internal stakeholders to translate open-ended problems into shipped systems within **tight sprint cycles**.

- Built **AI-assisted security automation** using **LangChain** and **Azure OpenAI**, generating real-time recommendations that reduced **manual analyst workload by 30%**.

- Designed and optimized **PostgreSQL** schemas and **REST APIs** (**Django REST Framework**) supporting **500+ concurrent users** with **sub-second response times**.

- Implemented **CI/CD pipelines** and containerized deployments (**Docker**, **Kubernetes**) for **production-critical services**, maintaining **99.9% uptime**.

- Built internal **monitoring and observability dashboards** (**Prometheus**, **Grafana**) for production services, cutting **mean-time-to-detect for incidents by 25%**.

**Founding Engineer (Full Stack)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance AI Platform*

- Joined as a **founding engineer** to build a **multi-tenant AI compliance SaaS platform** from the ground up using **Python/Django**, **AWS**, and **PostgreSQL**, scaling to **10,000+ users** with strict tenant isolation.

- Owned the full stack across **data models, APIs, and frontend** (**React**) - moving fluidly between architecture decisions and hands-on implementation as an early engineer.

- Built **LLM-powered compliance automation** (**LangChain**, **RAG pipelines** over **Pinecone**) that reduced **manual auditor effort by 70%** for enterprise customers.

- Developed robust **distributed backend services** with strict **data isolation**, supporting **15+ enterprise clients** in a fast-paced startup environment.

- Designed core **data ingestion pipelines** (**AWS Lambda**, **Step Functions**) to process **real-time operational events**, powering downstream analytics and reporting for enterprise customers.

- Implemented **CI/CD pipelines** and automated testing (**pytest**, **GitHub Actions**), reducing **deployment time by 35%** and enabling **weekly release cycles**.

- Collaborated directly with early customers and cross-functional teams to prioritize and ship **8+ major features** in an **agile, fast-moving startup environment**.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Autonomous Agricultural Systems*

- Contributed to **MLOps data infrastructure** for **autonomous tractor systems**, processing **location telemetry and sensor data** to support **computer vision model training** and real-time **navigation algorithms**.

- Developed **React** and **Golang** features for an internal **ML data labeling platform**, improving **annotation throughput by 20%** for training datasets used in production **robotics deployments**.

**Full Stack Developer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps / Laboratory-as-a-Service (SaaS)*

- Built and maintained **Python/Django** web applications and **REST APIs** powering a **LabOps SaaS platform**, supporting **inventory management**, experimental tracking, and sample lifecycle workflows for **500+ scientists**.

- Designed **PostgreSQL** schemas and optimized queries, reducing **report generation time by 30%** through indexing and query optimization across **10+ product modules**.

- Developed responsive frontend features using **React** and **JavaScript**, improving usability and data visualization for internal **analytics dashboards**.

- Authored **100+ automated tests** (**pytest**) and established **CI/CD pipelines** (**Jenkins**), resolving production issues through systematic debugging in an **agile environment**.

- Integrated third-party APIs for **lab equipment and vendor systems**, expanding platform capabilities and improving **data exchange reliability by 20%**.

- Participated in the full **software development lifecycle** - requirements gathering, code review, testing, and deployment - contributing to **12+ feature releases annually**.
