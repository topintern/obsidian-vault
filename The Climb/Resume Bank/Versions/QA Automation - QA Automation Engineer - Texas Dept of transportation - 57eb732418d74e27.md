## Summary





- Senior QA Automation Engineer with 6+ years of experience designing and executing end-to-end quality assurance strategies across enterprise applications. 

- Proven ability to independently own **test planning, automation frameworks, system integration testing, and UAT for complex systems**.

- Strong background in **Selenium automation** using **Java, test management tools (Xray, Zephyr, TestRail)**, and defect tracking using **Jira** and **Azure DevOps**, ensuring reliable releases through disciplined testing and documentation.




## Skills


**Automation Testing**: Selenium WebDriver, TestNG, JUnit, Java, Cypress

**Manual Testing**: System Testing, System Integration Testing (SIT), UAT

**Scripting & Automation**: PowerShell, Python, Bash, Power Automate, VBScript, VisualCV

**Test Design & Documentation**: Test Plans, Test Scenarios, Test Cases, Traceability Matrices

**Test Management**: Xray, Zephyr, TestRail

**Defect Management**: Jira, Azure DevOps, HP ALM / Octane

**CI/CD & Execution**: Maven, Git, Jenkins

**APIs & Tools**: Postman, REST APIs

**Databases & Data Management**: SQL (MySQL, PostgreSQL), NoSQL (MongoDB, DynamoDB)

**Methodologies**: Agile, Scrum, SDLC

**Operating Systems**: Windows Server, Linux (Ubuntu, CentOS), macOS 


## Professional Experience



**Epik Solutions**  |  *Jun 2025 - Present*

**Senior QA Automation Engineer**




- Designed automation frameworks using Selenium with Java to reduce repetitive regression cycles and enable faster validation of business-critical workflows.


- Authored detailed test plans, test cases, and execution reports to ensure traceability from requirements through UAT sign-off.


- Executed System Integration Testing (SIT) across multiple dependent systems to validate data flows and service interactions.


- Logged, tracked, and resolved defects using Jira, collaborating with developers to reproduce issues and verify fixes.


- Maintained test execution status and defect metrics in Xray, enabling stakeholders to make informed go/no-go decisions.


- Built Power Automate flows and Power Apps solutions with Dataverse as the backend, automating routine processes and enhancing end-user efficiency.


- Designed and automated SSRS reports integrated with Dynamics 365 (D365) to streamline operational reporting, ensuring accuracy and faster delivery of financial and business insights.



**Samay Systems LLC**  |  *Jul 2024 - Jun 2025*

**QA Automation Engineer**




- Developed automated test scripts using Selenium and Java to validate complex user journeys across web applications.


- Created and maintained manual test cases for edge scenarios not suitable for automation, ensuring full functional coverage.


- Performed UAT coordination with business users, validating that system behavior aligned with real operational needs.


- Documented test execution results and defect trends, supporting release readiness reviews.


- Used Azure DevOps to manage defects, test cycles, and sprint-level QA activities.




**Arvam Tech**  |  *Jul 2023 - May 2024*

**QA Engineer**




- Executed system testing and regression testing for enterprise applications with frequent release cycles.


- Built and enhanced Selenium automation suites to validate UI behavior and data integrity across releases.


- Designed test cases and test data aligned with functional and non-functional requirements.


- Used Zephyr to manage test cycles and track execution progress.


- Worked closely with developers during defect triage to ensure accurate root-cause identification and verification.



**RHYM Tech**  |  *Aug 2022 - May 2023*

**QA Analyst**




- Led manual testing efforts for system integration and end-to-end workflows across multiple services.


- Defined test strategies and execution plans to validate feature readiness prior to UAT.


- Supported automation efforts by identifying high-value test scenarios suitable for scripting.


- Managed defects using Jira, ensuring clear reproduction steps and validation criteria.



**ZeMoSo Technologies**  |  *Jul 2019 - Aug 2022*

**Associate QA Engineer**




- Conducted functional, regression, and integration testing across enterprise platforms.


- Wrote structured test cases and test scenarios aligned with evolving requirements.


- Assisted in building Selenium-based automation scripts using Java for repetitive validation tasks.


- Collaborated with cross-functional teams to ensure quality gates were met throughout the SDLC.
