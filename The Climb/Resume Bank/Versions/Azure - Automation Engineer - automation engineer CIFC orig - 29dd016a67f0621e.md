## Summary





- Experienced **Automation Engineer** with 5+ years of hands-on expertise in **scripting, automation workflows, and systems integration** across cloud and hybrid environments.

- Specialized in **PowerShell scripting for infrastructure automation**, data processing, and security controls across **AWS, Azure, and enterprise environments**.

- Proficient in building **workflow automations using Power Automate** and n8n to streamline repetitive business operations and improve process efficiency.

- Skilled in integrating APIs, managing IAM policies, and designing visual monitoring and reporting systems using Power BI, enabling data-driven decision-making.

- Proven track record in supporting compliance and security initiatives through custom automations, real-time dashboards, and cloud-native tools like Lambda, Step Functions, and EventBridge.




## Skills


**Scripting & Automation**: PowerShell, Python, Bash, Power Automate, VBScript, VisualCV

**Workflow Orchestration & RPA**: Power Automate, n8n, AWS Step Functions, EventBridge

**Data Visualization & Reporting**: Power BI, Tableau, Grafana

**Cloud Platforms & Services**: AWS (Lambda, S3, EC2, IAM), Azure (AD, Logic Apps), GCP (Cloud Functions)

**CI/CD & DevOps Tools**: Jenkins, GitHub Actions, Azure DevOps, Docker, Kubernetes, Terraform

**Databases & Data Management**: SQL (MySQL, PostgreSQL), NoSQL (MongoDB, DynamoDB)

**Testing & Monitoring**: Selenium, Postman, Splunk, Nagios, Prometheus

**Operating Systems**: Windows Server, Linux (Ubuntu, CentOS), macOS

**Security & Compliance**: IAM (AWS IAM, Azure AD), OAuth 2.0, JWT, SSO Integration


## Professional Experience



**Epic Solutions**  |  *Jun 2025 - Present*

**Senior Automation Engineer (Business Applications & Reporting)**

*Project: CIFC Enterprise Automation & KPI Reporting Modernization*



- Built Power Automate flows and Power Apps solutions with Dataverse as the backend, automating routine processes and enhancing end-user efficiency.

- Developed advanced n8n workflows for API-based integrations, orchestrating data pipelines to aggregate and normalize metrics from multiple systems into Dataverse and Azure storage.

- Delivered KPI dashboards and metrics tracking using Power BI, aligning business intelligence with compliance/security needs and enabling leadership to monitor trends across Defender, Darktrace and other security suites.

- Designed and implemented Microsoft Fabric data pipelines using Dataflows Gen2, Lakehouse, and Semantic Models, enabling centralized, long-term retention and analytics of security and compliance data beyond native source limits.

- Designed and automated SSRS reports integrated with Dynamics 365 (D365) to streamline operational reporting, ensuring accuracy and faster delivery of financial and business insights.



**Samay Systems LLC**  |  *Feb 2025 - Jun 2025*

**Senior Automation Engineer (Cloud & Compliance Automation)**

*Project: Compliance Platform (SaaS) – Security & Compliance Automation*



- Developed PowerShell modules to automate evidence collection from AWS CloudTrail, Azure Logs, and GitHub Audit Logs.

- Built Power Automate and n8n workflows for multi-system compliance checks via REST APIs (Jira, GitHub, Azure AD).

- Designed Power BI reports using DAX and DirectQuery for real-time SOC 2 and HIPAA control tracking.

- Implemented AWS Lambda (Python), EventBridge, and Step Functions to schedule tasks and send alerts.

- Automated IAM provisioning via Microsoft Graph API with Slack webhook notifications.

- Partnered with compliance teams to reduce audit prep time by 40%.



**Arvam Tech**  |  *Jul 2023 - Jan 2025*

**Automation Engineer**

*Project: Enterprise Asset Management System*



- Built PowerShell scripts to automate CMDB updates and validate asset configs using JSON schema.

- Developed n8n workflows to sync asset inventory and process webhook-driven events.

- Integrated Power BI dashboards with gateway refresh for asset tracking and usage metrics.

- Used Power Automate to route asset approvals and escalate issues via Teams and SharePoint.

- Configured Jenkins jobs with Groovy and shell scripts to enforce tagging compliance.



**RHYM Tech**  |  *Aug 2022 - May 2023*

**Automation Engineer**

*Project: Cybersecurity Threat Intelligence Platform*



- Created PowerShell scripts for threat detection using Windows Event Logs and Linux syslogs.

- Built Python pipelines to ingest Splunk and Kafka data into MongoDB.

- Developed Power BI dashboards using custom connectors for threat trend visualization.

- Integrated n8n to auto-create Jira tickets, tag CVEs, and alert via Slack.

- Managed conditional access and credential rotation using Azure AD Graph API.



**ZeMoSo Technologies**  |  *Jul 2021 - Aug 2022*

**Automation Developer**

*Project: Biotech LabOps Automation*



- Automated lab workflows using PowerShell, REST APIs, and CSV processors.

- Integrated OAuth2-secured APIs for RBAC control in lab pipelines.

- Built Power Automate flows for experiment approvals and lab availability checks.

- Designed Power BI dashboards with Power Query to visualize experiment KPIs.

- Created reusable n8n workflows for task orchestration and CRM syncing.
