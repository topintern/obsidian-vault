Questions on Resume
PROJECT RELATED
General Technical Experience:
- Can you walk me through a project where you applied [specific technology]?
For example: "Can you explain how you used React.js or Node.js in the asset management solution at Arvam Tech?"
- What was the most challenging aspect of integrating microservices into your architecture at Arvam Tech? How did you resolve it?
This question helps assess the depth of understanding of microservices, deployment, and troubleshooting.
- How did you implement the CI/CD pipelines at Arvam Tech using Jenkins? What specific challenges did you face in automating the deployments?
This question probes understanding of DevOps practices, especially CI/CD.
- Could you describe a time when you identified a security vulnerability in one of your applications? How did you address it?
This checks if the person has a genuine understanding of security best practices, such as encryption, authentication, and compliance.

Frontend Development (React.js/Vue.js):
- Can you explain how you managed state in React in your project at RHYM Tech? Which state management approach did you use, and why?
This checks knowledge of React's ecosystem and how the candidate handles state in large applications.
- How did you implement responsive design in the cybersecurity applications you developed at RHYM Tech? Were there any challenges with cross-browser compatibility?
This helps assess their attention to UX/UI and practical knowledge of front-end challenges.

Backend Development (Node.js, Ruby on Rails, Spring Boot):
- What kind of backend architecture did you design at ZeMoSo Technologies for the Strateos Platform? Can you describe the process of building RESTful APIs for it?
This confirms the candidate's experience with API design, including handling data models and API versioning.
- Can you walk me through the database design for the Strateos Platform? How did you ensure efficient querying and data integrity using PostgreSQL?
This checks for expertise in database design and optimization.
- What specific challenges did you face while building secure backend services with Node.js and Express at RHYM Tech, and how did you overcome them?
This reveals the candidate's ability to tackle security and backend challenges.

Cloud & DevOps (AWS, Docker, Kubernetes):
- How did you use AWS services at Arvam Tech to ensure scalability and reliability? Can you give an example of how you optimized cloud costs or handled scaling issues?
This checks if the candidate can manage cloud infrastructure and optimize costs.

This verifies knowledge of containerization and deployment pipelines.
- Can you describe your role in setting up or managing CI/CD pipelines with Jenkins? What steps did you take to troubleshoot or improve the pipeline?
This ensures the candidate understands CI/CD processes in depth.

Security & Authentication:
- You mentioned using OAuth and JWT for authentication—could you explain the flow of how JWT was used for secure user authentication in one of your projects at RHYM Tech?
This checks the candidate's understanding of secure authentication mechanisms.
- What security protocols did you use in your applications at RHYM Tech to ensure that user data remained private and protected from potential breaches?
This assesses practical experience with security measures such as encryption and secure coding.

Project Management & Collaboration:
- How did you work with cross-functional teams, such as security specialists or DevOps engineers, while working on projects at Arvam Tech or RHYM Tech?
This checks communication and collaboration skills.
- Can you describe the agile practices followed in your previous teams, such as sprint planning, code reviews, or stand-ups? How did you ensure your tasks were completed on time?
This assesses their familiarity with agile methodologies.
- Can you share how you handled any specific bugs or performance issues in the asset management application at Arvam Tech or the cybersecurity tools at RHYM Tech?
This helps evaluate troubleshooting and problem-solving abilities.

Project-Specific Deep Dive:
- In your Strateos project, how did the integration of AI-driven robotic labs enhance the process of scientific experiment management? Can you describe a key feature you developed and how it impacted the overall platform?
This dives deep into specific project contributions and ensures their understanding of the tech stack.
- Regarding the real-time data analytics systems you worked on at RHYM Tech, could you describe how you used Kafka and Splunk for monitoring? What specific event or anomaly did you track, and how did you handle it?
This validates experience with real-time data analytics tools and the ability to apply them to real-world scenarios.

Soft Skills & Problem-Solving:
- Tell me about a time you had to quickly learn a new tool or technology to solve a problem in one of your projects. How did you go about it, and what was the outcome?
This gauges their ability to learn and adapt quickly, a key trait for interns.
- How did you handle feedback during code reviews, especially when it came to security or performance issues in your projects? Can you provide an example of a piece of feedback that improved your code significantly?
This tests their ability to handle constructive criticism and continuously improve.

Questions on Git:
1. Git Internals & Architecture
- How does Git internally store commits? Explain the role of blobs, trees, and commits.
- What is the difference between Git’s object database and the working directory?
- Explain how Git handles branching under the hood. How does it differ from SVN?
- What happens when you run git gc? How does it optimize the repository?
- How does Git handle large binary files, and what are the downsides?

2. Branching & Merging
- What is the difference between merge (fast-forward vs. recursive vs. octopus)?
- What is a rebase, and how does it differ from a merge? When should you avoid rebasing?
- If a rebase results in conflicts, how do you resolve and continue the rebase process?
- How do you recover a deleted branch if it hasn’t been pushed yet?
- Explain git worktree and how it can be useful when working with multiple branches.

3. Conflict Resolution & Troubleshooting
- You’ve merged a branch and pushed it, but later realize it introduced a bug. What’s your best rollback strategy?
- You accidentally committed a secret API key and pushed it. How do you permanently remove it from the history?
- If two developers push conflicting changes to the same branch, how does Git handle the conflict?
- What’s the difference between git revert and git reset? When would you use each?
- How do you handle a rebase conflict that you’re unable to resolve manually?

4. History Manipulation & Debugging
- What’s the difference between git reflog and git log?
- How can you use git bisect to identify the commit that introduced a bug?
- How do you completely rewrite the commit history of a repository?
- If you need to remove the last three commits but keep the changes, how would you do it?
- Explain git blame and how it can be used to track down the source of a change.

5. Remote Repositories & Collaboration
- What happens when you run git push --force? When should you never use it?
- Explain the difference between git fetch, git pull, and git clone.
- How do you create and switch to a new tracking branch from a remote branch?
- What’s the difference between origin/main and main?
- How would you handle a desynchronized remote repository where git push keeps getting rejected?

6. Submodules & Large Repositories
- What are Git submodules, and when would you use them?
- How do you update a submodule and ensure all developers get the latest version?
- What are the best practices for managing monorepos with Git?
- How do you handle partial clones in large repositories?
- How can you use git sparse checkout to work with only specific folders in a large repository?

7. Performance Optimization
- How does git fsck help detect and repair repository corruption?
- What strategies can improve Git performance in large-scale repositories?
- How does git pack-objects work, and when should you use it?
- What’s the impact of a large .gitignore file on repository performance?
- How do you optimize Git for a repository with millions of commits?

8. Security & Access Control
- How do you ensure that only certain developers can push to a protected branch?
- What are signed commits, and how do they improve security?
- How do you verify the integrity of a commit history?
- How would you prevent force pushes on a critical branch?
- How does git credential-store differ from git credential-cache?
