## Professional Experience

**Software Engineer AI**  |  *Jun 2025 - Present*

*Epik Solutions | Enterprise Security & DevSecOps Platform*

- Built **Python, TypeScript, and Go microservices** for enterprise security telemetry, integrating security products into CI/CD workflows used by application and platform engineering teams.

- Implemented **Secure Development Lifecycle controls** including secrets detection, credential validation, SAST/DAST findings intake, vulnerability triage, and remediation workflow automation.

- Integrated **security tools into DevOps pipelines** with GitHub Actions, Jenkins, REST APIs, webhooks, and policy checks, reducing manual security review effort by **40%**.

- Developed **AI-assisted security scanning workflows** using LLMs, RAG, prompt regression tests, and human approval queues to review model outputs, application findings, and remediation suggestions.

- Built enterprise identity and access integrations with **SSO/SAML, OAuth2/OIDC, RBAC**, service credentials, and secret rotation patterns across internal security services.

- Deployed and supported services on **Kubernetes, Docker, Linux, Windows Server, AWS, Azure**, and Terraform-managed environments with observability through Prometheus, Grafana, and CloudWatch.

- Worked with architects, vendors, DevOps teams, and application owners to refine backlog priorities, evaluate security products, document integration behavior, and unblock adoption across engineering groups.

**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance AI Platform*

- Designed a **multi-tenant AI compliance platform** on AWS using Python, TypeScript, GraphQL, Lambda, ECS, SQS, PostgreSQL, and Neo4j for **15+ enterprise clients**.

- Built **DevSecOps automation** for evidence collection, cloud control validation, audit trails, secure configuration checks, and vulnerability remediation reporting across enterprise systems.

- Productionized **agentic AI workflows** with AWS Bedrock, Azure OpenAI, LangChain, RAG, tool-calling agents, and eval datasets, reducing manual evidence review by **70%**.

- Implemented tenant isolation, **RBAC**, secret handling, environment promotion, and CI/CD quality gates to support secure releases across dev, staging, and production.

- Developed **REST and GraphQL APIs** that connected compliance workflows with Jira, GitHub, cloud accounts, document stores, and identity systems for audit-ready enterprise integrations.

- Partnered with customer stakeholders, platform engineers, and security teams to translate ambiguous compliance/security requirements into backlog items, roadmap tradeoffs, and production-ready features.

**ML / Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Autonomous Systems & Identity Automation*

- Built **Python telemetry pipelines** for image, sensor, and operational datasets used in ML workflows, converting raw field data into validated artifacts for downstream analysis.

- Developed identity lifecycle automation across UKG, JumpCloud, and Azure AD/Entra-style systems, reducing provisioning time by **80%** through API integrations and validation scripts.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies | LabOps / Scientific Workflow Platform*

- Delivered full-stack workflow modules using React, TypeScript, Java Spring Boot, Ruby on Rails, and PostgreSQL for a regulated LabOps platform used by **500+ scientists**.

- Built **REST APIs**, role-based access workflows, audit logs, data validation, and release checks across **10+ product modules** including inventory, sample lineage, and file uploads.

- Authored **100+ automated tests**, debugged production defects on Linux-hosted services, and integrated Jenkins CI/CD gates to improve release quality for regulated workflows.

- Documented API behavior, troubleshooting steps, deployment notes, and validation paths for QA, infrastructure, and product teams in an Agile delivery environment.

## Education
