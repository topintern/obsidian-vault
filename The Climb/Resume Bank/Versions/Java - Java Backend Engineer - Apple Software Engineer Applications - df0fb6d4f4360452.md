## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | High-Traffic E-commerce Microservices*

- Designed and implemented **high-traffic server-side microservices** in **Java** using **Spring Boot** for e-commerce, handling 150M daily API requests for product pages, improving system scalability by 40%.

- Architected **cloud-native distributed systems** leveraging **Kafka** for **event-driven** processing of order status and inventory, reducing data propagation latency to 50ms.

- Developed **fault tolerance** mechanisms and **long polling design patterns** within **Java microservices**, ensuring 99.99% uptime for the critical mobile application checkout process.

- Led **CI/CD pipeline** enhancements using **Rio** for automated deployments of **Spring Boot** applications, accelerating release cycles from bi-weekly to daily frequency.

- Implemented complex **rule engines** for personalization of customer experience using **Pkl** and **Spring configuration management**, boosting user conversion rates by 18%.

- Optimized **Java multi-threaded REST applications** by analyzing **Datadog** traffic/error patterns, improving average response times by 20% across all **e-commerce logic**.

- Collaborated with **Security & Privacy** teams to embed **RBAC** and data encryption into **microservices**, achieving 100% compliance with stringent Apple policies.

- Defined **integration to other systems** via robust **REST APIs** and **server-side events**, facilitating seamless data exchange and reducing integration time by 30%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise Mobile E-commerce Platform*

- Developed **Java multi-threaded REST applications** using **Spring Boot** and **Spring MVC** for the Apple Store App, supporting product search and campaigns, handling 50K RPS.

- Implemented **e-commerce logic** within **fast, lightweight services**, integrating **NoSQL technologies** like **Cassandra** for high-volume order data **storage**, improving retrieval by 35%.

- Designed **high tolerance, asynchronous, low latency systems** using **Kafka** for **pub-sub** and **event-driven** messaging, ensuring real-time order updates within 100ms.

- Integrated **APNS** for managing **push notifications** to inform users about order status and promotions, increasing mobile application engagement by 22%.

- Optimized **Spring Boot** services caching strategy using **Redis** for **session management** and product catalog, reducing backend database load by 45%.

- Translated **design requirements** into **functional specifications**, creating detailed **UML diagrams** for **server-side microservices**, ensuring 98% alignment with project goals.

- Implemented **fault tolerance** and **server side events** for robust **REST APIs**, ensuring continuous service availability during traffic spikes, improving uptime by 10%.

- Contributed to **CI/CD pipelines** for **Spring Boot** applications, improving automated testing coverage and deployment reliability by 20%, reducing manual effort significantly.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Enterprise SaaS Platform Development*

- Developed **Java REST APIs** for core enterprise **SaaS platform** features using **Spring Boot**, supporting user authentication and data management, achieving 99.9% API uptime.

- Implemented **server-side logic** for a **multi-tenant SaaS platform**, ensuring data isolation and high performance for over 10,000 active users concurrently.

- Collaborated on designing and integrating **microservices** architecture into existing monolith, improving system modularity and reducing deployment risks by 25%.

- Optimized database interactions with **PostgreSQL** by creating efficient queries and indices for **large-scale codebases**, decreasing data retrieval times by 30%.

- Contributed to **CI/CD pipelines** for automated testing and deployment of **Java** applications, improving code quality and release frequency by 15% consistently.
