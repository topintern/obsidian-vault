## Professional Experience

**Software Engineer**  |  *Jun 2025 - Present*

*Epik Solutions*

- Built React SPAs with product-focused UX and clean component architecture, integrating Node.js REST APIs via well-structured contracts and reducing front-end bug reports by 32% across enterprise search

- Developed ASP.NET Core backend services with secure development practices including input validation, auth middleware, and rate limiting, reducing API-level security vulnerabilities by 30% across prod.

- Optimized PostgreSQL relational database queries serving 10M+ user interaction records, applying index tuning and query plan analysis to cut average response time by 40% under concurrent production load.

- Containerized React and .NET microservices with Docker and orchestrated Kubernetes deployments on AWS, implementing CI/CD pipelines that reduced release cycle time from two weeks to three days.

- Debugged complex web application bottlenecks using profiling tools across React front-end and Golang service layers, applying SDLC code review practices and reducing mean incident resolution time by 25%.

**Full Stack Engineer**  |  *Jul 2023 - Jun 2025*

*Samay Systems LLC*

- Architected clean RESTful and GraphQL APIs in Node.js for a multi-tenant platform serving 15+ enterprise clients, integrating third-party compliance data sources and maintaining 99.9% uptime.

- Designed and optimized PostgreSQL relational schemas with indexed queries and execution plan analysis, improving structured data retrieval by 45% and supporting 10,000+ concurrent users.

- Integrated DynamoDB non-relational stores for high-throughput session and event data alongside PostgreSQL for structured records, delivering a hybrid data architecture that scaled across all tenants.

- Provisioned AWS infrastructure using Terraform IaC and configured CI/CD pipelines across 10+ microservices, reducing manual deployment errors by 40% and enforcing consistent processes.

- Built full-stack React dashboards visualizing identity and compliance graphs, collaborating with stakeholders to define UX flows and API contracts that reduced user task completion time by 30%.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built Python data ingestion services with AWS Lambda and Terraform IaC, version-controlling via GitHub and reducing environment provisioning time by 40% across 3 production systems.

- Implemented secure serverless data synchronization services applying SDLC checkpoints, improving data consistency for 500+ employees and eliminating unauthorized cross-system data exposure.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies*

- Delivered 10+ full-stack feature modules using React and Spring Boot REST APIs with PostgreSQL, ensuring data integrity and accurate tracking for 500+ scientists on a regulated cloud platform.

- Designed relational database schemas across product modules in PostgreSQL and MSSQL, authoring optimized indexed queries that improved application response times by 35% under concurrent user load.

- Authored 100+ automated test cases and resolved critical production bugs through systematic debugging of complex web application layers, improving overall system reliability and data integrity by 40%.
