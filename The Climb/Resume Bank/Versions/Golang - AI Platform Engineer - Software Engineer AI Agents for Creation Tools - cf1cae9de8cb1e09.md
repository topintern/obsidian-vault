## Professional Experience

**Senior Platform Engineer**  |  *Jun 2025 - Present*

*Epik Solutions*

- Designed scalable distributed systems and microservices, integrating security platforms, automated 40% of SOC workflows, reducing MTTR by 15 minutes for internal teams.

- Developed React-based analytics dashboards, aggregating telemetry from 15+ systems, improved decision latency for C-suite, eliminating 20+ hours/week manual reporting.

- Engineered Python-based AI agents and automated workflows for incident triage, processed 1,000+ daily security events, reducing analyst workload by 30%.

- Automated enterprise workflows using Power Platform, serving 500+ users, reduced operational cycle times by 40%, enabling efficient automated workflows.

- Enhanced Live Site reliability by debugging distributed systems in Golang runbooks, improved end-to-end pipeline success by 25% for production systems.

**Lead AI Platform Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected a multi-tenant AI compliance SaaS platform on AWS, serving 15+ enterprise clients, scaled to 10,000+ users, demonstrating strong system design.

- Designed distributed backend systems (Golang, AWS, PostgreSQL, Neo4j) with strict tenant isolation, implemented robust system design for high performance services.

- Built LLM-powered AI agents (LangChain, AWS Bedrock) for compliance automation, orchestrated evidence collection, reducing manual auditor effort by 70%.

- Developed distributed systems for data ingestion pipelines (AWS Step Functions), integrated activity data from enterprise systems, feeding AI agents.

- Developed full-stack React + GraphQL applications for compliance controls, enabled identity graph visualization and evidence management for enterprise users.

**Software Development Engineer Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built automated identity lifecycle system (AWS/Azure) syncing 500+ employees, reduced provisioning time by 80%, demonstrating strong backend engineering.

- Developed full-stack features (React, Golang) for MLOps data labeling infrastructure, improved annotation throughput by 20% for machine learning systems.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered full-stack features for cloud-based lab automation platform, serving 500+ scientists, leveraged PostgreSQL and microservices architecture for backend systems.

- Designed and implemented features across 10+ core product modules, enabled accurate tracking of complex experimental data for content platforms.

- Authored 100+ test cases and resolved critical production issues, ensured data integrity and system reliability in the backend engineering environment.
