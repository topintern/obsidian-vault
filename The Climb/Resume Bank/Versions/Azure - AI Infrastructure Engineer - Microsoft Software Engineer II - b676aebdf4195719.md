## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Persistent Systems | AI Infrastructure & Services*

- Designed a **large language model** **API platform** using **Azure Kubernetes Service** for scalable inference, enhancing **service availability** by 99.9% for 1M daily requests.

- Implemented **agentic AI** workflows with **LangGraph** and **Python** to automate complex customer support, reducing response times by 40% for 500K users.

- Developed **CI/CD** pipelines using **Azure DevOps** for **LLM API platform** components, automating deployments and decreasing release cycle time by 30%.

- Integrated **OpenAI API** with internal systems, applying **Responsible AI** principles to ensure ethical **large language model** usage, improving compliance scores by 25%.

- Architected **microservices** on **Azure App Service** for a new feature, ensuring **security and privacy best practices**, supporting 50K concurrent users effectively.

- Led **threat modeling** and implemented **security best practices** for a critical **LLM API platform** component, mitigating 15 potential vulnerabilities with 95% effectiveness.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Globant | Enterprise Data Platform*

- Engineered **scalable software applications** using **Java Spring Boot** and **Kafka** for event streaming, handling 5M daily transactions efficiently, ensuring robust data flow.

- Designed and optimized **microservices** architecture on **Azure Cosmos DB** for critical customer data, improving data retrieval speeds by 3x for 200K active users effectively.

- Implemented robust **CI/CD** processes with **Jenkins** for **distributed systems** components, accelerating deployment frequency by 50% across 10+ services.

- Optimized database queries and **caching** strategies using **Redis** for **PostgreSQL**, boosting application performance by 25% for critical business operations.

- Successfully integrated **OpenAI API** for intelligent content generation, improving marketing campaign creation efficiency by 35% and engaging 100K new leads through innovative AI solutions.

- Managed **cloud computing** resources on **Azure Virtual Machines**, implementing **load-balancing** with **Azure Load Balancer** to ensure 99.9% **service availability**.

- Contributed to **service architecture** design for **SaaS services**, focusing on modularity and **operational excellence**, leading to 20% faster feature development.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Nagarro | CRM Solutions*

- Developed **scalable applications** using **Java** and **Spring Framework** for a CRM system, handling 1M customer records and 10K concurrent users efficiently.

- Implemented RESTful **APIs** for **microservices** communication using **Spring Boot**, integrating with third-party systems and improving data exchange speed by 20%.

- Designed **data platforms** using **MySQL** and **JPA** for persistent storage, optimizing schema and queries to reduce report generation time by 30%.

- Automated **CI/CD** workflows with **GitLab CI** for backend services, reducing manual deployment efforts by 40% and improving release consistency.

- Maintained and debugged **distributed systems** components, resolving production issues quickly and contributing to a sustained 99.5% **service uptime** for clients.

- Wrote comprehensive unit and integration tests using **JUnit** and **Mockito** to ensure code quality and **reliability**, reducing post-release defects by 25%.
