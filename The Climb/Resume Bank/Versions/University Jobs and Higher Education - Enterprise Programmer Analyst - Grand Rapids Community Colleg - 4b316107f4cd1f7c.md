## Professional Experience

**Application Developer**  |  *Aug 2024 - Present*

*CYAN Tech | Higher Education Practice*

- Designed and developed custom integrations between **Salesforce CRM** and **student information systems** for 5+ university clients, automating enrollment workflows and reducing manual data entry by 60%.

- Built **REST** and **SOAP APIs** using **Python** and **Node.js** to facilitate bidirectional data exchange between CRM, LMS, and ERP systems across multiple higher education institutions.

- Translated business requirements into technical specifications, conducting fit/gap analysis and delivering solutions that improved student engagement tracking by 40% for client institutions through advanced analytics.

- Developed advanced **SQL queries** and stored procedures for **PostgreSQL** and **SQL Server**, optimizing reporting performance for institutional research offices and reducing query execution time by 50%.

- Configured and customized **Salesforce Education Cloud** for university admissions workflows, implementing role-based access controls and data validation rules for 10,000+ student records per institution.

- Provided tier-3 support for academic applications, troubleshooting integration issues, submitting vendor tickets, and applying patches to maintain system availability during peak enrollment periods.

- Conducted system and integration testing using **unit testing frameworks** (pytest, Jest) to ensure quality standards before deploying solutions to production environments serving 15,000+ students.

**Graduate Research Assistant & Application Developer**  |  *Sept  2023 - Jul 2024*

*Oklahoma State University | Department of Computer Science*

- Developed and maintained **Canvas LMS** integrations using **Canvas REST API** and **LTI 1.3** standards, creating custom tools for automated grading and assignment submission workflows serving 500+ students.

- Built web applications using **JavaScript**, **HTML5**, **CSS3**, and **React.js** to enhance student learning analytics dashboards, integrating data from Canvas and student information systems.

- Designed relational database schemas and wrote complex **SQL queries** with joins, CTEs, and window functions to analyze student performance data supporting institutional effectiveness reporting.

- Implemented **object-oriented programming** solutions in **Python** and **Java** for academic workflow automation, reducing administrative overhead for course scheduling and grade processing by 35%.

- Provided application support for departmental systems, troubleshooting user issues, coordinating with vendors, and applying security patches and SSL certificate updates to maintain system uptime.

- Performed user acceptance testing for new LMS features, gathering feedback from faculty and students to ensure functional requirements were met before campus-wide deployment.

**Application Developer**  |  *Jul 2021 - Jul 2022*

*Keshav Memorial Institute of Technology | EdTech Platform*

- Designed and developed features for a learning management platform serving 100,000+ learners, implementing course delivery, assessment, and student progress tracking modules using **Python Django** and **PostgreSQL**.

- Built **RESTful APIs** for mobile and web applications, enabling seamless content delivery, user authentication, and integration with third-party payment and communication systems.

- Developed database table structures and optimized **SQL queries** for student enrollment and learning analytics systems, improving database performance by 45% for high-traffic academic periods.

- Created responsive web interfaces using **JavaScript**, **HTML5**, and **CSS3** for student portals and instructor dashboards, enhancing user experience and accessibility across devices.

- Implemented automated testing frameworks using pytest and Selenium, achieving 85% code coverage and reducing production defects by 30% across critical student-facing features.

- Maintained application servers, applied software patches and updates, and monitored system performance using logs to ensure 99.5% uptime for the mission-critical learning platform.

- Participated in agile development processes including sprint planning and code reviews, consistently delivering features on schedule and contributing to team velocity improvements.
