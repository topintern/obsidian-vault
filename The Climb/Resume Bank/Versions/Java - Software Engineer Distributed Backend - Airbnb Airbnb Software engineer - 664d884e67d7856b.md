## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Persistent Systems | Global Hotel Supply Platform*

- Designed and implemented a scalable **Java** microservices architecture using **Spring Boot** for global hotel onboarding workflows, achieving 99.9% uptime and processing 500k daily registrations efficiently.

- Led the development of robust **Kotlin**-based **REST APIs** on **AWS Lambda** for real-time inventory synchronization, reducing data latency by 75% and improving overall booking accuracy.

- Optimized **Apache Kafka** event streaming pipelines for critical hotel availability updates across **distributed systems**, enhancing data throughput by 40% and reducing processing delays significantly.

- Implemented comprehensive **monitoring** and alerting with **Prometheus** and **Grafana** for critical backend services, decreasing incident response time by 60% and bolstering overall system quality.

- Architected and deployed **Kubernetes** clusters using **Terraform** for new product features, enabling rapid scaling of hotel tools and significantly reducing deployment time by 30%.

- Enhanced **PostgreSQL** database performance through schema optimizations and meticulous query tuning, improving API response times by 25% for high-volume supply growth operations globally.

- Contributed to **operational excellence** by automating runbook procedures with **Ansible** for rapid service recovery, decreasing manual intervention by 80% and improving system reliability significantly.

- Developed secure authentication and authorization modules using **JWT** within **Spring Security** for partner access to hotel management APIs, ensuring critical data integrity for 100k partners.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Endava | Enterprise Fintech Platform*

- Developed high-performance **Java** backend systems using **Spring Boot** to process financial transactions, handling 1M daily requests with 99.95% accuracy and extremely low latency.

- Built and maintained secure **RESTful APIs** for external partners using **Kotlin** and **Spring WebFlux**, facilitating seamless data exchange for over 50 enterprise clients.

- Designed and implemented robust **Microservices** on **AWS EC2** and **AWS ECS** for a distributed payment processing platform, significantly improving transaction throughput by 35%.

- Integrated **Apache Kafka** message queues for efficient asynchronous communication between critical services, reducing inter-service dependencies and improving system resilience by 20% reliably.

- Managed and optimized **PostgreSQL** databases, including indexing and query optimization, to support high-volume data operations for financial reporting, effectively cutting report generation time by 40%.

- Developed automated **CI/CD** pipelines using **Jenkins** and **Gradle** for continuous deployment of backend services, reliably accelerating release cycles by 50% and improving efficiency.

- Collaborated on robust **distributed systems** design, focusing on data consistency and fault tolerance, achieving high system availability of 99.98% for critical fintech applications.

- Implemented robust error handling and logging mechanisms using **SLF4J** and **Logback** across all services, enhancing debug visibility and reducing issue resolution time by 30% effectively.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Nagarro | Digital Transformation Solutions*

- Developed core **Java** backend services using **Spring Framework** for an enterprise content management system, serving over 10,000 internal users efficiently and reliably daily.

- Created and consumed **RESTful APIs** to integrate with third-party applications and internal systems, effectively improving data synchronization efficiency by 25% across all platforms.

- Implemented robust data storage solutions with **MySQL**, designing schemas and optimizing queries for high-volume data retrieval, reducing database load by 15% effectively.

- Contributed to software development lifecycle (SDLC) by writing **clean, testable code** and conducting peer code reviews, significantly improving code quality metrics by 10%.

- Developed authentication and authorization features using **Spring Security** for robust user access control, enhancing overall system security posture by 20% against unauthorized access.
