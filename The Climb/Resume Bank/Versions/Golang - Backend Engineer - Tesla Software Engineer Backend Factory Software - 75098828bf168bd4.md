## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Manufacturing Operations Platform*

- Lead the design and implementation of new **Go**-based backend services for **manufacturing** control systems, reducing system latency by 35% for critical operations.

- Developed **Rust**-powered microservices integrating with **Kafka** streams and **PostgreSQL** to manage real-time inventory, improving data consistency by 99.8% across warehouses.

- Architected and deployed a **Kubernetes**-orchestrated platform on **AWS** for scalable production-critical systems, achieving 99.99% uptime and supporting 500+ daily users.

- Implemented robust **CI/CD pipelines** using **GitHub Actions** for automated testing and deployment, accelerating release cycles by 40% while maintaining code quality.

- Designed and built secure **REST APIs** using **Java Spring Boot** for external partner integrations, enhancing data exchange efficiency by 25% for supply chain logistics.

- Integrated **OpenAI API** into a **Python** data analysis tool for predictive maintenance in vehicle manufacturing, reducing equipment downtime by 18% through anomaly detection.

- Developed **monitoring** and **logging** solutions using **Prometheus** and **Grafana** for production-critical manufacturing systems, reducing incident resolution time by 30%.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | Enterprise Backend Systems*

- Developed core **Java** backend services for a high-traffic enterprise platform using **Spring Boot**, handling 10,000 requests per second with 200ms average latency.

- Optimized **SQL databases** (**MySQL**) through query tuning and indexing strategies, reducing critical report generation time from 5 minutes to 30 seconds.

- Implemented secure **RESTful APIs** for internal and external consumption, enforcing **OAuth2** and **JWT** for authentication, securing over 100 sensitive data endpoints.

- Contributed to the design and implementation of **microservices architecture** using **Docker** and **AWS ECS**, improving system scalability and resilience by 30%.

- Developed robust data validation and error handling mechanisms for critical data ingestion pipelines, reducing data quality issues by 90% across various datasets.

- Migrated legacy services to **AWS Lambda** and **DynamoDB**, achieving a 40% reduction in operational costs and improving response times by 50%.

- Implemented real-time **monitoring** and **logging** with **ELK Stack** for production systems, enabling proactive issue detection and resolving 95% of alerts within 15 minutes.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | B2B SaaS Solutions*

- Developed and maintained **Python** backend services for a B2B SaaS platform using **Django REST Framework**, supporting 5000+ active enterprise users monthly.

- Designed and optimized **PostgreSQL** schemas and queries for enhanced data retrieval performance, reducing API response times by an average of 30%.

- Implemented features for a multi-tenant application, ensuring data isolation and security policies were met, preventing 100% of cross-tenant data access attempts.

- Integrated third-party APIs for payment processing and CRM functionalities, improving platform capabilities by 20% and expanding service offerings significantly.

- Contributed to frontend development using **JavaScript**, **HTML**, and **CSS** with **JQuery**, enhancing user interface responsiveness and usability by 15%.

- Participated in full software development lifecycle, including requirements gathering, testing, and deployment, contributing to 12 successful feature releases annually.
