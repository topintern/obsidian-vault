- Integrated OpenAI LLM APIs into a multi-tenant search platform via RESTful interfaces, delivering low-latency AI-driven query responses for 15+ enterprise clients with 99.9% production uptime.

- Built React.js front-ends surfacing AI agent outputs to enterprise users, bridging LLM logic and UI improving task completion rates by 30% for 10,000+ production users.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built AWS Lambda data pipelines with GitHub version control enabling consistent ML model training across 3 production computer vision systems, reducing pipeline failures by 40%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies*
