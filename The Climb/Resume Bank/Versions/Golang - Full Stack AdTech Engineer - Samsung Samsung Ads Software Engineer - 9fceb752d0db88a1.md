**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Persistent Systems | Enterprise Ad Data Platform*

- Developed **Golang** backend services for **ad monetization** data ingestion, processing 20M daily ad events with 99.9% data accuracy.

- Built **React** and **JavaScript** **frontend development** for **customer-facing insights** dashboards, enhancing user data exploration by 40%.

- Implemented **Kafka** consumers and producers for **event-driven systems** handling ad campaign data, ensuring real-time **reporting** updates within 2 seconds.

- Contributed to **microservices architecture** for **analytics features**, enabling scalable data **aggregations** across diverse ad data sources, improving query speeds by 3x.

- Optimized **application performance** of **JavaScript** **frontend** components, reducing rendering times by 200ms and improving user experience scores by 15%.

- Implemented **RabbitMQ** for asynchronous task processing in **backend development**, reducing latency for complex **reporting** generation by 60%.

- Performed **performance optimization** on **Golang** APIs, decreasing average response times from 300ms to 80ms, supporting 5,000 requests per second.

- Applied **Agile** methodologies and conducted **test-driven development** for new features, improving sprint delivery predictability by 18% consistently.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Brillio | Digital Solutions & Client Platforms*

- Developed **Node.js** **backend development** APIs for client-facing applications, managing 1M daily requests with 99.8% uptime reliability.

- Implemented **React** **frontend development** for interactive web portals, improving user navigation and reducing support tickets by 10%.

- Ensured **responsive design** and **cross-browser compatibility** across all **JavaScript** applications, expanding user reach by 25% across different devices.

- Utilized **Git** for version control and collaborative **software development**, integrating changes from 5+ team members without conflicts.

- Contributed to **performance optimization** of web applications by optimizing assets via **webpack**, reducing initial load times by 15%.

- Participated in **Agile** sprints, delivering features incrementally and conducting code reviews, improving team velocity by 12%.
