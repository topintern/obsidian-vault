## Professional Experience

**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Security Automation*

- Architected **data pipelines** with **Python**, **PySpark**, and **Apache Airflow** to ingest security telemetry from 15+ systems into **Snowflake** data warehouse, automating 40% of SOC workflows and improving operational efficiency.

- Built production **dbt** transformation layers with 50+ modular SQL models, incremental materializations, and data quality tests over **Snowflake**, enabling self-service security analytics and reducing analyst ad-hoc queries by 60%.

- Designed **dimensional models** with Type 2 **SCD** patterns for identity and access tracking, implementing proper effective-date logic and surrogate keys in **PostgreSQL** to ensure accurate audit trails for compliance workflows.

- Engineered **AI agentic workflows** using **LangGraph** and **Azure OpenAI** integrated into **FastAPI** services for automated incident triage, processing 1,000+ daily security events and reducing analyst workload by 30%.

- Developed **Next.js** dashboards with server-side rendering consuming **FastAPI** backends to visualize security metrics and compliance posture for C-suite stakeholders, eliminating 20+ hours per week of manual reporting.

- Leveraged **Claude Code** and **Cursor** as primary development accelerators for **FastAPI** route scaffolding and **dbt** model generation, reducing boilerplate coding time by 50% while maintaining production quality standards.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance Startup*

- Built end-to-end **ETL/ELT pipelines** using **Python**, **PySpark**, and **Apache Airflow** on **AWS**, ingesting compliance data from 10+ sources into **Snowflake** data warehouse with full lineage tracking for audit trails.

- Implemented **dimensional modeling**, star schemas with fact and dimension tables, applying proper grain definition, conformed dimensions, and SCD Type 1/Type 2 patterns compliance analytics and reporting.

- Developed **dbt** transformation workflows with macro-driven incremental strategies, snapshot tables for SCD Type 2 tracking, and 150+ data quality tests, for compliance evidence collection across multi-tenant environments.

- Orchestrated complex **data pipelines** with **Airflow** DAGs managing dependencies across 25+ tasks, implementing retry logic and SLA monitoring, achieving 99.5% pipeline success rate for critical nightly compliance data loads.

- Built **FastAPI** microservices with async endpoints, Pydantic validation, and dependency injection patterns deployed on **AWS Lambda**, processing real-time webhook events from Salesforce and NetSuite for data synchronization.

- Engineered **RAG pipelines** with **LangGraph** and **Pinecone** for AI-driven compliance insights, enabling natural language querying of compliance evidence and reducing document review time by 70% for audit workflows.

- Designed **PostgreSQL** schemas with proper indexing strategies, partitioning, and materialized views supporting **Next.js** application backends, handling 30K transactions per day with sub-100ms p95 latency for dashboard queries.

**Associate Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Scientific Operations Platform*

- Contributed to cloud-based scientific platform by developing full-stack features using **Python**, **FastAPI**, and **React** to trace experiments and samples, building RESTful APIs and **PostgreSQL** schemas serving 500+ scientists.

- Built **ETL workflows** with **Pandas** and **SQL** to transform raw experimental data into normalized **PostgreSQL** tables with dimensional modeling, designing schemas with foreign key constraints and indexing for query performance.

- Implemented data validation pipelines with **Pydantic** models, enforcing schema contracts and data quality rules for sample tracking workflows, reducing downstream data errors by 40% in production environments.

- Designed **PostgreSQL** schemas for experiment tracking modules with normalization and indexing strategies, enabling accurate lineage tracing across 10+ core product modules for inventory, compounds, and batches.

- Deployed **CI/CD pipelines** with **GitHub Actions** and **Jenkins** for **FastAPI** microservices and **React** frontends on **AWS EC2**, automating testing and deployments, reducing manual release time from 2 hours to 10 minutes.

- Collaborated with scientists and product managers to translate experimental workflow requirements into database schemas and API contracts, ensuring data accuracy and integrity for regulated scientific environments.
