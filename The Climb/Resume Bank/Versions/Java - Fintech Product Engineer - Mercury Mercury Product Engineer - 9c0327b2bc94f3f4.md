## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Fintech Banking Platform for Startups*

- Designed and implemented a high-performance payment processing service using **Java** and **Spring Boot**, integrating with multiple banking APIs to support startup transactions, reducing processing latency by 30%.

- Led the migration of key UI components to **React** and **TypeScript**, improving the banking platform's user experience and reducing front-end bug reports by 25% for startup clients.

- Championed the development of a real-time fraud detection system utilizing **Apache Kafka** and **AWS Kinesis**, directly supporting product-minded goals to safeguard customer assets by 99.9%.

- Engineered a microservices architecture for new financial products using **Go** and **Docker**, ensuring scalability and resilience for an increasing number of startup customers.

- Developed and maintained robust **Python** ETL pipelines on **AWS Glue** to ingest and transform financial data from legacy industry tools, improving data availability by 40%.

- Optimized **PostgreSQL** database queries and indexing for a core ledger system, significantly reducing API response times by 20% and enhancing overall banking performance.

- Implemented **Kubernetes** deployments via **GitLab CI/CD** for critical backend services, streamlining releases and reducing deployment failures by 15% across the platform.

**Software Engineer**  |  *Jul 2023 - Jun 2025*

*Samay Systems LLC | Enterprise Financial Services Platform*

- Built secure **REST APIs** using **Node.js** and **Express.js** for a financial transaction portal, enhancing data exchange speed by 35% for enterprise users.

- Collaborated on delivering new features for a customer-facing dashboard using **React** and **Redux**, improving user engagement with the banking platform by 18%.

- Deployed and managed core application components on **AWS EC2** and **S3**, ensuring high availability and resilience for critical financial services, achieving 99.9% uptime.

- Designed and implemented data models in **MongoDB** for a transaction history service, accommodating varied financial data structures and improving query efficiency by 25%.

- Integrated **OAuth 2.0** and **JWT** for secure authentication across microservices, protecting sensitive financial data and complying with industry security standards by 100%.

- Conducted performance profiling and optimizations on backend services, reducing average API response times from 500ms to 200ms for a better user experience.

- Developed comprehensive unit and integration tests using **Jest** and **Mocha** for backend services, increasing code coverage to 90% and reducing post-release bugs by 15%.

- Configured **Prometheus** and **Grafana** for real-time monitoring of application health and performance metrics, enabling proactive issue resolution within 5 minutes.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*Zemoso Technologies | B2B SaaS Workflow Automation Platform*

- Developed and maintained core features of a B2B SaaS platform using **Python** and **Django**, delivering enhancements that improved client workflow efficiency by 20% for enterprise customers.

- Implemented user authentication and authorization modules with **Flask** and **SQLAlchemy**, ensuring data security and role-based access control (**RBAC**) across the platform, achieving 100% compliance.

- Designed and optimized relational database schemas in **MySQL** for various application modules, improving data retrieval speeds by 15% and supporting new product features.

- Contributed to front-end development using **JavaScript** and **jQuery** for interactive dashboards, enhancing user interface responsiveness and satisfaction by 10% for business users.

- Created and managed reproducible development environments using **Vagrant** and **Ansible**, standardizing setups for new engineers and reducing onboarding time by 25 hours.

- Wrote comprehensive documentation for API endpoints and system architecture, fostering knowledge sharing among team members and reducing support requests by 10% monthly.
