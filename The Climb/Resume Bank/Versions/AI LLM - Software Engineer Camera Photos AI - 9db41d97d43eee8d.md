## Professional Experience

**Software Engineer AI**  |  *Jun 2025 - Present*

*Epik Solutions | Enterprise Security AI Platform*

- Built **Python FastAPI** services and **React/TypeScript** internal tools that catalog high-volume security telemetry, model outputs, and analysis artifacts for engineering and operations teams.

- Designed **LLM-powered query interfaces** over large operational datasets using **RAG**, **Pinecone**, prompt templates, and structured output validation, reducing manual investigation time by 40%.

- Implemented asynchronous analysis workflows with **AWS SQS**, background workers, and retry-safe job state tracking, enabling long-running AI enrichment jobs to run reliably across bursty workloads.

- Integrated production **LLM** and **multimodal AI** features with evaluation checks for groundedness, latency, and failure modes, balancing quality, cost, and maintainability before release.

- Built real-time **React** dashboards with streaming status updates, drill-down metadata views, and regression indicators used by partner teams to review model behavior and operational trends.

- Improved service operability with **OpenTelemetry**, structured logs, alerting, and CI quality gates, sustaining 99.9% uptime for daily tools used by enterprise engineering and security teams.

**Software Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance AI Platform*

- Owned end-to-end product features across **React**, **Python REST APIs**, and data models for a multi-tenant AI compliance SaaS platform serving 15+ enterprise customers.

- Built **RAG** pipelines over audit evidence, cloud metadata, and policy documents using vector search, retrieval ranking, and context-window management for natural-language Q&A workflows.

- Developed **agentic workflows** that collected evidence, summarized control gaps, and routed human review steps, reducing manual auditor effort by 70% while preserving explainable outputs.

- Designed async ingestion and scoring jobs with **AWS Lambda**, **SQS**, **PostgreSQL**, and idempotent retries to process long-running compliance analyses without blocking user workflows.

- Partnered with product, customer success, and compliance leads to turn ambiguous audit workflows into reliable internal tools, documentation, dashboards, and release-ready APIs.

- Added model-version tracking, prompt regression datasets, and cost/latency dashboards for AI features, preventing quality regressions during weekly production releases.

**ML / Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Autonomous Vehicle Perception*

- Built **Python** preprocessing pipelines for image, sensor, and telemetry datasets used in perception model training, converting raw field data into validated, training-ready artifacts.

- Evaluated **computer vision** models with **PyTorch**, **TensorFlow**, and **OpenCV**, analyzing model outputs against operational constraints for real-world autonomous systems.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies | LabOps / Scientific Workflow Platform*

- Built full-stack scientific workflow tools using **React**, **Python/Java** REST APIs, and **PostgreSQL**, supporting experiment tracking, sample metadata, and analysis workflows for 500+ scientists.

- Developed async upload and validation services for large experiment files and metadata records, decoupling long-running processing from user-facing screens and reducing failed submissions.

- Implemented data cataloging workflows for experiment artifacts, metadata, and analysis outputs, helping scientists trace datasets from capture through review and downstream reporting.

- Built partner-facing dashboards that surfaced pipeline status, validation errors, and quality metrics, reducing back-and-forth between engineering, research, and QA teams during release cycles.

- Added retry-safe background processing and audit logs for long-running scientific analyses, improving reliability and debuggability for workflows used by research and quality stakeholders.

- Designed searchable metadata views and optimized database queries for experiment reports, cutting report generation time by 30% across regulated LabOps workflows.

- Authored automated tests and CI quality gates for scientific data workflows, improving correctness, traceability, and release confidence for tools used by research and quality teams.
