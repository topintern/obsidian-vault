## Professional Experience

**Senior Machine Learning Engineer (AI/NLP)**  |  *Jun 2025 - Present*

*Epik Solutions*

- Developed and deployed industrial search recommendation engine, boosting result relevance by 25% for enterprise users using NLP algorithms and large model applications.

**Machine Learning Engineer (AI/Search)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected a multi-tenant search system for 15+ clients, incorporating search algorithm models for enhanced query relevance by 20%, improving user satisfaction.

- Implemented LLM-powered compliance automation using large model applications, summarizing evidence with NLP algorithms, cutting manual auditor effort by 70%.

- Developed distributed data ingestion pipelines in Python on AWS, feeding real-time data for machine learning theory model training and continuous improvement.

- Built full-stack React + GraphQL applications visualizing identity graphs, enabling compliance controls and data management for enterprise users across various teams.

- Designed scalable backend systems using Golang and AWS CDK, ensuring high availability and tenant isolation for 10,000+ users, supporting critical operations.

**Machine Learning Engineer Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Developed Python scripts for MLOps data labeling infrastructure, boosting annotation throughput by 20% for critical ML training pipelines and efficiency.

- Implemented serverless data synchronization across systems, improving data consistency for 500+ employees and supporting future ML initiatives effectively.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered full-stack features for a cloud-based robotic lab platform, ensuring accurate tracking of complex experimental data for 500+ scientists.

- Designed features across 10+ product modules using React, Ruby on Rails, Spring Boot, and PostgreSQL in a microservices architecture for scalability.

- Authored 100+ test cases and resolved critical production issues, enhancing system reliability and data integrity in a regulated scientific platform.
