## Professional Experience

**Full Stack Engineer (Enterprise Finance)**  |  *Jun 2025 - Present*

*Epik Solutions*

- Analyzed and optimized **frontend performance** using **Chrome DevTools** and **Vite**, reducing initial bundle size by **30%** and improving **Core Web Vitals (LCP/FID)** for **real-time financial dashboards**

- Developed a secure **front-end application** using **React** and **TypeScript** for **Azure-hosted security platforms**, optimized **microservices** and **UI/UX**, reducing **incident response time by 15 minutes**

- Engineered **real-time analytics dashboards** with **React, Redux, Tailwind CSS**, eliminating **20+ hours/week** of manual reporting and improving **decision latency for C-suite stakeholders**

- Integrated **Azure AI Studio** and **RAG-based systems** via **REST APIs** and **WebSockets**, processing **1,000+ security events daily** and reducing **analyst workload by 30%**

- Implemented **DevOps practices** and **CI/CD pipelines** for **Azure-hosted applications**, accelerating deployment cycles by **40%** and ensuring reliable releases for **500+ users**

**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected the **front-end** of a **multi-tenant B2B compliance SaaS platform** using **React** and **TypeScript**, delivering scalable **UI/UX** for **15+ enterprise clients** and **10,000+ users**

- Delivered **production-ready UI/UX**, authored **ADRs and design docs**, and implemented **usage analytics**, driving a **20% increase in user engagement**

- Designed and integrated **RESTful APIs** using **Java**, ensuring **data isolation**, **high availability**, and scalable backend communication for **10,000+ users**

- Developed **AI-driven tooling (RAG, agentic systems)** integrated with **Azure AI Studio**, reducing **manual auditor effort by 70%** through automated **evidence collection and summarization**

- Implemented **CI/CD pipelines** and **DevOps workflows** for **data ingestion systems**, ensuring reliable **data flow** and improved **data integrity**

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Developed **accessible front-end components** using **Vue** and **TypeScript**, adhering to **WCAG 2.1** and **ARIA standards**, reducing **employee provisioning time by 80%**

- Implemented **REST APIs** and optimized **UI/UX** for **MLOps data labeling infrastructure**, improving **annotation throughput by 20%**

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered **full-stack features** and **backend microservices** using **React** and **Java (Spring Boot)** for a **robotic lab automation platform** used by **500+ scientists**

- Implemented **state management solutions** across **10+ modules**, ensuring accurate tracking of **complex experimental workflows**

- Authored **100+ test cases** and resolved **critical production issues**, ensuring **data integrity**, **system reliability**, and adherence to **Agile methodologies**
