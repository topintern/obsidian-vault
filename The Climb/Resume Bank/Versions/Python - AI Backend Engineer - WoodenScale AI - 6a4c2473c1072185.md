## Professional Experience

**AI Automation Engineer**  |  *Jun 2025 - Present*

*Epik Solutions*

- Engineered scalable backend services using Python and LangChain, processing 1000+ daily security events, reducing MTTR by 15 minutes for internal security teams.

- Developed advanced LangGraph workflows for automating SOC triage, integrating security platforms, optimized incident response, reducing manual effort by 40%.

- Implemented LangSmith for continuous LLM evaluation frameworks, enhancing model accuracy by 15%,  ensured reliable AI performance for critical security operations.

- Designed and deployed microservices on AWS, improving system resilience and scalability, maintaining 99.9% uptime, crucial for enterprise security platform operations.

- Resolved complex distributed system issues through first principles across UAT and prod, boosting pipeline success rates by 25%, enhanced Live Site reliability for security automation.

**Founding Engineer (FullStack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected multi-tenant AI compliance SaaS platform on AWS using Python for backend / AI engineering. Scaled to 10,000+ users, ensuring tenant isolation.

- Built LLM-powered compliance automation with LangChain and AWS Bedrock, reducing auditor effort by 70%, expedited evidence collection and control scoring.

- Developed robust distributed backend systems using Golang and PostgreSQL with strict tenant isolation, supported 15+ enterprise clients in a startup environment.

- Implemented sophisticated LLM evaluation frameworks to validate AI-driven compliance logic, achieved 95% accuracy, ensuring high-quality evidence summarization.

- Engineered data ingestion pipelines (Step Functions, Lambda) for identity/activity data, populated graph-based access models, enhancing security insights for clients.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built automated identity lifecycle system syncing 500+ employees across platforms, reduced provisioning time by 80% and eliminating manual efforts.

- Developed full-stack features (React, Golang) for MLOps data labeling infrastructure, improved annotation throughput by 20% for crucial ML training pipelines.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered full-stack features for a cloud-based robotic lab automation platform, supported 500+ scientists, improving experimental data tracking efficiency.

- Designed and implemented 10+ core product modules (inventory, compounds) using Ruby on Rails, enhanced accurate tracking of complex experimental data.

- Authored 100+ test cases and resolved critical production backend issues, ensuring data integrity, maintained system reliability in a regulated scientific platform.
