## Professional Experience

**Software Engineer**  |  *Jul 2025 - Present*

*Adyen, US*

- Designed and implemented scalable **Ruby** **APIs** for a financial transaction platform, processing 100M daily requests, enhancing system resilience and security by 30% through robust error handling.

- Led development of **Java** microservices using **Spring Boot** on **AWS EKS**, significantly improving payment processing throughput by 40% and reducing average transaction latency to under 50ms.

- Engineered critical **Go** **software infrastructure** components for real-time data ingestion using **Kafka**, achieving 99.99% uptime and processing millions of events per second with optimized resource utilization.

- Implemented advanced **Python** scripts for automating **AWS cloud infrastructure** provisioning with **Terraform**, decreasing deployment times by 60% and ensuring consistent, secure environments for development.

- Mentored junior engineers on best practices for **distributed backend applications** and **design patterns**, fostering team growth and improving code quality across the engineering department by 25%.

- Optimized database performance for **PostgreSQL** and **Redis** through schema refactoring and query tuning, leading to a 35% reduction in query execution time and improved data retrieval speed.

- Established new **CI/CD** pipelines using **Jenkins**, **Git**, and **Docker** for multi-service deployments, improving release frequency by 50% and reducing manual errors by 70% company-wide.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Plaid, US*

- Developed high-performance **Python** **APIs** using **Django REST Framework** for customer data management, supporting 500,000 active users and ensuring data consistency with 99.9% accuracy.

- Built and maintained robust **Java** **services** with **Spring Boot** on **AWS EC2** for billing and subscription processing, increasing system reliability by 20% and reducing processing errors.

- Implemented secure data storage solutions on **AWS S3** and **RDS (PostgreSQL)** for sensitive client information, adhering to compliance standards and enhancing data security posture by 40%.

- Designed and deployed a **Go** microservice for real-time user activity tracking, utilizing **Kafka** and **Elasticsearch** to process 1M events/minute, providing immediate analytics updates.

- Enhanced existing **software infrastructure** by integrating **Docker** containers for application isolation, reducing environment setup time by 75% and improving deployment consistency across teams.

- Conducted comprehensive **testing** and **validation procedures** for new features using **JUnit** and **Pytest**, identifying and resolving 150+ critical bugs before production deployment, improving software quality.

- Optimized **low latency systems** by refining data access patterns and implementing caching with **Redis**, decreasing API response times by 30% for high-volume transactions, enhancing user experience.

- Debugged complex **production issues across services** and **multiple levels of the stack**, collaborating with cross-functional teams to diagnose root causes and implementing permanent solutions, reducing downtime.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*Expedia, IN*

- Developed and maintained core **Java** **APIs** for a legacy system modernization project, enabling seamless data migration and improving system integration capabilities for enterprise clients.

- Contributed to backend development of a customer portal using **Python** and **Flask**, implementing user authentication and data retrieval, supporting 10,000 daily active users with consistent performance.

- Assisted in building scalable **software infrastructure** by configuring **AWS EC2** instances and **S3** buckets, ensuring robust storage and compute resources for various client applications.

- Wrote clear technical **documentation** for API endpoints and system architecture using **Swagger**, facilitating smoother onboarding for new developers and reducing integration time by 20%.

- Participated in **software requirements** gathering and **user needs analysis** sessions, translating business objectives into technical specifications for new features, improving project alignment by 15%.

- Implemented unit and integration **testing** using **JUnit** for critical application modules, increasing code coverage by 25% and reducing post-deployment defects by over 10% consistently.
