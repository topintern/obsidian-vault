## Professional Experience

**Automation Engineer (Full Stack / Distributed Systems)**  |  *Jun 2025 - Present*

*Epik Solutions*

- Designed scalable microservices integrating enterprise security platforms, automating 40% of SOC workflows, reducing MTTR by 15 minutes for internal security teams.

- Built real-time React analytics dashboards aggregating telemetry from 15+ systems, eliminating 20+ hours/week manual reporting, improving decision latency for C-suite.

- Developed AI-driven incident triage pipelines (Python, n8n) processing 1,000+ daily security events, reducing analyst workload by 30%.

- Automated cross-functional enterprise workflows using Power Platform and Powershell scripting, serving 500+ users, reducing operational cycle times by 40%.

- Enhanced Live Site reliability by debugging and resolving silent execution failures in distributed Golang runbooks, improving end-to-end pipeline success by 25%.

**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected multi-tenant AI compliance SaaS on AWS, serving 15+ enterprise clients, scaling to 10,000+ users per org, ensuring high availability.

- Designed distributed backend (Golang, AWS CDK, Lambda, ECS, PostgreSQL) with strict tenant isolation across relational, graph, and object storage layers.

- Built LLM-powered compliance automation (AWS Bedrock, LangChain) to orchestrate evidence collection, summarization, reducing manual auditor effort by 70%.

- Developed distributed data ingestion pipelines (Step Functions, Lambda) for identity/activity data from enterprise systems into graph-based access models.

- Developed fullstack React + GraphQL applications enabling compliance controls, identity graph visualization, evidence management for enterprise users.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built automated identity lifecycle system syncing 500+ employees across UKG, JumpCloud, Azure AD via serverless architecture, reducing provisioning by 80%.

- Developed full-stack features (React, Golang) for MLOps data labeling infrastructure, improving annotation throughput by 20% for ML training pipelines.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered full-stack features for cloud-based robotic lab automation platform, used by 500+ scientists (React, Ruby on Rails, Spring Boot, PostgreSQL).

- Designed and implemented features across 10+ core product modules, enabling accurate tracking of complex experimental data for 500+ scientists.

- Authored 100+ test cases and resolved critical production issues, ensuring data integrity and system reliability in a regulated scientific platform.

## Skills
