## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | FinTech Risk & Trust Platform*

- Led design and implementation of new **Ruby on Rails** backend services for fraud detection, ensuring robust, low-latency **APIs**. Mentored junior engineers on best practices, boosting team delivery velocity by 15%.

- Drove architectural decisions for integrating real-time spending insights using **Kafka** streams and **Redis** caching, enhancing member protection. Improved data processing efficiency by 20%, supporting 1M daily transactions.

- Optimized **PostgreSQL** database queries and indexes for core **Trust and Safety** platforms, reducing **API** response times. Implemented performance tuning strategies, decreasing critical query latency by 30% for key services.

- Developed comprehensive **observability practices** utilizing **Prometheus** and **Grafana** for critical backend services. Automated incident response procedures, improving system reliability by detecting anomalies 25% faster.

- Spearheaded **ML integration** capabilities within the **policy lifecycle** engine using **Python** and **FastAPI** to automate risk decisions. Achieved a 10% reduction in manual review effort while maintaining accuracy levels.

- Implemented **CI/CD pipelines** with **GitLab CI** and **Docker** for automated deployments across microservices architecture. Reduced deployment time by 40%, supporting faster iteration and experimentation initiatives.

- Designed and implemented **API Gateway** using **Kong** for secure and scalable access to backend services. Enhanced **API** security and managed traffic efficiently, handling 2M requests per minute.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise FinTech Data Platform*

- Developed and maintained **Python** and **Java** microservices for a large-scale **FinTech** data platform on **AWS**. Processed 500GB daily transaction data, ensuring high availability (99.9%).

- Engineered **REST APIs** using **Spring Boot** to expose spending insights and member data securely. Facilitated seamless data access for internal and external partners, reducing integration time by 20%.

- Designed and optimized **PostgreSQL** schemas and queries for **transactional databases**, handling millions of records efficiently. Improved data retrieval speeds by 35% for critical reporting functionalities.

- Implemented **Redis** caching strategies to enhance the performance of frequently accessed data. Decreased database load by 25%, resulting in a 15% reduction in **API** latency.

- Participated in **on-call rotation**, resolving critical production incidents within defined **SLAs**. Maintained platform reliability and performance, ensuring 99.95% uptime for core services.

- Contributed to the development of **CI/CD pipelines** using **Jenkins** and **Docker** for automated deployments. Streamlined release processes, decreasing time-to-market for new features by 20%.

- Implemented robust **security protocols** and **authentication mechanisms** for sensitive financial data. Ensured compliance with industry regulations, preventing unauthorized access by 100%.

- Refactored legacy **Java** modules into modern **Python** services, improving maintainability and scalability. Reduced technical debt by 30%, simplifying future enhancements and integrations.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Enterprise SaaS Platform Solutions*

- Developed core **Java** microservices for enterprise **SaaS** applications using **Spring Boot** framework. Implemented new features, supporting over 50,000 active users with high availability.

- Designed and implemented **RESTful APIs** for data exchange between frontend and backend systems. Improved system integration efficiency, reducing data retrieval times for clients by 20%.

- Managed and optimized **MySQL** databases, including schema design and query tuning. Enhanced database performance, accommodating 10M records and reducing report generation time by 15%.

- Wrote comprehensive unit and integration tests using **JUnit** and **Mockito** to ensure code quality. Maintained high code coverage above 85%, ensuring platform reliability and stability.

- Collaborated closely with product teams to translate requirements into technical specifications. Delivered features adhering to project timelines, ensuring 95% on-time project completion rate.

- Contributed to **CI/CD pipeline** enhancements, automating build and deployment processes. Reduced manual effort for deployments by 25%, speeding up time-to-market for software releases.
