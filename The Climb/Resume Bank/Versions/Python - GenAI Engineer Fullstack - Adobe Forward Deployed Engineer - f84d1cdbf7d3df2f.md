## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*EPAM Systems | Enterprise GenAI Solution Development*

- Designed and developed multi-agent **GenAI applications** using **LangGraph** and **CrewAI** to automate complex enterprise content workflows, improving task completion by 35%.

- Architected and deployed full-stack **GenAI solutions** with **React**, **Next.js**, and **Python** on **AWS EKS**, reducing time-to-market for prototypes by 40%.

- Led the development of **RAG pipelines** leveraging **Pinecone** **vector databases** and custom **embeddings** for **LLMs** like **GPT** and **Claude**, enhancing response accuracy by 28%.

- Implemented advanced **prompt engineering** techniques for various **LLMs** (e.g., **Llama**, **Mistral**) to optimize content generation and summarization, boosting output relevance by 30%.

- Collaborated with enterprise customers to gather requirements and co-build bespoke **GenAI applications**, translating complex needs into robust **production deployments**, achieving 95% customer satisfaction.

- Extracted reusable patterns into shared **Python** and **Node.js** libraries, improving development velocity for subsequent projects by 2x through standardized components.

- Automated **CI/CD pipelines** using **GitHub Actions** and **Terraform** for **GenAI application** deployments on **AWS**, decreasing deployment time by 60% and errors by 20%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Globant | AI-Enhanced Data Processing Platform*

- Developed and optimized **Python** microservices for data ingestion and processing on **AWS Lambda**, handling over 10 million records daily with 99.9% uptime.

- Implemented **RAG pipelines** using **LlamaIndex** and **ChromaDB** to integrate enterprise knowledge bases with **OpenAI API** **LLMs**, improving internal data retrieval by 40%.

- Built **full-stack** features for a B2B SaaS platform using **React**, **Next.js**, and **Node.js**, enhancing user engagement by 25% through improved functionality.

- Designed and deployed scalable **REST APIs** with **Node.js** (**Express.js**) and **MongoDB** for a high-traffic analytics dashboard, supporting 50,000 concurrent users.

- Containerized applications using **Docker** and orchestrated deployments on **AWS EKS**, achieving 99.95% system availability and streamlining infrastructure management.

- Contributed to **CI/CD pipelines** with **GitLab CI** for automated testing and deployment, accelerating release cycles by 30% and maintaining code quality.

- Developed custom **embeddings** for specialized domain data, enhancing the accuracy of search and recommendation features within an internal knowledge management system by 20%.

- Collaborated with product teams to translate business requirements into technical specifications for new features, delivering 12 successful releases over three years.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Nagarro | Digital Banking Platform Development*

- Developed backend **Java** microservices using **Spring Boot** for a digital banking platform, processing 20,000 transactions per minute, enhancing system modularity.

- Implemented **REST APIs** for customer account management and payment processing, integrating with third-party financial services, improving data exchange efficiency by 30%.

- Designed and maintained **SQL** databases, primarily **PostgreSQL**, ensuring data integrity and optimizing query performance for critical financial data, reducing lookup times by 25%.

- Contributed to frontend development using **React** and **JavaScript** to create intuitive user interfaces for banking applications, enhancing user experience by 15%.

- Assisted in setting up **CI/CD pipelines** using **Jenkins** and **Maven** for automated builds and deployments, reducing manual effort by 40%.

- Developed unit and integration tests using **JUnit** and **pytest** to ensure code quality and system reliability across various microservices, decreasing production bugs by 18%.
