## Summary

Software engineer connecting **React/TypeScript interfaces, Python APIs, and AI services** into production workflows. Builds internal tools, reusable service components, and evaluation pipelines with attention to testing, observability, and usability for operators, engineers, and research teams.

## Technical Skills

**Languages:** Python, TypeScript, JavaScript, SQL, Java, Go

**Full Stack:** React, Next.js, FastAPI, Flask, Node.js, REST APIs, GraphQL, PostgreSQL, Redis

**AI & Data:** LangChain, RAG, AWS Bedrock, Azure OpenAI, Vector Search, Prompt Evaluation, Data Pipelines

**Cloud & Delivery:** AWS Lambda, ECS, S3, SQS, Docker, Kubernetes, GitHub Actions, Jenkins, CI/CD

**Engineering:** Automated Testing, Code Review, CloudWatch, Prometheus, Grafana, Git, RBAC, Agile

## Professional Experience

**Software Engineer AI**  |  *Jun 2025 - Present*

*CIFC Asset Management | Enterprise Security AI*

- Built **React/TypeScript interfaces and Python REST APIs** for AI incident triage, connecting PostgreSQL, Redis, and AWS services into a unified review, approval, escalation, and audit-history workflow.

- Developed **RAG, prompt versioning, and evaluation pipelines** for duplicate detection, severity reasoning, and remediation guidance, with regression checks across incident categories.

- Packaged **reusable AI service components** for retrieval, workflow state, guardrails, telemetry, and error handling, enabling adjacent teams to build on a shared application foundation.

- Instrumented queue depth, LLM latency, failures, and operator decisions with **CloudWatch, Prometheus, and Grafana**, reducing repeat triage cycles by 35%.

- Implemented **role-based access, human approval queues, and source citations** so users could review AI recommendations against supporting evidence while protecting sensitive security data.

**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B Compliance AI Platform*

- Delivered **React/TypeScript and GraphQL applications** for evidence management, document review, policy authoring, and operator workflows on a platform serving 15+ enterprise clients.

- Built **Python backend services** with AWS Lambda, ECS, SQS, PostgreSQL, and Neo4j, integrating application workflows with tenant-specific compliance data and AI services.

- Implemented **LangChain tool-calling and evidence-review workflows** with Bedrock, Azure OpenAI, vector search, and evaluation datasets, reducing manual review effort by 70%.

- Added **AI job-latency, queue-failure, and evidence-coverage analytics**, giving teams visibility into automation gaps and release readiness before customer rollouts.

- Worked with users and product stakeholders on API/data modeling, demos, and production fixes; added **tenant isolation, audit logging, and CI/CD gates** to support reliable feature delivery.

**ML / Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Autonomous Systems & Workflow Automation*

- Built **Python telemetry pipelines** transforming image, sensor, and field-operations data into validated artifacts for labeling, analysis, and downstream ML workflows.

- Automated **identity, device, and data-validation workflows** across UKG, JumpCloud, and Azure AD integrations, reducing provisioning and validation time by 80%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies | LabOps / Scientific Workflow Platform*

- Delivered **React/TypeScript interfaces and backend APIs** for inventory, sample lineage, uploads, and experiment tracking, supporting a scientific platform used by 500+ researchers.

- Built **operational dashboards** for sample queues, upload failures, and experiment blockers, helping research and QA teams identify stalled workflows with fewer support handoffs.

- Implemented **background-job retries, validation rules, and failure-state reporting** for file uploads and sample processing, improving recovery from production errors.

- Optimized **PostgreSQL queries and backend jobs** for high-volume sample events, reducing recurring timeouts in daily scientific workflows.

- Authored **deployment checklists, feature-validation notes, and release smoke tests**, helping QA and infrastructure teams verify regulated workflow changes consistently.
