## Professional Experience

**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | AI-Powered Enterprise Automation*

- Architected scalable **microservices** using **Java Spring Boot** and **Kafka** on **AWS EKS**, enhancing system resilience and automation for enterprise security visibility.

- Developed responsive front-end components with **React.js** and **TypeScript**, integrating complex **REST APIs** to deliver an intuitive user experience, boosting engagement by 20%.

- Designed and implemented a serverless data processing pipeline using **AWS Lambda** and **S3**, automating **ETL** for secure analytics and compliance reporting, reducing data latency by 30%.

- Led the integration of **OpenAI API** into a customer support chatbot with **Python**, improving response accuracy by 25% and agent efficiency by 10%.

- Mentored junior engineers on best practices for **CI/CD** pipelines and secure coding standards, fostering team growth and improving code quality by 15%.

- Implemented **multi-tenant authorization** using **JWT** and **OAuth2** in **Node.js** microservices, ensuring data isolation for over 100 enterprise clients.

- Optimized database queries in **PostgreSQL** and **Redis**, improving API response times by 35% and supporting a 50% increase in concurrent users.

**Software Engineer**  |  *Jul 2023 - Jun 2025*

*Samay Systems LLC | Cloud-Native FinTech Platform*

- Engineered and deployed robust backend services with **Node.js** and **Express.js** on **AWS EC2**, handling over 1M daily financial transactions efficiently.

- Developed dynamic user interfaces using **React** and **Redux** for a trading platform, enhancing real-time data visualization and increasing user satisfaction by 18%.

- Managed and optimized **PostgreSQL** databases, writing complex queries and stored procedures to ensure data integrity for critical financial reporting by 25%.

- Implemented **Docker** containers for microservice deployment, improving development environment consistency and reducing onboarding time for new engineers by 15%.

- Integrated third-party APIs for payment processing and market data feeds, ensuring secure and reliable data exchange for financial operations with 99.9% uptime.

- Contributed to building **CI/CD** pipelines using **Jenkins** and **GitLab**, automating testing and deployment processes, accelerating release cycles by 20%.

- Performed comprehensive **unit testing** and **integration testing** with **Jest** and **Cypress** to maintain high code quality, reducing production defects by 22%.

- Utilized **OpenAI API** to build a transaction categorization module, enhancing fraud detection accuracy by 10% and streamlining compliance reviews after November 2022.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | B2B Web Application Development*

- Developed and maintained core features for an enterprise resource planning system using **Python** and **Django**, improving operational efficiency for 50+ clients.

- Designed and implemented **RESTful APIs** for data exchange between internal systems, reducing manual data entry efforts by 30% and improving accuracy.

- Created responsive web interfaces using **HTML**, **CSS**, and **JavaScript**, enhancing user experience and improving task completion rates by 15%.

- Managed **MySQL** databases, optimizing schemas and queries to support high data volumes and improving report generation speed by 20%.

- Collaborated with product teams to translate business requirements into technical specifications, ensuring timely delivery of features and reducing rework by 10%.
