## Professional Experience


**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Security Platform*




- Built reusable **React.js** component library and **Java Spring Boot** REST APIs for a customer-facing platform serving 10,000+ daily active users with consistent UI accessibility standards.

- Championed **GitHub Copilot**, **Cursor**, and **Anthropic Claude Code** adoption, reducing boilerplate authoring by 40%, improving code review throughput 25%,  accelerating team feature delivery.

- Shipped an agentic AI assistant using **LangGraph** and **OpenAI GPT-4o** that reduced manual workflow steps by 45%, demonstrating end-to-end GenAI product feature development and deployment.

- Designed **Hibernate ORM** entity models and **PostgreSQL** schemas for a multi-tenant SaaS application, optimizing query performance through strategic indexing and reducing p99 latency by 35%.

- Wrote comprehensive **JUnit** and **Jest** test suites covering critical business logic, raising code coverage from 48% to 82% and consistently catching regressions before production deployment.



**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance Platform*




- Led full-stack feature development across a **React** and **Spring Boot** B2B compliance platform, collaborating with cross-functional teams and shipping two major product releases on schedule.

- Modeled complex **Hibernate ORM** entity relationships for compliance workflows, writing optimized **PostgreSQL** queries that reduced report generation time from 30 seconds to under 3 seconds.

- Redesigned the compliance audit trail UI in **React.js**, adding filterable data tables, date range pickers, and CSV export that reduced user-reported support tickets by 60%.

- Integrated **OpenAI GPT-4** API into a **Java Spring Boot** microservice to auto-classify incoming compliance document types, cutting manual document review and triage time by 50%.

- Participated actively in weekly code reviews, championed clean architecture patterns, and mentored one junior engineer, improving team code quality scores by 20% over two quarters.



**Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Autonomous Vehicles*




- Developed **React.js** dashboard components for the autonomous fleet management UI, visualizing real-time tractor telemetry and GPS location data for operators across 50+ connected field devices.

- Implemented **Java Spring Boot** REST endpoints for tractor session and telemetry logging, integrating with **PostgreSQL** to persist and query historical operational data across device fleets.

- Collaborated with senior engineers to diagnose and resolve three high-priority production UI bugs affecting critical operator workflows, shipping verified and tested hotfixes within a sprint.



**Software Engineer**  |  *Aug 2021 - Aug 2022*

*Zemoso Technologies | LabOps Platform*




- Built full-stack features using **React.js** and **Java Spring Boot** for a regulated LabOps platform, improving scientific data entry UI and serving over 500 active researchers.

- Designed **Hibernate ORM** entity mappings and **PostgreSQL** queries for multi-step lab sample tracking, cutting report generation time by 30% while supporting full compliance audit requirements.

- Configured **Jenkins** CI/CD pipelines and authored 80+ **JUnit** and **Jest** test cases, establishing testing standards that raised overall platform code coverage from 40% to 72%.
