## Professional Experience


**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Document Platform*




- Built **React.js** and **TypeScript** component library, collaborating with UX designers to enforce WCAG AA accessibility and ship 12 reusable form and signature capture UI components.

- Developed **Java Spring Boot** REST APIs for document signing workflows, containerized backend services using **Docker** and deployed on **Kubernetes**, cutting deployment rollback time by 40%.

- Designed **Hibernate ORM** entities and **PostgreSQL** schemas for a multi-tenant document platform, optimizing query plans through strategic indexing and reducing p99 response latency by 35%.

- Shipped an AI document assistant using **LangGraph** and **OpenAI GPT-4o** that reduced manual review steps by 45%, collaborating cross-functionally with product and UX design teams.

- Championed **GitHub Copilot** and **Cursor** for team-wide assisted development, reducing boilerplate authoring by 40%, while maintaining 82% test coverage through comprehensive **Jest** and **JUnit** suites.



**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B Compliance Platform*




- Led full-stack feature development across a **React** and **Spring Boot** B2B compliance platform, collaborating with product managers to ship two major product releases on schedule.

- Modeled **Hibernate ORM** entity relationships for compliance workflows, writing optimized **PostgreSQL** queries on **AWS RDS** reducing report generation from 30 seconds to under 3 seconds.

- Redesigned the compliance audit trail UI in **React.js**, adding filterable data tables, date range pickers, and CSV export that reduced user-reported support tickets by 60%.

- Integrated **OpenAI GPT-4** API into a **Java Spring Boot** microservice to auto-classify incoming compliance document types, cutting manual document review and triage time by 50%.

- Participated actively in weekly code reviews, championed clean architecture patterns, and mentored one junior engineer, improving team code quality scores by 20% over two quarters.



**Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Autonomous Vehicles*




- Developed **React.js** and **TypeScript** dashboard components for autonomous fleet management UI, visualizing real-time tractor telemetry and GPS data for operators across 50+ connected field devices.

- Implemented **Java Spring Boot** REST endpoints for tractor session and telemetry logging, integrating with **PostgreSQL** to persist and query historical operational data across device fleets.

- Collaborated with senior engineers to diagnose and resolve three high-priority production UI bugs affecting critical operator workflows, shipping verified and tested hotfixes within a sprint.



**Software Engineer**  |  *Aug 2021 - Aug 2022*

*Zemoso Technologies | LabOps Platform*




- Built full-stack features using **React.js** and **Java Spring Boot** for a regulated LabOps platform, improving scientific data entry UI and serving over 500 active researchers.

- Designed **Hibernate ORM** entity mappings and **PostgreSQL** queries for multi-step lab sample tracking, cutting report generation time by 30% while supporting full compliance audit requirements.

- Configured **Jenkins** and **GitHub Actions** CI/CD pipelines, authoring 80+ **JUnit** and **Jest** test cases that raised overall platform code coverage from 40% to 72% consistently.
