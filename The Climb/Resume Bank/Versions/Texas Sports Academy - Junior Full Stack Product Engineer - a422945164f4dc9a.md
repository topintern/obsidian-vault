 Full-Stack AI Engineer

## Summary

Hands-on engineer shipping **React/TypeScript products, Node.js APIs, and PostgreSQL-backed workflows** for real users. Owns features from product scoping and data modeling through interface implementation, deployment, and production fixes. Built customer-facing compliance software and internal tools for security teams and scientists.

## Technical Skills

**Frontend:** TypeScript, JavaScript, React, Next.js, HTML, CSS, Responsive UI, Reusable Components

**Backend & Data:** Node.js, Express, REST APIs, GraphQL, PostgreSQL, SQL, Redis, Python, Flask

**Product & Quality:** Feature Scoping, Customer Feedback, Auth0/JWT, RBAC, Cypress, Playwright, Git

**Delivery & Integrations:** AWS, Docker, GitHub Actions, Jenkins, CloudWatch, LangChain, OpenAI, Bedrock

## Professional Experience

**AI Automation Engineer**  |  *2025 - Present*

*Epik Solutions | Enterprise Security*

- Built **React/TypeScript operational dashboards** consolidating telemetry from 15+ security systems, replacing fragmented reporting and saving 20+ hours of manual work each week.

- Delivered an **AI incident-triage workflow** with React, Python, REST APIs, and PostgreSQL, giving operators a single place to review alerts, approve actions, escalate issues, and inspect audit history.

- Developed **Node.js services and PostgreSQL queries**, applying indexing and caching to reduce API response times by 40% under concurrent production load.

- Instrumented queue depth, service latency, and workflow failures with **CloudWatch and application telemetry**; resolved silent runbook failures and improved automation success rates by 25%.

- Automated authentication-flow validation with **TypeScript/Cypress** and deployed containerized services through GitHub Actions, supporting repeatable releases of internal applications.

**Founding Engineer (Full Stack AI)**  |  *2023 - 2025*

*Samay Systems LLC | AI Compliance SaaS*

- Shipped **customer-facing features end to end** for a compliance SaaS product serving 15+ enterprise clients, taking work from discovery and design tradeoffs through API/data modeling, demos, and post-launch fixes.

- Built **React/TypeScript interfaces** for evidence upload, review queues, policy authoring, and integration configuration, iterating with early customers through weekly product releases.

- Developed **Node.js REST and GraphQL APIs** with PostgreSQL data models for multi-tenant workflows; implemented tenant isolation across relational, graph, and object storage.

- Delivered a searchable **hierarchical controls registry** with independent pagination, filters, inline expansion, and tabbed detail views, replacing spreadsheet-based compliance tracking.

- Integrated **PDF/image previews and drag-and-drop uploads** into evidence review, allowing users to attach and inspect audit artifacts directly in the relevant control workflow.

- Implemented **Auth0 JWT validation, role-based access, and audit logging**; added Cypress tenant-isolation checks to GitHub Actions to protect customer data during releases.

- Connected **Microsoft Entra ID, GitHub, Jira, and AI services** through backend integrations; built LangChain/Bedrock evidence-review automation that reduced manual auditor effort by 70%.

**Software Engineer**  |  *2020 - 2022*

*ZeMoSo Technologies | LabOps Platform*

- Delivered **React/TypeScript and PostgreSQL-backed features** across 10+ LabOps modules, including inventory, sample tracking, batch records, and experiment uploads, for a platform used by 500+ scientists.

- Built **REST APIs and background jobs** for experiment workflows; added validation, retries, and failure-state reporting so users could recover from upload and sample-processing errors.

- Optimized **PostgreSQL schemas, indexes, and SQL queries** for compound, container, and batch records, improving report generation and reducing repeated timeout/debug cycles.

- Created **operational dashboards** for sample queues, upload failures, inventory exceptions, and experiment blockers, helping lab users resolve issues with fewer support handoffs.

- Authored **100+ test cases**, resolved production defects, and worked with product and QA on weekly releases, using Jenkins quality checks and release-validation notes to verify changes consistently.
