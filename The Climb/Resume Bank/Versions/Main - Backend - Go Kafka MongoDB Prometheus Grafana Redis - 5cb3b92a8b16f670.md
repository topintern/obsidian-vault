## Professional Experience



**Software Engineer**  |  *Jun 2025 - Present*

*Epik Solutions | Enterprise Security Data Platform*




- Designed and maintained **Golang** and **Python** microservices for a cloud data platform, applying event-driven patterns with Kafka to improve data-processing throughput by **35%**.

- Built **REST/JSON APIs** for configuration, reporting, and operational workflows backed by PostgreSQL-style data models and MongoDB, sustaining **sub-50ms p95** read latency across **10M+** records.

- Debugged production services on **Linux**, tracing API failures, queue backlogs, container logs, and configuration issues to reduce mean incident detection time by **40%**.

- Optimized **Redis** caching layers across hot read paths, designing cache invalidation strategies and TTL policies that reduced database load by **60%** and cut API response times by **40%**.

- Partnered with SRE and database teams on **Kubernetes** deployment topology, service reliability, performance profiling, and rollout readiness for distributed microservices.

- Documented service functionality, API contracts, testing strategy, and troubleshooting flows for production support and cross-team handoffs.



**Backend Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance AI Platform*




- Architected distributed backend microservices in **Golang**, **Python**, and Node.js for a multi-tenant platform serving **15+ enterprise clients**, sustaining **99.9% uptime**.

- Designed **PostgreSQL**, MongoDB, and Redis data models for high-read/write workloads, optimizing indexes and query paths to improve retrieval performance by **45%**.

- Built Kafka-based **message queue** and event pipelines for real-time data ingestion, decoupling producers and consumers across **5+ microservices** and reducing processing latency by **35%**.

- Developed **REST APIs** for configuration, reporting, tenant administration, and operational data access using JSON payloads, XML export paths, and stable service contracts.

- Containerized services with **Docker** and deployed on **Kubernetes**, configuring HPA, liveness probes, rollback checks, and CI/CD workflows that reduced deployment downtime by **40%**.

- Worked with product, SRE, and data stakeholders to troubleshoot defects, review database changes, and document release behavior for customer-facing workflows.



**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Autonomous Vehicle Telemetry*




- Built **Python** data pipeline services on AWS Lambda, designing event-driven ingestion workflows that processed sensor telemetry with **40%** fewer pipeline failures across 3 environments.

- Developed validation and transformation scripts enforcing schema consistency, reducing cross-system data integrity issues by **40%** across telemetry and operational workflows.



**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies | LabOps / Scientific Workflow Platform*




- Delivered **10+ backend services** using Node.js and Java REST APIs with **PostgreSQL**, designing relational data models and indexed query patterns for **500+ scientists**.

- Analyzed and optimized slow **PostgreSQL** queries through execution-plan profiling and index tuning, improving application response times by **35%**.

- Built async validation and reporting workflows for large experiment files, improving reliability across upload, processing, and metadata search paths.

- Authored **100+ integration and unit tests**, diagnosed distributed service failures, and documented API behavior, test strategy, and release notes for regulated LabOps workflows.
