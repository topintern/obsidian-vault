**Neel Gali**

 Software Engineer | Ruby on Rails & Backend Systems

Sunnyvale, CA   |   [neelgali7@gmail.com](mailto:neelgali7@gmail.com)   |   +1 (475) 291-1455

## Summary

Software engineer with **5+ years of experience** building enterprise security, compliance SaaS, and LabOps applications. Strong in **Ruby on Rails**, REST APIs, SQL optimization, automated testing, and production support.

## Technical Skills

**Languages:** Ruby, SQL, Java, Python, JavaScript, TypeScript

**Backend:** Ruby on Rails, ActiveRecord, MVC, Object-Oriented Design, REST APIs, Sidekiq, Pundit, Spring Boot

**Databases:** PostgreSQL, MySQL, Redis, Schema Migrations, Indexing, Query Optimization, Caching

**Testing & Delivery:** RSpec, FactoryBot, Minitest, RuboCop, Git, GitHub Actions, Jenkins, CI/CD, Code Review

**Cloud & Web:** AWS, Docker, Microservices, CloudWatch, Prometheus, Grafana, React, HTML/CSS

## Professional Experience

**Software Engineer**  |  *2025 - Present*

*Epik Solutions | Enterprise Security*

- Developed **Ruby on Rails REST APIs** for enterprise workflows, implementing request validation and structured JSON responses for frontend clients and service integrations.

- Secured Rails endpoints with **JWT authentication and role-based access controls**, restricting access to enterprise resources based on authenticated user permissions.

- Improved backend response times by resolving **ActiveRecord N+1 queries**, adding eager loading, and tuning PostgreSQL composite indexes for frequently accessed records.

- Built **Sidekiq background jobs** for reporting, notifications, and third-party webhook delivery, moving long-running work off request paths with retry handling for failed tasks.

- Integrated Rails services with **Python/FastAPI** document-processing APIs, validating payload contracts and handling downstream failures across service boundaries.

- Added API rate limiting and investigated production bottlenecks using **Prometheus/Grafana** request, error, and latency metrics to guide performance fixes.

**Software Engineer**  |  *2023 - 2025*

*Samay Systems LLC | B2B Compliance SaaS*

- Owned **Ruby on Rails backend features** for compliance workflows, delivering three product releases across API development, business logic, data persistence, and production support.

- Introduced **Redis caching** for frequently accessed compliance data, reducing database read pressure and lowering average API response latency by **45%**.

- Expanded **RSpec model, controller, and service tests**, increasing coverage from **38% to 84%** and enforcing automated checks before merges through CI pipelines.

- Implemented **PostgreSQL tenant isolation** and Rails schema migrations, separating customer records and supporting enterprise compliance requirements.

- Replaced scattered authorization checks with **Pundit policy objects**, centralizing per-tenant resource scoping and access rules across Rails controllers.

- Deployed containerized Rails services to **AWS** with Docker and CI/CD, using health checks and rolling releases to support reliable production updates.

**Software Engineer**  |  *2020 - 2022*

*ZeMoSo Technologies | LabOps Platform*

- Built **Ruby on Rails APIs** and React features for laboratory workflows, implementing ActiveRecord models and CRUD operations for samples, inventory, and experiment records.

- Developed **versioned REST endpoints** with consistent JSON responses, request validation, and error handling to support predictable integration with frontend clients.

- Implemented **Pundit policy scopes** and role-based permissions to control access to laboratory records and actions across user groups.

- Optimized **PostgreSQL queries and ActiveRecord scopes** for sample tracking and reporting, reducing report generation time by **30%** through targeted index tuning.

- Wrote **RSpec, FactoryBot, and Minitest** coverage for backend behavior, pairing regression fixes with automated tests and reviewing changes with cross-functional engineering and QA teams.

- Automated **GitHub Actions CI/CD** for Rails services, running RSpec tests and RuboCop checks on pull requests and deploying validated builds to staging.
