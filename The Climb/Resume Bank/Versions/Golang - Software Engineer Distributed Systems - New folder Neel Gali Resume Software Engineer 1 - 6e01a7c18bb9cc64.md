**Founding Engineer**  |  *Aug 2023 - Jun 2025*

*Samay Systems LLC*

- Architected multi-tenant SaaS compliance platform for 15+ clients, scaling to 10,000+ users on AWS. Designed technology stacks ensuring high-quality, scalable, and reliable software solutions.

- Designed distributed backend systems using Go, AWS, PostgreSQL, and Neo4j. Implemented tenant isolation for relational/NoSQL databases, ensuring data integrity and system reliability.

- Developed compliance automation for evidence collection and scoring using Python. Reduced manual auditor effort by 70% through efficient data structures, contributing to software applications.

- Developed distributed data ingestion pipelines to process identity data into graph models. Ensured robust implementation, testing, and maintenance, contributing to backend systems.

- Developed full-stack React and GraphQL applications for compliance controls and data visualization. Contributed to all phases of the software development lifecycle, enhancing business operations.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built automated identity lifecycle system syncing 500+ employees across platforms using Azure Serverless architecture. Reduced provisioning time by 80% through technical design and implementation.

- Developed full-stack features (React, Go) for data labeling infrastructure. Improved annotation throughput by 20% for ML pipelines, applying data structures and algorithms development.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies*

- Delivered full-stack features for robotic lab automation platform used by 500+ scientists. Utilized React, Ruby on Rails, and PostgreSQL in a microservices architecture for scalable software solutions.

- Designed and implemented features across 10+ product modules, enabling accurate tracking of complex data. Contributed to technical design, ensuring high-quality software applications.

- Authored 100+ automated test cases and resolved critical production issues. Ensured data integrity and system reliability, contributing to documentation and software performance.
