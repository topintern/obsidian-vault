## Professional Experience


**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Security Platform*




- Architected and delivered scalable **Go** microservices for enterprise security platform, processing 50,000+ authentication requests daily with sub-100ms p99 latency across multi-tenant distributed infrastructure.

- Built high-performance **RESTful APIs** using **Go** and **gRPC**, implementing connection pooling and circuit breakers that reduced downstream service failures by 40% during traffic spikes.

- Designed and optimized complex **PostgreSQL** schemas with 20+ tables, writing advanced SQL queries with CTEs, window functions, and materialized views that improved reporting performance by 65%.

- Implemented distributed data pipelines using **AWS Lambda**, **S3**, and **SQS** for event processing, establishing fault-tolerant message patterns and idempotency guarantees for 1M+ daily events.

- Owned end-to-end feature delivery from design to production, leveraging **AI coding assistants** (Augment Code, GitHub Copilot, Cursor) daily to accelerate development velocity by 30% while maintaining code quality.

- Built **React** analytics dashboards integrated with Go backend APIs, reducing manual security reporting overhead by 20+ hours weekly for C-suite stakeholders and operational teams.



**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | Series A B2B SaaS Startup*




- Joined early-stage compliance startup (pre-Series A) and owned complete backend architecture using **Golang**, **Python**, **AWS CDK**, and **PostgreSQL**, scaling platform from 0 to 15+ enterprise customers.

- Designed and built production **Go** microservices for identity sync and access graph generation, implementing distributed worker pools and job queues that processed 5M+ daily events reliably.

- Architected multi-tenant **distributed systems** with per-tenant PostgreSQL schemas and **Neo4j graph databases**, implementing isolation guarantees, data partitioning strategies, and cross-region replication for high availability.

- Wrote complex **SQL** queries and stored procedures for compliance reporting, optimizing joins across 30+ tables and reducing audit report generation from 45 minutes to under 2 minutes.

- Built **AI-enabled** compliance automation using **AWS Bedrock** and **LangChain**, creating revenue-generating features that reduced customer manual effort by 70% and became key product differentiators for sales.

- Deployed 17 **AWS CDK** stacks provisioning Lambda functions, ECS Fargate services, AppSync GraphQL APIs, and RDS instances, establishing infrastructure-as-code patterns for reproducible multi-environment deployments.

- Leveraged **AI development tools** daily to accelerate feature delivery, using LLM-assisted code generation, automated test writing, and intelligent refactoring to ship 8+ major features in 12 months.



**SDE Intern**  |  *Jul 2023 - Aug 2023*

*Monarch Tractor | Autonomous Agricultural Systems*




- Built automated identity provisioning system using **Python** and serverless architecture, integrating multiple HR and directory systems with event-driven workflows that reduced onboarding time by 80%.

- Developed **React** and **Golang** features for internal MLOps platform, contributing to data labeling infrastructure supporting computer vision models deployed on production autonomous tractors.



**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Scientific Cloud Platform*




- Developed backend services using **Python**, **Spring Boot**, and **Ruby on Rails**, building RESTful APIs and database schemas that served 500+ laboratory scientists across regulated workflows.

- Designed **PostgreSQL** data models for complex scientific workflows, writing optimized SQL queries with proper indexing strategies that reduced report generation time by 30% for large datasets.

- Built full-stack features across 10+ product modules including inventory tracking, experiment management, and batch processing, owning features end-to-end from requirements to production deployment.

- Established CI/CD pipelines with Jenkins and Docker, authored 100+ automated tests, and participated in agile ceremonies contributing to consistent sprint velocity and product quality improvements.
