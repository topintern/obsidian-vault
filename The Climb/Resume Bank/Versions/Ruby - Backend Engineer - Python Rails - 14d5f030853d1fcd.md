## Professional Experience


**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise SaaS Platform*




- Built **Ruby on Rails** RESTful API layer for an enterprise SaaS platform, implementing **JWT** authentication and role-based access control serving 20,000+ daily active users consistently.

- Optimized **ActiveRecord** query performance by replacing N+1 queries with eager loading and composite **PostgreSQL** indexes, cutting average API response time by 65% under production load.

- Built **Sidekiq** background job system for email delivery, report generation, and third-party webhook dispatch, processing 50,000+ async tasks daily with retry logic and dead-letter queues.

- Built **Python** **FastAPI** microservice for document ingestion and OCR processing, integrating with the Rails monolith via internal REST, handling 10,000+ document uploads per day reliably.

- Extended FastAPI microservice with **Pydantic** request validation and async **SQLAlchemy** sessions, enforcing strict schema contracts and reducing document ingestion error rates by 35% in production.

- Configured **Rack::Attack** middleware for per-IP and per-user API rate limiting, blocking credential stuffing attacks and protecting Rails endpoints serving 20,000+ concurrent users from abusive traffic.



**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | B2B Compliance Platform*




- Owned **Ruby on Rails** and **Python** backend for a B2B compliance SaaS, shipping three product releases on schedule and consistently serving 10,000+ enterprise platform users.

- Configured **Redis** as the Rails session store and a compliance lookup cache, reducing database read pressure by 60% and average API response latency by 45%.

- Authored **RSpec** test suite covering models, controllers, and service objects, raising code coverage from 38% to 84% and blocking failing merges via automated CI pipelines.

- Migrated a 3M+ record **PostgreSQL** database from a single-schema **Rails** app to per-tenant schema isolation, eliminating cross-tenant data leakage and satisfying enterprise compliance audit requirements.

- Built **Python** **Celery** task queue integrated with the Rails platform via **Redis**, processing 200K+ daily background jobs with configurable priority lanes and dead-letter retry queues.

- Refactored synchronous Python compliance services to **asyncio** using **httpx**, enabling concurrent third-party validation calls and reducing external API round-trip time by 55% under production load.

- Deployed **Rails** application to **AWS** using **Docker** and **Kubernetes**, configuring rolling deployments, health checks, and autoscaling policies that maintained 99.9% uptime during peak traffic spikes.

- Replaced ad-hoc Rails authorization checks with **Pundit** policy objects, enforcing per-tenant resource scoping across all controllers and cutting authorization-related security bugs on the compliance platform.

- Integrated **Elasticsearch** into the Rails compliance platform, indexing 5M+ regulatory documents and reducing document lookup time from 8 seconds to under 300ms for compliance officers.



**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps Platform*




- Built **Ruby on Rails** full-stack features for a LabOps SaaS platform, developing CRUD interfaces, REST endpoints, and **ActiveRecord** models for multi-step laboratory sample processing workflows.

- Developed **Python** data export APIs for lab reporting, building CSV and PDF generation pipelines that reduced manual report creation time by 30% for 500+ researchers.

- Built Python **pandas** pipelines for lab sample transformation, processing 500K+ monthly records with automated QC rules and cutting manual scientist data preparation time by 50%.

- Set up **GitHub Actions** CI/CD for Rails and Python services, automating **RSpec** and **pytest** runs, **Rubocop** linting, and **Heroku** staging deployments on every pull request.

- Authored optimized **PostgreSQL** queries and **ActiveRecord** scopes for lab sample tracking, reducing report generation time by 30% through index tuning and targeted query denormalization strategies.

- Added **Prometheus** and **Grafana** observability to Rails and Python services, tracking request throughput, error rate, and p99 latency for on-call incident triage and performance tuning.
