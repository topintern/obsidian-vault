**Neel Gali**

 Software Engineer

[neelgali7@gmail.com](mailto:neelgali7@gmail.com) | +1 (475) 291-1455 | Sunnyvale, CA | [linkedin.com/in/neelgali](https://linkedin.com/in/neelgali)

## Summary

Software engineer building **React/TypeScript interfaces, Python and Node.js APIs, and PostgreSQL-backed applications**. Experience turning user needs into tested features, integrating external services, and supporting production releases. Applies generative AI to practical security and compliance workflows.

## Technical Skills

**Languages:** Python, JavaScript, TypeScript, Java, SQL, HTML, CSS

**Web & Data:** React, Node.js, Express, Flask, REST APIs, GraphQL, PostgreSQL, Redis

**Development:** Git, GitHub Actions, Jenkins, Docker, Cypress, pytest, Unit/Integration Testing, Agile

**Cloud & AI:** AWS Lambda, S3, CloudWatch, Azure OpenAI, AWS Bedrock, LangChain, RAG

## Experience

**Software Engineer AI**  |  *2025 - Present*

*CIFC Asset Management | Enterprise Security*

- Built **React/TypeScript screens and Python REST APIs** for an incident-triage application, giving security analysts a single workflow to review alerts, approve actions, and track escalations.

- Integrated **PostgreSQL and Redis** with backend services to support workflow state and audit history; implemented role-based access and human approval steps for sensitive actions.

- Developed **AI-assisted incident summaries** with supporting evidence and recommended actions, reducing analyst workload by 30% across 1,000+ daily security events.

- Added **regression checks and prompt evaluations** for incident categorization and remediation guidance, helping identify behavior changes before AI workflow releases.

- Packaged **reusable service components** for retrieval, workflow state, and error handling, enabling adjacent teams to build AI features on a shared application foundation.

- Instrumented application failures, queue depth, and response latency with **CloudWatch, Prometheus, and Grafana**, helping troubleshoot production issues and reduce repeat triage cycles by 35%.

**Founding Engineer (Full Stack AI)**  |  *2023 - 2025*

*Samay Systems LLC | B2B Compliance SaaS*

- Developed **React/TypeScript features** for evidence upload, review queues, and policy management on a compliance platform serving 15+ enterprise clients.

- Built **Node.js REST and GraphQL APIs** with PostgreSQL data models, connecting frontend workflows to tenant-specific compliance records and backend integrations.

- Worked with product stakeholders and early users to refine requirements, demonstrate features, and incorporate feedback into **weekly releases**.

- Implemented **Auth0 JWT validation, role-based access, and audit logging**; integrated Cypress smoke tests into GitHub Actions to check tenant-isolation boundaries during releases.

- Connected enterprise systems including **Microsoft Entra ID, GitHub, and Jira** to collect identity and activity data for compliance review and reporting.

- Built **LangChain/Bedrock evidence-review workflows** that summarized supporting documents and scored controls, reducing manual auditor effort by 70%.

**Software Developer Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Internal Tools & Automation*

- Implemented an **employee-management automation system**, reducing manual HR tasks by 40% and saving approximately 150 hours per month.

- Wrote **Python integrations for UKG, JumpCloud, and Azure AD APIs** to synchronize user data and automate account, device, group, and license-management tasks.

- Used **AWS Lambda, S3, and CloudWatch** to run scheduled automation, store operational data, and monitor execution through application logs.

## Education

**Master's in Computer Science**, Oklahoma State University  |  *May 2024*

**Bachelor's in Computer Science**, JNTU Hyderabad  |  *2021*
