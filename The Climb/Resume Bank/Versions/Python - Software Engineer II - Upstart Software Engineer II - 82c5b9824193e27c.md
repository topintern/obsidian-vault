## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Lifecycle Marketing Platform*

- Designed and launched a **Ruby** microservice for a unified communications platform leveraging **AWS SNS** and **SQS**, processing 5M real-time event-triggered messages daily, boosting engagement by 15%.

- Developed a **Python** self-serve marketing automation tool using **AWS Lambda** and **DynamoDB** for campaign orchestration, empowering Growth teams to launch 20+ experiments weekly, increasing user activation 12%.

- Implemented **Hightouch** reverse **ETL** workflows on **Databricks** to sync customer segmentation data from **Snowflake** to **Iterable** **CDP**, ensuring target accuracy for 10M users, improving campaign ROI by 10%.

- Led system design for a high-throughput messaging architecture with **Kafka** and **Spring Boot** **APIs**, handling 10,000 requests per second, reducing message delivery latency by 30% for critical alerts.

- Championed **Terraform** for **AWS** infrastructure as code, establishing robust **CI/CD** pipelines and **Prometheus** observability, reducing deployment time by 40% and MTTR by 25%.

- Engineered **Python** data pipelines with **Airflow** to ingest and transform customer data from 10+ third-party **APIs**, enriching profiles for 2M users, enhancing personalization effectiveness by 18%.

- Enhanced platform security and data governance by implementing **OAuth2** for **API** authentication and **AWS KMS** for encryption, ensuring compliance for 100% of sensitive customer data.

**Software Engineer**  |  *Jul 2023 - Jun 2025*

*Samay Systems LLC | FinTech Data Platform*

- Developed and maintained scalable **Java** **Spring Boot** microservices for a FinTech data platform on **AWS EC2**, processing 500,000 financial transactions daily, achieving 99.9% uptime.

- Built real-time streaming data pipelines using **Apache Kafka** and **Kinesis** for credit risk assessment, processing 1GB of data per minute, reducing fraud detection time by 50%.

- Designed and implemented **RESTful APIs** in **Python** to integrate with external financial institutions, exposing normalized data from 10TB+ large datasets, increasing data accessibility for analysts by 35%.

- Optimized database performance for **PostgreSQL** on **AWS RDS** by implementing query tuning and indexing strategies, reducing critical report generation time from 6 hours to 1 hour.

- Deployed and managed microservices using **Docker** and **Kubernetes** on **AWS EKS**, improving application scalability and resource utilization by 25% while reducing operational overhead.

- Configured comprehensive monitoring and logging with **Prometheus** and **Grafana** for critical services, proactively identifying and resolving 80% of potential issues before user impact.

- Integrated **OpenAI API** into a **Python** service for natural language processing of financial documents, automating data extraction for 10,000 documents monthly, improving data entry accuracy by 15%.

- Enhanced system reliability by establishing incident response protocols and implementing automated alerts via **PagerDuty**, reducing critical incident resolution time by 20% across the platform.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Custom Software Development*

- Developed robust **Java** **Spring Boot** backend services and **RESTful APIs** for client-specific web applications, supporting 100,000 active users, ensuring 99.8% API availability for all services.

- Designed and optimized relational database schemas using **PostgreSQL** and wrote efficient **SQL** queries, improving data retrieval performance by 40% for customer-facing dashboards.

- Collaborated with frontend teams to integrate **JavaScript**-based user interfaces with backend **APIs**, ensuring seamless data flow and functionality for 5 major client projects.

- Implemented comprehensive unit and integration tests using **JUnit** and **Mockito**, achieving 85% code coverage for critical modules, reducing production bugs by 25% across applications.

- Conducted performance profiling and refactored critical code sections, reducing application response times by 15% for high-traffic components, enhancing overall user experience.

- Utilized **Git** for source code management, implementing branching strategies and code reviews, facilitating collaborative development for a team of 10 engineers, boosting productivity by 10%.
