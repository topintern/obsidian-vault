## Professional Experience

**AI Automation Engineer**  |  *Jun 2025 - Present*

*Epik Solutions*

- Embedded directly with internal security stakeholders as **sole engineer** on the workstream, owning **technical design end-to-end** and automating 40% of SOC workflows, cutting MTTR by 15 minutes

- Built real-time **React**-based analytics dashboards aggregating telemetry from 15+ systems, eliminating 20+ hours/week of manual reporting and improving decision latency for C-suite stakeholders

- Developed AI-driven incident triage pipelines (**Python**, **n8n**, **Azure OpenAI**) processing 1,000+ daily security events, reducing analyst workload by 30% while ensuring **CI/CD** governance using **Terraform Sentinel**

- Shipped **drama-free** automation by resolving silent execution failures in distributed **Go** runbooks and hardening **TypeScript**/**Cypress** test suites for complex authentication flows, improving pipeline success rates by 25%

- Deployed and debugged services directly in client-facing **Azure** environments (**Docker**, **Kubernetes**, **GitHub Actions**), taking **ownership from design through production** incident response

- Partnered directly with security leadership to scope and prioritize a fast-moving automation roadmap, converting ambiguous asks into **shipped tooling within days** rather than multi-week sprint cycles

**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Joined as **founding engineer** and took **end-to-end ownership** of architecture and delivery for a multi-tenant **AI compliance SaaS** platform, scaling from zero to 15+ enterprise clients and 10,000+ users per org on **AWS**

- Made **independent technical-design calls** across the stack — **Golang**, **AWS CDK**, **Lambda**, **ECS**, **AppSync**, **SQS**, **PostgreSQL**, and **Neo4j** — with strict tenant isolation across relational, graph, and object storage layers

- Built LLM-powered compliance automation (**AWS Bedrock**, **LangChain**, **MCP**, **n8n**) to orchestrate evidence collection, summarization, and control scoring, reducing manual auditor effort by 70%

- Owned distributed pipelines ingesting 5M+ daily identity events into knowledge graphs, shipping a **GraphRAG**-based compliance chatbot that cut unauthorized user access footprints by 30%

- Instituted continuous **Cypress** smoke-tests within **GitHub Actions** to verify tenant-isolation boundaries pre-release, keeping launches **drama-free** across high-availability environments

- Iterated directly with enterprise customers during pilot rollouts to harden onboarding and configuration flows, cutting **time-to-first-value** from weeks to under 48 hours

**IT Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built an automated identity lifecycle system syncing 500+ employees across **UKG**, **JumpCloud**, and **Azure AD** using (**AWS**/**Azure**) **Serverless** architecture, reducing provisioning time by 80%

- Engineered a **TypeScript** automation suite using **Cypress** to perform end-to-end validation of identity lifecycle transitions, resolving edge cases in cross-platform (UKG/Azure AD/JumpCloud) propagation

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered full-stack features for a cloud-based robotic lab automation platform used by 500+ scientists, working across **React**, **Ruby on Rails**, **Spring Boot** and **PostgreSQL** in a **microservices** architecture

- Designed and implemented features across 10+ core product modules (inventory, compounds, batch tracking, LCMS uploads, container linkage), enabling accurate tracking of complex experimental data

- Engineered a custom **TypeScript** wrapper for **Playwright**/**Cypress** to perform automated 'proof-of-concept' validation, capturing DOM snapshots across complex scientific experimentation workflows

- Architected **RESTful APIs** in **Spring Boot** and **PostgreSQL** for inventory, batch-tracking, and container-linkage modules, reducing average query response time by 30% through schema and index optimization

- Collaborated directly with 500+ scientists to translate complex experimental workflows into sprint-ready engineering tasks, replacing manual spreadsheet tracking with production features
