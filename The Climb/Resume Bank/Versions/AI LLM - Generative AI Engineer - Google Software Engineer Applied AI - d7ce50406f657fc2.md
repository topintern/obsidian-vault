**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | Enterprise AI/ML Platform*

- Built **Python** **ETL pipelines** on **AWS Lambda** and **S3** processing 10M daily compliance records, reducing ingestion lag from 4 hours to 20 minutes.

- Designed and deployed **ML models** for **natural language processing** using **TensorFlow** on **AWS EC2**, improving sentiment analysis accuracy to 91% for client feedback.

- Developed **microservices** using **Java** and **Spring Boot** for **real-time data ingestion** into **Kafka** topics, supporting robust processing of 20K messages per second.

- Engineered robust **ML infrastructure** for **model deployment** using **Docker** and **Kubernetes** on **AWS EKS**, achieving 99.9% uptime for critical services.

- Integrated **OpenAI API** into a customer support chatbot for enhanced **natural language understanding**, reducing agent resolution time by 18% post-Nov 2022.

- Optimized **PostgreSQL** database queries for **large-scale data storage**, reducing report generation time by 40% and improving application responsiveness.

- Implemented **CI/CD pipelines** with **Jenkins** and **Git** for automated **model retraining** and **deployment**, accelerating release cycles by 35% weekly.

- Developed **data processing** modules in **Python** for feature engineering of diverse datasets, feeding **ML models** and boosting predictive accuracy by 12%.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*Zemoso Technologies | Enterprise SaaS Application Development*

- Developed robust **RESTful APIs** using **Java** and **Spring Boot** for a customer management platform, handling 5M daily requests with 99.9% availability.

- Implemented **distributed caching** with **Redis** to optimize data retrieval for high-traffic modules, reducing latency by 50% for critical user operations.

- Designed and maintained **PostgreSQL** schemas for various application features, ensuring data integrity and supporting millions of user accounts efficiently.

- Developed **frontend components** using **React** and **JavaScript** for an intuitive user interface, enhancing user experience and engagement by 15% across the platform.

- Contributed to **DevOps** practices by automating deployment scripts using **Shell** and **Ansible**, accelerating release cycles by 25% for new features.

- Collaborated with **cross-functional teams** to define **system architecture** for new modules, ensuring scalability and integrating seamlessly with existing services.
