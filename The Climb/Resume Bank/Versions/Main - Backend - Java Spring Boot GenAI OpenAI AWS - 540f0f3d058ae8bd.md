## Professional Experience


**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Security*




- Built scalable **Java** and **Spring Boot** backend services for **enterprise security workflows**, improving security visibility through auditable dashboards and reducing analyst reporting overhead by 35%.

- Implemented **MCP-based tool calling** with **OpenAI API** to build **AI agents** for security triage workflows, automating security metric collection and reducing manual overhead by 35%.

- Designed **LLM-powered agentic workflows** using **Azure OpenAI** and **LangChain** to automate security data ingestion pipelines, substantially reducing manual analyst collection and processing time by 40%.

- Architected **real-time data pipelines** using **Apache Kafka** and **Spark** to capture raw event streams, enabling accurate auditability and operational reporting across distributed security monitoring systems.

- Translated stakeholder requirements into **GraphQL APIs** and **Spring Boot** backend services powering security compliance reporting dashboards, improving data accuracy and cross-team operational efficiency by 25%.

- Monitored distributed production security automation systems using **Prometheus** and **Grafana**, proactively identifying performance bottlenecks and ensuring long-term auditability of compliance reporting pipelines with 99.9% uptime.



**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance*




- Owned end-to-end development of core compliance data modules in **Java** and **Spring Boot** for a **B2B SaaS** startup, operationalizing audit-ready workflows for enterprise finance clients.

- Integrated **OpenAI API** into compliance reporting pipelines to generate **AI-driven insights** and risk summaries, reducing manual analyst review time and improving decision accuracy by 20%.

- Engineered **RESTful APIs** using **Spring WebFlux** for real-time compliance data exchange with external partners, achieving 99.9% system reliability and sub-100ms response times for critical operations.

- Optimized **PostgreSQL** schemas and query plans for large-scale compliance datasets, reducing average report generation times by 25% and enabling real-time dashboards for compliance operations teams.

- Containerized **Java** compliance services using **Docker** and deployed on **Kubernetes** via **Jenkins** CI/CD pipelines, accelerating feature delivery while maintaining high availability across enterprise SaaS deployments.

- Contributed unit and integration tests for **Java** compliance services, achieving 90% code coverage and reducing production incidents through rigorous test-driven development and automated CI checks.



**Software Development Engineer Intern**  |  *Jul 2023 - Aug 2023*

*Monarch | Semi-Autonomous Agricultural Vehicles*




- Supported **Python** backend development for production environments powering **semi-autonomous agricultural vehicles**, enabling reliable real-world field operations and onboard sensor data telemetry collection for the team.

- Integrated vehicle sensor data streams into backend processing services, building robust **Python** pipelines that parsed and normalized real-time telemetry payloads for autonomous navigation decision systems.



**Associate Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Cloud-Based Scientific Operations*




- Developed **Java** and **Spring Boot** backend modules for a cloud-based scientific operations platform, enabling researchers to trace experiments and biological samples across laboratory workflows reliably.

- Designed **RESTful APIs** for client-facing laboratory applications, enabling seamless integration with third-party scientific tools and increasing data throughput for experiment and sample tracking by 20%.

- Optimized **SQL** queries and **PostgreSQL** schemas for scientific data storage, reducing average response times for critical laboratory traceability services and complex analytical queries by 30%.

- Contributed to a cloud-based microservices architecture using **Java**, enhancing scalability and maintainability of the scientific operations platform serving a growing research user base of 10K.

- Deployed and maintained **Java** backend services on **AWS EC2**, ensuring 99.8% system reliability and security compliance for handling sensitive scientific operational and laboratory experiment data.
