**Software Engineer**  |  *Jul 2025 - Present*

- Architected and implemented **LLM-powered RAG system** using **LangChain** and **Hugging Face** models on **AWS SageMaker**, processing medical queries with 90% accuracy.

- Designed and deployed scalable **AI infrastructure** on **AWS Fargate** and **Kubernetes** for real-time inference, supporting 10,000 concurrent users with 99.9% uptime.

**Software Engineer**  |  *Jul 2023 - Jun 2025*

*Samay Systems LLC | B2B Platform*

- Developed and maintained responsive **React** frontend components for a critical financial reporting dashboard, improving user experience and reducing load times by 25%.

- Built secure **RESTful APIs** using **Node.js** and **Express.js** for data exchange between frontend and **PostgreSQL** database, handling 1M daily transactions.

- Integrated **OpenAI API** into a client-facing data analytics tool (after Nov 2022) for natural language querying, enhancing data accessibility for 500+ users.

- Implemented real-time data streaming features using **Kafka** and **Python** on **AWS Lambda** for financial data aggregation, ensuring data freshness within seconds.

- Contributed to **full-stack development** of a multi-tenant **SaaS** platform, designing scalable **microservices architecture** with **Docker** and **AWS ECS**, onboarding 3 new clients.

- Optimized database queries and schemas in **PostgreSQL** for high-volume transactions, improving overall application performance by 30% and reducing latency.

- Designed and developed robust authentication and authorization modules using **JWT** and **OAuth2**, securing critical financial data and achieving 100% compliance.

- Automated testing frameworks with **Jest** and **Cypress** for frontend and backend components, reducing bug reports in production products by 40%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | SaaS Platform*

- Developed interactive **React** applications for enterprise clients, translating complex business requirements into intuitive **UX-minded** interfaces, increasing user engagement by 18%.

- Implemented robust backend services using **Java Spring Boot** and **PostgreSQL** for a global logistics platform, processing 500K daily requests efficiently.

- Configured and deployed applications on **AWS EC2** and **S3**, ensuring high availability and scalability for critical business operations, achieving 99.9% uptime.

- Collaborated on designing database schemas and optimizing queries for performance, reducing data retrieval times by 30% across various applications.

- Integrated third-party **APIs** for payment gateways and CRM systems, streamlining business processes and improving operational efficiency by 20% for clients.
