**Senior AI Engineer**  |  *Jul 2025 - Present*

- Engineered **multi-agent orchestration** systems with **CrewAI** and **LangGraph**, designing supervisor-agent hierarchies with dynamic routing that improved complex task completion accuracy by 32% over baselines.

- Built production **RAG pipelines** using **Pinecone** and **OpenSearch** vector databases with hybrid semantic search, improving AI response accuracy by 38% over baseline LLM retrieval for 10,000+ daily enterprise queries.

- Deployed **agentic AI** services on **AWS** (Lambda, ECS, S3) with **Docker** and **Kubernetes**, implementing **GitHub Actions** CI/CD pipelines that cut AI feature release cycles from two weeks to three days.

**AI/ML Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance*

- Trained and deployed **HuggingFace** fine-tuned **BERT**/T5 models for enterprise compliance document classification and information extraction, processing 10K+ documents monthly and reducing manual auditor effort by 70%.

- Built **Apache Kafka** event-driven pipelines to stream real-time compliance documents into ML model inference workers, decoupling 6+ microservices, improving throughput by 50% across 15+ enterprise clients.

- Integrated **OpenAI GPT-4** APIs in 2023 for unstructured compliance text summarization and Q&A, applying structured output prompting that reduced post-processing errors by 45% over rule-based extraction baselines.

- Built **RAG** pipelines with **Azure AI Search** vector databases in 2023-2024, pairing embedding-based retrieval with LLM generation to deliver context-aware compliance intelligence reports at 89% retrieval precision.

- Adopted **LangChain** and **LangGraph** in 2024 to orchestrate stateful multi-step compliance agent workflows, enabling parallel document processing and reducing end-to-end pipeline time by 35% at production scale.

- Provisioned ML and AI infrastructure on **AWS** (SageMaker, ECS, Lambda, S3) with **Terraform** IaC, enforcing **CI/CD** best practices for model versioning and reducing deployment errors by 40% across all tenants.

- Surfaced ML and AI outputs via **React.js** front-ends with real-time streaming responses, improving enterprise user task completion rates by 30% and reducing support escalations across 10,000+ production users.

**Associate ML Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps Platform*

- Trained **PyTorch** classification and regression models on scientific experiment datasets, building end-to-end **scikit-learn** feature engineering pipelines that reduced model training cycle time by 30% across LabOps modules.

- Fine-tuned **HuggingFace BERT**-based NLP models for domain-specific document classification and named entity extraction over lab reports, achieving 85%+ accuracy and replacing manual data entry for 500+ scientists.

- Built **AWS Lambda** and **S3**-triggered data ingestion pipelines for automated ML training dataset refresh, reducing manual data prep effort by 40% and ensuring model freshness across 3 production CV systems.

- Delivered full-stack experiment tracking features integrating **React.js** front-ends with **Spring Boot** REST APIs and **PostgreSQL**, providing accurate data management across 10+ regulated scientific workflows.

- Authored 100+ **pytest** automated test cases for ML data pipelines and model services, resolving critical production defects via systematic debugging and reducing regression incidents by 35% across LabOps modules.
