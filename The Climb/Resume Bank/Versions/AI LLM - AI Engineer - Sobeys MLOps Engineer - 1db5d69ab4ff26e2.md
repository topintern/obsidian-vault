**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | Data Engineering & AI Platform*




- Maintained and debugged production **ML pipelines** processing 50M+ daily events using **Apache Airflow** and **PySpark**, achieving 99.5% pipeline reliability through monitoring and alerting.

- Built scalable **data processing workflows** with **PySpark** on **Databricks** and **AWS Glue**, writing efficient UDFs for custom transformations and reducing processing time by 30%.

- Deployed **LLM-powered applications** using **Python**, **Hugging Face Transformers**, and **OpenAI API** on **Azure ML**, improving document classification accuracy by 22%.

- Implemented **vector search systems** with **FAISS** and **Elasticsearch** for semantic retrieval in RAG pipelines, reducing query latency by 200ms for 5000+ requests/minute.

- Designed **object-oriented Python** modules for ML feature stores using factory and strategy patterns, improving code reusability by 35% across multiple ML projects.

- Contributed to **MLOps infrastructure** using **Docker**, **Kubernetes**, and **AWS EKS** for model serving, enabling auto-scaling and high availability for ML endpoints.

- Partnered with Data Analysts and business teams to research operational processes, identifying 5+ automation opportunities that drove $500K in annual efficiency gains.

- Integrated **Snowflake** data warehouse for analytics workloads, building Python connectors for ML feature extraction and supporting bi-directional data flows with vector stores.



**Software Engineer**  |  *Jul 2021 - Aug 2022*

*Zemoso Technologies | Backend & Data Services*




- Developed robust backend services in **Python** using **FastAPI** and object-oriented design patterns, supporting 50,000+ active users with sub-200ms API response times.

- Built **ETL pipelines** with **Python** and **Pandas** for customer data processing, implementing modular class structures that reduced maintenance effort by 25%.

- Optimized **PostgreSQL** queries and database schemas for high-traffic applications, improving report generation performance by 30% for critical business operations.

- Implemented **CI/CD pipelines** using **Jenkins** and **Docker** for automated testing and deployment, accelerating release cycles by 25% and ensuring code quality.

- Collaborated with Product Managers and stakeholders across multiple concurrent projects in fast-paced environments, consistently delivering features on time with 95% sprint completion rate.
