## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Globant | Financial Analytics Platform*

- Led development of **Java** **Spring Boot** microservices for a high-performance financial analytics platform, enhancing data processing efficiency by 35% through optimized algorithms.

- Designed and implemented scalable **system architecture** utilizing **Docker** and **Kubernetes** to support low-latency data ingestion, improving system responsiveness for 5000+ daily users.

- Developed shared **Python** libraries for data aggregation and reporting, integrating with existing systems to streamline data delivery, reducing report generation time by 40%.

- Created responsive **Angular** front-end components for data visualization dashboards, improving user experience and enabling real-time insights for over 20 financial analysts.

- Implemented robust **CI/CD** pipelines using **Jenkins** and **Gradle** for automated testing and deployment, accelerating feature delivery by 30% across multiple environments.

- Optimized **SQL** queries and database schema for **DB2** and **Teradata** databases, significantly improving data retrieval performance for critical financial reports by 25%.

- Mentored junior engineers on **development and system architecture best practices**, improving team's code quality and reducing post-release defects by 15% through peer reviews.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Nagarro | Enterprise Banking Applications*

- Developed and maintained **Java** **Spring Boot** **REST APIs** for core banking services, processing 1M daily transactions and ensuring secure, reliable data exchange.

- Implemented automated testing frameworks using **JUnit** and **Mockito** for backend services, increasing code coverage to 90% and reducing regression bugs by 20%.

- Contributed to **Angular** front-end development, building interactive user interfaces for internal banking applications, enhancing workflow efficiency for 100+ operations staff.

- Managed code versioning and collaboration using **Git**, facilitating seamless integration of new features and reducing merge conflicts by 15% in a large team.

- Optimized database interactions with **DB2** using advanced **SQL** queries, improving data retrieval speeds for customer profile lookups by 30% daily.

- Authored **Shell Scripting** tools to automate deployment processes and server configurations, reducing manual setup time for new environments by 50%.

- Integrated **Gradle** into build processes, standardizing project dependencies and accelerating build times by 25% across various microservices and shared libraries.

- Integrated a **CI/CD** tool, **Jenkins**, to automate build, test, and deployment workflows, reducing release cycles by 20% and improving overall software delivery speed.

- Developed batch processing scripts in **Python** for daily reconciliation tasks against **Teradata** warehouses, ensuring data consistency and accuracy for 500,000 records.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*Persistent Systems | Client Data Management System*

- Developed backend modules using **Java** and **Spring Boot** for a client data management system, handling 5000+ client records daily with high reliability.

- Designed and implemented relational database schema and optimized **SQL** queries for **PostgreSQL**, improving data access latency by 20% for critical client information retrieval.

- Wrote comprehensive unit and integration tests using **JUnit** and **Mockito** for application components, achieving 85% code coverage and ensuring system stability.

- Collaborated on feature development and bug fixes, managing code changes using **Git** for version control, ensuring smooth team collaboration and code integrity.

- Developed **Shell Scripting** utilities to automate daily data validation and report generation tasks, improving data consistency and reducing manual effort by 25% across client portfolios.

- Implemented new features based on client feedback, enhancing user interfaces and improving overall application workflow efficiency for 100+ internal users by 10%.
