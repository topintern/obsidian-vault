## Profile

Software engineer pursuing an entry-level manufacturing engineering role, bringing experience in test validation, operational data analysis, process automation, and traceable documentation. Built software for regulated laboratory workflows and data pipelines for autonomous systems, partnering with QA and product teams to investigate defects and improve reliability.

## Skills

**Analysis & Validation**: Defect Analysis, Test Results, Data Quality, Regression Testing, Operational Metrics

**Process & Quality**: Workflow Improvement, Traceability, Audit Records, Release Validation

**Tools**: Python, SQL, PostgreSQL, REST APIs, Git, CI/CD, AWS/Azure

**Documentation**: Test Procedures, Validation Notes, Deployment Checklists, Technical Requirements

## Professional Experience

Software Engineer AI | Jun 2025 - Present | Epik Solutions | Enterprise Security / Incident Triage

- Developed an **incident-analysis workflow** that organized alerts, logs, and tickets into prioritized findings with supporting evidence, enabling consistent investigation and review.

- Built **operational monitoring for queue depth, latency, failures, and review decisions**, identifying repeated workflow bottlenecks and reducing repeat triage cycles by **35%**.

- Designed **regression evaluations and validation checks** across incident categories to assess software behavior before release and identify changes requiring further investigation.

- Implemented **approval steps and audit records** in Python-backed operational workflows, maintaining traceability between system output, user review, and follow-up actions.

Founding Engineer (Full Stack AI) | Jul 2024 - Jun 2025 | Samay Systems LLC | B2B Compliance SaaS

- Engineered a **multi-tenant compliance platform for 15+ enterprise clients**, translating requirements into data models, operational workflows, and validated software releases.

- Structured policies, controls, and supporting documents into **traceable compliance evidence**, improving consistency of records used for review and audit preparation.

- **Automated evidence-review workflows** to reduce manual effort by **70%**, while retaining source references for validation and follow-up investigation.

- Created **release-readiness reporting** for processing latency, queue failures, and evidence gaps, and implemented CI/CD gates for controlled changes across environments.

ML / Software Engineering Intern | Jun 2023 - Aug 2023 | Monarch Tractor | Autonomous Systems / Workflow Automation

- Built **Python pipelines to validate sensor, image, and field-operations data** for autonomous-system ML workflows, turning raw inputs into datasets suitable for analysis.

- Automated **data-quality and operational validation checks** alongside identity and device provisioning workflows, reducing provisioning and validation time by **80%**.

Software Engineer | Jul 2020 - Aug 2022 | ZeMoSo Technologies | LabOps / Regulated Workflow Software

- Delivered **LabOps workflow software for 500+ scientists**, covering inventory, sample lineage, scheduling, uploads, and experiment tracking in a regulated operating environment.

- Implemented **validation rules, role-based approval flows, and audit logs**, improving reliability and traceability of scientific data capture across backend services.

- Built **exception reporting for sample queues, failed uploads, and inventory discrepancies**, making workflow issues visible for investigation and resolution.

- Optimized **SQL queries and background processing** for high-volume sample events, reducing repeated timeout and debugging cycles in daily lab operations.
