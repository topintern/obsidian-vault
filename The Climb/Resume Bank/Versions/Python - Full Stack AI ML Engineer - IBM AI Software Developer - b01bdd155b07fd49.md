## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*EPAM Systems | AI-Powered Enterprise Solutions*

- Designed and implemented **Python** microservices with **FastAPI** for financial fraud detection, integrating **OpenAI API** for anomaly scoring, enhancing detection accuracy by 15%.

- Developed **Node.js** backend services on **IBM Cloud Infrastructure** with **Kubernetes** for an LLM content platform, supporting 500k daily requests efficiently.

- Architected and deployed **RAG** pipelines with **LangChain** and **PostgreSQL** vector stores, significantly improving content relevance for enterprise search by 20%.

- Led **Watsonx** integrations for a customer service chatbot, fine-tuning **Granite** models on proprietary data, achieving a 10% reduction in support tickets.

- Implemented **CI/CD pipelines** using **GitHub Actions** and **Docker** for automated testing and deployment of **Python** AI services, accelerating release cycles by 25%.

- Mentored junior engineers on **LLM prompt engineering** best practices and **micro-services architecture** principles, improving team productivity and code quality by 15%.

- Developed robust **JavaScript** frontend components using **React** for an AI-powered analytics dashboard, improving user engagement with data visualizations by 30%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Globant | Enterprise SaaS Platform Development*

- Built **Java** **REST** APIs with **Spring Boot** for enterprise HR SaaS, processing 100k daily transactions, enhancing system reliability by 20%.

- Implemented scalable data processing workflows using **Python** and **Apache Kafka** for real-time analytics, handling 5M events/hour, enabling faster business intelligence decisions.

- Designed and optimized **PostgreSQL** database schemas and queries for a high-volume e-commerce application, improving data retrieval performance by 35% for critical operations.

- Integrated **OpenAI API** into a document classification system using **Python** and **PyTorch** models, automating document categorization with 90% accuracy.

- Developed secure authentication/authorization modules using **JWT** and **Node.js** with **Express.js**, enhancing platform security and user access control by 25%.

- Collaborated on developing **Docker** containers and **Kubernetes** deployments for microservices, streamlining environment setup, reducing deployment time by 40% across teams.

- Configured **CI/CD pipelines** using **Jenkins** and **Git** for automated testing and deployment of backend services, reducing manual release efforts by 50%.

- Developed accessible **HTML**, **CSS**, and **JavaScript** frontends using **Angular** for a client portal, improving user experience and reducing load times by 15%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Thoughtworks | Agile Web Development*

- Developed robust backend APIs using **Ruby on Rails** and **PostgreSQL** for supply chain management, processing 50k daily inventory updates, improving data integrity.

- Implemented interactive **JavaScript** frontends with **React** and **Redux** for data visualization, enhancing user engagement and reducing page load times by 20%.

- Contributed to **CI/CD pipeline** setup with **Jenkins** and **Git** for automated builds and testing, accelerating deployment frequency by 30% for teams.

- Authored comprehensive unit and integration tests using **JUnit** and **Selenium** for critical application modules, reducing post-release defects by 25%.

- Participated actively in **agile development methodologies**, including daily stand-ups and sprint reviews, improving team collaboration and project delivery efficiency.

- Designed and optimized **MySQL** databases for a ticketing system, improving query performance by 40%, ensuring efficient data storage for 1M user records.
