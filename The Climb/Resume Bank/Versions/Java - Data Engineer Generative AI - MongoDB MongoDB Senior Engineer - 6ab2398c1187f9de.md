- Implemented high-performance **data migration** tools leveraging **Kafka** and **Debezium** for real-time **CDC** from diverse relational databases efficiently.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise SaaS Data Platform*

- Developed high-performance **backend systems** using **Java** and **Spring Boot** for an enterprise SaaS data platform, serving 10,000+ active users daily.

- Architected **distributed systems** for **event-driven architecture**, integrating **Kafka** to manage 20M data points per hour for real-time analytics delivery.

- Designed and implemented **RESTful APIs** with **Spring Security** for secure data access and management, improving system security posture by 15%.

- Managed and optimized **Postgres** and **MySQL** **relational data models**, enhancing data retrieval performance by 30% for crucial reporting functionalities.

- Implemented complex ETL processes using **Python** scripts on **AWS EC2**, reducing manual data preparation efforts by 40% weekly across departments.

- Contributed to client-side development for internal dashboards using **React** and **JavaScript**, improving developer efficiency and data visualization by 20%.

- Utilized **Docker** and **Git** for version control and containerization, streamlining deployment workflows and achieving 99.9% uptime for critical core services.

- Developed internal tools integrating **OpenAI API** for natural language processing on customer feedback, improving sentiment analysis accuracy by 18%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | B2B E-commerce Platform*

- Implemented critical **backend systems** for a B2B e-commerce platform using **Java** and **Spring Framework**, supporting 500 concurrent users effectively.

- Developed and maintained **RESTful APIs** for product catalog and order management, improving data consistency by 10% across various system modules.

- Designed and optimized **MySQL** database schemas and queries, reducing average query response times by 20% for high-traffic application endpoints.

- Integrated third-party payment gateways leveraging **Maven** and **Spring Boot**, enabling secure transactions and increasing platform revenue by 15%.

- Contributed to **CI/CD** pipeline setup using **Jenkins** for automated testing and deployment processes, decreasing software release cycles by 25%.
