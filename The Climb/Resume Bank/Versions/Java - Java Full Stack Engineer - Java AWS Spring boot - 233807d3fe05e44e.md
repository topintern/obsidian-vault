## Professional Experience

**Software Engineer**  |  *Jun 2025 - Present*

*Epik Solutions*

- Developed scalable Java Spring Boot microservices with RESTful API endpoints and Oracle database integration, applying secure coding standards that reduced API-level vulnerabilities by 30% in prod.

- Deployed Spring Boot applications on AWS (EC2, RDS Oracle, S3), configuring auto-scaling and IAM security policies to sustain 99.9% uptime for 10,000+ daily active enterprise users.

- Containerized Java microservices with Docker, orchestrating Kubernetes deployments via Jenkins CI/CD pipelines and cutting enterprise release cycle time from two weeks to three days.

- Collaborated in Agile sprint ceremonies, delivering 5+ Java backend features per sprint following compliance and secure coding standards with peer code reviews across cross-functional teams.

- Integrated Java Spring Boot backend APIs with React.js front-end modules, applying Spring Security and RESTful service patterns to support 10,000+ enterprise users with sub-100ms response times.

**Full Stack Engineer (AI/Search)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected React.js dashboards for identity and compliance visualization, collaborating with Java back-end engineers on RESTful API contracts ensuring consistent data flow for 10,000+ enterprise users.

- Built Java Spring Boot compliance APIs with Spring JPA/Hibernate and Spring Security over Oracle database, processing 10K+ records monthly and cutting manual auditor effort by 70%.

- Leveraged Redis for distributed session caching and Elasticsearch for full-text search across multi-tenant data, cutting average query response time by 45% under peak concurrent enterprise load.

- Designed distributed Java microservices backend applying circuit breakers, retry logic, and tenant isolation patterns that sustained 99.9% uptime across 15+ enterprise client deployments.

- Provisioned AWS infrastructure (ECS, RDS Oracle, Lambda) with Terraform IaC, enforcing CI/CD best practices and reducing manual deployment errors by 40% across all client environments.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Wrote Python and Shell scripting data pipelines for MLOps labeling infrastructure, automating annotation workflows and boosting overall throughput by 20% across 500K+ agricultural training data.

- Deployed serverless CI/CD data delivery pipelines integrating Docker containers and version-controlled datasets, sustaining model training across 3 production systems with 40% fewer pipeline failures.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Built Java Spring Boot services with Spring JPA/Hibernate over Oracle database, designing RESTful endpoints that tracked complex experimental data for 500+ scientists across 10+ product modules.

- Built React.js SPA feature modules with centralized error handling and async REST API integration, ensuring accurate data display for a regulated scientific platform used by 500+ scientists.

- Authored 100+ JUnit automated test cases, resolved critical Java production bugs via systematic profiling and debugging, reducing regression incidents by 35% and improving platform data integrity.
