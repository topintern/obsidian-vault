## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Cloud AI Operations Platform*

- Designed and implemented core components of an **AI-powered operational platform** using **Python** and **Kubernetes**, integrating **LLM frameworks** to automate complex incident response by 45%.

- Led the development of **AI-driven workflows** for cloud infrastructure management, leveraging **AWS Lambda** and **OpenAI API** to reduce manual intervention in system alerts by 60%.

- Developed scalable **Typescript** **microservices** and **REST APIs** on **Azure** for real-time data ingestion, processing 50M daily events to feed AI models accurately and efficiently.

- Implemented **prompt engineering** techniques and **PII redaction** solutions for sensitive data, ensuring compliance and enhancing model safety and reliability by 99.8%.

- Orchestrated **CI/CD pipelines** using **GitHub Actions** and **Docker** for seamless deployment of **AI models**, reducing release cycle time from weeks to just 2 days.

- Contributed to building a multi-tenant **cloud AI platform** leveraging **GCP** and **TensorFlow** for diverse client operational needs, achieving 99.9% uptime and scalability.

- Developed **LangGraph**-based agentic AI systems for dynamic operational task automation, processing intricate workflows across monitoring and ticketing tools, reducing resolution time by 35%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise SaaS Data Platform*

- Developed high-performance **Python** backend services on **AWS EC2** and **RDS** to support data processing for enterprise SaaS applications, handling 10M daily transactions efficiently.

- Integrated **OpenAI API** into a client-facing data analytics platform to provide intelligent insights, enhancing user engagement and data interpretation capabilities by 20%.

- Designed and built **ETL pipelines** using **Apache Airflow** and **S3** for **structured data** and **unstructured data**, improving data ingestion speed by 40% for reporting.

- Implemented scalable **microservices** architecture using **Spring Boot** and **Docker** for a core platform module, improving system reliability and reducing latency by 15%.

- Contributed to the development of **REST APIs** using **Node.js** and **Express.js** for integration with various monitoring systems, supporting 500+ daily API calls effectively.

- Automated infrastructure provisioning using **Terraform** on **AWS** for new service deployments, reducing setup time from days to just 3 hours for development teams.

- Developed real-time **event-driven architectures** components using **Apache Kafka** for streaming data, supporting instant alerts and analytics across 3 critical enterprise systems.

- Collaborated on **CI/CD pipeline** enhancements with **Jenkins** and **Kubernetes** for automated testing and deployment, decreasing critical bug introduction by 10%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | B2B E-commerce Solutions*

- Developed robust **Java** backend services for a high-traffic B2B e-commerce platform using **Spring Boot**, handling 500K daily user interactions with 99.9% uptime.

- Implemented **REST APIs** for third-party integrations and internal services, facilitating seamless data exchange and expanding platform capabilities for over 20 partners.

- Designed and managed **MySQL** databases, optimizing schemas and queries to improve data retrieval performance for critical business reports by 30%.

- Contributed to deployment automation scripts using **Bash** and **Ansible** on **AWS EC2** instances, reducing manual deployment efforts by 60%.

- Collaborated on building secure user authentication and authorization modules using **JWT** for sensitive data, ensuring compliance and protecting over 100K user accounts.

- Developed features for order processing and inventory management systems, utilizing **RabbitMQ** for asynchronous communication and improving system throughput by 15%.
