## Professional Experience

**Software Engineer**  |  *Jun 2025 - Present*

*CIFC Asset Mangement  | Enterprise Security Platform*

- Built **JWT-secured microservices** powering a **Next.js security dashboard** for enterprise security analyst teams, cutting mean incident resolution time **(MTTR) by 15 minutes** across 500+ enterprise users.

- Built foundational **Telemetry ingestion pipelines** on **AWS Lambda and S3**, establishing reusable event schemas adopted as cross-team platform standards for **10+ downstream** security dashboard services.

- Implemented **SSE streaming** endpoints in **FastAPI** to surface **AI-generated security insights** in real time, cutting **analyst wait time by 40%** across 1,000+ daily event reviews.

- Diagnosed and resolved cross-origin auth failures across FastAPI services, implementing **session controls and regression guards** that eliminated **recurring CORS bugs** for three enterprise client integrations.

- Containerized and shipped the **Python/Next.js stack to AWS** with Docker, Kubernetes, and GitHub Actions, enforcing Terraform infrastructure-as-code standards and lifting **CI pipeline reliability by 25%**.

- Implemented **RBAC authorization middleware** in FastAPI, evaluating tenant and role permission hierarchies to enforce **fine-grained access control** across all 500+ enterprise security platform users.

- Owned **Alembic migration scripts** for all **PostgreSQL** schema evolution in FastAPI services, enforcing backward-compatible, zero-downtime database changes that kept production and staging always in sync.

**Founding Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance Platform*

- Architected the multi-tenant **SaaS compliance platform** on AWS as founding engineer, scaling to **10,000+ active users per org** across 15 enterprise clients with 99.9% uptime.

- Designed **direct-to-S3 compliance evidence upload pipelines** for audit reports, writing **IAM policies** with least-privilege per-tenant access to prevent unauthorized document reads and writes.

- Delivered **compliance features** including evidence management, policy authoring, and document storage in **React/TypeScript** with a **Node.js GraphQL layer**, launching **8 production modules in 12 months**.

- Instrumented platform observability with **Prometheus and Grafana**, maintaining **99.99% uptime** across all production services and surfacing usage signals that drove a 15% feature adoption lift.

- Built **FastAPI async backends** on **AWS Lambda** with JWT-secured endpoints and **PostgreSQL**, processing real-time Salesforce and **NetSuite webhooks** to keep compliance evidence records always current.

- Automated **AWS EC2 deployments** with **Jenkins CI/CD and Terraform**, cutting **release cycles by 40%** and eliminating manual configuration that caused environment drift and deployment errors.

- Built **LLM-powered compliance features** using **Python**, **LangChain**, OpenAI API, and **AWS Bedrock** to automate **evidence summarization and control scoring**, reducing **manual auditor effort by 70%**.

- Introduced **AWS SQS background queues** and Python workers to fully decouple compliance microservices, driving **job completion to 99.5%** and eliminating cascade failures under peak load.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Strateos Labs | Scientific Experimentation Platform*

- Shipped **Experiment tracking features** like compound management, inventory and sample tracing for a **Cloud lab automation platform** used by 500+ scientists, working end-to-end across **React, Ruby on Rails and FastAPI**.

- Built **Python parsers**, validators, and **S3 ingestion APIs** for **h5ad, MTX, tar.gz** file formats, enabling reliable ** LCMS batch data** ingestion across 10+ platform modules.

- Implemented **Session auth and RBAC** for a regulated scientific platform, enforcing **strict per-team data isolation** and eliminating all unauthorized cross-team access to sensitive experimental records.

- Built **async Python job workers** to process long-running experiment results, **decoupling lab data** collection from the React frontend and cutting user wait time by 50%.

- Optimized slow **PostgreSQL and MySQL queries** backing complex scientific experiment reports, cutting **generation time from 2 minutes to 15 seconds** for 500+ active platform users.

- Authored **100+ unit and integration tests**, triaged and resolved critical production bugs, and enforced code quality standards through **Jenkins CI/CD** for a regulated scientific platform.
