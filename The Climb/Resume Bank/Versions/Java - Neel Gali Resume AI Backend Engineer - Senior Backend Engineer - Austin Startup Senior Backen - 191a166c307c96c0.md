## Professional Experience

**AI Automation Engineer**  |  *Jun 2025 - Present*

*Epik Solutions*

- Engineered scalable **backend services** using **Python** and **LangChain**, processing 1000+ daily security events, reducing MTTR by 15 minutes for internal security teams.

- Built **RAG** pipelines with **LangGraph** over internal security knowledge bases to automate SOC triage, integrating security platforms and optimizing incident response, reducing manual effort by 40%.

- Implemented **LangSmith** for continuous **LLM evaluation frameworks**, enhancing model accuracy by 15%, ensuring reliable AI performance for critical security operations.

- Designed and deployed **microservices** on **AWS**, improving system resilience and scalability, maintaining 99.9% uptime, crucial for enterprise security platform operations.

- Resolved complex **distributed runbooks** issues through first principles across UAT and prod on **Linux** environments, boosting pipeline success rates by 25%, enhancing Live Site reliability for security teams.

**Founding Engineer (FullStack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected multi-tenant AI compliance **SaaS** platform on **AWS** using **Python** for **backend** / AI engineering in a highly regulated compliance domain, **scaling to 10,000+ users** with tenant isolation.

- Built **LLM-powered compliance automation** with **LangChain**, **RAG pipelines** over Pinecone vector embeddings, and **AWS Bedrock**, reducing auditor effort by 70% and expediting evidence retrieval.

- Developed robust distributed **backend systems** using **Golang** and **PostgreSQL** with strict tenant isolation, supporting 15+ enterprise clients in a fast-paced **startup** environment.

- Implemented sophisticated **LLM evaluation frameworks** to validate AI-driven compliance logic, achieving 95% accuracy and ensuring high-quality evidence summarization.

- Engineered **data ingestion pipelines** (**Step Functions**, **Lambda**) for identity/activity data, populating graph-based access models and feeding **RAG** retrieval context to enhance security insights for clients.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built automated identity lifecycle system syncing 500+ employees across platforms, reducing provisioning time by 80% and eliminating manual effort.

- Developed full-stack features (**React**, **Golang**) for **MLOps** data labeling infrastructure, improving annotation throughput by 20% for crucial ML training pipelines.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered full-stack features for a cloud-based robotic lab automation platform, supporting 500+ scientists and improving experimental data tracking efficiency.

- Designed and implemented 10+ core product modules (inventory, compounds) using **Ruby on Rails**, enhancing accurate tracking of complex experimental data.

- Authored 100+ test cases and resolved critical production **backend** issues, ensuring data integrity and maintaining system reliability in a **highly regulated** scientific platform.
