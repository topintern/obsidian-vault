## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | AI-Powered Enterprise Solutions*

- Led development of an **AI-powered** agentic system using **LangGraph** and **OpenAI API** to automate complex workflows, reducing manual processing by 40% across 5 enterprise clients.

- Designed and implemented scalable **RAG** (Retrieval Augmented Generation) pipelines with **Pinecone** **vector store** on **AWS Lambda** for dynamic context retrieval, improving answer relevance by 35%.

- Developed an automated **eval harness** using **Langfuse** and custom **Python** scripts, establishing golden datasets to monitor LLM quality and detect regressions 90% faster.

- Implemented robust **data governance** and **PII** masking strategies for **external LLM APIs** on **AWS Glue**, ensuring 100% compliance with strict privacy regulations.

- Architected and deployed critical **context pipelines** for real-time **product data** assembly using **Kafka** and **AWS S3**, achieving 99.9% data availability for LLM inference.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | FinTech Data Platform*

- Developed and maintained high-performance **Python** and **Java Spring Boot** **RESTful APIs** for financial data processing, handling 10M daily requests with 99.9% uptime.

- Implemented scalable **ETL pipelines** using **AWS Glue** and **Python** for ingesting complex financial datasets into **PostgreSQL** and **DynamoDB**, reducing processing time by 30%.

- Integrated **OpenAI API** for text summarization and sentiment analysis within a secure internal **Python** application, improving data insight generation by 20% post-November 2022.

- Designed and deployed containerized **microservices** with **Docker** and **AWS EC2**, optimizing resource utilization and achieving a 20% reduction in operational overhead.

- Built robust **async systems** using **Kafka** for real-time data streaming and event processing, ensuring data consistency across 5 interdependent financial applications.

- Managed and optimized **PostgreSQL** and **DynamoDB** production databases, implementing schema migrations and performance tuning that improved query speeds by 15%.

- Automated deployment processes using **Jenkins** and **CI/CD** pipelines for multiple services on **AWS**, increasing release frequency by 40% and reducing manual errors by 90%.

- Conducted thorough **cost and latency tradeoffs** analysis for new features, ensuring optimal performance and budget adherence while integrating new third-party APIs with a 10% saving.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Enterprise SaaS Platform*

- Developed core backend services using **Java Spring Boot** and **RESTful APIs** for an enterprise SaaS platform, supporting over 50,000 active users with 99.95% uptime.

- Designed and implemented scalable database schemas in **PostgreSQL** and **MySQL**, optimizing complex queries to reduce response times by 20% for critical reporting features.

- Deployed and managed applications on **AWS EC2** and **AWS S3**, leveraging **Docker** for containerization to ensure consistent environments across development and production.

- Contributed to a modular **microservices** architecture, enhancing system scalability and maintainability, which allowed for a 30% faster integration of new client features.

- Implemented secure authentication and authorization mechanisms using **JWT** and **RBAC**, protecting sensitive user data and achieving 100% compliance with security audits.

- Automated software build and deployment processes using **Jenkins** and **Git** for **CI/CD**, accelerating release cycles by 25% and improving code quality.
