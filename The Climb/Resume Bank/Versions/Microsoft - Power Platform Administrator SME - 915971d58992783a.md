## Professional Experience

**Power Platform / Microsoft Automation Engineer**  |  *Jun 2025 - Present*

*Epik Solutions | Enterprise Security & Microsoft Platform Operations*

- Administered **Power Platform environments** across dev, test, and production, managing environment strategy, maker access, solution promotion, and operational controls for enterprise users.

- Implemented **DLP policies, security roles, RBAC, audit logging**, and connector governance to reduce risky data movement across Power Apps, Power Automate, Dataverse, and Microsoft 365 services.

- Built and supported **Power Apps and Power Automate** workflows backed by **Dataverse**, Azure storage, and enterprise APIs, automating SOC, compliance, and operations processes for **500+ users**.

- Developed **PowerShell automation** for user provisioning, environment inventory, access reviews, connector reporting, and administrative cleanup across Microsoft cloud and SaaS platforms.

- Integrated workflows with **Entra ID, Microsoft 365, ServiceNow-style ITSM, Dynamics 365-style CRM**, REST APIs, and security tools to streamline approvals, notifications, and operational escalations.

- Partnered with infrastructure teams supporting **Windows, Linux, IIS, Azure, Docker, Kubernetes**, and enterprise applications to troubleshoot platform issues and coordinate upgrades.

- Piloted **Copilot Studio and Azure OpenAI/AI Foundry** use cases for governed assistant workflows, adding human approval paths, auditability, and prompt/output review before production rollout.

**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance & Microsoft Integration Platform*

- Owned Microsoft-facing administration and integration work for a **multi-tenant compliance SaaS platform**, supporting customer workflows across identity, documents, CRM-style data, and audit evidence.

- Configured **Entra ID, OAuth/SAML-style SSO, SCIM-style provisioning**, tenant isolation, and role-based access controls for enterprise customers and internal operator workflows.

- Built **Dataverse/Dynamics 365-style data models** and admin workflows for accounts, contacts, evidence records, policy metadata, exception queues, and audit-trail reporting.

- Developed **Power Automate and Logic Apps-style workflows** for approvals, evidence intake, notifications, user lifecycle events, and compliance status updates across Microsoft 365 and third-party systems.

- Created **PowerShell and Python scripts** for environment validation, data reconciliation, migration checks, tenant setup, and recurring platform administration tasks.

- Supported **DLP/security governance** by documenting connector usage, sensitive data flows, access boundaries, and release controls for compliance-heavy customer deployments.

- Built **Power BI/Fabric-style reporting** and operational dashboards over PostgreSQL, Neo4j, and audit datasets, giving customer success and compliance teams self-service visibility.

**ML / Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Enterprise Identity & Operations Automation*

- Built identity lifecycle automation syncing **500+ employees** across UKG, JumpCloud, and **Azure AD/Entra ID**, reducing provisioning time by **80%**.

- Developed **PowerShell/Python validation scripts** and operational runbooks for account reconciliation, group membership checks, and exception handling across enterprise systems.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies | LabOps / Enterprise Workflow Platform*

- Built **enterprise workflow modules** for regulated LabOps teams using **React, Java Spring Boot, Ruby on Rails**, and PostgreSQL, supporting **500+ scientists** across **10+ product modules**.

- Developed admin-facing tools for inventory, batch tracking, sample lineage, LCMS uploads, user permissions, and operational reporting with strong auditability and data validation.

- Supported **Windows/Linux-hosted services**, CI/CD release checks, SQL troubleshooting, and production incident triage for high-trust scientific workflows.

## Education

**Master's in Computer Science**, Oklahoma State University, Stillwater  |  *Aug 2022 - May 2024*
