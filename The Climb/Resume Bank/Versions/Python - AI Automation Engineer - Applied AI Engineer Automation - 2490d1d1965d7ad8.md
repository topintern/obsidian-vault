## Professional Experience

**Automation Engineer (Full Stack / Distributed Systems)**  |  *Jun 2025 - Present*

*Epik Solutions*

- Designed and implemented scalable microservices with Python, integrating enterprise security platforms and
automating 40% of SOC workflows and reducing MTTR by 15 minutes for internal security teams

- Developed Generative AI incident triage pipelines using LLMs and n8n, processing 1,000+ daily events, cutting analyst workload by 30%.

- Built real-time analytics dashboards using React, aggregating telemetry from 15+ systems, eliminating 20+ hours/week manual reporting for C-suite.

- Automated enterprise cross-functional workflows using Power Platform and PowerShell scripting, serving 500+ users, reducing operational cycle times by 40%.

- Deployed services using Azure cloud-native infrastructure, Docker, Kubernetes, and CI/CD
pipelines, resolved silent execution failures in distributed Go runbooks, improving pipeline success rates by 25%.

**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected multi-tenant AI compliance SaaS platform for 15+ enterprise clients, scaling 10,000+ users on AWS, ensuring data and AI governance, tenant isolation and high availability.

- Designed serverless backend systems on AWS, built a hybrid data model (relational + Neo4j graph) enabling knowledge graphs and user access footprint over complex compliance relationships.

- Built LLM-powered compliance automation (Python, n8n, AWS Bedrock, LangChain) for evidence collection, summarization, and control scoring, reducing manual auditor effort by 70%.

- Implemented RAG-style querying over historical compliance data using vector databases, allowing customers to ask natural-language questions and receive contextual answers.

- Developed full-stack React + GraphQL applications for compliance controls, identity graph visualization, and evidence management for enterprise users.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built an automated identity lifecycle system syncing 500+ employees across UKG, JumpCloud, and Azure AD using Python and AWS serverless architecture, reducing provisioning time by 80%.

- Developed full-stack features (React, Python, Golang) for MLOps data labeling infrastructure, improving annotation throughput by 20% for ML training pipelines, performed monitoring and inference validation.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered full-stack features for a cloud-based robotic lab automation platform used by 500+ scientists, utilizing React, Ruby on Rails, and Spring Boot.

- Designed and implemented features across 10+ core product modules, implemented database migrations to create and manage batch tables, ensuring schema consistency across environments

- Authored 100+ test cases and resolved critical production issues, integrated CI/CD pipelines to validate models, enforce quality checks, and promote artifacts in a regulated scientific platform
