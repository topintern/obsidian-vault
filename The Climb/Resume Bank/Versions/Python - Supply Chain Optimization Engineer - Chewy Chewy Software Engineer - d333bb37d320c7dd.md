**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise Data Integration Platform*

- Developed and maintained **Python** ETL scripts for **data transformation** and integration of high-volume datasets into enterprise systems on **AWS S3**, processing 10M records daily.

- Implemented automated solutions to detect and resolve **data quality issues**, utilizing **Python Pandas** for validation and cleaning, reducing data errors in reporting by 70% consistently.

- Advocated for and enforced **unit testing** and **peer review** processes for all new code, ensuring high standards for **clean, maintainable code** across a team of six developers.

- Contributed to establishing robust **CI/CD pipelines** using **Git** and **Jenkins** for automated deployments on **AWS EC2**, reducing release cycles from bi-weekly to daily.

- Performed in-depth **root cause analysis** for critical production outages using **monitoring tools** and logs, resolving complex issues within 30 minutes, minimizing system downtime.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Cloud-based Logistics Solutions*

- Developed and optimized backend microservices using **Python Django** and **REST APIs** for a logistics platform, improving API response times by 30% for 100K daily requests.

- Supported **CI/CD pipelines** for automated build and deployment processes on **AWS EC2** instances, streamlining releases and reducing manual deployment time by 50%.
