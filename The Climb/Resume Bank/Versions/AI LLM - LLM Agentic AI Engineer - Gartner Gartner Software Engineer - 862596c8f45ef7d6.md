- Managed infrastructure with **Terraform** for **AWS** resources including **DynamoDB** and **S3**, ensuring reproducible environments and reducing setup time by 50%.

- Optimized database queries and **asynchronous programming** in **Python** applications, improving data retrieval speeds for critical business operations by 30%.

- Developed custom **API Gateway** endpoints for secure access to internal **microservices**, protecting sensitive client data and achieving 99.9% security compliance.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

- Automated testing frameworks for backend services using **Pytest**, improving code quality and reducing post-release bug reports by 25% across projects.
