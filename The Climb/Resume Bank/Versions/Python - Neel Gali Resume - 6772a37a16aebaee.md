**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance Startup*

- Owned end-to-end **Python** backend modules for an early-stage **B2B SaaS** compliance startup, building audit-ready data pipelines serving enterprise finance clients with full feature lifecycle ownership.

- Engineered high-performance **Python** and **FastAPI** RESTful backend services for real-time compliance data exchange, achieving sub-100ms latency and 99.9% system reliability across 50K concurrent enterprise users.

- Integrated **OpenAI API** into **Python** compliance data pipelines to generate **AI-driven** risk summaries, reducing manual analyst review time and improving regulatory decision-making accuracy by 20%.

- Containerized **Python** compliance services with **Docker** and deployed on **Kubernetes** via CI/CD pipelines, accelerating feature delivery cycles and maintaining high availability across enterprise SaaS deployments.

- Designed **Python** microservices architecture for modular compliance feature delivery, enabling independent team scaling and rapidly iterating on new product features as an early-stage startup engineer.

**Software Development Engineer Intern**  |  *Jul 2023 - Aug 2023*

*Monarch | Semi-Autonomous Agricultural Vehicles*

- Supported **Python** backend development for production environments powering **semi-autonomous agricultural vehicles**, enabling reliable real-world field operations and onboard sensor data telemetry collection for the team.

- Integrated vehicle sensor data streams into backend processing services, building robust **Python** pipelines that parsed and normalized real-time telemetry payloads for autonomous navigation decision systems.

**Associate Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Cloud-Based Scientific Operations*

- Developed **Python** backend services and **RESTful APIs** for a cloud-based scientific operations platform, enabling research teams to trace experiments and biological samples with 99.8% uptime.

- Optimized **SQL** queries and **PostgreSQL** schemas for large-scale scientific data storage, reducing response times for critical laboratory traceability services and complex analytical queries by 30%.

- Contributed to cloud-based **Python** microservices on **AWS EC2**, deploying backend services for scientific operations and ensuring 99.8% uptime and security compliance for sensitive laboratory data.

- Built **Python** data processing workflows for large scientific datasets, reducing report generation time by 80% and improving operational efficiency across experiment and sample analysis pipelines.

- Containerized **Python** services with **Docker** for client laboratory applications, integrating with third-party scientific tools and increasing data throughput for sample and experiment tracking by 20%.
