**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | Cloud-based Data Integration Platform*

- Developed high-performance **Python** backend services for a data integration platform, handling 20,000 concurrent user requests daily, improving data synchronization speed by 25%.

- Designed and implemented database schemas in **PostgreSQL** and **MongoDB** for client data storage, optimizing query response times by 40% across various data types.

- Built and maintained secure **RESTful APIs** using **FastAPI** for third-party integrations, processing 10 million transactions monthly, enhancing partner connectivity by 50%.

- Migrated legacy data pipelines to **AWS S3** and **Lambda** for improved scalability, reducing operational costs by 20% and processing delays by 3 hours.

- Implemented **CI/CD** pipelines using **GitLab CI** for automated deployments, decreasing release cycles from bi-weekly to daily, improving deployment efficiency by 75%.

- Contributed to infrastructure as code efforts with **Terraform** on **AWS**, provisioning resources efficiently and reducing manual setup time by 60% for new environments.

- Optimized existing **Python** scripts for data processing, reducing execution time from several hours to minutes, enabling real-time analytics for key business metrics.

- Monitored service performance and reliability using **Datadog** and **CloudWatch**, proactively addressing issues and maintaining 99.95% availability for critical services.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Enterprise Web Application Development*

- Developed robust **Python** backend services for custom enterprise web applications, supporting 5,000 daily active users with sub-second response times.

- Implemented and managed **PostgreSQL** databases, designing efficient schemas and optimizing **SQL** queries, improving data retrieval speeds by 30% for client applications.

- Built secure **RESTful APIs** in **Python** for data exchange between frontend and backend systems, ensuring reliable integration for multiple client projects.

- Utilized **Git** and agile methodologies for version control and project management, collaborating effectively with cross-functional teams on feature development.

- Deployed and managed applications on cloud infrastructure, ensuring high availability and scalability for critical client-facing platforms, achieving 99.8% uptime.

- Conducted thorough unit and integration testing for all developed modules, ensuring code quality and reducing post-deployment bugs by over 20%.
