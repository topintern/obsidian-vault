## Professional Experience

**Software Engineer**  |  *Jun 2025 - Present*

*Epik Solutions*

**Full Stack Engineer (AI/Search)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected Angular 2+ SPAs visualizing identity and compliance graphs, collaborating with Java back-end engineers on RESTful API contracts ensuring consistent data flow for 10,000+ enterprise users.

- Built Java Spring Boot compliance APIs with Spring JPA/Hibernate and Spring Security for RDBMS persistence, processing 10K+ documents and cutting manual auditor effort by 70%.

- Leveraged Redis for distributed session caching and Elasticsearch for full-text search across multi-tenant data, cutting average query response time by 45% under peak concurrent enterprise load.

- Designed distributed microservices backend using Golang, applying circuit breakers, retry logic, and tenant isolation design patterns that sustained 99.9% uptime across 15+ enterprise client deployments.

- Configured Azure DevOps pipelines and Terraform infrastructure-as-code for 10+ microservices, enforcing CI/CD best practices and reducing manual deployment errors by 40% across all environments.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Wrote Python and Shell scripting data pipelines for MLOps labeling infrastructure, automating annotation workflows and boosting overall throughput by 20% across 500K+ agricultural training data.

- Deployed serverless CI/CD data delivery pipelines integrating Docker containers and version-controlled datasets, sustaining model training across 3 production systems with 40% fewer pipeline failures.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Built Java Spring Boot services with Spring JPA/Hibernate for PostgreSQL RDBMS persistence, designing RESTful endpoints that tracked complex experimental data for 500+ scientists across 10+ modules.

- Developed Angular 2+ SPA feature modules with RxJS observable-driven state management, centralized error handling, and cross-browser DOM manipulation in a regulated platform used by 500+ scientists.

- Authored 100+ Jasmine and JUnit automated test cases covering DOM interactions and API contracts, reducing production regression incidents by 35% and improving overall platform data integrity.
