- Contributed to **CI/CD** pipeline enhancements using **Jenkins** and **Git** for automated build verification, enabling faster feedback loops and improving code deployment frequency by 2x.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*Zemoso Technologies | Cloud-Based Platform QA*

- Designed and executed comprehensive **test plans** for critical cloud-based applications, employing **Python** scripting and **Robot Framework** to validate features across releases, improving test coverage by 35%.

- Developed robust automated **test scripts** using **Python** and **Selenium** for web-based UI testing, integrating with **Jenkins** **CI/CD** pipelines to reduce manual testing efforts by 40%.

- Performed in-depth **root cause analysis** on identified software defects, filing detailed **Jira** tickets and collaborating with developers to achieve a bug resolution rate of 90%.

- Validated network protocols like **OSPF** and **BGP** within embedded systems using specialized tools, ensuring device interoperability and stability for enterprise clients, reducing critical network issues by 15%.

- Maintained and enhanced existing **regression test suites** for legacy systems, streamlining test execution with **Bash** scripts on **Linux**, accelerating release cycles by 20%.
