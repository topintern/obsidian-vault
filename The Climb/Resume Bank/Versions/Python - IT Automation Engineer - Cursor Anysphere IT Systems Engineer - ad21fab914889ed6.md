**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Identity & Automation Platform*

- Engineered automated onboarding/offboarding workflows leveraging **SCIM** and **REST APIs** to provision access across 50+ **SaaS applications**, reducing manual effort by 90% and improving security posture.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Cloud SaaS & Automation Solutions*

- Managed and secured enterprise **SaaS platforms** like **Okta**, **Google Workspace**, and **Zoom**, ensuring 99.9% uptime and compliance with internal security policies for 500+ users.

- Configured and maintained **SAML**, **OAuth**, and **SCIM** integrations for critical business applications, standardizing authentication and identity management across 30+ services seamlessly.

- Developed and maintained **Python** and **Bash** scripts for routine system administration and automation tasks, reducing manual configuration time by 60% across various server environments.

- Administered **MDM platforms** (e.g., **Jamf**) to manage a mixed-platform fleet including **macOS** and **Windows** devices, ensuring secure configurations and compliance for 400+ endpoints.

- Implemented **Infrastructure as Code** practices using **Terraform** for provisioning **AWS** resources, achieving consistent environments and reducing deployment errors by 40% across projects.

- Contributed to designing **Zero-Trust** security architectures, implementing granular access controls and network segmentation strategies that reduced internal threat surface by 20%.

- Developed custom monitoring solutions using **Prometheus** and **Grafana** for critical **IT infrastructure**, proactively identifying and resolving issues, improving system reliability by 15%.

- Collaborated with security teams to implement **defense in depth** strategies, enhancing endpoint protection and data loss prevention across all corporate devices, reducing security incidents by 10%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Enterprise Software Development*

- Developed and maintained backend services using **Java** and **Spring Boot**, supporting a core enterprise application utilized by 10,000+ daily active users with 99.9% uptime.

- Designed and implemented **RESTful APIs** for data integration with third-party systems, improving data exchange efficiency by 30% and enabling new feature development rapidly.

- Wrote comprehensive unit and integration tests for new features using **JUnit** and **Mockito**, increasing code coverage to 85% and significantly reducing post-release bugs by 20%.

- Utilized **SQL** to manage and optimize **PostgreSQL** databases, improving query performance by 25% and ensuring data integrity for critical business operations.

- Automated deployment scripts using **Shell Scripting** and **Jenkins** for application releases, reducing deployment time from 2 hours to 15 minutes, enhancing development velocity.

- Collaborated with cross-functional teams using **Agile** methodologies to deliver software solutions, ensuring projects were completed on time and met client requirements with 95% satisfaction.
