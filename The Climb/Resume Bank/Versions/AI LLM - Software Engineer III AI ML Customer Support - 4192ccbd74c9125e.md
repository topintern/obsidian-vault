## Professional Experience

**Software Engineer AI**  |  *Jun 2025 - Present*

*Epik Solutions | Enterprise Security & Support Automation Platform*

- Built **Java Spring Boot** and **TypeScript/React** workflows for AI-assisted customer support and security operations, reducing issue triage time by **40%** across production support queues.

- Integrated **LLM and ML models** into production services using Python/FastAPI, REST APIs, and streaming UI components for ticket classification, intent detection, summarization, and answer recommendation.

- Designed **model evaluation pipelines** with regression datasets, groundedness checks, latency/cost tracking, and human review loops, reducing low-confidence support recommendations by **28%**.

- Built **ML infrastructure** for model rollout, prompt/version promotion, feature extraction, and debugging using Docker, Kubernetes, GitHub Actions, OpenTelemetry, Prometheus, and Grafana.

- Developed **RAG-based knowledge retrieval** over support runbooks, security policies, and incident history using embeddings, OpenSearch/Pinecone, and metadata filters to improve answer relevance by **38%**.

- Partnered with product, support, and engineering teams to publish **external-facing API docs, troubleshooting guides, and integration notes** for enterprise technical audiences.

**Software Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance AI Platform*

- Developed **Java Spring Boot**, **Python**, and **TypeScript** microservices for a multi-tenant AI SaaS platform serving **15+ enterprise clients** with support, audit, and compliance workflows.

- Integrated production **OpenAI/Azure OpenAI** models for document understanding, evidence summarization, policy Q&A, and ticket routing, reducing manual review effort by **70%**.

- Built **React/TypeScript** dashboards for customer support, evidence review, model feedback, failure analysis, and admin configuration, improving internal operator visibility into AI workflows.

- Implemented **data processing pipelines** with Kafka, SQS, PostgreSQL, Redis, and Python batch jobs to transform audit logs, tickets, documents, and user feedback into ML-ready artifacts.

- Added **model monitoring and debugging** for retrieval quality, prompt drift, data freshness, tenant isolation, API failures, and response latency using CloudWatch, Grafana, and structured logs.

- Collaborated cross-functionally with customer success, compliance SMEs, and engineers to author **developer docs, integration playbooks, and release notes** for external enterprise customers.

**ML / Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Autonomous Vehicle Perception*

- Built **Python data processing pipelines** for image, sensor, and telemetry datasets used in perception model training, converting raw field data into validated, training-ready artifacts.

- Evaluated **ML model quality** with PyTorch, TensorFlow, and OpenCV, debugging edge cases and quality regressions across autonomous perception datasets.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies | LabOps / Scientific Workflow Platform*

- Built **Java Spring Boot APIs** and **React/TypeScript** workflows for experiment tracking, inventory, sample metadata, and support-facing operational tools used by **500+ scientists**.

- Developed REST and GraphQL-style APIs for search, validation, sample lineage, experiment status, and reporting workflows, standardizing contracts across **10+ LabOps modules**.

- Optimized PostgreSQL schemas, indexes, and query paths for scientific metadata search and report generation, reducing slow queries by **30%**.

- Added audit logs, data quality checks, retry-safe processors, and CI quality gates, improving production reliability and supportability for regulated scientific workflows.

- Authored **OpenAPI specs, onboarding notes, and troubleshooting documentation** for frontend/backend integrations, reducing repeated clarification cycles across engineering teams.
