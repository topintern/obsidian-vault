**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise Data Platform*

- Developed and maintained high-performance **RESTful APIs** using **Python** and **FastAPI** to power a large-scale enterprise data platform, serving 500K daily users.

- Designed and optimized **PostgreSQL** database schemas and queries, significantly improving data retrieval efficiency by 30% for critical business intelligence reports.

- Built and deployed scalable **microservices** on **AWS EC2** and **Docker**, supporting asynchronous data processing and enhancing system modularity by 20%.

- Implemented **data pipelines** using **Python** scripts and **AWS S3** for data ingestion and transformation, reducing manual data preparation efforts by 45%.

- Integrated various third-party systems and APIs using **OAuth2** for secure data exchange, expanding platform capabilities and reaching 20% more data sources.

- Enhanced system reliability and **observability** by implementing comprehensive **monitoring** and **logging** solutions using **Prometheus** and **Grafana**.

- Contributed to architectural discussions for new features, focusing on **scalability** and performance, leading to the successful rollout of two major product updates.

- Utilized **Redis** for caching frequently accessed data, decreasing database load by 25% and improving overall application responsiveness for user interactions.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Custom Software Development*

- Developed core backend services and **RESTful APIs** using **Python** with **SQLAlchemy** for client-facing web applications, supporting 10K concurrent users effectively.

- Designed and maintained **MySQL** and **PostgreSQL** databases, including schema migrations and query optimizations, improving data access speeds by 20%.

- Implemented secure authentication and authorization mechanisms (**JWT**) for user management, ensuring data protection and compliance across multiple projects.

- Collaborated on deployment processes, containerizing applications with **Docker** and assisting with cloud infrastructure setup on **AWS EC2** instances.

- Wrote extensive unit and integration tests using **Pytest**, contributing to a 15% reduction in production bugs and enhancing overall code quality.
