## Professional Experience

**Software Engineer AI / ML **  |  *Jun 2025 - Present*

*Epik Solutions*

**Software Engineer (AI/Search)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Built and deployed production-grade ranking models on AWS SageMaker for a multi-tenant search system serving 15+ clients, maintaining 99.9% uptime and sub-100ms response at peak load.

- Implemented an LLM-powered NLP pipeline (HuggingFace Transformers + LangChain) for text classification and document summarization, processing 10K+ compliance documents monthly

- Developed computer vision preprocessing modules combining OCR and layout parsing for document ingestion, improving structured data extraction F1-score from 0.71 to 0.89 across 500K+ artifacts.

- Architected a real-time ML feature store integrating Snowflake and AWS SageMaker Feature Store via Kinesis + S3, enabling continuous model retraining and reducing drift accuracy degradation by 35%.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Designed features across 10+ product modules using React, Ruby on Rails, Spring Boot, and PostgreSQL in a microservices architecture for scalability.

- Authored 100+ test cases and resolved critical production issues, enhancing system reliability and data integrity in a regulated scientific platform.
