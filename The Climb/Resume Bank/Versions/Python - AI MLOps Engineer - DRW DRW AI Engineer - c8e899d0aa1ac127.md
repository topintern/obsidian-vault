## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | AI-Powered Algorithmic Trading*

- Led the full lifecycle development of an **AI** driven algorithmic trading engine using **Python** and **PyTorch**, increasing trade execution efficiency by 15%.

- Designed and implemented robust **MLOps** pipelines on **Kubernetes** and **AWS SageMaker** for continuous training and validation of models, reducing deployment time by 40%.

- Developed a **Large Language Model** (LLM) based research assistant using **LangChain** and **OpenAI API**, accelerating market analysis for traders by 25%.

- Optimized **GPU** and **CPU** resource usage for high-frequency trading models utilizing **TensorRT** and **ONNX**, achieving a 20% latency reduction.

- Engineered a scalable feature store using **Redis** and **Apache Kafka** streams to provide real-time data for **ML** models, improving prediction accuracy by 10%.

- Spearheaded the integration of **RAG** (Retrieval-Augmented Generation) techniques into **LLMs** for financial news analysis, enhancing contextual understanding and reducing misinformation by 18%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise AI/ML Platform*

- Built end-to-end **ML** pipelines using **Python** and **Scikit-learn** on **AWS Lambda** for predictive analytics, improving forecast accuracy by 12% for key business metrics.

- Developed and deployed multiple production **AI** models leveraging **TensorFlow** and **Keras** for anomaly detection in transaction data, preventing $500K in potential fraud.

- Provided technical leadership in evaluating and integrating new **AI** and **ML** frameworks, optimizing existing tooling for enhanced productivity and improved model scalability by 20%.

- Implemented **MLOps** practices including version control for models and data using **DVC** and **Git**, standardizing deployment and increasing reproducibility by 35%.

- Designed a robust feature engineering framework using **Pandas** and **Apache Spark** to preprocess diverse datasets for **ML** model training, reducing data preparation time by 20%.

- Created automated systems for continuous validation and monitoring of **ML** models in production environments using **Apache Airflow** and custom alerting, ensuring 99.9% uptime.

- Contributed to the development of a secure **RESTful API** for serving **ML** inferences using **Flask** and **Docker**, supporting 10,000 requests per minute.

- Managed **compute infrastructure** for **ML** workloads, optimizing cluster configurations on **AWS EC2** instances to reduce operational costs by 18%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Cloud-Native SaaS Development*

- Developed and maintained high-performance **RESTful APIs** using **Java** with **Spring Boot** for enterprise applications, handling over 500 requests per second.

- Engineered scalable backend services on **AWS EC2** and **AWS S3** to support a rapidly growing user base, accommodating a 40% increase in daily active users.

- Designed and implemented data storage solutions using **PostgreSQL** and **MongoDB**, ensuring data consistency and query optimization for critical business operations by 25%.

- Collaborated on building **CI/CD** pipelines using **Jenkins** and **GitLab CI/CD** for automated deployments, reducing release cycle time from weekly to daily.

- Optimized database queries and application performance through code refactoring and indexing strategies, enhancing overall system responsiveness by 30%.

- Implemented secure user authentication and authorization mechanisms using **JWT** and **OAuth2** protocols, bolstering system security posture by 20%.
