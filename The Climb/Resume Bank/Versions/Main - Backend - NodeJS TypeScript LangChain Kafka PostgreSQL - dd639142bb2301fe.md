**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | AI Communication Platform & Billing Systems*

- Implemented **microservices** for a complex **billing system** using **TypeScript** and **NestJS**, processing 100,000 transactions daily while reducing error rates by 15%.

- Designed and maintained robust **public APIs** with **OAuth2** for external partners, facilitating seamless **API-based integrations** and increasing partner adoption by 20%.

- Developed an intelligent agent system utilizing **CrewAI** and **LangChain** to automate customer support workflows, decreasing response times by 30% for 5,000 daily queries.

- Led the integration of **internal management tools** with third-party services via **Webhooks** and **RESTful APIs**, improving operational efficiency for 20+ internal teams by 25%.

- Implemented comprehensive **testing frameworks** like **Jest** and **Mocha** for backend services, ensuring high **code quality** and reducing production bugs by 40%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise SaaS Backend & API Development*

- Developed robust **Node.js** backend services for a core SaaS platform, using **Express.js** to handle 500,000 daily requests with 99.99% uptime.

- Designed and implemented various **RESTful APIs** supporting new product features and external integrations, improving data exchange efficiency for 10+ client applications.

- Contributed to a **microservices** architecture migration, refactoring monolithic components into independent services using **Docker**, improving deployment frequency by 50%.

- Implemented automated testing strategies with **Jest** and **Cypress** for backend and frontend components, increasing test coverage to 85% and reducing regression bugs by 20%.

- Managed and optimized **PostgreSQL** databases, including schema design and query tuning, supporting high-traffic applications handling 1TB of data monthly.

- Utilized **AWS** services like **EC2** and **S3** for deploying and managing backend applications, achieving 99.9% availability and reducing infrastructure costs by 10%.

- Collaborated with **cross-functional teams** in a **Scrum** environment, delivering new features bi-weekly and enhancing product capabilities for 2,000 active users.

- Integrated third-party payment gateways into the **billing system** using **secure code** practices, ensuring PCI compliance and processing $1M+ monthly transactions.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Web Application Development & API Services*

- Developed and maintained **Node.js** backend for client-facing web applications using **Express.js**, serving 10,000 active users with low latency.

- Implemented **RESTful APIs** for mobile and web frontends, enabling data synchronization and real-time updates for over 50,000 daily user interactions.

- Built interactive user interfaces with **Angular** and **TypeScript**, enhancing user experience and improving conversion rates for a key product feature by 10%.

- Managed data storage and retrieval using **MongoDB** for various application modules, ensuring data integrity and improving query performance by 20%.

- Deployed applications to production environments leveraging **Nginx** and **Linux** servers, achieving 99.9% uptime and supporting continuous feature delivery.

- Participated in code reviews and utilized **Git** for version control, maintaining high **code quality** standards and facilitating collaborative development for a team of 5.
