**Software Engineer**  |  *Jun 2025 - Present*

**Backend Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected distributed backend microservices in Golang and Node.js for a multi-tenant platform serving 15+ enterprise clients, applying tenant isolation and circuit breaker patterns  sustaining 99.9% uptime.

- Designed PostgreSQL and MongoDB data models for high read/write compliance workloads, optimizing indexes and query patterns to improve data retrieval performance by 45% across 10K+ records monthly.

- Built Kafka-based event-driven pipelines for real-time compliance data ingestion, decoupling producers and consumers across 5+ microservices and reducing end-to-end processing latency by 35%.

- Engineered Redis caching strategies for session management and hot query results across a high-concurrency search system, reducing MongoDB read load by 50% and sustaining sub-100ms

- Containerized all services with Docker and deployed on Kubernetes, configuring horizontal pod autoscaling and liveness probes that reduced deployment downtime by 40% across  production.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built AWS Lambda data pipeline services with Python, designing scalable event-driven ingestion workflows that processed agricultural sensor data with 40% fewer pipeline failures across 3 prod envs.

- Developed data validation and transformation scripts enforcing schema consistency and reducing cross-system data integrity issues by 40% across 500+ employee workflows via GitHub-releases

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered 10+ backend services using Node.js REST APIs with PostgreSQL, designing relational data models and indexed query patterns that ensured data integrity for 500+ scientists

- Analysed and optimised slow PostgreSQL queries through execution plan profiling and index tuning, improving application response times by 35% and resolving critical production bottlenecks

- Authored 100+ integration and unit test cases, systematically diagnosed distributed service failures, and enforced code review standards that reduced production regression incidents by 40%.
