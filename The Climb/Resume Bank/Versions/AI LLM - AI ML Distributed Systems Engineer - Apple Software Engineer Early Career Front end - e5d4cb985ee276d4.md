## Professional Experience

**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Privacy-Preserving Ad Tech Platform*

- Engineered high-performance **Scala**-based **distributed systems** for real-time ad serving, leveraging **Kafka** streams and **Spark** for data processing, reducing query latency by 35%.

- Developed **Generative AI** models using **PyTorch** and **TensorFlow** for dynamic ad content creation, increasing ad engagement rates across platforms by 20%.

- Implemented **LLM**-powered recommendation engines with **Python** and **Kubernetes** for personalized ad delivery, boosting click-through rates by an average of 15% for users.

- Designed and maintained scalable **AWS**-based data infrastructure for large-scale ad campaign analytics, handling 10TB of daily event data with 99.9% uptime.

- Optimized **backend services** using **Java** and **Spring Boot** for low-latency ad request handling, improving system throughput by 25% for 5M concurrent users.

- Contributed to a privacy-preserving ad delivery framework, integrating **differential privacy** techniques using **Python**, ensuring compliance for 100M user profiles.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | Real-time FinTech Data Platform*

- Developed and deployed robust **Java** **microservices** with **Spring Boot** on **AWS EC2**, enhancing a financial data platform's processing capacity by 40% for 1M transactions.

- Built automated **data pipelines** using **Apache Flink** and **Kafka** to ingest and process real-time market data, improving data freshness by 60% for trading algorithms.

- Integrated **OpenAI API** for fraud detection into an existing system using **Python** and **AWS Lambda**, improving detection accuracy by 15% and saving $50K monthly.

- Implemented secure **REST APIs** for client data access with **Spring Security** and **PostgreSQL**, safeguarding sensitive information for 250k registered users.

- Optimized database queries and schema for **PostgreSQL** and **Redis**, reducing data retrieval latency by 30% for high-volume analytical reports.

- Collaborated on system architecture design for a scalable transaction processing system, contributing to a 99.99% reliability increase across 12 core services.

**Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Agricultural Robotics Platform*

- Implemented **Python** **REST APIs** for tractor telemetry data using **Django** and **PostgreSQL**, enabling real-time monitoring for 150+ IoT devices.

- Developed data ingestion scripts for sensor data using **Python** and **AWS S3**, processing 500GB of daily agricultural metrics.

**Software Engineer**  |  *Aug 2021 - Aug 2022*

*Zemoso Technologies | Enterprise Software Development*

- Developed and optimized **Java** **Spring Boot** **microservices** to manage user authentication and data, reducing response times by 18% for 200k active users.

- Implemented complex business logic using **Java** and **Hibernate** for an enterprise resource planning system, increasing data consistency by 25%.

- Designed and managed relational databases using **MySQL** for various application modules, ensuring data integrity for over 500 enterprise clients.

- Engineered data migration scripts in **Python** for onboarding new clients, successfully migrating 10TB of legacy data without disruption.
