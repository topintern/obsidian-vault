## Professional Experience

**Software Engineer**  |  *Jun 2025 - Present*

*Epik Solutions | Enterprise Security Platform*

- Engineered scalable backend microservices in **Go** and **Python** on **AWS** (Lambda, ECS), integrating enterprise security platform APIs and automating workflows for 500+ users, reducing MTTR by 15 minutes.

- Built **RAG** pipelines with **LangGraph** over internal security knowledge bases to automate SOC triage with LLM-based event classification, processing 1,000+ daily events and reducing analyst workload by 30%.

- Implemented continuous **LLM evaluation frameworks** to validate model accuracy for AI-driven triage logic, improving detection accuracy by 15% within a highly regulated enterprise environment.

- Designed and optimized **PostgreSQL** data models and queries supporting high-throughput event-processing pipelines, ensuring data integrity across **Linux**-based production systems.

- Deployed and maintained backend services on **AWS** using **Docker**, **Kubernetes**, and **GitHub Actions** CI/CD, enforcing Terraform Sentinel infrastructure standards and improving pipeline success rates by 25%.

- Debugged and resolved complex distributed-systems issues across **Linux** UAT/prod environments, applying first-principles troubleshooting to boost site reliability for security teams.

**Founding Engineer (Full Stack)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Web Platform*

- Architected a multi-tenant SaaS platform in a **highly regulated** compliance domain, serving **15+ enterprise clients**, **scaling to 10,000+ users per org** on **AWS**, ensuring tenant isolation, scalability, and 99.9% high availability.

- Designed distributed **Go** and **Python** backend systems on **AWS** (Lambda, ECS, PostgreSQL, Neo4j) deployed on **Linux**-based infrastructure with strict tenant isolation across relational, graph, and object storage layers.

- Developed full-stack **React** and **GraphQL** web applications enabling compliance controls, evidence management, policy authoring, and document storage workflows for 10,000+ enterprise users.

- Built LLM-powered web features using **Python**, **LangChain**, and **AWS Bedrock** to automate content summarization and control scoring, reducing manual user effort by 70% platform-wide.

- Designed distributed **Python** data pipelines ingesting 5M+ daily identity events, building RESTful API features and graph-backed search that reduced unauthorized access footprints by 30%.

- Utilized **OpenAI API** and **LangChain** for personalized content generation features, enhancing user engagement by 25% through dynamic interactions across enterprise client deployments.

- Monitored system health using **Prometheus** and **Grafana**, iterated on features via **Jira** and **Confluence**, achieving 99.99% uptime and 15% improvement in feature adoption.

- Implemented **CI/CD pipelines** using **Jenkins** and **Terraform** to automate deployments on **AWS EC2**, accelerating feature releases by 40% and improving deployment reliability.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies | Cloud-Native Product Development*

- Delivered full-stack features for a cloud-based robotic lab web platform used by 500+ scientists, working across **React**, **Ruby on Rails**, **Java Spring Boot**, and **PostgreSQL** in a microservices architecture.

- Designed and implemented features across 10+ core product modules (inventory, compounds, batch tracking, LCMS uploads, container linkage), enabling accurate web-based tracking of complex experimental data.

- Developed and maintained **Java Spring Boot** backend APIs handling 10,000+ concurrent requests, designing RESTful endpoints that ensured data integrity and application stability at 98% uptime.

- Implemented robust data models in **PostgreSQL** and **MySQL**, optimizing database queries for complex reports and reducing generation time from 2 minutes to 15 seconds for end users.

- Authored 100+ test cases, resolved critical production bugs, and integrated **Jenkins** CI/CD pipelines on **Linux** build agents to enforce quality standards in an **Agile** team on a regulated scientific platform.
