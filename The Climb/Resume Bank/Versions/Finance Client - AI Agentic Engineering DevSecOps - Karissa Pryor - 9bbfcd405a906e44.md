## Summary

Software engineer building **Python AI agents** for financial-services security and compliance SaaS, combining LangGraph/LangChain, RAG, and evaluations with **CI/CD, DevSecOps, and reusable platform services**.

## Technical Skills

**Languages:** Python, SQL, TypeScript, JavaScript, Go, Java, Bash

**AI Engineering:** LangGraph, LangChain, Agent Orchestration, Tool Calling, RAG, LLM Evaluations, Guardrails

**Models & APIs:** AWS Bedrock, Azure OpenAI, OpenAI API, FastAPI, REST APIs, GraphQL, Webhooks

**CI/CD & Security:** GitLab CI/CD, GitHub Actions, Jenkins, Git, Testing, SAST/DAST, Secrets Management

**Cloud & Data:** AWS (Lambda, ECS, SQS, S3), Docker, Kubernetes, Terraform, Linux, PostgreSQL, Redis, Neo4j

**Observability & Delivery:** CloudWatch, Prometheus, Grafana, Code Review, API Documentation, Agile

## Professional Experience

**Software Engineer AI**  |  *2025 - Present*

*Epik Solutions | CIFC Asset Management - Enterprise Security*

- Built a **Python AI incident-triage pipeline** that correlated security alerts, logs, and tickets into prioritized summaries, cited evidence, confidence scores, and recommended remediation actions.

- Developed **LangGraph-based CI failure analysis** with OpenAI GPT-4o to distinguish flaky tests from regressions and surface root-cause context, reducing developer debugging time by **40%**.

- Packaged **reusable AI platform components** for retrieval, workflow state, guardrails, telemetry, and error handling, giving adjacent teams a shared foundation for production AI features.

- Designed **RAG and LLM evaluation workflows** with prompt versioning and regression checks for duplicate detection, severity reasoning, and remediation guidance across incident categories.

- Enhanced **GitLab CI/CD and Terraform** provisioning workflows; integrated security-tool APIs, webhooks, and policy checks into delivery pipelines to automate findings intake and remediation tracking.

- Implemented **least-privilege access and human approval queues**, with RBAC, source citations, and structured audit logs to protect sensitive security data and govern AI-assisted actions.

- Instrumented queue depth, LLM latency, failure modes, and operator decisions using **CloudWatch, Prometheus, and Grafana**, reducing repeat incident-triage cycles by **35%**.

**Founding Engineer (Full Stack AI)**  |  *2023 - 2025*

*Samay Systems LLC | B2B Compliance AI SaaS*

- Engineered a **Python-based compliance platform** on AWS Lambda, ECS, and SQS, with PostgreSQL and Neo4j data models supporting workflows for **15+ enterprise clients**.

- Productionized **LangChain tool-calling agents** with AWS Bedrock, Azure OpenAI, RAG, and evaluation datasets for evidence review, reducing manual review effort by **70%**.

- Built **REST and GraphQL integrations** connecting agents and compliance workflows to Jira, GitHub, cloud accounts, document stores, and identity systems through enterprise APIs.

- Modeled policies, evidence, controls, and tickets into a **traceable compliance graph**; tracked AI job latency, queue failures, and evidence coverage to guide release-readiness decisions.

- Implemented **tenant isolation, secret handling, and CI/CD quality gates**, with audit logging and environment promotion across development, staging, and production.

- Automated **cloud control validation and vulnerability reporting**, connecting security findings with compliance evidence to support remediation tracking and audit preparation.

- Partnered with customers and platform engineers on **technical design and delivery**, translating ambiguous requirements into API contracts, production features, demos, and post-launch fixes.

**Software Engineer**  |  *2020 - 2022*

*ZeMoSo Technologies | LabOps Platform*

- Delivered **REST APIs and full-stack workflows** using Java Spring Boot, Ruby on Rails, React, and PostgreSQL for inventory and sample tracking used by **500+ scientists**.

- Built **Python and Bash automation** for schema migrations, environment setup, and test-data generation, reducing repetitive developer setup work across LabOps services.

- Authored **100+ automated tests** and integrated Jenkins build, test, and deployment gates; debugged production defects and validated fixes in Linux-hosted services.

- Optimized **SQL queries and backend jobs** for sample events, reducing timeouts in daily laboratory workflows.

- Added **job retries and failure reporting** to recover failed uploads and sample-lineage tasks.

- Documented **API behavior, troubleshooting, and deployment procedures**, working with QA, infrastructure, and product teams to deliver and validate releases consistently.
