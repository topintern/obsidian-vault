## Experience



**Full stack Engineer,** Arvam Tech - CA  |  Jul 2023 - present





- Led the development and maintenance of **enterprise asset management (EAM)** solutions, providing scalable, secure, and high-performance applications

- Utilized **React** for frontend development and **Node.js** with **Express** for backend services, implementing RESTful APIs and ensuring seamless integration with the system’s database

- Designed and implemented **microservices-based architecture** using **Spring Boot** and **Docker**, streamlining deployment processes and improving system reliability

- Integrated **AWS services** for cloud infrastructure and managed **CI/CD pipelines** with **Jenkins**, automating deployments and enhancing the development workflow

- Enhanced data security and integrity by applying best practices in **encryption, authentication, and authorization**, working closely with the security team to meet compliance standards


**Full stack developer,** RHYM Tech - Remote, Stillwater, OK  |  Aug 2022 - May 2023






- Delivered custom web applications and solutions tailored to the unique needs of cybersecurity systems, enhancing the performance and scalability of key tools

- Built secure, **responsive web applications** using **React** and **Node.js**, leveraging **JWT for secure authentication** and OAuth for third-party integration

- Contributed to designing and implementing **real-time data analytics** systems with **Kafka and Splunk** for monitoring network traffic and detecting anomalies

- Enhanced system security by developing **web-based dashboards** for **intrusion detection and security event management**, providing users with visual insights into potential vulnerabilities

- Collaborated with a cross-functional team to integrate **threat detection algorithms** and APIs into existing systems, supporting **penetration testing and vulnerability assessments**




**Full stack developer,** ZeMoSo Technologies - Hyderabad, India  |  Jul 2021 - Aug 2022





- Contributed to the development of the Strateos Platform, a remote-controlled AI robotic lab for scientific experiment design, running, and analysis
- Designed **UI components in React** and **RESTful APIs in Ruby on Rails**, collaborating with cross-functional teams in a biotech startup to achieve a 20% increase in user base growth

- Integrated new features for **user roles and permissions management** in Ruby on Rails, using custom Pundit policy scopes to filter data based on user roles and enforcing **Role-Based Access Control (RBAC)**

- Managed complex relational models, Implemented **CRUD operations, structured JSON responses, versioned APIs** and ensured consistent API behavior through comprehensive **request validation and error handling**

- Developed backend services using **Ruby on Rails**, implementing complex data models and **integrating third-party APIs** for experiment management and data analysis

- Optimized **database queries using PostgreSQL**, ensuring seamless access and retrieval of data from the system’s relational database



**Full stack developer,** RHYM Tech - Hyderabad, India  |  Jun 2020 - May 2021






- Developed secure, scalable web applications for **internal cybersecurity tools** and services, ensuring they met high standards for privacy and data protection

- Led frontend development efforts using **Vue.js** for creating interactive UIs and **Node.js** for building robust backend services

- Integrated **OAuth** and **JWT** for secure user authentication, ensuring strict access control and safeguarding data confidentiality

- Utilized **AWS** for cloud-based infrastructure and deployed microservices using **Docker** containers, enhancing the deployment pipeline and reducing downtime

- Contributed to ongoing code reviews, ensuring the implementation of secure coding practices and adherence to best practices






## Projects

 


**Enterprise Asset Management (EAM) Solution – Arvam Tech**




- **Problem**: The firm required a scalable, secure, and high-performance web-based solution for managing and tracking enterprise assets in real-time

**Solution**:  Led the development of a robust **EAM solution** using **React** for frontend development and **Node.js** with **Express** for backend services. Implemented RESTful APIs for seamless communication between the system and its database, ensuring smooth asset tracking, reporting, and management



**Permissions Management System for Sensitive Data Access – ZeMoSo Technologies**




- **Problem**:The platform required a secure and flexible permissions management system to handle varying user roles with different levels of access to sensitive experimental data.

**Solution**: Assisted in developing a **permissions management system** using **Ruby on Rails**, ensuring robust security protocols for handling multiple user roles. This system allowed for precise control over who could access and modify experimental data, improving data security and compliance



**Custom Web Application for Cybersecurity Systems – RHYM Tech**




- **Problem**: The cybersecurity firm required a custom web application to enhance the performance and scalability of their monitoring tools, specifically in real-time threat detection and data visualization

**Solution**:  Developed secure and **responsive web applications** using **React and Node.js**, implementing **JWT** for secure authentication and OAuth for third-party integrations. The applications provided seamless user experiences for monitoring network traffic and detecting anomalies, supporting the firm’s cybersecurity initiatives
