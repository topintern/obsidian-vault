## Professional Experience

### Software Engineer AI

*Epik Solutions | CIFC Asset Management - Enterprise Security* | 2025 - Present

- Built **Python services and APIs** to correlate security alerts, logs, and tickets into prioritized incident summaries with supporting evidence and remediation guidance, streamlining analyst triage.
- Packaged **reusable automation components** for retrieval, workflow state, guardrails, and error handling so adjacent teams could build on shared services rather than duplicate integration logic.
- Developed **RAG and LLM evaluation workflows** with versioned prompts and regression checks to assess incident reasoning and remediation suggestions before releasing changes.
- Implemented **human approval workflows, RBAC, and audit trails** to govern AI-assisted actions and preserve traceability for sensitive enterprise security operations.
- Monitored production automation and investigated failures across services, APIs, and model outputs; used operational feedback to refine workflows and improve reliability.

### Founding Engineer (Full Stack AI)

*Samay Systems LLC | B2B Compliance AI SaaS* | 2023 - 2025

- Built **Python automation and enterprise API integrations** for GitHub, Jira, and Microsoft Entra ID, scheduling evidence collection and normalizing data for compliance controls and reporting.
- Developed AWS workflows using **Lambda, ECS, SQS, and Step Functions**; codified infrastructure with AWS CDK and connected PostgreSQL, S3, and Neo4j with tenant-aware data processing.
- Delivered **React interfaces and REST/GraphQL APIs** for integration configuration, control testing, and evidence review, translating business requirements into usable end-to-end workflows.
- Built **LangChain tool-calling agents and RAG** with Bedrock and Azure OpenAI for evidence analysis; applied tenant isolation, evaluations, and release controls to support dependable AI automation.
- Wrote **architecture, deployment, and troubleshooting documentation** covering integration behavior, data flows, and known limitations so engineers could operate and extend the tooling.

### Software Engineer

*ZeMoSo Technologies | LabOps / Scientific Workflow Platform* | 2020 - 2022

- Developed **Ruby on Rails APIs and React features** for inventory, samples, compound records, and experiment datasets, connecting relational data models with role-based scientific workflows.
- Wrote **backend and frontend regression tests** for permissions, data validation, uploads, and batch relationships; worked with Jenkins CI/CD and Docker environments to validate changes.
- Diagnosed defects across HTTP/JSON payloads, backend queries, and UI state; fixed duplicate pagination, inventory filters, and persistence issues to restore correct data behavior.
- Extended a **shared React component library** and updated consuming screens, coordinating code reviews with onshore teams to deliver consistent UI behavior across the application.
