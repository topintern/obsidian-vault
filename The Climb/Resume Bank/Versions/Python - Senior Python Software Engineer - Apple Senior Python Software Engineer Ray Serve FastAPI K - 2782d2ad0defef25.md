## Summary

Senior Software Engineer with 5+ years building **production-grade Python backend services and APIs**, deploying and scaling **ML/LLM inference workloads** on **Kubernetes**, and designing **AI-assisted workflows** directly from user-feedback research with security and compliance stakeholders.

## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Security Platform*

- Designed and shipped production-grade **Python** and **FastAPI** backend services and REST APIs powering real-time security automation, sustaining 99.9% uptime for internal SOC and enterprise customer workloads.

- Sat directly with **SOC analysts** and **C-suite stakeholders** to diagnose alert fatigue, translating their real-world triage frustration into an AI-assisted incident pipeline that auto-scored and routed 1,000+ daily security events

- Deployed and scaled **ML inference services** for the incident-triage and analytics platform on **Kubernetes**, troubleshooting pod scheduling, resource limits, and rolling-update failures across production clusters serving 500+ users.

- Built **LLM-powered agentic workflows** (Azure OpenAI, LangChain, MCP-based tool calling) to automate SOC runbook execution, reducing mean-time-to-resolution by 15 minutes per incident while preserving human-in-the-loop approval.

- Built real-time analytics dashboards aggregating telemetry from 15+ systems via internal **FastAPI** services, eliminating 20+ hours/week of manual reporting and improving decision latency for C-suite stakeholders.

- Implemented automated evaluation and **CI/CD** gating (**GitHub Actions**) for AI-assisted workflows, tracking latency and accuracy regressions before promoting changes to production **Kubernetes** clusters, cutting deployment incidents by 20%.

- Automated cross-functional enterprise workflows using **Power Platform** (Power Automate, Power Apps, Dataverse) and **PowerShell** scripting, serving 500+ users, reducing operational cycle times by 40%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance Platform*

- Built **Python**/**FastAPI** document-intelligence APIs that extracted and structured clause-level data from vendor PDFs, replacing manual spreadsheet logging and cutting compliance-manager review time by 70%.

- Designed **LLM agent orchestration** (LangChain, MCP-based tool calling, AWS Bedrock) to automate evidence collection, summarization, and audit-trail scoring across 10K+ monthly compliance records for 15+ enterprise clients.

- Containerized and deployed compliance services with **Docker** and **Kubernetes** on **AWS**, building CI/CD pipelines with automated rollback that reduced production deployment errors by 40%.

- Engineered **Ray** and **Apache Spark** distributed data pipelines to process and enrich terabytes of compliance and event data daily, supporting downstream model inference and analytics.

- Built **Apache Kafka** event-driven microservices in **Python** and **Java** with dead-letter queues, idempotent consumers, and retry logic, decoupling 6+ services and improving throughput by 50% at peak.

- Collaborated across ML research, platform engineering, and product teams to translate compliance domain requirements into agent architectures, shipping 4+ LLM-driven product features per quarter.

- Shadowed **compliance managers** through tenant discovery and onboarding, observing them manually open hundreds of vendor PDFs and log it into spreadsheets to define what context an audit-trail validator needed to surface first.

- Engineered **LangChain** RAG pipelines with **Azure AI Search** vector retrieval and HuggingFace embedding models, delivering natural language Q&A over enterprise compliance corpora at 89% retrieval precision for 15+ clients.

**Associate Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps Platform*

- Built distributed **Java Spring Boot** backend services and REST APIs over a regulated multi-module scientific platform, handling experiment and sample tracking for 500+ scientists across 10+ modules.

- Designed normalized **PostgreSQL** schemas and query layers for high-read experiment data endpoints, improving retrieval performance by 30% for concurrent access across the platform.

- Authored 100+ test cases and integrated **Jenkins** CI/CD pipelines to enforce quality gates, reducing production regression incidents by 35% on a regulated platform.

- Developed full-stack features with **React.js** and **TypeScript** front-ends wired to async backend APIs, delivering responsive data entry and retrieval workflows adopted across all 10+ LabOps product modules.

- Implemented **Spring Security** with OAuth2 role-based access control enforcing data isolation across research teams.

- Designed and implemented features across 10+ core product modules (inventory, compounds, batch tracking, LCMS uploads, container linkage), enabling accurate tracking of complex experimental data.

- Implemented **RESTful APIs** for third-party integrations, increasing platform extensibility and enabling new partnerships that generated $500K in annual revenue.
