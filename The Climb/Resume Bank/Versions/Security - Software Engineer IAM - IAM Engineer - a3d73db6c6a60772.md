## Professional Experience


**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise IAM & Security Platform*




- Implemented **OAuth2** and **OpenID Connect** authentication flows for an enterprise IAM platform, enabling secure delegated access and federated single sign-on across 50+ enterprise tenant organizations.

- Built **SCIM** 2.0 user and group provisioning service in **TypeScript** and **Node.js**, automating identity lifecycle management for enterprise directory sync across five integrated identity providers.

- Designed **RBAC** access control model for a multi-tenant SaaS platform, enforcing granular per-tenant role and permission boundaries across **PostgreSQL** schemas and **AWS** Secrets Manager namespaces.

- Provisioned scalable IAM services on **AWS** using **Terraform** infrastructure as code and **Kubernetes** container orchestration, enabling zero-downtime deployments and automated rollback for identity platform services.

- Enforced least-privilege **AWS IAM** policies across Lambda and ECS tasks, eliminating hardcoded credentials, satisfying SOC 2 access control requirements, and reducing unauthorized permission escalation risks.

- Built **TypeScript** REST APIs for user, group, and membership management, implementing request validation, rate limiting, and **JWT** token verification across all authenticated identity service endpoints.

- Implemented **ReBAC** relationship-based access model in **Node.js**, evaluating resource ownership and delegation chains to enforce fine-grained contextual permission decisions that flat role assignments cannot express.

- Engineered **OAuth2** refresh token rotation and revocation service using **Node.js** and **Redis**, preventing token reuse after logout and cutting compromised credential exposure window by 90%.



**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | B2B Identity & Compliance Platform*




- Integrated **SAML** 2.0 and **OAuth2** **SSO** with three enterprise identity providers, enabling federated authentication and cutting manual provisioning overhead for 10,000+ B2B tenant platform users.

- Built **AWS Lambda** pipelines ingesting 5M+ daily identity events from enterprise systems, synchronizing user and group membership state into compliance access graphs with near-real-time latency.

- Implemented **RBAC** and **ABAC** access control for a multi-tenant B2B compliance platform, enforcing least-privilege permissions per tenant and reducing unauthorized user access incidents by 30%.

- Developed **Node.js** microservices exposing RESTful identity management APIs consumed by **React** frontend clients, handling authentication token exchange, session validation, and user preference management at scale.

- Designed **PostgreSQL** schemas for identity and compliance event storage, writing optimized queries with index tuning that cut audit report generation time by 85% across tenants.

- Built **React** and **TypeScript** user management dashboards for enterprise compliance officers, enabling fine-grained identity access reviews, role assignment workflows, and full exportable audit trail reporting.

- Integrated **LDAP** directory sync to pull user and group membership from enterprise **Active Directory**, reconciling the platform identity store and detecting stale provisioning drift nightly.

- Participated in weekly scheduled on-call rotations for the identity platform, triaging authentication failures and **SAML** assertion errors, maintaining 99.9% SSO availability SLA across enterprise customers.



**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps Platform*




- Developed Python and Java REST APIs with **JWT**-based authentication and session management for a LabOps platform, implementing **RBAC** middleware to restrict access by user roles.

- Authored optimized **PostgreSQL** queries and stored procedures for lab sample tracking, reducing report generation time by 30% through strategic index tuning and targeted query denormalization.

- Containerized Python and Java microservices using **Docker** and provisioned multi-environment cloud infrastructure with **Terraform**, enabling reproducible deployments and reducing new-developer onboarding configuration time by 60%.

- Configured **GitHub Actions** CI/CD pipelines for Python and Java services, automating unit test execution, Docker image builds, and staging environment deployments on every pull request.

- Authored **AWS CloudFormation** stacks to provision VPC-isolated Lambda functions, RDS instances, and IAM role boundaries, establishing repeatable infrastructure patterns across dev, staging, and production environments.




## Skills
