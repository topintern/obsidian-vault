## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

- Led development of innovative **AI initiatives** for dynamic screensavers and featured experiences using **Python**, **LangChain**, and **LLMs**, enhancing user engagement by 15%.

- Architected scalable microservices using **AWS Lambda** and **Kubernetes** for content generation and delivery, reducing operational costs by 20% for millions of users.

- Designed and implemented new **BrightScript** features for interactive trivia and dynamic wallpapers on **Roku** platforms, achieving a 25% increase in daily active users.

- Collaborated with **UI/UX design** and product teams to integrate **React Native** frontends with **Python** **AI/ML** backend services, improving feature rollout speed by 30%.

- Developed and optimized **API design** for external content publishers using **TypeScript** and **Next.js**, streamlining content management workflows for over 50 partners.

- Managed the full lifecycle of **PoC** development to **productionizing solutions** for user-enhancing experiments, delivering critical features ahead of schedule by 10%.

- Implemented robust **CI/CD** pipelines for automated testing and deployment of **AI-powered** content modules on **AWS EC2**, reducing deployment time by 40%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise Media Integration & SaaS*

- Developed and maintained core features for an enterprise SaaS platform using **Python** and **TypeScript**, supporting over 100,000 concurrent users with 99.9% uptime.

- Engineered scalable **API design** and **cloud backend integration** with **AWS S3** and **AWS SQS** for media content ingest, processing 5TB of data monthly efficiently.

- Implemented **UI development** for customer-focused dashboards using **React Native** and **JavaScript**, improving user experience and data visualization by 20%.

- Collaborated on designing robust **Microservices** architecture for content management systems using **Docker** and **Kubernetes**, enhancing system resilience by 35%.

- Optimized **PostgreSQL** database queries and schema for improved performance, reducing average API response times by 15% across critical platform features.

- Integrated third-party **OpenAI API** services to power internal knowledge base tools, increasing developer productivity by 25% through advanced content analysis.

- Wrote comprehensive unit and integration tests for new features using **Jira** for tracking, ensuring high code quality and reducing post-release bugs by 40%.

- Participated in **productionizing solutions** for critical streaming data pipelines, ensuring data integrity and availability for business intelligence reporting with 98% accuracy.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Cross-Platform Application Development*

- Developed cross-platform mobile applications for consumer electronics using **JavaScript** and **React Native**, reaching over 50,000 active users with smooth performance.

- Implemented **UI development** components and features, ensuring seamless integration with backend **REST APIs** to deliver intuitive user experiences across devices.

- Contributed to embedded software development using **C++** for device firmware, optimizing resource utilization and improving system boot times by 10%.

- Applied **Core OS concepts** like **memory management** and **multi-threading** to enhance application stability and responsiveness, reducing crash rates by 18%.

- Investigated and resolved critical software bugs and performance bottlenecks using debugging tools, improving application reliability by 25% for end-users.

- Managed code versioning and collaboration using **Git**, adhering to best practices for code reviews and continuous integration for a team of 8 engineers.
