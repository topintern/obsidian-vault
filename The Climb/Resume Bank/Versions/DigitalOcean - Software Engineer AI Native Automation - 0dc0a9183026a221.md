## Professional Experience



**Software Engineer AI**  |  *Jun 2025 - Present*

*Epik Solutions | Enterprise Security & Infrastructure Automation Platform*




- Built **Go, Python, and TypeScript services** that automated manual security and infrastructure workflows across ingestion, policy checks, approvals, notifications, and audit-ready reporting.

- Used **Cursor, Claude, GitHub Copilot, and Codex** to accelerate implementation while validating generated code through tests, code review, observability checks, and production rollback plans.

- Designed **REST APIs and internal tooling** for engineering teams to inspect service health, credential findings, deployment status, and recurring operational work from a single interface.

- Deployed services on **Linux, Docker, Kubernetes, AWS, and Terraform**, with GitHub Actions pipelines for testing, release promotion, and environment checks.

- Implemented **LLM-assisted remediation workflows** using RAG, prompt regression tests, human approval queues, and evaluation datasets to summarize defects and recommend next actions.

- Added structured logs, metrics, dashboards, and alert routes in Prometheus, Grafana, and CloudWatch, reducing repeated triage cycles by **35%**.



**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance AI Platform*




- Designed a **multi-tenant AI SaaS platform** on AWS using Python, TypeScript, GraphQL, Lambda, ECS, SQS, PostgreSQL, and Neo4j for **15+ enterprise clients**.

- Built **agentic AI workflows** with AWS Bedrock, Azure OpenAI, LangChain, tool-calling agents, vector search, and eval datasets to automate evidence review and compliance analysis.

- Created **automation services** for evidence collection, cloud-control validation, Jira/GitHub intake, document processing, and customer-facing workflow status across dev, staging, and production.

- Implemented CI/CD with **GitHub Actions, Docker, Terraform, and AWS**, adding test gates, configuration checks, and deploy notes so features could move quickly without losing reliability.

- Built workflow analytics for **AI job latency, queue failures, and automation gaps**, giving engineers a production-readiness view before customer releases.

- Owned features from discovery through deployment, including architecture, implementation, demos, production fixes, and handoff documentation for stakeholders.



**ML / Software Engineering Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor | Autonomous Systems & Physical Infrastructure Data*




- Built **Python telemetry pipelines** for image, sensor, and operational datasets used in ML workflows, converting raw field data into validated artifacts for downstream analysis.

- Created automation and dashboards for identity, device, data-quality, and field-operations workflows, reducing provisioning and validation time by **80%**.



**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies | LabOps / Scientific Workflow Platform*




- Delivered full-stack workflow modules using React, TypeScript, Java Spring Boot, Ruby on Rails, and PostgreSQL for a regulated LabOps platform used by **500+ scientists**.

- Built **REST APIs**, role-based workflows, audit logs, data validation, and release checks across inventory, sample lineage, file uploads, scheduling, and experiment tracking modules.

- Developed **React/TypeScript operational views** for lab inventory, sample status, and experiment queues so users could resolve blockers without database or support tickets.

- Refactored backend jobs and SQL queries for high-volume sample events, improving page loads and reducing repeated timeout/debug cycles in daily LabOps workflows.

- Automated checks for failed jobs, stale records, upload errors, and environment drift, giving support teams faster visibility into production workflow health.

- Partnered with QA, product, and infrastructure teams in Agile sprints to ship fixes, demo workflow improvements, and document deployment behavior for regulated releases.
