**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise Data & Analytics Platform*

- Constructed scalable **ETL** pipelines using **Apache Spark** on **AWS S3** and **AWS Lambda** for **consumer datasets**, processing 50M records daily with 99.9% accuracy.

- Developed **statistical modeling** frameworks in **R** and **Python** (**NumPy**, **Pandas**) to analyze **renter behavior**, providing insights that informed product design by 8%.

- Designed and maintained **data warehousing** solutions in **Snowflake** for **investment strategy** reporting, enabling cross-functional teams to access data 30% faster.

- Implemented **A/B testing** infrastructure with **Python** and **SQL** to evaluate new **product design** features, resulting in a 5% increase in user engagement.

- Built **RESTful APIs** using **Node.js** and **Express.js** to expose **predictive analytics** results, integrating with internal dashboards for 20% efficiency gain.

- Collaborated on a **CI/CD** pipeline using **Jenkins** and **Docker** for **machine learning** model deployment, reducing deployment time from hours to minutes by 70%.

- Created **data visualization** tools using **Looker** for presenting **market intelligence** reports, improving data consumption and decision-making for stakeholders by 15%.

- Utilized **OpenAI API** with **Python** for generating preliminary **demographic** summaries from unstructured text, enhancing data enrichment processes by 10%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Custom Software Development & Data Services*

- Developed backend services with **Java** and **Spring Boot** for **data integration** from various sources, handling 1M transactions daily with 99.8% uptime.

- Designed and optimized **SQL** queries for **PostgreSQL** databases, improving data retrieval performance for reporting applications by 40%.

- Implemented **REST APIs** using **Python** and **Flask** for client-facing applications, enabling seamless data exchange and supporting 10K active users.

- Managed **Git** version control workflows for a team of 5 engineers, ensuring code integrity and facilitating parallel **development** efforts by 25%.

- Contributed to **system design** for a scalable **enterprise SaaS platform** using **microservices architecture**, supporting growth to 20+ clients.

- Created automated **data validation** scripts in **Python** for ingested **consumer datasets**, reducing manual data cleaning efforts by 35% weekly.
