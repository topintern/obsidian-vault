- Contributed to architectural decisions for resilient and secure enterprise systems, handling peak loads and improving concurrent user capacity by 50% while maintaining optimal performance.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance Platform*

- Developed and maintained scalable **Python** **RESTful APIs** using **Django** to power AI agentic compliance solutions, ensuring secure data exchange and adherence to industry standards.

- Designed and optimized **PostgreSQL** database schemas with compliance in mind, implementing granular access controls and data retention policies for sensitive B2B client data.

- Deployed and managed compliant **backend** applications on **AWS EC2** and **S3**, adhering to strict B2B SaaS security protocols and regulatory requirements for data integrity.

- Implemented compliant **CI/CD** pipelines using **Git** and **GitLab CI**, streamlining software delivery while ensuring auditability and adherence to B2B SaaS regulations.

- Contributed to **ground up development** of new **microservices** for enhanced features using **Python**, improving system modularity and future **scalability** by 25%.

- Designed AI agentic monitoring solutions leveraging **CloudWatch** for automated audit trails, proactively identifying and using LLMs to summarize compliance events and risks.

- Optimized existing codebase for **performance** and resource utilization, decreasing server costs by 15% through efficient **Python** programming practices.

- Collaborated with cross-functional teams in a **fast-paced** environment to deliver high-quality software, exceeding project deadlines by an average of 10%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Lab Operations Software*

- Developed robust **backend** **APIs** using **Java** and **Spring Boot** for LabOps, facilitating secure data ingestion from scientific instruments and experimental workflows.

- Designed and implemented **MySQL** database solutions for LabOps, optimizing storage and retrieval of experimental metadata, lab inventory, and scientific results efficiently.

- Integrated third-party scientific services and lab equipment APIs, ensuring seamless data exchange and interoperability for complex experimental workflows and analysis.

- Developed **Python** data processing modules for LabOps analytics, transforming raw experimental data into actionable insights via automated agents for research and operational efficiency.

- Implemented automated unit and integration tests using **pytest** and **JUnit**, increasing code quality and reducing post-deployment bugs by 20% consistently.
