## Summary

Software Engineer with 4+ years building **cloud services**, **distributed platforms**, and **secure infrastructure automation** across **Go**, **Python**, **AWS**, **GCP**, **Kubernetes**, and **Terraform**; experienced with **RESTful APIs**, **CI/CD**, **observability**, **IAM/SSO**, and reliability patterns for enterprise security and AI compliance SaaS systems.

## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Security Platform*

- Architected **Go** and **Python** cloud services on **AWS EKS** for an **enterprise security platform**, improving service uptime to **99.99%** while supporting scalable customer-facing workflows.

- Built internal **Kubernetes** platform capabilities with **Helm**, **Terraform**, and reusable deployment templates, reducing environment setup time by **60%** across security engineering teams.

- Designed multi-account **AWS Organizations** guardrails with **Service Control Policies (SCPs)**, root/member account boundaries, and least-privilege **IAM**, reducing risky permission drift by **35%**.

- Standardized **cloud security controls** across **AWS** and **GCP** org policies, codifying account baselines, network boundaries, and audit logging for **20+** production services.

- Implemented secure **RESTful APIs** and **gRPC** middleware with **OAuth2/JWT** authorization, rate limiting, and request validation, decreasing cross-service integration defects by **25%**.

- Enhanced **CI/CD pipelines** with **GitHub Actions**, **Buildkite**, and **Terraform** plan/apply workflows, reducing manual release intervention by **70%** and deployment errors by **20%**.

- Integrated **Prometheus**, **Grafana**, and structured logs for application health monitoring, enabling faster diagnosis of **Linux**/network incidents and cutting critical MTTR by **30%**.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B AI Compliance SaaS Platform*

- Developed **Go** and **Python** microservices for a **B2B AI compliance SaaS platform**, processing **100M+** daily events through reliable APIs, queues, and distributed workers.

- Migrated monolithic compliance services to **Docker**/**Kubernetes** on **AWS** and **GCP**, improving platform scalability and resilience by **35%** for enterprise tenants.

- Provisioned cloud infrastructure with **Terraform** across **AWS EKS**, **EC2**, **S3**, **RDS**, and **VPC** networks, accelerating repeatable environment delivery by **40%**.

- Implemented **IAM**, **SSO**, and tenant access controls using **OAuth2**, **JWT**, and role-based authorization, reducing unauthorized access incidents by **30%**.

- Built **RESTful APIs** for partner integrations using **Python FastAPI** and **Java Spring Boot**, increasing integration throughput by **40%** for new enterprise customers.

- Collaborated with developers, SREs, and compliance stakeholders on reliability reviews, adding health checks, rollback paths, and dashboards that maintained **99.9%** production availability.

- Automated deployment and operational scripts with **Bash**, **Ansible**, and **GitLab CI**, reducing manual deployment errors by **80%** and deployment time by **50%**.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps Platform*

- Built **Java Spring Boot** and **Python** **REST APIs** for a regulated **LabOps SaaS platform**, supporting experiment and sample tracking for **500+** scientists.

- Implemented service health checks, deployment runbooks, and **Linux** log diagnostics for **LabOps** services, reducing recurring production incidents by **20%**.

- Implemented **Spring Security**, **OAuth2**, and **RBAC** middleware to enforce research-team data isolation, reducing authorization defects by **30%**.

- Designed normalized **PostgreSQL** schemas and optimized high-read query paths, improving experiment data retrieval performance by **30%** across **10+** product modules.

- Containerized services with **Docker** and maintained deployments on **Linux** servers and **AWS EC2**, achieving **99.9%** uptime for core LabOps services.

- Configured **Jenkins** and **GitHub Actions** CI/CD pipelines for automated tests, image builds, and staging deployments, reducing release-cycle defects by **25%**.

- Authored unit and integration tests for backend services, improving **code reliability** and reducing production regressions by **35%** on regulated workflows.
