**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | Digital Banking Platform*

- Led the development of **Java** **Microservices** for a digital banking platform, integrating complex business logic, improving feature delivery speed by 30% through **Agile**.

- Created high-performance **RESTful APIs** using **Spring Boot** to handle customer account transactions securely, processing over 1M requests per hour efficiently.

- Integrated payment gateways using **JPA** with **PostgreSQL**, ensuring data consistency and transactional integrity for critical financial operations, reducing errors by 15%.

- Implemented CI/CD pipelines with **Jenkins** for automated build and deployment processes on **AWS**, improving release frequency by 2x for new functionalities.

- Designed and optimized NoSQL data models in **MongoDB** for user profiles and preferences, enhancing data retrieval **Performance Optimization** by 25% for personalized experiences.

- Developed comprehensive unit and integration tests for new features, ensuring high code quality and reducing post-release issues by 20%, adhering to **Testable Code** standards.

- Applied architectural best practices in designing **Microservices** with **Spring Boot**, considering **Scalability**, **Reliability**, and **Performance Optimization** for core banking functions, supporting future growth requirements.

- Conducted rigorous code reviews, mentoring junior engineers on best practices and ensuring compliance with development standards, leading to a 10% improvement in overall code quality and maintainability.

**Software Engineer**  |  *Aug 2020 - Aug 2022*

*Zemoso Technologies | B2B SaaS Platform Development*

- Collaborated cross-functionally with product and QA teams to translate business requirements into technical specifications, ensuring high-quality software experiences and adherence to project standards throughout.
