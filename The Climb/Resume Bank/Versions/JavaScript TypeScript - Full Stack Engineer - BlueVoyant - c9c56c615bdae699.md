## Professional Experience

**Full Stack Engineer (Enterprise Security)**  |  *Jun 2025 - Present*

*Epik Solutions*

- Analyzed and optimized frontend performance using Chrome DevTools and Vite, reducing initial bundle size by 30% and improving Core Web Vitals (LCP/FID) for real-time security dashboards

- Developed a secure front-end application using Vue and TypeScript for Azure hosted security platforms, optimized microservices and UI/UX, reducing incident response time by 15 minutes for security teams.

- Engineered real-time analytics dashboards with Vue, Pinia, and Tailwind CSS, eliminating 20+ hours/week manual reporting, improved decision latency for C-suite stakeholders.

- Integrated Azure AI Studio and RAG via RESTful APIs and Websockets into front-end tooling, processed 1,000+ security events daily, reducing analyst workload by 30%.

- Implemented robust DevOps practices and CI/CD pipelines for Azure hosted applications, accelerating deployment cycles by 40%. Ensured consistent, high-quality releases for 500+ users.

**Founding Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected front-end of a multi-tenant B2B Compliance SaaS platform using Vue and TypeScript, delivered intuitive UI/UX for 15+ enterprise clients, scaling to 10,000+ users.

- Delivered production-ready UI/UX for 15+ enterprise clients, implemented application usage metrics and A/B test experiments to track feature adoption, resulting in a 20% increase in user engagement

- Designed and integrated RESTful APIs for cloud-hosted applications, ensuring data isolation and high availability, supported 10,000+ users with secure, efficient back-end communication.

- Developed AI tooling (RAG, Agentic Systems) integrated with Azure AI Studio, reduced manual auditor effort by 70% through automated evidence collection and summarization.

- Implemented DevOps practices for CI/CD pipelines, automating deployment of data ingestion systems., ensured reliable data flow from enterprise systems, enhancing data integrity.

**SDE Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Developed front-end components with WCAG 2.1 accessibility standards and ARIA patterns for an Azure hosted identity lifecycle system using Vue and TypeScript, reduced employee provisioning time by 80%.

- Implemented RESTful APIs and UI/UX improvements for MLOps data labeling infrastructure, enhanced annotation throughput by 20%, benefiting ML training pipelines effectively.

**Software Engineer**  |  *Jul 2021 - Aug 2022*

*ZeMoSo Technologies*

- Delivered front-end features for a robotic lab automation platform, utilized by 500+ scientists, applied modern front-end design principles to enhance user experience.

- Implemented robust state management solutions across 10+ product modules, ensuring accurate tracking of complex experimental data. Demonstrated strong problem-solving skills.

- Authored 100+ test cases and resolved critical production issues, adhering to agile development methodologies, ensured data integrity and system reliability for regulated platform.
