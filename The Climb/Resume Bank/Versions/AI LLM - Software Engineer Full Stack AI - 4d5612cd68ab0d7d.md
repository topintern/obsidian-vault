## Professional Experience


**Software Engineer II**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Security Platform*




- Engineered **LangGraph**-based AI agent workflows for automated security alert triage and remediation suggestions, integrating **OpenAI GPT-4o** structured outputs into the core product and reducing MTTR by 40% for SOC teams.

- Built **RAG**-powered search features using **Pinecone** vector database and **LangChain** retrieval chains over enterprise security corpora, improving context-aware search relevance by 38% over keyword-based approaches.

- Implemented LLM evaluation and guardrail checks for agent outputs using prompt versioning, regression datasets, and structured JSON validation, reducing hallucinated remediation suggestions by 28%.

- Developed scalable **Python** and **Node.js** REST API microservices with async processing and **Redis** caching, sustaining 99.9% uptime for 10,000+ daily active enterprise users under peak security event loads.

- Implemented **React.js** front-end real-time streaming UI for LLM-generated security insights, building WebSocket-backed components that cut perceived response wait time by 50% for end users.

- Deployed all services on **AWS** (ECS, Lambda, S3, SQS) with **Docker** and **Kubernetes**, implementing **GitHub Actions** CI/CD pipelines that reduced release cycle time from two weeks to three days.



**Software Engineer II**  |  *Jul 2023 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance Platform*




- Architected **Node.js** and **Python** backend microservices with **Spring Boot** REST APIs and **PostgreSQL**, processing 10K+ compliance records monthly across 15+ enterprise tenants with 99.9% uptime SLA.

- Built **React.js** and **TypeScript** front-end modules including multi-step compliance workflows, data grids, and role-based dashboards, improving enterprise user task completion rates by 35%.

- Designed tenant-aware **GraphQL** APIs and evidence collection workflows for SOC 2 and ISO audits, standardizing integrations across AWS, Azure, GitHub, and Jira while reducing onboarding time by 30%.

- Engineered **Apache Kafka** event-driven pipelines for async inter-service communication, decoupling 6+ microservices and improving platform throughput by 50% under high-load enterprise scenarios.

- Integrated **OpenAI API** into the compliance product for unstructured document summarization and auto-categorization, cutting manual evidence review time by 45% across 10K+ monthly compliance records.

- Built a **LangChain**-powered document Q&A feature backed by **Azure AI Search** vector retrieval, enabling natural language querying over enterprise compliance corpora with 89% retrieval accuracy.

- Provisioned **AWS** infrastructure (ECS, RDS, Lambda, S3) and **Azure** services with **Terraform** IaC and **CI/CD** pipelines, enforcing environment parity and reducing deployment errors by 40% across all tenants.

- Delivered **Redis** caching and query optimization across high-traffic compliance API endpoints, reducing average API latency by 45% and meeting all SLA targets for 15+ enterprise clients.



**Software Engineer I**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps Platform*




- Built **React.js** front-end modules and async **Spring Boot** REST APIs over **PostgreSQL**, delivering accurate experiment data tracking and inventory management for 500+ scientists across 10+ product modules.

- Designed normalized **PostgreSQL** database schemas and optimized complex SQL queries for scientific experiment workflows, improving data retrieval performance by 30% across 500+ experiment datasets.

- Developed reusable **TypeScript** React component libraries with responsive design and accessibility standards, reducing new-feature UI development time by 25% across the engineering team.

- Integrated background job processing and CI quality gates for experiment upload workflows, improving traceability for regulated data changes and reducing failed release validations by 22%.

- Implemented **Spring Security** with role-based access control for a regulated scientific platform, enforcing data isolation across research teams and eliminating unauthorized cross-team data access.

- Authored 100+ **JUnit** and **Jest** automated test cases, resolved critical production defects via systematic debugging and profiling, reducing regression incidents by 35% throughout the platform.
