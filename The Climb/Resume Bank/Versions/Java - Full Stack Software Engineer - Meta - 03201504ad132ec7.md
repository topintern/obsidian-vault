## Professional Experience


**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Security Platform*




- Built large-scale **Java** (Spring Boot) backend infrastructure services processing 50M+ daily security events across distributed microservices, applying secure coding standards that reduced API-level vulnerabilities by 30%.

- Developed **Python** (FastAPI) web application services for enterprise security analytics, designing **RESTful** API endpoints consumed by 10,000+ daily active users with 99.9% uptime SLA.

- Implemented **JavaScript**/**TypeScript** and **React.js** web interfaces with responsive **HTML5**/**CSS3** layouts, delivering real-time security dashboards and user-facing workflow tools across the enterprise platform.

- Designed and optimized **PostgreSQL** relational database schemas with complex SQL queries, stored procedures, and indexing strategies supporting high-throughput security data access for 10,000+ enterprise users.

- Deployed large-scale infrastructure on **AWS** (EC2, ECS, RDS, S3) with **Docker** and **Kubernetes**, implementing **CI/CD** pipelines that cut release cycle time from two weeks to three days.

- Led **Agile** sprint planning and peer code reviews across a 6-engineer team, delivering 3+ production infrastructure features per sprint with zero critical defects across 4 consecutive releases.



**Software Engineer II**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance Platform*




- Architected large-scale **Java** Spring Boot microservices infrastructure with **Spring JPA/Hibernate** over **PostgreSQL**, processing 10K+ compliance records monthly and 99.9% uptime across 15+ enterprise tenants.

- Built **Python** web application services for compliance data ingestion and transformation, integrating 10+ third-party REST APIs and handling schema drift, pagination, and idempotent writes across all data sources.

- Developed **React.js** and **TypeScript** front-end modules with **JavaScript**, **HTML5**, and **CSS3**, delivering multi-step compliance workflows and role-based dashboards for 10,000+ production users.

- Designed and exposed **GraphQL** APIs over the compliance data model, enabling flexible client-driven queries that eliminated over-fetching across 8+ front-end consumer integrations and reduced round trips by 35%.

- Designed and managed both **PostgreSQL** relational schemas (star-schema, normalized transactional tables) **MongoDB** NoSQL document stores, **neo4j** graph for unstructured compliance artifact storage across 15+ clients.

- Engineered **Apache Kafka** event-driven pipelines for asynchronous inter-service communication, decoupling 6+ microservices and improving platform throughput by 50% under high-load enterprise workloads.

- Provisioned AWS infrastructure (ECS, RDS, Lambda, S3) with **Terraform** IaC and enforced **CI/CD** best practices, reducing manual deployment errors by 40% across multi-tenant production environments.

- Implemented **Redis** NoSQL caching across high-traffic API endpoints and **Spring Security** with OAuth2/JWT across all microservices, reducing average query latency by 45% and eliminating unauthorized cross-tenant access.



**Software Engineer I**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps Platform*




- Developed **Java** Spring Boot and **Ruby on Rails** backend web application services for a regulated scientific platform, RESTful APIs that tracked complex experimental data for 500+ scientists across 10+ product modules.

- Built **React.js** front-end web interfaces with **JavaScript**, **HTML5**, and **CSS3**, delivering responsive inventory, compound tracking, and experiment management modules across the LabOps product suite.

- Designed normalized **PostgreSQL** relational database schemas with optimized SQL queries for experiment tracking workflows, improving data retrieval performance by 30% across 500+ experiment datasets.

- Integrated **MongoDB** NoSQL document storage for flexible unstructured experiment metadata, enabling schema-free scientific data capture across heterogeneous instrument types and lab workflows.

- Authored 100+ **JUnit** and **RSpec** automated test cases, resolved critical production defects via systematic profiling and debugging, reducing regression incidents by 35% across all LabOps modules.
