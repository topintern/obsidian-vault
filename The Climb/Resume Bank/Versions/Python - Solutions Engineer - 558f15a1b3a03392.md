## Professional Experience


**Solutions Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise SaaS Platform*




- Authored **OpenAPI 3.0** specifications for the enterprise SaaS API, defining complete typed request and response contracts that standardized integrations across 30+ third-party client consumer applications.

- Built **webhook** delivery system with **HMAC** signature verification and exponential-backoff retries, enabling 30+ enterprise clients to receive real-time event notifications from the SaaS platform reliably.

- Designed **API versioning** using URL path prefixes and deprecation headers, maintaining backward compatibility while shipping five breaking-change-free evolution cycles across all existing enterprise client integrations.

- Built **Python** **FastAPI** microservice integrating **GPT-4o** for intelligent document classification and extraction, reducing manual processing time by 70% across 10,000+ daily document uploads in production.

- Shipped **React** and **TypeScript** client-facing analytics dashboard, iterating rapidly on user feedback and delivering three major feature milestones ahead of schedule for enterprise SaaS clients.

- Prototyped **LangGraph** agentic AI workflow on the Python document pipeline, chaining LLM reasoning steps with automated validation loops and human-in-the-loop review for high-stakes classification decisions.

- Partnered with non-technical stakeholders and executive sponsors to translate complex system architecture decisions into clear product roadmaps, securing alignment across engineering, product, and operations teams.



**Solutions Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | B2B Compliance Platform*




- Owned backend solutions engineering for a B2B compliance SaaS, shipping three product releases on schedule while consistently serving 10,000+ enterprise users with strong reliability guarantees.

- Implemented **OAuth2** and **JWT** API security on the compliance platform, enforcing scope restrictions, token rotation, and **OpenAPI 3.0** security annotations across all public service endpoints.

- Built **React** and **TypeScript** compliance reporting dashboard, integrating the **Rails** REST API and enabling compliance officers to self-serve audit data with zero engineering team intervention.

- Refactored synchronous **Python** compliance services to **asyncio** with **httpx**, enabling concurrent third-party regulatory API calls and cutting external integration latency by 55% under production load.

- Integrated **WebSocket** streaming into the compliance dashboard using **FastAPI** and **React**, delivering live regulatory alert feeds that eliminated manual page refreshes for compliance officer workflows.

- Integrated **Elasticsearch** into the compliance data platform, indexing 5M+ regulatory documents and cutting document lookup latency from 8 seconds to under 300ms for compliance officers.

- Built **Python** **RAG** pipeline on the compliance platform, embedding regulatory documents into **Pinecone** and serving **GPT-4o**-powered natural language Q&A with cited source references to officers.

- Built **Python** analytics pipeline to profile API endpoint latency hot spots, surfacing optimization opportunities that drove a 60% reduction in compliance platform database query load.



**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps Platform*




- Engineered **Ruby on Rails** and **Python** modules for a LabOps SaaS, designing REST API endpoints, data models, and CI-enforced test coverage shipped iteratively from scratch.

- Delivered rapid proof-of-concept prototypes for two LabOps client stakeholders, iterating on feedback over two-week sprints and converting both demos into fully scoped production feature contracts.

- Built **Python** data export APIs for lab reporting, designing transformation pipelines that processed 500K+ monthly records and reduced manual researcher data preparation time by 50%.

- Configured **GitHub Actions** CI/CD for Rails and Python services, automating **RSpec** and **pytest** test runs, Rubocop linting, and staging deployments on every pull request submitted.

- Profiled **PostgreSQL** queries for lab sample tracking using **EXPLAIN ANALYZE** and targeted index tuning, reducing report generation time by 30% and eliminating production database slowdowns.
