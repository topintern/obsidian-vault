## Professional Experience

**Software Engineer AI**  |  *Jun 2025 - Present*

*Epik Solutions | Enterprise Security Platform*

- Built **AI-powered copilots and chat workflows** for security operations using **Python, C#/.NET Core, FastAPI, React**, and streaming REST APIs, reducing analyst triage time by **40%**.

- Orchestrated **agentic AI workflows** with **LangGraph, Semantic Kernel, CrewAI**, and tool-calling patterns for alert enrichment, evidence lookup, remediation drafting, and human approval checkpoints.

- Built reusable **agent tool adapters** for ticketing, knowledge-base, and document APIs, standardizing auth, pagination, retries, and structured outputs for enterprise workflow automation.

- Designed **RAG architectures** over enterprise security knowledge using **OpenAI/Azure OpenAI, embeddings, Pinecone, OpenSearch**, and MongoDB-backed metadata filters, improving answer relevance by **38%**.

- Implemented **AI governance, evaluations, and observability** with prompt regression suites, groundedness checks, audit logs, latency/cost telemetry, and fallback paths for production LLM features.

- Created **human-in-the-loop React review queues** for low-confidence AI outputs, enabling analysts to approve, edit, reject, and audit assistant-generated recommendations.

- Developed secure **microservices and GraphQL/REST APIs** with OAuth2/JWT, RBAC, secret handling, and structured logging, supporting 5M+ daily security events across enterprise systems.

- Deployed services on **AWS, Docker, Kubernetes, Terraform**, and **GitHub Actions** CI/CD pipelines, improving release frequency while maintaining production reliability.

**Software Engineer (Full Stack AI)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance AI Platform*

- Architected a **multi-tenant AI compliance SaaS platform** using **Python, C#, .NET Core, React, GraphQL, AWS Lambda, ECS, SQS**, and PostgreSQL for **15+ enterprise clients**.

- Built **enterprise knowledge RAG** for policies, evidence, tickets, and audit docs using **LangChain, Azure AI Search, Pinecone, embeddings**, and tenant-aware retrieval controls.

- Implemented **conversation memory and source citation stores** using MongoDB/Cosmos DB patterns, vector freshness jobs, and tenant-scoped metadata for auditable AI responses.

- Integrated AI workflows with **Jira, Confluence, GitHub, SharePoint-style document stores, ServiceNow-style ITSM flows**, cloud audit APIs, and relational/graph databases.

- Developed **agent-based review workflows** using LangGraph-style state machines and AutoGen/CrewAI prototypes for evidence collection, summarization, control mapping, and exception routing.

- Built **React/TypeScript and Next.js** product surfaces for chat, evidence review, policy authoring, admin configuration, and human-in-the-loop approval queues.

- Automated **Terraform and GitHub Actions** deployment workflows for backend services, vector indexes, queues, and environment promotion across dev, staging, and production.

- Added **LLM quality controls** including citation requirements, role-based data access, tenant isolation, eval datasets, retry queues, and CloudWatch/Grafana alerts, reducing manual review by **70%**.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies | LabOps / Scientific Workflow Platform*

- Delivered **full-stack LabOps workflow tools** using **React, TypeScript, Java/Spring Boot, Python REST APIs**, and PostgreSQL for experiment tracking, inventory, and sample metadata used by **500+ scientists**.

- Built **microservices and async background jobs** for file upload, validation, reporting, and long-running scientific analysis workflows across 10+ product modules.

- Developed **REST and GraphQL-style APIs** consumed by React/Angular modules for inventory search, sample lineage, experiment status, and operational reporting workflows.

- Designed normalized schemas, indexes, and query paths for regulated scientific datasets, reducing slow experiment report generation by **30%**.

- Implemented **audit logs, data quality checks, retry-safe processors**, and release validation gates for scientific metadata changes, improving traceability and production reliability.

- Built **React dashboards** for validation errors, pipeline status, review queues, and workflow blockers, giving research and QA teams faster operational visibility.

- Authored **100+ automated tests** and CI/CD quality gates with Jenkins, reducing regression incidents across regulated LabOps releases.
