## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Energy & Climate Grid Optimization*

- Architected and implemented **Go** microservices for a proprietary operating system coordinating thousands of distributed batteries, enhancing grid stability by 15%.

- Led **SRE** initiatives on **AWS** for critical **energy** storage services, optimizing resource utilization and improving system uptime to 99.99%.

- Developed robust **Python** APIs for **climate tech** data ingestion and processing, securing data integrity and reducing processing latency by 25%.

- Designed and deployed **Network Infrastructure** components using **Terraform** and **Kubernetes**, improving communication efficiency across distributed nodes by 20%.

- Implemented advanced **Security Infrastructure** controls including **OAuth2** and **JWT** for sensitive **power grids** data, preventing 100% of reported external threats.

- Orchestrated **DevOps** pipelines with **Jenkins** and **Docker** for continuous delivery of backend services, accelerating deployment cycles by 30%.

- Contributed to **ground up development** of a new **Go**-based real-time analytics module, providing critical insights for **energy** load balancing, decreasing energy waste by 10%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Distributed Systems Platform for IoT*

- Engineered high-performance **Go** services for **distributed systems**, processing sensor data from 500K IoT devices daily, achieving 99.9% data reliability.

- Executed significant **migration** of legacy **Python** applications to modern **Go** microservices on **AWS EC2**, reducing operational costs by 18%.

- Implemented **DevOps** practices using **GitLab CI/CD** and **Docker** for automated deployments, shortening release cycles from weeks to days by 60%.

- Optimized database queries and schema designs in **PostgreSQL** for a data analytics platform, enhancing report generation speed by 40%.

- Developed secure **REST APIs** in **Python** (Flask) for third-party integrations, expanding platform reach to over 50 new partners.

- Built monitoring and alerting solutions using **Prometheus** and **Grafana** for backend services, identifying and resolving issues 50% faster.

- Contributed to **ground up development** of a new **Python** service handling payment processing, supporting transaction volume increases by 25%.

- Focused on **performance optimization** of backend services, redesigning critical data pathways to handle 2x increased user load without degradation.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Enterprise SaaS Solutions*

- Developed and maintained **Java** (Spring Boot) backend services for a B2B SaaS platform, serving over 100 enterprise clients.

- Designed and implemented robust **REST APIs** for client-facing applications using **Java**, supporting daily transactions exceeding $1M.

- Integrated third-party services and payment gateways into the platform, improving feature rollout efficiency by 20%.

- Contributed to database schema design and optimization in **MySQL**, reducing query execution times for critical reports by 35%.

- Implemented comprehensive unit and integration tests using **JUnit** and **Mockito**, ensuring high code **quality** and reducing production bugs by 25%.
