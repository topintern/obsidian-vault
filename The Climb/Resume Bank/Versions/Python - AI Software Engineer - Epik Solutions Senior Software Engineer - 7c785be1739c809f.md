## Professional Experience

**Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Platform*

- Spearheaded the development of a novel RAG architecture for LLM-based threat intelligence analysis, integrating  **LangGraph** for complex agentic workflows and achieving 95% accuracy in identifying geopolitical risk vectors.

- Engineered production-grade  **Python** microservices on  **AWS Lambda** and  **ECS**, handling over 500,000 daily requests for real-time threat data enrichment, reducing latency by 30%.

- Designed and implemented fine-tuning pipelines for large language models using  **PyTorch** on  **AWS SageMaker**, enhancing sentiment analysis capabilities and improving detection of emerging threats by 20%.

- Developed and deployed robust  **JavaScript** front-end components using  **React** for an interactive threat visualization dashboard, improving user comprehension of complex security data by 40%.

- Optimized  **Elasticsearch** indexing strategies and query performance for massive threat intelligence datasets, cutting search response times by 50% and enabling near real-time anomaly detection.

- Led the adoption of  **CrewAI** for orchestrating multi-agent systems, automating complex threat hunting scenarios and reducing manual investigation effort by 60% for the security operations team.

- Implemented comprehensive  **CI/CD** pipelines with  **Jenkins** and  **Docker**, automating build, test, and deployment processes for all AI services, decreasing release cycles by 75%.

**Software Engineer**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC | B2B Platform*

- Developed and deployed advanced  **NLP** models using  **scikit-learn** and  **Pandas** for text classification and entity resolution in customer support tickets, improving automated routing accuracy by 18%.

- Built scalable RESTful APIs with  **FastAPI** in  **Python** to serve real-time data to internal and external applications, processing over 1 million transactions daily with sub-second latency.

- Contributed to the development of a data processing pipeline using  **Apache Spark** on  **AWS EC2**, efficiently transforming and aggregating terabytes of user activity data for analytical purposes.

- Implemented robust data validation and cleaning routines for large datasets, ensuring data integrity and accuracy for critical business intelligence reporting, reducing data errors by 15%.

- Worked with  **PostgreSQL** to design and optimize database schemas, supporting complex analytical queries and significantly improving application performance by 25%.

- Integrated the  **OpenAI API** for experimental generative features, exploring prompt engineering techniques to enhance user engagement and content creation capabilities within the platform.

- Leveraged  **event-driven architecture** patterns using  **AWS SQS** to build decoupled and resilient microservices, processing asynchronous tasks and improving system fault tolerance by 30%.

- Collaborated with cross-functional teams to gather requirements and translate business needs into technical specifications for new platform features, ensuring alignment and timely delivery.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | SaaS Platform*

- Developed backend services using  **Python** and  **Flask** for a financial data aggregation platform, processing and normalizing diverse data sources from multiple third-party providers efficiently.

- Implemented data ingestion pipelines that utilized  **SQLAlchemy** to interact with  **PostgreSQL** databases, ensuring reliable storage and retrieval of financial market data for analysis.

- Designed and built RESTful APIs to expose financial data to client applications, enabling seamless integration and data access for internal dashboards and external partners.

- Wrote unit and integration tests using  **Pytest** to ensure code quality and application stability, achieving over 90% test coverage for critical backend modules.

- Participated in agile development processes, including sprint planning and daily stand-ups, contributing to the timely delivery of software releases and feature enhancements.

- Assisted in the migration of legacy systems to a more modern microservices architecture, improving scalability and maintainability of the platform codebase.
