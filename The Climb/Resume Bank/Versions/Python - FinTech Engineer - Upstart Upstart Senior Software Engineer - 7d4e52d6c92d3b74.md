## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | FinTech Lending Platform*

- Designed and implemented a high-throughput **Python** lending decision engine using **AWS Lambda** and **DynamoDB**, processing 1.5M loan applications daily with 99.9% uptime.

- Led development of a new **Kotlin** **microservice** for partner integrations, utilizing **gRPC** and **Kafka** to ensure secure, real-time data exchange for over 20 financial partners.

- Architected and deployed an enhanced **Java** payments system on **Kubernetes**, integrating with **Stripe** APIs; reduced transaction latency by 35% across 5M monthly payments, improving efficiency.

- Implemented comprehensive **observability** solutions using **Prometheus** and **Grafana** for critical FinTech services, enabling proactive issue detection and reducing incident response by 40%.

- Developed **Terraform** scripts to manage **AWS** infrastructure as code, standardizing environments and accelerating deployment cycles for new features by 25% under regulated guidelines.

- Engineered data consistency checks and audit trails across distributed **PostgreSQL** databases using **event-driven architectures**, ensuring 100% data integrity for regulatory reporting.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise Data Integration Platform*

- Developed and maintained robust **Python** **ETL** pipelines using **Apache Airflow** on **AWS S3** for large-scale financial data ingestion, processing 10M records daily.

- Built scalable **RESTful APIs** with **Django** and **PostgreSQL** to support internal operational tooling, handling 500k daily requests with 99.8% availability for users effectively.

- Migrated legacy services to **AWS Lambda** and **SQS** for improved resilience and cost-efficiency, reducing infrastructure costs by 30% and enhancing system reliability.

- Contributed to a data streaming platform using **Kafka** and **Apache Flink** for real-time analytics, processing 2M events per second, supporting critical business intelligence needs.

- Developed an internal tool using **Python** and **Streamlit** to visualize financial data, enabling business analysts to generate reports 50% faster, improving decision-making processes.

- Integrated **Elasticsearch** for log aggregation and full-text search across distributed **Java** microservices, improving debugging efficiency for engineers by 30% effectively.

- Collaborated on backend service optimization using **Java** and **Spring Boot**, decreasing response times by 15% for high-traffic financial APIs, enhancing user experience.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Client Solutions Development*

- Developed responsive web applications using **React.js** and **Node.js** for client-facing projects, improving user engagement by 20% across multiple industry verticals.

- Implemented **RESTful APIs** with **Java** **Spring Boot** to support mobile and web clients, handling 100k daily requests with robust error handling reliably.

- Designed and optimized **MySQL** database schemas for various projects, enhancing data retrieval performance by 30% for reporting modules and user-facing dashboards.

- Utilized **Git** for version control and collaborated effectively in an **Agile** environment, delivering features on time and reducing merge conflicts by 10% consistently.

- Configured and deployed applications to **AWS EC2** instances, ensuring secure, scalable infrastructure for client solutions, improving system availability to 99.5% reliably.

- Wrote comprehensive documentation for APIs and system architecture using **Confluence**, facilitating smoother onboarding for new team members and reducing integration issues significantly.

- Ensured adherence to security best practices for client data by implementing secure coding standards and conducting regular code reviews, protecting sensitive information across web applications.
