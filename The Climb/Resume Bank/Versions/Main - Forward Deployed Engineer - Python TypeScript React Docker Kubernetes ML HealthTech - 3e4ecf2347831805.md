## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | HealthTech AI & Clinical Data Platform*

- Built a greenfield **React** and **TypeScript** clinical web application entirely from scratch, enabling care teams to access patient data 35% faster across enterprise health clients.

- Designed and deployed **Python** **microservices** on **Kubernetes** for processing health records, handling 300k daily transactions at 99.9% uptime for distributed clinical operations teams.

- Integrated **deep learning** classification models via **TensorFlow** into production **FastAPI** services, enabling real-time patient risk scoring and improving early clinical intervention rates by 22%.

- Containerized the health platform using **Docker** and **Kubernetes**, reducing deployment cycle time by 40% and eliminating environment inconsistencies between development and production systems.

- Partnered directly with healthcare stakeholders to translate complex clinical workflows into detailed engineering requirements, leading successful delivery of three major platform feature releases.

- Architected **RESTful APIs** in **Node.js** and **TypeScript** bridging the **React** frontend to health data backend services, cutting data retrieval latency by 30ms across modules.

- Built **CI/CD** pipelines using **GitHub Actions** and **Docker**, enabling zero-downtime releases and accelerating deployment frequency by 40% for a fast-moving startup engineering team.

- Built interactive **React** data visualization components for clinical analytics dashboards, equipping physicians with real-time insights and improving overall diagnostic workflow efficiency by 25%.

- Served as forward-deployed technical lead at healthcare client sites, resolving integration failures on-site and reducing customer escalation resolution time by 45% through direct collaboration.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise SaaS & Full Stack Data Platform*

- Built high-performance **Python** **microservices** using **FastAPI** for a critical data ingestion platform, processing 500k daily transactions with sub-100ms response times at 99.9% uptime.

- Developed full-stack features using **React**, **TypeScript**, and **Node.js** for a customer-facing SaaS application from scratch, serving over 200 enterprise clients across multiple verticals.

- Integrated **OpenAI API** and **Python** ML services for document NLP classification, improving accuracy by 18% and reducing manual review workload significantly for enterprise operations teams.

- Designed **RESTful APIs** and **PostgreSQL** data models from scratch for new product modules, enabling three product launches and reducing average API response time by 35%.

- Collaborated with product managers and stakeholders to clarify business requirements and decompose customer workflows into sprint-ready engineering tasks across a cross-functional development team.

- Deployed containerized services using **Docker**, **AWS Lambda**, and **S3**, building event-driven pipelines that cut infrastructure costs by 20% while improving horizontal scalability.

- Implemented user authentication using **JWT** and **OAuth2**, enforcing enterprise-grade security standards and eliminating unauthorized access incidents across all production customer-facing systems.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | E-commerce & Digital Experience Platform*

- Built backend services from scratch using **Python** and **Django** for a high-traffic e-commerce platform, sustaining 1,000 requests per second under peak load with stable performance.

- Designed **RESTful APIs** and **MySQL** schemas for product catalog and order management, reducing average query response time by 40% through targeted query indexing and optimization.

- Developed **JavaScript** and **React** frontend components for customer-facing product pages, increasing user engagement by 15% through improved UI responsiveness and interactive feature delivery.

- Containerized application services using **Docker**, standardizing local development environments and reducing new engineer onboarding setup time from three days to under four hours.

- Contributed to a **microservices** decomposition initiative, helping break a legacy monolith into independently deployable services and improving release velocity across multiple engineering squads.

- Managed feature branches and release cycles using **Git**, resolving 20+ critical production defects and maintaining stable deployment cadence across a team of eight engineers.
