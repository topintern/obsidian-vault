## Summary

Senior Software Engineer with 5+ years designing enterprise **Java microservices**, **RESTful APIs**, and distributed systems on **Spring Boot**, **AWS**, and **Kubernetes**, delivering scalable, secure solutions for 10,000+ enterprise users across identity, compliance, and scientific domains, driving consistent quality and measurable performance.

## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | Enterprise Security*

- Developed scalable **Java Spring Boot** microservices with **RESTful API** endpoints and **Oracle** database integration, applying **secure coding** standards that reduced API-level vulnerabilities by 30% in prod.

- Deployed **Spring Boot** applications on **AWS** (EC2, RDS Oracle, S3), configuring auto-scaling and IAM security policies to sustain 99.9% uptime for 10,000+ daily active enterprise users.

- Containerized Java microservices with **Docker**, orchestrating **Kubernetes** deployments via **Jenkins CI/CD** pipelines and cutting enterprise security platform release cycle time from two weeks to three days.

- Implemented **Spring Security** with **OAuth2** and **JWT** token validation, enforcing **role-based access control** and SSO across 8+ microservices to eliminate unauthorized cross-service data access.

- Monitored enterprise security API performance using **AWS CloudWatch** and custom alerting, proactively identifying and resolving throughput bottlenecks that improved p99 response times by 25% across prod endpoints.

- Led **Agile** sprint ceremonies and peer code reviews across a 6-engineer enterprise security team, consistently delivering 3+ microservice features per sprint with zero critical defects across 4 consecutive production releases.

**Software Engineer II**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | B2B SaaS Compliance*

- Built **Java Spring Boot** compliance APIs with **Spring JPA/Hibernate** and **Spring Security** over **Oracle** database, processing 10K+ records monthly and cutting manual auditor effort by 70%.

- Designed distributed Java microservices backend using **Spring Cloud Eureka** service discovery, **circuit breakers**, and tenant isolation patterns that sustained 99.9% uptime across 15+ enterprise client deployments.

- Engineered **Apache Kafka** event-driven pipelines for async inter-service communication in a B2B SaaS compliance platform, decoupling 6+ microservices and improving high-load enterprise workflows throughput by 50% .

- Provisioned **AWS** infrastructure (ECS, RDS Oracle, Lambda) with **Terraform** IaC for a multi-tenant B2B SaaS compliance platform, enforcing **CI/CD** best practices and reducing manual deployment errors by 40%.

- Managed API lifecycle using **Kong API Gateway**, enforcing rate limiting, authentication policies across all microservices to improve API governance and reduce unauthorized access attempts by 35%.

- Delivered **Redis** caching and **Elasticsearch** search capabilities across **Agile** sprints, collaborating with product and QA teams to cut average query latency by 45% and meet sprint velocity targets across 15+ enterprise tenants.

- Containerized 12 **Spring Boot** compliance microservices with **Docker** and orchestrated rolling deployments via **Kubernetes**, enabling zero-downtime releases, reducing service provisioning time by 60% across 15+ B2B clients.

**Software Engineer I**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | LabOps*

- Built **Java Spring Boot** services with **Spring JPA/Hibernate** over **Oracle** database, designing **RESTful** endpoints that tracked complex experimental data for 500+ scientists across 10+ product modules.

- Migrated **J2EE** legacy modules into **Spring Boot** microservices for a LabOps platform, applying single-responsibility principles and reducing cross-module regression incidents by 25% across 10+ lab workflows.

- Authored 100+ **JUnit** automated test cases, resolved critical Java production bugs via systematic profiling and debugging, reducing regression incidents by 35% and improving platform data integrity.

- Designed normalized **Oracle** database schemas and optimized SQL queries for LabOps experiment tracking workflows, improving data retrieval performance by 30% and data integrity across 500+ experiment datasets.

- Documented API specifications, data models, and system architecture for a regulated scientific platform, creating reference materials adopted as onboarding standards across the full engineering team.
