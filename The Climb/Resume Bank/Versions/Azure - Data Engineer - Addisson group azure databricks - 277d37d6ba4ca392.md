 Data Engineer

## Summary





- Data Engineer with 5+ years of experience designing and productionizing scalable data platforms on Azure.

- Deep expertise in Azure Databricks, PySpark, Delta Lake, and ADLS Gen2, with a strong track record of building governed, high-reliability ETL/ELT pipelines for batch and streaming workloads.

- Proven ability to translate complex business and scientific workflows into optimized data models, enforce data governance with Unity Catalog, and deliver SLA-driven pipelines through CI/CD and monitoring-first design




## Skills


**Data Engineering**: Azure Databricks, PySpark, Spark SQL, Delta Lake, Delta Live Tables

**Data Storage**: Azure Data Lake Storage Gen2, Delta Tables, Parquet

**Pipelines & Orchestration**: Databricks Workflows, Azure Data Factory, Event-driven ingestion

**APIs & Ingestion**: REST APIs, incremental loads, CDC-like patterns, schema evolution

**Governance & Security**: Unity Catalog, RBAC, data lineage, data quality checks

**DevOps & CI/CD**: Azure DevOps, Git, automated deployment pipelines

**Monitoring & Reliability**: Pipeline metrics, alerts, SLA enforcement

**Languages**: Python, SQL




## Professional Experience



**CIFC Asset Management**  |  *Jun 2025 - Present*

**Senior Automation Engineer (Enterprise Security & Reporting)**

*Project: CIFC Enterprise Automation & KPI Reporting Modernization*



- Designed and implemented Azure Databricks data pipelines using PySpark and Delta Lake to ingest, normalize, and store security and operational datasets, enabling scalable analytics beyond source-system retention limits.

- Built robust ETL/ELT frameworks supporting both batch and near-real-time ingestion, ensuring consistent schema enforcement and optimized query performance for downstream analytics.

- Integrated RESTful SaaS APIs (with and without native CDC) by implementing incremental extraction logic, watermarking, and idempotent writes to Delta tables.

- Implemented data governance and access controls using Unity Catalog, enforcing role-based access, table-level permissions, and end-to-end lineage tracking.

- Optimized Spark workloads through partitioning strategies, file compaction, caching, and query tuning, reducing job runtimes and improving SLA adherence.

- Productionized pipelines with Databricks Workflows, adding monitoring, failure handling, and alerting to ensure reliable daily operations.

- Collaborated with business and engineering stakeholders to convert reporting and investigation workflows into scalable analytical data models.



**Samay Systems LLC**  |  *Feb 2025 - Jun 2025*

**Senior Automation Engineer (Cloud & Compliance)**

*Project: Compliance Platform (SaaS) – Security & Compliance Automation*



- Architected Azure Databricks-based ELT pipelines to support a compliance SaaS platform, transforming raw cloud and application data into governed analytical datasets.

- Developed PySpark ingestion jobs to pull structured and semi-structured data from REST APIs, handling pagination, rate limits, schema drift, and data validation.

- Designed Delta Lake table schemas optimized for analytical queries, supporting time-based filtering, auditability, and historical analysis.

- Implemented data quality checks and validation rules at ingestion and transformation stages to prevent downstream data integrity issues.

- Integrated pipelines into Azure DevOps CI/CD workflows, enabling version-controlled deployments and repeatable environment promotion.

- Worked closely with customers and internal teams to translate audit and compliance workflows into scalable data models and reporting layers.



**Arvam Tech**  |  *Jul 2023 - Jan 2025*

**Enterprise Automation Engineer**

*Project: Enterprise Asset Management System*



- Built batch ETL pipelines to consolidate enterprise asset and inventory data into a centralized Azure data lake for long-term analytics.


- Developed Python and Spark SQL transformations to standardize schemas, enforce referential integrity, and support cross-system reporting.


- Implemented incremental load strategies for API-based sources lacking CDC, minimizing data movement and processing cost.


- Designed monitoring and alerting mechanisms to track pipeline health, failures, and data freshness.


- Partnered with stakeholders to evolve data models as business requirements changed, maintaining backward compatibility.



**RHYM Tech**  |  *Aug 2022 - May 2023*

**Associate solutions Engineer**

*Project: Cybersecurity Threat Intelligence Platform*



- Developed PySpark pipelines to ingest and transform high-volume security and telemetry data into analytical storage.

- Built optimized Delta Lake tables to support trend analysis and historical investigations.

- Tuned Spark jobs by optimizing joins, partitions, and file sizes to improve reliability and runtime performance.

- Supported schema design and evolution to accommodate new data sources without breaking downstream consumers.



**ZeMoSo Technologies**  |  *Jul 2021 - Aug 2022*

**Associate Developer**

*Project: Biotech LabOps Automation*



- Implemented data ingestion and transformation logic using Python and SQL to support laboratory and scientific workflows.


- Designed structured data models aligned with experiment and operational reporting needs.


- Assisted in productionizing pipelines with basic monitoring, logging, and error handling patterns.




## Projects



**CIFC Platform**

**Problem**: Fragmented systems and short data retention windows limited analytics and trend analysis.

**Solution**: Built governed Azure Databricks pipelines using PySpark, Delta Lake, and Unity Catalog to centralize, secure, and scale analytical data with SLA-driven reliability.

**Agent-based Compliance Dashboard – RHYM Tech**

**Problem**: Manual audit preparation and inconsistent data ingestion slowed customer workflows.

**Solution**: Implemented API-driven ELT pipelines with Delta Lake and automated quality checks to deliver reliable, self-service analytics.

**Enterprise Asset Management Automation – Arvam Tech**

**Problem**: Manual asset tracking was inefficient.

**Solution**: Automated data flows with PowerShell + Express.js, integrated Power BI, and used Power Automate for approval chains.
