## Professional Experience

**Generative AI Engineer**  |  *Jun 2025 - Present*

*Epik Solutions*

- Architected enterprise GenAI solutions on **Azure OpenAI** and **AI Studio**, building **LLM-powered copilots** that automated threat summarization and improved SOC security reporting relevance by **25%**.

- Implemented **RAG pipelines** using **Azure AI Search** over enterprise security data sources, enabling natural language querying of audit logs with **91% grounding accuracy** across findings.

- Built **Python** LLM orchestration layers using **LangChain** to generate structured security metrics dashboards from unstructured incident data, delivering enterprise risk insights with **sub-2s latency**.

- Designed GenAI **REST APIs** with **responsible AI guardrails** including PII redaction and content filtering, ensuring secure handling of sensitive security data per enterprise governance policies.

- Optimized **Golang microservices** for real-time security event ingestion and LLM inference routing, reducing end-to-end pipeline latency by **15%** and supporting **10,000+ daily** monitored enterprise events.

**ML Engineer (AI/Search)**  |  *Jul 2024 - Jun 2025*

*Samay Systems LLC*

- Architected a **multi-tenant RAG system** for **15+ enterprise clients** using **Azure AI Search** with **vector embeddings**, improving query relevance scores by **20%** across all tenants.

- Implemented an **LLM-powered compliance automation pipeline** using **Azure OpenAI** and **LangChain**, summarizing and classifying **10K+ compliance documents** and cutting manual auditor effort by **70%**.

- Integrated GenAI solutions with **Azure Data Lake** and **Synapse Analytics**, enabling real-time enterprise knowledge base refresh and sustaining retrieval accuracy above **89%** across live corpora.

- Built document intelligence APIs using **Azure Form Recognizer** with custom **NLP post-processing**, improving structured data extraction accuracy from **71% to 89%** across **500K+ compliance artifacts**.

- Drove **responsible AI practices** across **10+ production deployments**, instrumenting model evaluation dashboards tracking faithfulness, relevance, and  metrics with enterprise alerting on quality drift.

**AI/ML Intern**  |  *Jun 2023 - Aug 2023*

*Monarch Tractor*

- Built **Python data pipelines** feeding agricultural data into cloud AI training jobs, applying **prompt engineering** for synthetic label generation and boosting annotation throughput by **20%**.

- Deployed serverless **Azure Functions** pipelines for version-controlled dataset delivery, integrating **Blob Storage** to sustain continuous training across **3 production vision models** with **40% fewer failures**.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*ZeMoSo Technologies*

- Delivered full-stack features for a cloud-based scientific lab platform using **React** and **Spring Boot REST APIs**, ensuring accurate tracking of experimental data for **500+ scientists**.

- Designed and integrated **RESTful API contracts** across **10+ product modules** with **Spring Boot** and **PostgreSQL**, establishing reusable data validation patterns adopted as team-wide engineering standards.

- Authored **100+ automated test cases** with **JUnit** and **Jasmine**, resolving critical production issues and improving system reliability and data integrity in a regulated scientific environment.
