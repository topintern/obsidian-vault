## Professional Experience

**Senior Software Engineer**  |  *Jul 2025 - Present*

*Epik Solutions | AI Data Platform & ML Ops*

- Developed an **agentic AI** system using **LangChain** and **OpenAI API** for automated **synthetic dataset** generation, accelerating data delivery by 35% monthly.

- Implemented **evaluation workflows** and **quality standards** for **LLM-based solutions** using **Weights & Biases**, improving model performance validation accuracy by 20%.

- Designed and deployed **ML-based workflows** on **AWS SageMaker** for robust **MLOps** and **AI data pipeline lifecycle** management, achieving 99.9% uptime for critical services.

- Engineered a **human-in-the-loop (HITL)** data annotation platform with **React** and **FastAPI**, enhancing **data generation** efficiency by 40% for labeling tasks.

- Led the development of **production-grade datasets** with automated **data quality** checks using **Great Expectations**, ensuring 98% data accuracy for downstream **AI initiatives**.

- Optimized **Apache Spark** jobs for large-scale **data engineering** operations on **AWS EMR**, reducing processing time by 30% for over 10TB of daily data.

- Implemented **model benchmarking** and A/B testing frameworks using **MLflow** for **LLM-based solutions**, providing insights that improved model selection efficacy by 15%.

**Software Engineer**  |  *Jul 2022 - Jun 2025*

*Samay Systems LLC | Enterprise Data & Analytics Platform*

- Built scalable **Python** **ETL pipelines** using **Apache Airflow** and **Pandas** for ingesting 500GB daily transactional data, improving data availability by 25%.

- Deployed machine learning models as **REST APIs** on **AWS Lambda** and **Docker**, serving 10,000 predictions per second with 99.9% uptime.

- Integrated **OpenAI API** into a customer support chatbot written in **Python**, reducing initial response times by 50% for user inquiries.

- Developed **data quality** monitoring tools with **Prometheus** and **Grafana** for data streams, proactively identifying and resolving issues, reducing data errors by 20%.

- Managed **CI/CD pipelines** using **GitLab CI** for automated testing and deployment of **microservices**, accelerating release cycles by 30% weekly.

- Contributed to a data governance framework using **AWS S3** and **Glue** for secure data storage and access, ensuring compliance for 10+ regulatory standards.

- Implemented **Apache Kafka** event streaming for real-time data ingestion from 20+ sources, supporting critical fraud detection systems with <100ms latency.

- Refactored legacy data processing scripts to use **PySpark** on **AWS EMR**, improving processing efficiency and reducing operational costs by 15%.

**Software Engineer**  |  *Jul 2020 - Aug 2022*

*Zemoso Technologies | Enterprise Web Solutions*

- Developed robust **Java** **Spring Boot** microservices for a large-scale e-commerce platform, handling 50,000 concurrent users with 99.9% availability.

- Designed and implemented **RESTful APIs** for backend services, facilitating seamless data exchange across 15+ frontend applications, reducing integration effort by 20%.

- Managed and optimized **MySQL** databases, including indexing and query tuning, improving average response times for critical operations by 30%.

- Deployed applications to **AWS EC2** instances using **Docker** containers and **Terraform**, automating infrastructure provisioning and reducing deployment time by 50%.

- Implemented secure user authentication and authorization using **JWT** and **OAuth2** for **multi-tenant applications**, protecting sensitive customer data across 3 distinct client environments.

- Collaborated on frontend development using **Angular** to consume backend **APIs**, delivering new features that increased user engagement by 10%.
