## Summary





- Expert **Automation Engineer** with 5+ years of experience in **RPA, process automation, and data integration**, delivering scalable solutions across finance, compliance, asset management, and cybersecurity domains.

- Specialized in **UiPath and Alteryx** for RPA-driven automation, data transformation, and process optimization, reducing manual workloads and improving audit/compliance readiness.

- Proficient in designing **workflow automations with Power Automate, UiPath Orchestrator, and n8n**, integrating enterprise systems and APIs to streamline business operations.

- Skilled in building real-time **dashboards with Power BI and Alteryx** to visualize KPIs, monitor security posture, and drive data-informed decision making.

- Proven success in enabling digital transformation through automation-first strategies, supporting security, compliance, and operational excellence initiatives.

## Professional Experience



**Epic Solutions**  |  *Jun 2025 - Present*

**Senior Automation Engineer (RPA & KPI Reporting)**

*Project: CIFC Enterprise Automation & KPI Reporting Modernization*



- Designed and deployed end-to-end UiPath workflows to automate high-volume financial reconciliation and reporting processes, reducing manual effort by 70%.

- Built Alteryx pipelines for data blending and preparation, integrating feeds from Defender, Darktrace, and D365 into Dataverse and Azure Storage for downstream analytics.

- Created Power Automate flows and Power Apps with Dataverse backend to streamline approvals, data entry, and exception handling across business units.

- Delivered real-time KPI dashboards in Power BI with automated refresh schedules, enabling leadership to monitor security and compliance posture through integrated RPA-driven data pipelines.



**Samay Systems LLC**  |  *Feb 2025 - Jun 2025*

**Senior Automation Engineer (Compliance & Cloud RPA)**

*Project: Compliance Platform (SaaS) – Security & Audit Automation*



- Developed UiPath robots to automate compliance evidence collection from AWS CloudTrail, Azure AD, and GitHub audit logs, reducing audit preparation time by 40%.

- Built Alteryx workflows to cleanse and transform multi-cloud compliance data, feeding into Power BI dashboards for SOC 2 and HIPAA controls monitoring.

- Orchestrated RPA-driven Power Automate and n8n workflows for Jira ticket creation, GitHub checks, and access reviews across Azure AD.

- Leveraged AWS Lambda (Python) and Step Functions for cloud task scheduling, integrating outputs with UiPath queues for downstream automation.

- Automated IAM provisioning and notifications using Microsoft Graph API with Slack and Teams integration.



**Arvam Tech**  |  *Jul 2023 - Present*

**Automation Engineer (Enterprise Asset RPA)**

*Project: Enterprise Asset Management System*



- Deployed UiPath robots to update and reconcile CMDB records, validating asset configurations against JSON schemas.

- Built Alteryx workflows for asset usage analytics, combining real-time telemetry with CMDB data to drive Power BI dashboards.

- Implemented Power Automate flows to streamline asset approval workflows, integrate with Teams notifications, and auto-escalate exceptions.

- Integrated webhook-driven n8n automations with UiPath orchestrator to trigger asset compliance checks and generate exception reports.

- Configured Jenkins RPA integration jobs with Groovy scripts to enforce asset tagging and compliance rules across environments.



**RHYM Tech**  |  *Aug 2022 - May 2023*

**Automation Engineer (Threat Intelligence RPA)**

*Project: Cybersecurity Threat Intelligence Platform*



- Automated threat detection workflows using UiPath bots to process Windows Event Logs, Linux syslogs, and forward enriched data to Splunk.

- Developed Alteryx pipelines for real-time blending of Splunk, Kafka, and endpoint data, normalizing inputs for Power BI threat dashboards.

- Built Power Automate flows integrated with n8n to auto-create Jira tickets, tag CVEs, and push alerts to Slack/Teams channels.

- Designed RPA-driven credential rotation and conditional access routines via Azure AD Graph API.

- Delivered incident trend dashboards in Power BI with drill-through capabilities, enabling analysts to pivot across severity, category, and detection source.



**ZeMoSo Technologies**  |  *Jul 2021 - Aug 2022*

**Automation Developer (LabOps RPA)**

*Project: Biotech LabOps Automation*



- Designed UiPath bots to automate lab experiment scheduling, approvals, and status updates from CSV inputs and REST APIs.

- Built Alteryx workflows to transform experiment telemetry into structured KPIs for Power BI visualization.

- Developed Power Automate flows to orchestrate experiment approvals and lab availability notifications across Outlook and Teams.

- Integrated OAuth2-secured APIs with UiPath robots for RBAC-based experiment access control.

- Created reusable RPA components and n8n orchestrations for lab task routing and CRM sync.






## Projects



**Compliance Automation Platform – Samay Systems**

**Tech Stack**: UiPath, Alteryx, Power Automate, AWS Lambda, Python, Power BI, PostgreSQL

**Problem**: Compliance evidence collection across multi-cloud systems was manual and inconsistent.

**Solution**: Designed a serverless RPA-enabled compliance platform. Built UiPath robots to extract evidence from AWS CloudTrail, Azure AD, and GitHub; Alteryx workflows for data normalization; and Power Automate flows for approval routing. Delivered Power BI dashboards with automated refresh for SOC 2/HIPAA readiness tracking.

**Enterprise Asset Management Automation – Arvam Tech**

**Tech Stack**: UiPath, Alteryx, Power Automate, Express.js, Jenkins, Power BI

**Problem**: Manual asset tracking and approval workflows caused delays and compliance gaps.

**Solution**: Automated asset lifecycle processes with UiPath robots for CMDB updates and compliance checks. Used Alteryx pipelines to blend inventory and telemetry data, feeding asset utilization dashboards in Power BI. Deployed Power Automate flows for approval chains and Teams notifications. Configured Jenkins pipelines to enforce tagging compliance with RPA triggers.

**Real-Time Threat Dashboard – RHYM Tech**

**Tech Stack**: UiPath, Alteryx, Splunk, Kafka, Power Automate, Power BI

**Problem**: Security teams lacked centralized visibility into threats and incident response.

**Solution**: Built UiPath bots to parse Windows/Linux logs and auto-ingest into Splunk. Used Alteryx workflows to unify Splunk + Kafka feeds, normalizing for threat intelligence KPIs. Automated ticket creation and CVE tagging with Power Automate flows integrated into Jira/Slack. Delivered Power BI dashboards with incident trends and resolution metrics for SOC analysts.

**LabOps RPA Automation – ZeMoSo Technologies**

**Tech Stack**: UiPath, Alteryx, Power Automate, n8n, Power BI

**Problem**: Lab experiment scheduling and approvals were handled through manual spreadsheets, creating bottlenecks.

**Solution**: Developed UiPath bots to process experiment requests from CSV inputs and REST APIs, updating lab schedules in real time. Built Alteryx pipelines to transform raw lab telemetry into KPIs. Automated experiment approvals and availability checks using Power Automate with Teams/Outlook integration. Designed interactive Power BI dashboards to visualize experiment throughput and turnaround times.
