# Data Directory

This directory contains data files used by the application.

## Structure

- `training_data/` - Contains training examples and versions
  - `current_examples.json` - Current set of training examples
  - `system_message.txt` - System message used for finetuning
  - `versions/` - Saved versions of training examples

## Notes

- The `versions` directory is used to store snapshots of training examples
- Each version is a JSON file with metadata and examples
- The `current_examples.json` file contains the active set of examples
