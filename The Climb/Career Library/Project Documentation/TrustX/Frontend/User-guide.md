# TrustX User Guide

This guide provides instructions for using the TrustX application to manage compliance, policies, controls, and related documentation.

## Getting Started

### Logging In

1. Navigate to the TrustX application URL
2. Click the "Log In" button
3. Enter your credentials in the Auth0 login screen
4. After successful authentication, you will be redirected to the dashboard

### Dashboard Overview

The dashboard provides a summary of your compliance status and recent activities:

- **Compliance Status**: Visual representation of your compliance progress
- **Tasks**: List of pending tasks that require attention
- **Alerts**: Important notifications about compliance issues
- **Compliance Assistant**: AI-powered chatbot for compliance guidance

## Compliance Management

### Policies

#### Viewing Policies

1. Navigate to "Compliances" > "Policies" in the sidebar
2. Browse the list of existing policies
3. Use the search and filter options to find specific policies

#### Creating a New Policy

1. Click the "Create Policy" button
2. Fill in the required fields:
   - Title
   - Description
   - Status
   - Owner
   - Trust Service Criteria (select applicable criteria)
3. Optionally, attach a document to the policy
4. Click "Save" to create the policy

#### Editing a Policy

1. Find the policy you want to edit in the policies list
2. Click the "Edit" button
3. Modify the policy details as needed
4. Click "Save" to update the policy

#### Deleting a Policy

1. Find the policy you want to delete
2. Click the "Delete" button
3. Confirm the deletion in the confirmation dialog

### Controls

#### Viewing Controls

1. Navigate to "Compliances" > "Controls" in the sidebar
2. Browse the list of controls
3. Use the filters to view controls by framework, category, or status

#### Control Details

1. Click on a control to view its details
2. The control details page shows:
   - Description
   - Implementation status
   - Owner
   - Related evidence
   - Exceptions
   - Implementation guidance

#### Updating Control Status

1. Open the control details
2. Click the "Edit" button
3. Update the implementation status
4. Add implementation details if necessary
5. Click "Save" to update the control

### Documents

#### Viewing Documents

1. Navigate to "Compliances" > "Documents" in the sidebar
2. Browse the list of available documents
3. Use the search function to find specific documents

#### Creating a New Document

1. Click the "Create Document" button
2. Enter a title for the document
3. Use the document editor to create content
4. Select the document type and format
5. Click "Save" to create the document

#### Editing a Document

1. Select the document you want to edit from the documents list
2. Click the "Edit" button
3. Modify the document content using the editor
4. Click "Save" to update the document

#### Downloading a Document

1. Find the document you want to download
2. Click the "Download" button
3. Select the desired format (if applicable)
4. The document will be downloaded to your device

## SOC 2 Framework

### SOC 2 Dashboard

1. Navigate to "Compliances" > "Frameworks" > "SOC 2" in the sidebar
2. The dashboard displays:
   - Overall compliance status
   - Progress by category
   - Implementation status of controls
   - Test pass rates

### Category Details

1. Click on a category in the SOC 2 dashboard
2. View detailed information about the category
3. See the list of controls within that category
4. Track implementation progress for the category

## Access Visualization

### Using the Neo4j Visualizer

1. Navigate to "Access" in the sidebar
2. Enter a natural language query in the search bar (e.g., "Show all users with admin role")
3. View the resulting graph visualization
4. Interact with the graph:
   - Click on nodes to see details
   - Drag nodes to rearrange the graph
   - Zoom in/out for better visibility

### Sample Queries

The Neo4j Visualizer includes sample queries to help you get started:
- "Give All User Names"
- "Profile Emma"
- "Give me all Relationships"
- "Give me all Users with QA role"

### Analyzing the Results

1. Click on a node in the graph to view its details
2. Use the filters to focus on specific node types
3. Switch between graph and table views for different perspectives
4. Double-click on a node to expand its relationships

## Integrations

### Setting Up Integrations

1. Navigate to "Integrations" in the sidebar
2. Browse available integration options
3. Click on an integration to configure it

### Microsoft Entra ID Integration

1. Select "Microsoft Entra ID" from the integrations list
2. Click "Configure"
3. Enter the required information:
   - Tenant ID
   - Client ID
   - Client Secret
4. Click "Connect" to establish the integration
5. Verify the connection status

## Using the Compliance Assistant

### Starting a Conversation

1. Locate the Compliance Assistant chatbot in the sidebar
2. Type your question or request in the input field
3. Press Enter or click the send button

### Example Interactions

The Compliance Assistant can help with:
- "What controls do I need for SOC 2 compliance?"
- "Help me create a password policy document"
- "What evidence do I need for control CC5.1?"
- "Explain the requirements for CC7.2"

### Document Creation

1. Ask the Compliance Assistant to help create a document
2. Provide details about the document type and content
3. Review the generated document
4. Edit as needed and save

## User Profile Management

### Viewing Your Profile

1. Click on your user avatar in the top-right corner
2. Select "Profile" from the dropdown menu
3. View your profile information

### Updating Profile Information

1. Navigate to your profile page
2. Click "Edit Profile"
3. Update your information as needed
4. Click "Save" to apply changes

## Troubleshooting

### Common Issues

#### Page Not Loading

If a page fails to load:
1. Check your internet connection
2. Refresh the page
3. Clear your browser cache
4. Try logging out and back in

#### Data Not Displaying

If data is not displaying correctly:
1. Verify you have the necessary permissions
2. Check if the data exists in the system
3. Refresh the page
4. Contact support if the issue persists

#### Authentication Problems

If you encounter authentication issues:
1. Ensure your session hasn't expired
2. Try logging out and back in
3. Clear browser cookies
4. Contact your administrator if the issue continues

## Getting Help

For additional assistance:
- Use the Compliance Assistant for guidance
- Refer to this documentation
- Contact your system administrator
- Email support at support@trustx.cloud
