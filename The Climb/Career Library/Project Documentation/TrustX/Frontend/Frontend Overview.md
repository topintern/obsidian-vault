# TrustX static mock pages

These files recreate key UI sections of the app as static pages so you can browse the old experience without running the React app.

## Start here
- Open `html/index.html` in your browser.

## Included mock sections
- Core pages: Login, Overview, Profile360, Integrations, Profile
- Compliances: Policies, Controls, Documents, SOC 2 Dashboard
- Compliances states: Policy View, Policy Editor, Document Editor
- Integrations modal states:
	- GitHub: Connect, Linked Organizations, Repository Scope
	- Jira: Connect, Linked Instances
	- Entra ID: Connect, Linked Tenants
- App state variants: Auth Loading, Auth Error, User Menu Open, Collapsed Nav, Overview Chat+Doc mode

## Navigation map
- Open `html/index.html` for the complete clickable catalog.
- Most section pages also include direct links to related states/modals.

## Notes
- Fully isolated from production app code (`src/` untouched).
- Visual only: no API calls, auth, or backend interactions.
- SVG visuals are in `svgs/` and referenced by the HTML pages.
