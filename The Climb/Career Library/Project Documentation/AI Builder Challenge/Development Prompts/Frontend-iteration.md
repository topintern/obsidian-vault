# Frontend Iteration Prompt Log

## Prompt 1: Product surface

```text
Design the frontend for a Consumer Signal Intelligence Agent. It should feel like a marketer's insight workspace, not a landing page or generic chat widget. The first screen should let the user ask a business question, set category/geography/timeframe, and generate an insight brief.
```

### Rationale

The app starts with the actual workflow. The assignment asks for a web application, not a marketing splash page.

## Prompt 2: Trust and evidence

```text
Add UI areas that show the answer, tool trace, source links, and caveats. The user should understand what the agent called and where the public signals came from.
```

### Rationale

This is important for an insights product. Trust comes from showing the path, not just the generated summary.

## Prompt 3: Demo examples

```text
Add sample prompts that demonstrate consumer trend intelligence use cases: better-for-you energy drinks, private label groceries, plant-based protein, and convenience-store coffee. Keep the controls simple enough for a five-minute demo.
```

### Rationale

The evaluator should be able to see the intended use case immediately.
