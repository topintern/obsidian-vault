## Progress is yours

Edit `practice_status` to `attempted`, `review`, or `comfortable`, and set `last_practiced` when you actually practise. Imports never mark problems solved. Fields in this board do not auto-stamp dates or submit code to a website.

## A useful session

Read the specification and constraints. State the approach and invariant or DP state. Implement independently, test boundaries, then compare the reference. Record the reason for a mistake, not just the final answer.
