# Backtracking Study Guide

[[Coding Ninjas]] · [[Coding Practice]]

Describe the choice, constraints, and state restoration. Trace one branch before coding and justify each pruning condition.

## Recognition cue

A recursive call should have a precise contract. After exploring a choice, restore the state needed by its siblings.

## First session

Start with [[The Climb/Career Library/Coding Practice/Coding Ninjas/Backtracking/Rat In A Maze|Rat In A Maze]]. Write your own approach and tests before expanding the reference solution.
