# Search and Sort Study Guide

[[Coding Ninjas]] · [[Coding Practice]]

Recognise monotone feasibility, prefix counts, and ordering. Write the search invariant and check both ends of the interval.

## Recognition cue

For an answer-space search, separate the candidate answer from the feasibility check. Explain why feasibility changes in only one direction.

## First session

Start with [[The Climb/Career Library/Coding Practice/Coding Ninjas/Search and Sort/Aggressive Cows|Aggressive Cows]]. Write your own approach and tests before expanding the reference solution.
