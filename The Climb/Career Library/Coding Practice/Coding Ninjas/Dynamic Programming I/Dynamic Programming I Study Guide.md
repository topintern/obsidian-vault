# Dynamic Programming I Study Guide

[[Coding Ninjas]] · [[Coding Practice]]

Define the state in a sentence, identify dependencies, then write base cases and iteration order.

## Recognition cue

Start with a recurrence you can explain. Only compress memory after proving which earlier states are still needed.

## First session

Start with [[The Climb/Career Library/Coding Practice/Coding Ninjas/Dynamic Programming I/Adjacent Bit Counts|Adjacent Bit Counts]]. Write your own approach and tests before expanding the reference solution.
